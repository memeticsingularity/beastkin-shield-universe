# Beastkin Universe 内容分级标准 v1.0

> 本文档定义四维分级矩阵（🔞💀🧠⚡）与九类内容标签（🐾🔞⚔️🏛️🎭🎨🗺️🧩🎯）的评分依据与使用规范。

---

## 1. 四维分级矩阵 / 4-Dimensional Rating Matrix

每个作品README必须标注以下四个维度的级别。级别为 **Lv.0–5** 的离散整数，不得使用小数。

---

### 🔞 性内容 / Sexual Content

| 级别 | 判定标准 | 典型表现 |
|:----:|:---------|:---------|
| **Lv.0** | 无性内容 | 无身体描写、无性暗示、无 romantic 接触 |
| **Lv.1** | 背景提及 | 世界观存在性相关机制但正文未直接描写；或仅有轻微 romantic 氛围 |
| **Lv.2** | 间接/暗示性 | 制服 fetish、身体轮廓描写、性器官名称提及、勃起/射精机制作为背景说明 |
| **Lv.3** | 明确但服务于叙事 | explicit 身体描写（性器官触碰、精液场景）、性弱点攻击，但核心服务于战斗/救赎/体制批判等主题 |
| **Lv.4** | 频繁且 explicit | 大量性器官 mechanical stimulation、射精死亡全过程、体液 detailed 描写、性暴力场景 |
| **Lv.5** | 极端/ pervasive | 性内容构成叙事核心且极为 graphic；大规模性虐、系统性性暴力作为主题 |

**核心判定原则**：
- 描写密度 > 单次场景：整部作品中性内容出现的频率与持续性
-  explicit 程度：从暗示到 graphic 细节的程度差异
- 叙事功能：性内容是服务于主题，还是单纯的情色呈现

---

### 💀 暴力与死亡 / Violence & Death

| 级别 | 判定标准 | 典型表现 |
|:----:|:---------|:---------|
| **Lv.0** | 无暴力 | 无冲突、无伤害描写 |
| **Lv.1** | 轻度冲突 | 擒拿、推搡、威胁，无流血或永久伤害 |
| **Lv.2** | 战斗伤害 | 流血、骨折、战斗击倒，无死亡 |
| **Lv.3** | 死亡出现 | 有角色死亡，但描写克制或数量少（1–3人）；或死亡被弱化/逆转（治愈线） |
| **Lv.4** | 大量死亡 | 频繁处决、屠杀场景、尸体 detailed 描写、战后亵玩尸体；死亡数量较多（4–15人） |
| **Lv.5** | 极端/大规模 | 大规模屠杀（15+人）、尸山/尸体堆叠、系统性处决流程、儿童死亡、虐杀细节 |

**核心判定原则**：
- 死亡数量：单场景/全作品累计死亡人数
- 描写 graphic 程度：从“倒地不起”到“解剖式检查”的差异
- 死亡性质：战斗中的公平击杀 vs 处决/虐杀/系统清洗
- 战后处理：是否有尸体亵玩、解剖、回收等后续暴力

---

### 🧠 心理黑暗度 / Psychological Darkness

| 级别 | 判定标准 | 典型表现 |
|:----:|:---------|:---------|
| **Lv.0** | 无黑暗元素 | 纯日常、纯治愈、无冲突心理 |
| **Lv.1** | 轻度压抑 | 离别、小挫折、轻微不安，可快速化解 |
| **Lv.2** | 中度心理负担 | 角色面临道德困境、生存压力、身份焦虑，但有明确出口 |
| **Lv.3** | 深度创伤 | PTSD、失去亲人、自我否定、复仇执念、系统压迫下的绝望；治愈线中背景提及 |
| **Lv.4** | 系统性碾压 | 存在主义绝望、组织洗脑、身份异化、背叛与利用、自杀/自残倾向；心理伤害难以逆转 |
| **Lv.5** | 极端精神摧毁 | 全面 identity 崩溃、系统性精神控制、克隆伦理困境、无法区分的记忆与现实 |

**核心判定原则**：
- 创伤深度：表层情绪（悲伤）vs 深层 identity 瓦解
- 可逆性：治愈线作品即使背景黑暗，若最终被温暖化解，可降低 1 级
- 普遍性：是单个角色的心理阴影，还是整个世界的集体精神状态
- 叙事功能：心理黑暗是背景设定还是推动情节的核心动力

## 3. 评分实操指南 / Practical Rating Guide

### 3.1 世界观总览 vs 单作品评分差异

| 场景 | 评分策略 | 示例 |
|------|---------|------|
| **世界观根README** | 给出范围（如 Lv.2–4），说明"因作品而异" | 兽盾世界观：🔞 Lv.3–5 / 💀 Lv.3–5 / 🧠 Lv.2–4 |
| **单作品README** | 给出精确级别 | 兽盾主线第一卷：🔞 Lv.4 / 💀 Lv.4 / 🧠 Lv.2 |
| **章节级** | 在章节列表中标注每章级别 | 第01章 R15 / 第02章 R18 |

### 3.2 复合判定法

当一部作品在单一维度上表现不一时，取**最高级别**，并在说明中解释差异：

> 示例：《兽盾主线第三卷》
> - 🔞 Lv.4：战争主线中情色描写相对减少，但死亡机制（射精死亡）贯穿始终，仍有明确性场景
> - 💀 Lv.5：大规模战争与尸山堆叠达最高级别
> - 🧠 Lv.4：组织阴谋、背叛、复制体 identity crisis 构成深度心理黑暗

### 3.3 治愈/温暖作品的降级原则

如果作品整体基调为治愈/温暖，但背景提及原作黑暗元素：

- **当前叙事无直接黑暗**：可在说明中注明"背景提及"，级别降低 1–2 级
- **但不可低于 Lv.1**：只要世界观本身包含成人机制，最低为 Lv.1

示例：
- 《兽盾天堂》主线：🔞 Lv.3（明确身体描写但服务于救赎）→ 不能降为 Lv.1
- 《奇克兽士乐园》：🔞 Lv.1–2（和平日常，仅背景提及芯片机制）
