# 通用故事模板使用指南 4.0（新命名体系适配版）

---

## 简介

本指南详细说明如何使用适配新命名体系的通用故事模板来创建短篇、分章（主线/支线）故事。该模板完全遵循
Beastkin Shield Universe 的标准化命名体系，支持原作、改编、联动等创作性质，并提供完整的角色评述系统。请根据您的创作需求，遵循本指南的步骤与规范进行操作。

---

## 快速开始

1. **选择模板**：根据创作语言，从 `/templates/` 目录中复制对应模板：
    - 中文创作：`universal-story-template-chinese.md`
    - 英文创作：`universal-story-template-english.md`
2. **确定创作性质**：明确作品为原作（`o`）、改编（`a`）还是联动（`c`）。
3. **填写配置**：在模板的“配置区”填写世界观编码、作品性质、作品形式、作品序号、作品标识名等核心信息。
4. **选择导航栏**：根据作品性质和章节位置（如第一章、中间章、最终章），选择合适的导航栏配置。
5. **编写内容**：替换所有 `{{...}}` 占位符，填入您的故事正文、评述等内容，并遵循下文所述的格式规范。

---

## 新命名体系详解

### 作品编码格式

```
[世界观]-[性质]-[形式]-[序号]-[作品名]
```

示例：`bs-o-c-001-flame-wraith`

### 字段说明

| 字段      | 可选值                                                                                  | 含义       |
|---------|--------------------------------------------------------------------------------------|----------|
| **世界观** | `bs` (Beastshield)<br>`bsr` (Beastshield Reforged)<br>`uba` (United Beasts Alliance) | 作品所属的世界观 |
| **性质**  | `o` (original) - 原作<br>`a` (adaptation) - 改编<br>`c` (crossover) - 联动                 | 作品的创作性质  |
| **形式**  | `c` (chaptered-story) - 分章故事<br>`s` (short-story) - 短篇故事                             | 作品的结构形式  |
| **序号**  | 三位数字，如 `001`                                                                         | 同类作品中的编号 |
| **作品名** | 英文kebab-case，如 `flame-wraith`                                                        | 作品的英文标识名 |

### 文件命名规范

- **短篇故事**：`{世界观}-{性质}-{形式}-{序号}-{作品名}.md`
  示例：`bs-o-s-001-farm-inn.md`
- **分章故事**：`{世界观}-{性质}-{形式}-{序号}-{作品名}-ch{章节号}.md`
  示例：`bs-o-c-001-flame-wraith-ch001.md`
- **改编分章故事**（作品目录内）：`ch{章节号}-{章节英文标题简写}.md`
  示例：`ch001-infiltration.md`

---

## 目录结构规范

### 原作作品 (`o`)

```
worlds/{世界观}/original-archives/{语言}/{形式}/{子类型}/
```

- **语言**：`chinese`（中文）或 `english`（英文）
- **形式**：`short-story`（短篇）或 `chaptered-story`（分章）
- **子类型**（仅分章）：`main`（主线）或 `side`（支线）

示例：

```
worlds/bs/original-archives/chinese/chaptered-story/main/bs-o-c-001-flame-wraith-ch001.md
worlds/bs/original-archives/english/short-story/bs-o-s-001-farm-inn.md
```

### 改编作品 (`a`)

```
worlds/{世界观}/adaptation-works/{形式}/{完整作品编码}/
```

- **形式**：`short-story`（短篇）或 `chaptered-story`（分章）
- **完整作品编码**：如 `bs-a-c-001-a-new-gamer`

示例：

```
worlds/bs/adaptation-works/chaptered-story/bs-a-c-001-a-new-gamer/ch001-new-chapter.md
worlds/bs/adaptation-works/short-story/bs-a-s-001-first-blood/new-short-story.md
```

## 配置详情

### 核心配置项

1. **世界观编码**：`bs`、`bsr`、`uba`
2. **作品性质**：`o`（原作）、`a`（改编）、`c`（联动）
3. **作品形式**：`c`（分章故事）、`s`（短篇故事）
4. **作品序号**：三位数字，如 `001`
5. **作品标识名**：英文kebab-case，如 `flame-wraith`
6. **作品标题**：中英文完整标题

### 分章故事额外配置

1. **分章故事子类型**：`main`（主线）、`side`（支线）
2. **章节号**：三位数字，如 `001`
3. **章节标题**：中英文章节标题
4. **总章节数**（可选）：如 `15`

### 路径配置

- **原作**：需选择语言 (`chinese`/`english`)
- **改编**：无需选择语言，直接进入作品目录

## 导航栏配置选择

根据作品性质和章节位置，从模板中提供的8种配置里选择其一：

1. **短篇原作导航**
2. **短篇改编导航**
3. **分章原作-第一章**
4. **分章原作-中间章节**
5. **分章原作-最后一章**
6. **分章改编-第一章**
7. **分章改编-中间章节**
8. **分章改编-最后一章**

---

## 正文格式规范

1. **段落间距**：行与行之间、段落与段落之间均保持一个空行。
2. **设定加粗**：以下元素需使用 `**加粗**`：
    - 角色姓名（如 **炎**、**熊守卫**）
    - 专有名词、地点、装备道具
    - 组织势力、剧情/世界观设定
3. **对话格式**：角色对话本身不加粗，保持原有引号格式。例如："你是谁？"**熊守卫**问道。
4. **原文空行处理**：如果原文中有空行，请确保转换为Markdown后仍保持段落间的空行效果。

## 故事评述与感慨写作指南

此部分位于正文之后，用于以感性、口语化的语言评述本章角色和事件。

> *注意：本世界观中所有角色均为具有双重性征的雄兽人。*

### 写作结构

1. **他们最后的故事**：评述本章中所有死去的角色。按出场顺序，用【】标注其身份与制服颜色，描述其特征、死因并表达感慨。
2. **还活着的人们**：评述本章中所有幸存角色，分析其处境、选择与可能的命运。
3. **故事感慨**：以第一人称分享对本章故事的整体感受、对世界观或角色命运的思考。

### 格式要求

- 评述内容行与行之间保持一个空行，段落之间也保持一个空行。
- 如果原文评述中有多个自然段落，请使用分割线 `---` 进行分隔。
- 语气像与朋友聊天，自然提及角色的双重生理特征。
- 为每个角色（无论主次）写下评述，无字数限制。

## 默认值

若未提供任何配置，模板将使用以下默认值：

- 世界观编码：`bs`
- 作品性质：`o`
- 作品形式：`s`
- 作品序号：`001`
- 作品标识名：`untitled-story`
- 作品中文标题：未命名故事
- 作品英文标题：Untitled Story
- 分章故事子类型：`main`
- 章节号：`001`
- 语言：`chinese`
- 导航栏配置：短篇原作导航

## 故障排除

- **导航链接失效**：检查导航栏中的相对路径是否正确指向目标文件。注意原作和改编的路径结构不同。
- **图片不显示**：确认图片路径和文件名是否正确，图片文件是否存在于指定目录。
- **格式未生效**：确保加粗使用 `**文本**`，并遵循段落空行规范。
- **评述不知如何下笔**：参考模板中的详细示例，从描述角色外貌、制服、死亡/生存细节开始，融入个人真实感受。
