# 中文

## Part I: 关于原作

《兽盾公司》是一部设定独特的兽人题材叙事作品，讲述了一个名为"兽盾"
的庞大公司掌控世界的黑暗故事。在这个世界里，兽盾公司员工都是兽人，他们经营着从军事安保到娱乐产业的方方面面，形成了一个权力滔天、无法无天的庞大组织。

故事以一名普通玩家意外进入这个世界的视角展开，发现所有攻击都会转化为性欲值，当欲望达到极限时便会"
喷射死亡"。玩家需要利用这一独特机制，在各种情境下与兽盾员工互动、战斗或建立关系。

## Part II: 分级与内容提示

**成人内容警告 / 18+ Only**

本作品包含以下内容：

- 强烈的性暗示和明确的性内容描写
- 暴力、战斗和死亡场景
- 支配、屈服等成人主题
- 可能令人不适的黑暗叙事元素

**推荐读者年龄：18岁以上**

所有内容均为虚构创作，不鼓励在现实中进行类似行为。如果您对上述内容感到不适，请谨慎阅读。

## Part III: 关于新世界观

**兽盾宇宙 (BeastShield Universe)** 是一个基于"兽盾公司"概念扩展的跨媒介叙事宇宙。

在这个重构的世界观中：

- 保留"兽盾公司"作为核心设定和主要势力
- 对原有世界观进行系统化重构和扩展
- 建立完整的角色档案系统和故事模组体系
- 支持多种叙事风格和故事线并行发展
- 引入"双周目叙事系统" - 每个角色拥有两种命运选择

**核心理念：同样的角色，同样的舞台，不同的故事。**

我们旨在创建一个开放的创作平台，让创作者可以使用共享的角色和地点设定，创作出风格迥异的故事模组。

## Part V: 特色系统

#### 双周目叙事系统

每个角色都有两条命运线：

- **第一周目 (Alpha)**: 遵循原作黑暗基调，探索角色的悲剧命运
- **第二周目 (Omega)**: 改写命运，创造救赎与希望的故事

#### 模组化故事体系

- **核心设定库**: 共享的角色档案和地点设计
- **独立故事模组**: 不同风格、不同主题的完整故事线
- **创作者工具集**: 标准化模板和写作指南

#### 跨媒介兼容设计

支持文字小说、视觉小说、TRPG模组、音频剧等多种表现形式。

# English Version

## Part I: About the Original Work

"Beast Shield Corporation" is a unique furry-themed narrative work that tells a dark story about a
massive corporation named "Beast Shield" controlling the world. In this world, Beast Shield
employees are all beastkin, operating everything from military security to entertainment industries,
forming a powerful, lawless organization.

The story unfolds from the perspective of an ordinary player who accidentally enters this world,
discovering that all attacks are converted into sexual desire values, and when desire reaches its
limit, characters "ejaculate to death." Players must utilize this unique mechanism to interact,
fight, or build relationships with Beast Shield employees in various situations.

## Part III: About the New Universe

**BeastShield Universe** is a cross-media narrative universe expanded from the "Beast Shield
Corporation" concept.

In this reconstructed worldview:

- Retains "Beast Shield Corporation" as the core setting and main faction
- Systematically restructures and expands the original worldview
- Establishes a complete character dossier system and story module framework
- Supports multiple narrative styles and parallel storylines
- Introduces the "Dual Playthrough Narrative System" - each character has two fate choices

**Core Concept: Same Characters, Same Stages, Different Stories.**

We aim to create an open creative platform where creators can use shared character and location
settings to produce vastly different story modules.

## Part V: Featured Systems

#### Dual Playthrough Narrative System

Each character has two fate lines:

- **First Playthrough (Alpha)**: Follows the original dark tone, exploring tragic character fates
- **Second Playthrough (Omega)**: Rewrites fate, creating stories of redemption and hope

#### Modular Story System

- **Core Setting Library**: Shared character dossiers and location designs
- **Independent Story Modules**: Complete storylines with different styles and themes
- **Creator Toolkit**: Standardized templates and writing guides

#### Cross-Media Compatible Design

Supports various formats including text novels, visual novels, TRPG modules, audio dramas, and more.
