# AI 讨论记录目录

本目录包含本原创支线章节故事创作过程中的 AI 辅助讨论记录、需求分析、方案设计、实现过程及优化记录等文档。

---

## 目录结构

文件按类别分放在子文件夹中，命名格式为 `YYYY-MM-DD-描述.md`，便于按时间排序。

```
ai-discussion/
├── README.md                           # 本文件
├── opt/                                # 优化方案
├── check/                              # 一致性检查报告
├── plan/                               # 重构/扩展计划
├── archive/                            # 存档记录
├── insights/                           # 经验总结/洞察
├── discussion/                         # 讨论记录
├── qa-session/                         # Q&A 对话记录
├── setting/                            # 设定相关
├── tech/                               # 技术实现
└── process/                            # 创作流程
```

---

## 使用建议

1. **按时间查找**：文件名前缀为 `YYYY-MM-DD`，可直接按时间排序
2. **按类别查找**：进入对应子文件夹浏览
3. **查找优化方法**：查看 `opt/` 文件夹
4. **检查设定一致性**：参考 `check/` 文件夹
5. **了解重构计划**：阅读 `plan/` 文件夹
6. **学习写作技巧**：查看 `insights/` 文件夹
7. **回顾讨论历史**：查看 `qa-session/` 或 `discussion/` 文件夹
8. **核对世界观设定**：参考 `setting/` 文件夹
9. **了解技术实现**：查看 `tech/` 文件夹
10. **回顾创作流程**：查看 `process/` 文件夹

## 原创作品说明

本作品为原创支线故事，AI 讨论记录主要关注：

- **支线与主线的关联设计**
- **支线独有的世界观补充**
- **独立角色塑造**
- **与主线故事的呼应与补充**

跨作品的世界观讨论请参见所属 worlds 根目录的 `ai-discussion/`。
