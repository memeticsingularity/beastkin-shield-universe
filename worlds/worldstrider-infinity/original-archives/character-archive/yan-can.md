## 二、原作设定

### 2.1 原作中的角色定位

岩参在原作中并未直接出场（正文），但通过岩岁的回忆和设定文件，他是一个**关键的精神象征**和**悲剧源头**：

- **兽盾精神的真正传承者**：在"牙董事长"上任导致兽盾变质前退休，是"真正的兽盾兵"
- **岩岁道德底色的塑造者**：教导儿子"力量与责任并存，拥有力量就意味着承担更多的责任"
- **家庭悲剧的核心**：他的遭遇（被打致残→最终被杀）是岩岁痛苦的根源，也是岩岁入职兽盾的动机

### 2.2 原作背景故事（yan-sui-2-1 / yan-sui-2-2）

**兽盾黄金时代：**
- 岩参是**最初的兽盾员工**，那时的兽盾"没有背离自己的初衷，确实是兽民们结实的后盾"
- 不同于后来"从兽盾中退休等于死亡"的情况，那会的兽盾名副其实
- 岩参身边有不少前兽盾的同事一同生活，形成了积极向上的氛围

**兽盾变质与离职：**
- 兽盾在迎来"牙董事长"后发生180度大转变
- **幸运的是**，岩参刚好在牙董上任之前辞退了兽盾的工作，因此逃过一劫
- 岩岁的童年对兽盾的第一印象并非污浊不堪，正是源于父亲这段经历

**抗议致残：**
- 兽盾质变后，暴行不断扩大笼罩白之都
- 岩参身为前兽盾员工，看到兽盾如此堕落"心中很不是滋味"
- 选择联合身边的前兽盾同事一起去"讨个说法"
- 结果：白之都环境已彻底变成"谈兽盾色变"，抗议遭到兽盾兵暴力殴打
- **不幸变为残疾，卧病在床**
- 左腿残疾，膝盖关节变形，无法像正常人一样行走

**家庭破碎（原作版本）：**
- 岩岁为养活父亲，瞒着他偷偷入职兽盾
- 岩参康复无望（或伤势好转后），**为了不拖累岩岁而选择自尽**
- 留下遗言："不要怨恨具体的某一个或者一群人，要恨某一种行为或者是概念，憎恶前者没有任何意义，因为前者随时会从兽人的行为中再度诞生，只有粉碎其源头才是真正的斩断循环。"

**原作世界线结局：**
- 岩参已死亡（自杀/被杀）
- 岩岁在兽盾中迷茫地生存
- 最终在《白兔暗影》第一章被仇染处决
- **父子二人在原作中都是悲剧牺牲品**

### 2.3 父子回忆故事（yan-can-yan-sui-flashback）

**童年回忆（岩岁约4-5岁）：**

*共浴时光：*
- 岩参下班后穿着制服回家，身上带有汗酸味
- 岩岁调皮地要求和父亲一起洗澡
- 岩参作为"肉垫"托举着岩岁，任儿子对自己"又捏又摸"
- 岩岁意外挑逗父亲乳头，被岩参教育"这种地方不能乱碰"
- 岩参因厨房危险而态度冷淡，岩岁误解为"爸爸不要我了"

*交流券的诞生：*
- 岩岁产生偏激想法："只要我把自己换掉，爸爸就会更幸福"
- 岩岁独自出走，岩参焦急寻找后和解
- **岩参手写一沓"交流券"**，承诺"无论如何都一定会和你好好说话"
- 这个设定成为父子情感的核心象征

**成年后的孤独（岩参死后，岩岁的回忆）：**

*新年扫墓：*
- 岩岁独自带着酒去父亲墓前
- 醉酒后的哭诉："岁岁没能成为一个顶天立地的男子汉"
- **烧"交流券"**：将珍贵的交流券点燃，呼唤父亲来梦中相见
- 奇迹发生：醒来时躺在家里的床上，桌上有热饺子和字条

*字条内容：*
> "岁岁，爸爸爱你，新年快乐。"

**故事性质**：留白的温情超自然结局——是幻觉？是父亲的灵魂？还是岩岁的梦境？作者没有明确说明，但情感冲击力极强。

## 三、外貌特征（基于新版改编故事 ch-1至ch-5）

### 3.1 整体形象

岩参是一位**年迈苍老的老虎兽人**，曾经魁梧挺拔的身躯被岁月和苦难消磨，但依然能看出当年的威严。

**体型特征：**
- **曾经魁梧挺拔**，现在佝偻消瘦
- **身形依然能看出年轻时的宽阔骨架**，但肌肉已经萎缩
- **整体呈现出年迈者的脆弱与尊严并存**

### 3.2 毛发与肤色

| 部位 | 特征 |
|------|------|
| **皮毛主色** | 橙黄色（已黯淡），夹杂大量灰白 |
| **虎纹** | 曾经清晰锐利的黑色虎纹，现已模糊稀疏 |
| **脸颊/脖颈** | 毛发几乎完全变白，如覆霜雪 |
| **胸部/腹部** | 皮毛稀疏，能看到皮肤下的肋骨 |
| **受伤部位** | 左腿膝盖处皮肤青紫，呈现长期炎症后的暗红色 |

### 3.3 面部特征

- **眼睛**：琥珀色，依然锐利但蒙着疲惫的阴霾
- **眉毛**：灰白，睡觉时舒展，专注时皱起
- **皱纹**：
  - 额头横纹深刻如刀刻
  - 眼角鱼尾纹延伸进灰白毛发
  - 法令纹深深刻进皮肤
- **鼻梁**：高挺，但鼻翼两侧法令纹明显
- **嘴唇**：干燥，嘴角下垂，带着常年隐忍的苦涩
- **胡须**：灰白相间，临死前沾着血点
- **牙齿**：有些发黄

### 3.4 身体细节（基于ch-3拯救场景）

**躯干：**
- **胸膛**：曾经饱满，如今干瘪，肋骨在皮毛下清晰可见
- **胸肌**：只剩薄薄一层，胸骨嶙峋
- **腹部**：肌肉松弛，呈现老年人特有的苍白和斑点

**手臂：**
- **整体**：枯瘦，肌肉松弛但骨骼结实
- **手掌**：粗糙，深色的肉垫，指关节粗大变形
- **手指**：修长但骨节分明，指甲厚实发黄、边缘不规则
- **手背**：皮毛稀疏，能看到青紫色血管

**腿部：**
- **左腿（残疾）**：
  - 膝盖关节彻底变形，骨骼错位
  - 软组织肿胀僵硬
  - 皮肤呈现不健康的紫红色
  - 走路时一瘸一拐，发出摩擦声
- **右腿**：相对完好，但也因年迈而无力

**尾巴：**
- 灰白相间，尾毛稀疏
- 自然下垂，尾尖偶尔轻轻摆动

### 3.5 伤痕

- **腹部**：被匕首刺入的伤口（被奇点救下后愈合）
- **全身**：年轻时作为兽盾士兵的疤痕，后来被殴打致残的印记
- **左腿**：被兽盾殴打致残的旧伤，永久性残疾

## 四、性格特征

### 4.1 原作设定性格

| 特征 | 描述 |
|------|------|
| **正直负责** | 真正的兽盾精神传承者 |
| **深沉父爱** | 独自抚养儿子，教导正确价值观 |
| **理性光辉** | 遗言中体现超越仇恨的智慧 |
| **牺牲精神** | 为了不拖累儿子选择自尽 |

### 4.2 新版故事展现的性格

1. **沉默寡言但观察入微**
   - 注意到油热了、奇点可能炒糊菜
   - 话不多，但总能注意到关键细节

2. **内敛深沉的父爱**
   - 不擅表达，行动上处处为儿子着想
   - 将肉丝夹给奇点表达认可

3. **坚韧与尊严**
   - 濒死时仍用意志力抑制屈辱反应
   - 维护身为父亲的尊严

4. **对奇点的复杂情感**
   - 最初的警惕与困惑
   - 逐渐的信任与感激
   - 最终的认可与托付（夹菜、拥抱、按肩）

5. **适应新环境的能力**
   - 虽然年迈，但愿意接受这个"超越认知"的新世界

## 五、关键场景形象（新版故事）

### 5.1 濒死时刻（ch-3）

**环境：** 白之都西区后巷，肮脏的雪地

**状态：**
- 灰白毛发被血和污泥粘成一绺一绺
- 腹部插着匕首，血液浸透皮毛
- 左腿以扭曲角度瘫在地上
- 仰面躺着，仰望夜空

**神态：**
- 琥珀色眼睛半睁，瞳孔涣散
- 灰白眉毛舒展，仿佛接受命运
- 嘴角有血迹，胡须沾血
- 但依然保持尊严，没有恐惧

### 5.2 康复初期（ch-3/ch-4）

**在万象庭院：**
- 灰白毛发逐渐恢复少许光泽
- 气色好转，皱纹舒展
- 穿着深灰色家居服
- 左腿戴着奇点制作的特殊护膝

**动作特征：**
- 走路缓慢，一瘸一拐
- 坐下时左腿需要搁在小凳上
- 剥蒜、打牌时手指灵活

### 5.3 父子重逢（ch-3/ch-4）

**情感爆发：**
- 泪水滑落苍老的脸颊
- 枯瘦的手臂紧紧拥抱儿子
- 灰白胡须蹭着儿子的脸颊
- 声音哽咽："爸爸在这里"

### 5.4 认可奇点（ch-4/ch-5）

**无声的认可：**
- 将肉丝夹入奇点碗中
- 拥抱奇点（生疏但有力）
- 双手同时按在奇点和岩岁肩上
- 烟火下的老泪纵横

## 六、原作与改编对比

| 维度 | 原作 | 改编（新版五章） |
|------|------|------------------|
| **结局** | 被平民围殴致死/自杀，尸体未详 | 被奇点穿越时空救下，获得新生 |
| **直接出场** | 仅在回忆和设定中提及 | 第三章起作为主要配角正面登场 |
| **形象完整性** | 侧面描写，精神象征 | 从苍老憔悴到逐渐康复的全过程 |
| **与儿子关系** | 生离死别，阴阳两隔 | 跨越时空重逢，继续相伴 |
| **外貌描写** | 几乎没有 | 详细的老年兽人外貌、残疾细节 |
| **身体描写** | 无 | 枯瘦身躯、灰白毛发、残疾左腿 |
