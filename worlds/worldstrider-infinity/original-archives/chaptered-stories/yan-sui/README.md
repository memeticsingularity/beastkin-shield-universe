## 📝 创作原则（V2版本）

根据最新要求，V2版本将遵循：

1. **叙事结构**：取消分幕，连续叙事
2. **节奏**：慢节奏，不跳环节
3. **篇幅**：单章至少1万字以上
4. **描写重点**：
    - 动作和细节（大量、细致、直白、朴素）
    - 感官体验（视觉、触觉、嗅觉、味觉）
    - 兽人肉体特征（脂包肌、各肌肉群）
    - 体温、毛发、服饰、肌肉的交互
5. **推进方式**：人物互动推动，非情节推动
6. **五要素齐全**：心理、神态、动作、环境、语言
