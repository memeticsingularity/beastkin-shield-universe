# 《万界巡行：无限》(Worldstrider: Infinity)

> **世界观定位**：以《万界巡行：无限》VR 沙盒平台为载体的原创及改编创作集合。
>
> **与 beastshield 的关系**： beastshield 是接入本平台的**世界观之一**（通过"意识原型"机制）。当前活跃创作聚焦于 beastshield 角色的改编，但本平台**不限于** beastshield。原作设定、作者对话、角色档案统一存放于 [`worlds/beastshield/`](../beastshield/)。

---

## 简介

《万界巡行：无限》是一个提供无限可能性的沉浸式模拟平台。玩家接入近乎无限的内容世界，与虚拟个体建立深度联系，并将其锚定至私人空间"万象庭院"。

**在此世界观下**：
- 多个世界观（包括 beastshield）的角色以"意识原型"形式可被接入
- 原作悲剧线可被改写、延伸或保留
- 当前用户的创作聚焦于**岩岁/岩参父子救赎故事**（基于 beastshield 角色），但平台支持接入更多世界观与原创角色

## 核心创作项目

### 岩岁/岩参父子救赎故事 (`yan-sui/`)

**主线（trunk/）**：奇点穿越时空介入，救下濒死的岩参，父子在万象庭院重逢的救赎线。

**分支（branches/yan-can-canon-death/）**：基于原作岩参死亡线的改编，保留悲剧内核，探索不同叙事版本。

- **v1（老赵版）**：同事为"老赵"（退休老兵，平辈战友）
- **v2（壹安版）**：同事为"壹安"（伯恩山犬，46岁，岩参后辈，蓝制服）
