```markdown
[世界观/创作背景]
作品《帝国万岁》源于作者个人XP（性癖）的延伸与补全，初始灵感始于五年级，后受《大狗》小说影响，于2023年正式创作，标题由群友提议确定。【eks-o-author】

[世界观/核心基调] 世界观基调为黑暗、压抑与绝望，旨在满足作者对支配、惩罚及死亡美学的表达，写作过程也是作者宣泄与整理负面情绪的途径。【eks-o-author】

[角色/皇帝]
皇帝为被高等文明放逐至此星球的个体，原本身份为科研人员，解除封印后混入本地国家逐步掌权，引导科技发展并建立帝国，拥有克隆技术，是当前世界观战力的顶点，无人能抗衡。【eks-o-author】

[角色/虎猛] 虎猛是皇帝的心腹，担任白袜指挥官，是作者羡慕和部分代入的角色，希望拥有解除下属撸杀机制并培养忠心部属的能力。【eks-o-author】

[角色/基尅兵] 基尅兵是作者主要的代入对象，尤其是被惩罚和处决的黑袜兵，承载了作者对受罚、死亡及权力支配下无力感的投射。【eks-o-author】

[科技/植入芯片]
植入芯片存在极低概率的“情绪过载报废”机制，理论上可作为基尅兵获得自由的途径，但作者设定其触发几率极低。芯片会抑制自我意识生成（上限15%），预设程序可在战争状态下关闭部分功能（如瞒报），并非100%实时远程监控所有思维。【eks-o-author】

[科技/克隆技术] 皇帝掌握克隆技术，用于批量制造研究人员及核心手下。【eks-o-author】

[规则/服役与轮换]
基尅兵标准服役期为十年，服役期满可退伍，但退伍后五年内芯片会激活死亡程序。基地与外围警戒塔/哨所实行轮换制，通常以两个黑袜兵小队为单位，每半个月轮换一次。【eks-o-author】

[规则/生理与死亡机制] 基尅兵的生理弱点为被抓握裆部会导致全身无力。“射精即死”与“脱袜即死”是植入芯片的底层代码，无法更改，构成帝国核心控制手段。【eks-o-author】

[装备/标准着装] 基尅兵标准作战服为黑色蛙服套装（非连体），内穿黑色平角内裤。面部有编号标识。【eks-o-author】

[装备/储物柜] 基尅兵在浴室更衣室配有个人储物柜，用于洗澡时临时存放装备。【eks-o-author】

[行为/睡姿] 基尅兵早期采用躺姿睡眠，后因基地遭袭，为防范睡梦中被“掏裆撸杀”，统一改为趴姿睡眠。【eks-o-author】

[社会/晋升与希望] 帝国存在晋升机制（如黑袜、绿袜、蓝袜、白袜等级），此为高层有意给予基尅兵的渺茫希望，用以维持控制与激励。【eks-o-author】

[社会/秘密部队] 皇帝掌握一支秘密部队，其成员外表与普通兽人无异，混迹于市井，但他们的“撸杀”机制由皇帝本人直接控制。【eks-o-author】

[资源/精液回收] 被处决基尅兵的精液是帝国的重要战略物资，用于培养新的基尅兵。【eks-o-author】

[拓展/星际背景] 放逐皇帝的原有文明已毁灭于内战。皇帝在抵达的星球上发现了“钥匙”。世界观具备向其他星球拓展的潜力，但核心叙事仍围绕内部惩罚与支配展开。【eks-o-author】

[创作/作者心态]
作者创作时主要代入惩罚者（皇帝/军官）与受罚者（基尅兵）双重身份，通过构建绝对绝望的体系获得支配感与宣泄感，写作后个人欲望与负面情绪显著降低。【eks-o-author】

[设施/培养系统] 基尅兵的标准培养周期为20天，培养舱持续运作，每天都有成熟的基尅兵待命，可随时取用。基尅兵诞生时即具备20岁成年兽人的身体。【eks-o-author】

[编制/作战单位] 基尅兵基础作战单位为“战队”，每队10人；3个战队组成一个“中队”（30人）；3个中队组成一个“大队”（90人）。【eks-o-author】

[设施/警戒塔] 警戒塔标准常驻兵力为10名基尅兵，另有10名基尅兵在培养舱中待命，随时可补充。【eks-o-author】

[角色/基尅兵/寿命] 基尅兵的平均寿命约为20年（从20岁诞生至40岁死亡），但实际因纪律处决、战斗损耗等原因，平均生存时间远低于理论寿命。【eks-o-author】

[设施/基地]
一个标准主基地的常驻活动兵力约为1000人，此外还有约2000名预备部队在冷冻舱中休眠，可随时唤醒。基地内设有宿舍楼，宿舍为大通铺形式，每间宿舍容纳10人，厕所为公共设施。【eks-o-author】

[群体/基尅兵/等级规模]
在一个标准主基地内，各等级基尅兵的大致数量比例为：黑袜兵600多名，绿袜兵210名，蓝袜兵90名，白袜兵1名。总兵力约1000人（不含冷冻预备队）。【eks-o-author】

[角色/基尅兵/冷冻预备队] 冷冻舱内休眠的预备队由帝国崛起扩张阶段幸存下来的老兵组成，他们拥有战斗经验，其芯片内预设了特殊的“老兵机制”。【eks-o-author】

[科技/特殊机制] 冷冻老兵阵亡后，其尸体将自爆，产生一种覆盖半径300米的特殊毒辐射。该辐射对基尅兵无效，但对普通兽人是致命的。这是老兵芯片内预设的特殊程序。【eks-o-author】

[社会/资源分配]
新培养的基尅兵（新兵）主要用于日常维稳，并作为白袜、蓝袜等军官的娱乐消耗品。冷冻老兵则作为战略预备队，在新兵消耗殆尽或面临重大威胁时投入使用。【eks-o-author】

[角色/灰袜兵] 后期帝国会生产专职后勤的“灰袜兵”，他们将逐步取代部分黑袜兵的后勤职能。【eks-o-author】

[社会/生产偏好] 每批基尅兵的种族比例通常根据主管军官的个人喜好决定，但一般而言各兽人种族的比例较为平均。【eks-o-author】
```
