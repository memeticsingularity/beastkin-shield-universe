# **《帝国万岁》温暖玩家篇章·最终创作要求大全**

## **一、核心原则**

**救赎的本质是：**
让一个被系统彻底剥夺人性的工具，在绝境中被温柔地告知“你的感受是合法的，你的存在是值得的”，然后**由他自己选择
**抓住那只伸来的手。

## **二、非做不可的清单**

### **1. 情感与心理曲线（必须完整呈现）**

- **绝望等待期**：描写“等死”的具体状态——身体感受、时间流逝感、对包庇者的复杂情绪。
- **目睹暴力共情**：看到包庇者因自己受罚时，必须有负罪感与恐惧的交织。
- **初次接触的奴性反应**：开口必须是“大人…小的不配…”，这是芯片规训的肌肉记忆。
- **情感觉醒时刻**：意识到芯片失效（不再惩罚情感表达）时的震惊与崩溃。
- **自愿的转折点**：从“小的不配”到崩溃说出“我愿意”——**必须挣扎，必须真实**。
- **新生茫然期**：抵达家园后的不真实感、适应过程。

### **2. 感官描写矩阵（必须全部涉及）**

**视觉**：绷带缝隙的狭窄视野、伤口细节、光线变化、奇点的面部表情。
**触觉**：疼痛（灼痛/钝痛/刺痛）、拥抱的温度与力度、布料质感（粗糙制服/柔软便服）、木徽章的温润。
**嗅觉**：血与脓的腥味、汗与军袜的酸涩、烧焦皮肉味、家园的花草与食物香。
**听觉**：压抑的呼吸、电击的爆响、雪豹的脚步声、狼嚎的凄厉、家园的笑语。
**味觉**：营养膏的人工甜味、胶囊的微甜、水的清甜、粥的咸香。

### **3. 奇点的行为准则**

- **动作**：先治伤，再说话。动作轻柔如对待易碎品。
- **对话**：问“疼吗？”“想死吗？”“你是什么？”，**不问“编号”“任务”**。
- **仪式固定流程**：
    1. 拥抱（根据角色调整力度/时长）
    2. 亲吻额头（在编号烙印或伤口附近）
    3. 赠木徽章（只说“这是你的”）
    4. 问：“愿意成为我的家人吗？”
- **关键台词**：
    - “小笨蛋…说什么呢。”（回应奴性自称）
    - “家人之间没有‘大人’，也没有‘小的’。”
    - “因为你是你，所以你值得。”
    - “因为我心软。”（被问动机时的唯一回答）

### **4. 基尅兵的独特性塑造**

每个角色必须有：

- **一个身体标记**：伤疤、缺耳、异色瞳、特殊肉垫颜色
- **一件秘密珍藏**：不能总是“金属片”，可以是任何无实用价值的小物件
- **一段未记录的记忆**：芯片未捕捉的瞬间（如听到半句歌、见过一次日出）
- **与室友的特殊关系**：沉默的保护、被欺负的共情、无言的默契
- **面对死亡的态度**：麻木、愤怒、恐惧、不甘、平静——**必须不同**

## **三、绝对禁止的事项**

1. ❌ **解释机制**：不提逝影原理、不说药丸成分、不分析时停科技。
2. ❌ **全知视角**：奇点不知道角色过去（除非角色自己说），不读心。
3. ❌ **强买强卖**：必须问“愿意吗”，必须等到回答。
4. ❌ **雷同反应**：不是所有角色都崩溃大哭，愤怒者可能咬牙沉默，麻木者可能茫然落泪。
5. ❌ **跳过情感积累**：不能直接从“将死”跳到“被救”，必须展示中间的挣扎。
6. ❌ **家园流水账**：治愈后要有具体场景（如喝第一口粥时的手抖），而不是“从此幸福”。

## **四、叙事结构（必须按此顺序）**

```
1. 绝望前奏（重伤等待期，含对包庇者的复杂情绪）
2. 暴力降临（处刑者出场、惩罚包庇者、固定重伤员）
3. 静止时刻（世界停，奇点出现）
4. 治愈优先（先治伤，不废话）
5. 对话破冰（问“疼吗”“想死吗”“你是什么”）
6. 情感觉醒（角色意识到芯片失效，情感爆发）
7. 家庭仪式（拥抱→亲吻→赠徽章→问“愿意吗”）
8. 自愿答复（从奴性自称到崩溃的“我愿意”）
9. 告别观看（看影子替死，最后一眼看原世界）
10. 新生开端（家园第一刻：醒来、确认治愈、第一餐、起名）
```

## **五、细节检查清单（每个场景必须包含）**

### **等待期**

- [ ] 身体疼痛的具体描述（哪疼、怎么疼）
- [ ] 时间流逝的感官体现（光线变化、声音循环）
- [ ] 对包庇者的情绪（愧疚？恐惧？感激？）
- [ ] 一个回忆碎片（与编号无关的瞬间）

### **处决前**

- [ ] 处刑者的动作细节（尾巴摆动、靴子踩地）
- [ ] 惩罚包庇者的感官描写（声音、气味、视觉）
- [ ] 自身被固定时的身体感受（束带勒痕、肌肉紧绷）

### **静止时刻**

- [ ] 世界停止的异常感（声音消失、光线凝固）
- [ ] 奇点出场的不突兀（自然如走入房间）
- [ ] 治伤过程（药膏触感、愈合时的体感变化）

### **对话时刻**

- [ ] 第一反应必是奴性自称（“大人…小的…”）
- [ ] 奇点的第一次触碰（先碰未伤处）
- [ ] 角色说出秘密时的身体语言（抖、蜷缩、捂脸）
- [ ] 情感爆发时的生理表现（泪、涕、颤、咳）

### **仪式时刻**

- [ ] 拥抱的双方体温差描写
- [ ] 亲吻额头的具体位置（伤疤旁、烙印上）
- [ ] 赠徽章时木头的质感描述
- [ ] 问“愿意吗”时的眼神交流

### **答复时刻**

- [ ] 答复前的挣扎（咬唇、闭眼、深呼吸）
- [ ] 答复时的声音状态（破音、哽咽、气声）
- [ ] 答复后的身体释放（瘫软、抓住奇点、埋首）

### **新生时刻**

- [ ] 醒来第一感知（软床、暖光、香气）
- [ ] 确认治愈的动作（摸伤处、眨眼、转头）
- [ ] 第一餐的味觉冲击（描述味道与情感反应）
- [ ] 起名时的思考过程（为何是这个名字）

## **六、字数与节奏分配建议**

- **等待与暴力**：20%（建立绝望感）
- **静止与治愈**：15%（奇点出场要舒缓）
- **对话与觉醒**：30%（**核心，必须最慢最细**）
- **仪式与答复**：20%（情感高潮，动作>语言）
- **告别与新生**：15%（留白，给回味空间）
