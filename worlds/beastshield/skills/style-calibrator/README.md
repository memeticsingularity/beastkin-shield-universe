# Style Calibrator — Tone & Rhythm Guide

> Current version: [v0.2](v0.2-tone-and-rhythm-guide.md)
> Changelog: [changelog.md](changelog.md)

---

This skill addresses the gap between "writing that checks all the boxes" and "writing that feels like the original works." It focuses on **how** to write, not **what** to write — complementing the existing `writing-style-guide-v2.md` which covers narrative style selection and fetish elements.

## Scope

- **Not** a replacement for the setting guide (`world-setting.md`)
- **Not** a replacement for the existing style guides (`writing-style-guide-v2.md`)
- **Is** a layer on top of both: a calibration tool for naturalness
