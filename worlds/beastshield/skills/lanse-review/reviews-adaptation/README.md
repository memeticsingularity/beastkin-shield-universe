## 审阅说明

### 与原作审阅的区别

改编作品审阅在 v1.2 框架基础上，额外关注：

1. **风格还原度权重更高** — 改编作的首要目标是"像 lanse 写的"，其次才是故事本身的质量
2. **叙事模式判断** — 区分第一人称VR / 第三人称冷感，判断是否与选定的叙事模式一致
3. **原创内容评价** — 改编作加入的原创设定/角色是否符合兽盾宇宙的内在逻辑
4. **AI 腔识别** — 改编作多为 AI 辅助创作，需特别注意"AI 腔"问题

### 评级标准

| 等级 | 含义 |
|------|------|
| 🔥 这很可以 | 读起来像 lanse 原作，甚至某些地方更好 |
| 👍 还不错 | 风格基本对了，有几个细节需要调整 |
| 🤔 差口气 | 骨架对了但缺灵魂 |
| 👎 不太行 | 风格偏了、xp不对味、太机械化 |
| 💀 谁教你这么写的 | 从根上就理解错了 |
