## 审阅框架版本差异

v1.1 相较于 v1.0 的新增/修订要点（本次审阅重点关注的升级内容）：

1. **第三人称叙事模式独立判断** — v1.1 新增了模式B（第三人称叙事）的独立风味标准，区别于第一人称VR游戏叙事
2. **长筒袜规则细化** — 明确 G/O/W 级 = 白袜，E 级 = 黑袜，"同等待遇"原则
3. **批量/群体系决规则** — 新增了对大规模处决场景的差异化压缩策略
4. **制服色用词规范** — "军绿"不是"绿"，"蓝白"不是"浅蓝"
5. **死后仪式拓展表** — 新增完整的死后仪式分类体系
6. **处决方式补全** — 新增射精控制/干预（堵马眼、掐根抑制）
7. **"道"体系弹性范围** — 明确定义了可用的对话标签变体
8. **"一定四要"精液描写规范** — 将精液描写的强制要求正式编码
