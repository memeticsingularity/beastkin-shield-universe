# 指南审视报告：lanse-review-guide.md v1.0 复盘

> **审视时间**：2026-07-17
> **审视范围**：全部6个审阅目标（短篇×8 / 主线Vol.1-3 / 炎魉 / 墨犬）共约55章+8短篇
> **审视方式**：以原作反向验证框架的有效性和完整性

---

## 一、框架做得好的地方

### 1.1 五个维度的分级结构合理

从最抽象的"风味"到最具体的"语感"的递进结构经得起检验。审阅过程中最有用的是"维度作为检查清单"——审阅时逐维过一遍，不容易遗漏。

### 1.2 核心标记表是高价值工具

"白袜/登场公式/对话标签/省略号/制服色"这一套硬指标的检查表，在所有作品中都能快速识别风格一致性。表格形式的可操作性最强。

### 1.3 精液"一定四要"是最精确的标准

量/射向/质地/终态四个锚点，在所有作品中都能有效评价精液描写的精细度。没有任何一个分支维度比这个更稳定。

### 1.4 差异化处决要求抓住了核心审美

"每个敌人的死亡必须独一无二"是lanse风格最强的区分特征之一。在贯彻得好的地方（SS-002 黑石杀7人7种死法），效果非常显著。

## 二、框架的盲区（需要修复）

以下按照严重程度从高到低排列。

---

### 2.1 🔴 维度一仅针对第一人称游戏化叙事

**问题**：维度一（风味还原度）的 1a 节完全围绕"第一人称+VR游戏+双重身份+贤者模式"设计。但兽盾宇宙中：

- **Vol.2·魔影** = 第三人称职业杀手叙事
- **Vol.3·白之都** = 战争/多线叙事  
- **炎魉** = 第三人称双主角叙事
- **SS-002~003·黑石** = 第三人称赏金猎人叙事

以上所有作品**都没有第一人称、没有贤者模式、没有游戏化滤镜**，但它们是lanse原作的组成部分。框架目前无法评价它们的"风味还原度"。

**建议方案**：在 1a 中增设 **"第三人称叙事时的判断标准"** 小节，补充：

```
**第三人称时我会这样判断：**
- ✅ 叙述者关注角色的外部行为多于内心活动
- ✅ 叙述者的知识边界和角色一致（不利用全知视角透露角色未知信息）
- ✅ 冷幽默来自职业态度（专业杀手的调侃/对尸体的温情/公事公办式的残忍）
- ✅ 角色对话直接反映性格（不是作者的传声筒）
- ❌ 叙述者停下来解释世界观设定
- ❌ 角色之间进行说教式对话（"你不懂，这世界是这样的……"）
```

同时明确标注：**"1a节中VR游戏特有的标记（贤者模式/读档滤镜/玩家吐槽）仅适用于第一人称VR叙事作品，出现与否取决于作品类型而非风格质量。"**

---

### 2.2 🟠 批量处决场景缺乏过渡规则

**问题**：维度四要求"每个敌人的死亡必须是独一无二的"。但在 Vol.2 ch-1（更衣室16人）和 Vol.3（晋升测试/战争场景）中，**叙事效率必然要求批量处理**。框架没有为这种场景设置任何过渡条款，导致审阅时只能"不适用"或"扣分"。

**建议方案**：在维度四中添加一个子节：

```
### 批量处决场景的差异化策略

当一个场景中死亡角色超过3人时，允许以下压缩方式：
1. **抽样详写** — 选2-3个代表性角色精细描写死法，其余概括
2. **维度差异化** — 按射精量/反应类型/精液质地等维度分批，每个维度内角色共享同一特征
3. **群像差异** — 用"有的……有的……有的……"句式在概括中仍体现多样性
4. **死因分层** — 不同角色死于不同机制（药物/物理/技能），即使在同一场景

**及格线**：在抽样详写的角色中，确保死法在至少3个维度上有差异。
```

---

### 2.3 🟠 "处决方式"分类不完全

**问题**：维度四列出的8种处决方式（手撸/勒颈/内劲/器械/摔死/第三方/战斗/自裁）中，"内劲"的定义太窄——仅描述为"内部破坏"。但实际作品中至少有两种不同的内劲用法：

1. **灼流催情**（炎魉·炎/SS-008·老雷）——内劲导入下体→加速精槽填充→控制射精节奏，而非"内部破坏"
2. **堵马眼延迟**（SS-008·老雷）——物理手段干预射精节奏，属于"控制型"而非"摧毁型"处决

**建议方案**：将"内劲致死"改为 **"内劲/能量传导致死"**，下设两个子类：
```
- 内劲·摧毁型：能量直接破坏内部器官→死亡→精液被动流出
- 内劲·催情型：能量刺激前列腺/睾丸→加速精槽→主动射精死亡
```

并在处决方式列表中新增 **"射精控制/延迟/干预"** 方式：
```
- 堵马眼/掐根/抑制器——不直接导致射精但控制射精节奏
```

---

### 2.4 🟡 缺少"处决分工"维度

**问题**：炎魉模式中，处决者和善后人是两个人。框架目前只理解"单人完成全部流程"的模式。

**建议方案**：在维度四中增加一条：
```
### 处决分工（如适用）

当处决流程由多人协作完成时，标记分工方式：
- ✅ 一人执行 + 一人善后（炎魉模式）
- ✅ 一人控制 + 一人处决（未出现但可能）
- ❌ 分工导致仪式感断裂（杀人者和善后者之间缺乏衔接）
```

---

### 2.5 🟡 缺少"死后仪式"的多样性标准

**问题**：框架的"仪式感完整性"只要求"死亡确认"（不动了/瞳孔涣散等）。但实际作品中有一套丰富的死后仪式系统：

| 仪式 | 使用角色 | 功能 |
|------|---------|------|
| 合眼 | 玩家(Vol.1)、魔影(Vol.2) | 给予死者最后的尊严 |
| 拉上裤头/整理着装 | 玩家(Vol.1)、魔影(Vol.2) | 恢复制服秩序 |
| 亲吻脸颊/抚摸 | 魔影(Vol.2)、黑石(SS-002) | 杀手的职业温情 |
| 摆放姿势（配对） | 魔影(Vol.2) | 死后幽默/补偿 |
| 堆尸山 | 兽盾员工(Vol.3) | 系统化的抹杀 |
| 塞警棍/器官 | 潜入者(SS-006) | 羞辱式装饰 |
| 排列整理（叠放） | 玩家(Vol.1)、黑石(SS-002) | 清理战场 |
| 拍死不瞑目的照片 | 黑石(SS-002) | 职业证据 |
| 穿上尸体的制服 | 黑石(SS-002/003)、魔影(Vol.2) | 身份继承 |

**建议方案**：在维度四中扩展"仪式感"子节：
```
### 死后仪式

处决后的场景处理是风格的重要组成。请检查：
- ✅ 有"死亡确认"（不动了/瞳孔涣散/呼吸停止）
- ✅ 有"整理"动作（合眼/拉裤头/拉直白袜/擦精液）
- ✅ 仪式与角色性格一致（冷血职业杀手会有"职业温情"仪式）
- ❌ 死后场景被跳过（射精=死亡，没有结尾动作）
```

---

### 2.6 🟡 省略号规定有理但缺乏解释

**问题**：指南规定省略号使用"。。。"（三个汉字全角句号+空格），但审阅中发现几乎所有作品都混用了"。。。"、"……"和"..."三种格式。这可能是因为作者/编辑器对格式规定不了解或认为不重要。

**建议方案**：添加一句话说明为什么必须用"。。。"：
```
**为什么必须是"。。。"：**
这不是标点规范问题——"。。。"在阅读体验中产生"断顿感"（每个句号都是一个小停顿），
而"……"是流畅的波浪线。我需要的正是那种"说话卡住了、断断续续"的生硬感，
而不是"优雅地沉默"。
```

---

### 2.7 🟡 白袜规则过于机械

**问题**："每章至少出现1次白袜"在 SS-003（黑石2）中遇到问题——该章敌人都是E级黑制服，按规定穿黑袜，强行插入白袜会破坏制服设定的逻辑。

**建议方案**：将要求调整为：
```
**白袜频次（弹性要求）：**
- 优先场景：G级杂兵为主角的章节——每章至少1次白袜描写
- 例外场景：E级黑制服/R级白制服等非白袜兵种为主的章节——不强制要求，但应有合理的叙事补偿（如通过背景中的G级角色出现白袜、或主角的穿着）
- 硬性标准——不能一整篇作品完全不出现白袜
```

## 三、框架未覆盖但可选的补充维度

以下属于"如果有更好"但非"必须有"的拓展方向：

### 3.1 角色关系维度（炎魉特有）

炎魉中处决者和善后者的对话张力是叙事魅力来源之一。框架不评价角色关系，但如果有"双主角互动"类型的作品，可以考虑。

### 3.2 "失忆主角"叙事模式（墨犬特有）

墨犬的"空白石板"模式（角色和读者同步发现世界规则）既不是玩家视角也不是原住民视角。这是极特殊的叙事模式，不值得单独设维，但应知道它存在。

### 3.3 AI评述附件的存在

多篇作品在章节末尾附带AI生成的"故事评述与感慨"。这些评述与正文风格割裂。这不是审阅框架应该评价正文的问题，但如果指南连AI使用规范也想纳入，可以增加一条建议：
```
### AI 辅助内容的使用建议

- ✅ 正文部分使用AI润色/扩写
- ❌ 将AI生成的"文学化评述"附加在故事正文中
- 建议：评述类内容应作为独立文件存放，不要混入故事正文
```
