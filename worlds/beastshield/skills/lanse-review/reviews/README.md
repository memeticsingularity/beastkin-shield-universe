## 审阅维度

每份审阅覆盖五个维度：

1. **风味还原度** — 叙语气、信息节奏、幽默来源
2. **核心标记检查** — 白袜/登场公式/对话标签/省略号/射精描写等硬指标
3. **肉体吸引力** — 体型偏好/制服审美/精液美学
4. **死亡美学** — 差异化/仪式感/处决创意/临界拉扯
5. **语感自然度** — 段落节奏/语言自然度/信任读者/AI腔避坑
