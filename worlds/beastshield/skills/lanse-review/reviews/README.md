## 审阅目的

1. **风格确认** — 每篇原作是否一致地体现了lanse风格特征
2. **框架盲区** — 原作中有但框架未覆盖的风格要素
3. **演变追踪** — 早期作品到后期作品的风格变化
4. **指南升级** — 全部审阅完成后评估是否需要更新 `lanse-review-guide.md`
