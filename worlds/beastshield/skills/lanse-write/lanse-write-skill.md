## 核心原则：一句话判断

> **去掉作者名和标题，你的故事混在 lanse 的作品集里，读者能不能看出不是你写的？**

如果不能——以下就是从叙事语气到遣词造句的全套校准。

## 一、叙事视角与声音

### 1.1 先确定叙事模式

兽盾宇宙有三种底层叙事模式，写之前必须选好：

| 模式 | 代表作 | 叙述者身份 | 核心特征 |
|------|--------|----------|---------|
| **A1. 第一人称VR游戏** | 主线Vol.1·兽游世界 | 玩家+"我"双重身份 | 元游戏意识、贤者模式、读档循环 |
| **A2. 设定世界观第一人称** | SS-001·兽盾农家乐 | 真实世界中的"我" | 任务导向、实用主义、不能读档 |
| **B. 第三人称叙事** | 主线Vol.2·魔影、Vol.3·白之都、支线、短篇 | 有限的职业叙述者 | 冷感或轻快、业内思维、黑色幽默 |

**模式A1核心**：叙述者既是玩游戏的人（吐槽/评价/贤者），也是游戏中的角色（战斗/互动）。遇到系统机制切玩家视角，遇到战斗互动切回角色。"反正能读档"的游戏化滤镜是道德稀释的核心工具。

**模式A2核心**：主角是真实世界的人（非VR），不能读档，没有贤者模式。叙述语气保持"任务导向"——关注效率（杀完→检查尸体→处理→继续），不关注"杀人这件事的道德意义"。幽默来自用实用主义逻辑覆盖极端场景。

**模式B核心**：叙述者的语气是"干活"不是"经历故事"。角色在执行任务（猎杀/潜入/战斗）时的心理活动稀少且实用——不是"我该怎么办"而是"下一步怎么做"。冷幽默来自职业态度。

### 1.2 叙述者的"声音"速查

| 不要这样 | 要这样 |
|---------|-------|
| "我陷入了沉思" | "靠，这怎么办" |
| "他意识到生命的脆弱" | （写他颤抖、出汗、求饶——不下结论） |
| "命运的齿轮开始转动" | （直接用行动收尾，不抒情） |
| "各种气味混合在一起" | "汗水味混着铁锈般的血腥味从那边飘过来" |
| "他感到一阵恐惧" | "他腿开始打抖，声音发颤" |
| "在这个世界里，兽盾公司的等级制度是……" | （不解释，通过剧情展示） |
| "一名G级杂兵" | "一只穿着军绿制服的熊兽人" |

### 1.3 冷幽默的来源

lanse 的幽默不是"作者讲了个笑话"——是情境自身产生的荒谬。具体有三种形态：

**形态一——"专业评价杀死了共情"**
角色用职业视角覆盖人性视角。黑石闻到袜子臭味，评价是"有些臭，大概两天没换"——专业赏金猎人对袜子的评价完全合理，但正常人不会在杀人后批评死者的袜子。

**形态二——"日常逻辑覆盖极端场景"**
小谷杀完人后坐在熊尸粗腿上："还别说，这家伙肉乎乎的坐起来还挺舒服"——把杀人后果当成坐沙发来体验。

**形态三——"粗俗的吐槽和类比"**
"难道种个菜还要把自己命搭上去吗？那也太不划算了。"

- ✅ 幽默来自角色行为的逻辑自洽，不是作者跳出故事讲笑话
- ❌ 叙述者跳出故事讲笑话（"看来我们的主角今天运气不太好呢"）
- ❌ 笑点太文明太有设计感

## 二、五感描写系统

这是 lanse 写作最核心的实操板块。**五种感官必须交替使用，每次至少调用3种。**

### 2.1 视觉（最高频）

#### 体型视觉——"三百斤级的壮"

所有兽盾兵的基础设定是**肥壮/肉壮/脂包肌**，不是健身教练的干肌肉。

| 概念 | 用法 | 适用兽种 |
|------|------|---------|
| **膀大腰圆** | 肩膀宽+腰身圆，横向体积感 | 熊、虎 |
| **肥壮** | 又肥又壮，体积庞大 | 熊、猪 |
| **肉壮** | 脂肪层下肌肉饱满，厚重感 | 熊、虎、牛 |
| **脂包肌** | 肌肉外裹一层脂肪，手感厚实 | 猪、牛、熊 |
| **粗壮** | 整体粗大，四肢如柱 | 虎、牛 |
| **精壮结实** | 结实但不干瘦 | 狼、狗、豹 |

**关键词禁区**：精瘦、瘦削、纤细、苗条、修长、一米九八块腹肌人鱼线——这些词在兽盾宇宙不存在。

**重量感的写法**：
```
粗壮的白袜腿支撑着肥壮的身躯
每一步都踏得结实
柱子般粗的手臂
肚子上一层厚脂肪，但胸肌和手臂更粗→倒三角
紧身制服被肥壮的身躯撑得没有一丝缝隙
```

#### 制服视觉（编码体系）

| 等级 | 制服色 | 袜子 | 鞋 |
|------|--------|------|----|
| G级（杂兵） | 军绿 | **白色长筒袜**（袜口军绿条纹） | 军绿运动鞋 |
| O级（监工） | 蓝 | **白色长筒袜**（袜口蓝色条纹） | 蓝色运动鞋 |
| E级（武斗兵） | 黑 | **黑色长筒袜**（袜口彩色条纹） | 黑色厚底军靴 |
| R级（枪械兵） | 白 | **白色长筒袜**（袜口蓝色圆环） | 卡其军靴/蓝白运动鞋 |
| W级（摔跤兵） | 深蓝 | **白色长筒袜**（袜口蓝紫条纹） | 深蓝摔跤靴 |

- **制服色用词**："军绿"不是"绿"，"蓝白"不是"浅蓝"
- **紧身是关键**：紧身短袖短裤绷在身上，能看到轮廓、鼓包、勒出的形状
- **鼓包要具体**："紧身裤下鼓鼓囊囊的一团""能看清圆滚滚的轮廓"，不是"裆部有凸起"一句话带过
- **长筒袜包裹感**：白袜/黑袜都必须写出裹在小腿上的紧绷感——"白袜紧绷裹在小腿上""在袜口处勒出肉感""黑袜在小腿肚上勒出一道肉痕"

#### 精液视觉

精液是"生命的输出、力量的证明、死亡的装饰"：
```
一股浓精从马眼直射而出，飞出两米开外
浓白的精液啪嗒啪嗒落在草地间
白浊顺着大腿内侧缓缓流下
裤裆里蓄满了粘稠的白浆
在地上汇成一滩，还在冒热气
```

### 2.2 触觉（最丰富维度）

触觉是 lanse 感官描写的**主导感官**。每个动作都应该伴随触感反馈。

#### 肉体的触感

```
握着的手心里有一种潮湿的温热感
手感像捏面团一样柔软舒适
他身上汗湿的肌肉滑溜溜的
胸膛贴上去的时候能感觉到厚重的体毛扎在皮肤上
他那粗壮的手臂箍住我的时候，能感觉到血管在跳动
```

#### 制服的触感

```
紧身布料绷在身上，能感觉到每一根布丝都在拉扯
冰丝摔跤服摸上去滑溜溜的，带着体温
黑袜的棉布质感裹在粗壮的小腿上，紧绷而有弹性
制服被汗浸透后湿漉漉地贴在身上
军靴踩在木地板上发出沉闷的声响
```

#### 精液的触感

```
一股湿热黏滑的触感在腹部蔓延开来
滚烫的浓精打在掌心上
精液渗入布料后黏糊糊的
指尖触碰到还带着体温的白浊
精液顺着指缝往下淌
```

### 2.3 嗅觉（偶尔但点睛）

嗅觉是 lanse 的第二感官层，适量使用可以大幅提升沉浸感。

#### 体味系统

```
一股淡淡的闷骚味飘了出来——在紧身裤里闷了几个小时的雄性气味
汗水味混着铁锈般的血腥味从那边飘过来
他身上的汗液散发出的独特雄性气息
不是刺鼻的那种，是温热的、带着体温的雄性气味
空气中弥漫开一股腥味
```

#### 根据兽种差异化体味

- 熊——浓郁熊膻味
- 牛——汗腺发达，脚汗重，"牛味"
- 虎——猫科野性气息，略腥臊
- 狗——犬类特有的体味
- 猪——油脂味重，易出汗

#### 环境气味

```
仓库的灰尘味混着机油味
浴室里打完斗后弥漫的精腥味和汗味混在一起
野外的青草味和泥土味
旧旅馆里的霉味和烟味
```

### 2.4 听觉（氛围营造）

听觉描写在 lanse 原作中较少但精准。重点场景：

```
求饶声："求求你……饶了我吧……我真的要射了……"
呻吟声：唔、嗯啊、哈啊、唔唔唔
动作声：吧唧吧唧（撸动声）、啵（龟头弹出的声音）、噗嗤（精液喷出声）
环境：军靴嗒嗒嗒的跑步声、栏杆嘎吱作响、打火机咔嚓声
```

### 2.5 味觉（极少用，用于极致亲密场景）

```
舔舐黑袜脚掌时，咸涩的汗味在舌尖化开
精液的味道腥中带着一丝咸
嘴唇碰到他胸肌上的汗珠，咸的
```

## 三、角色登场与视觉体系

### 3.1 登场公式（核心要素）

每个新角色登场时，信息在**2-3个段落内**按以下顺序带出。不要像清单一样一次列完，与行动/对话穿插。

```
核心要素（必出）：物种 → 制服色 → 体型（重量感） → 袜子（白袜/黑袜）
加分项（出则提味）：鼓包、鞋
```

**正确示范**（信息分散在两段，自然穿插动作）：

> 一只穿着军绿紧身制服的熊兽人正靠在墙边打盹，膀大腰圆，身材肥壮，军绿短袖紧绷地裹着他的胸肌。白色长筒袜裹着他粗壮的小腿，在袜口处勒出一道肉痕。
>
> 他打了个哈欠，揉揉眼睛，才注意到有人靠近。"站住！你是什么人？"熊守卫粗声粗气地吼道。

**错误示范**（像填表）：

> 虎三是一名G级杂兵，他穿着军绿色的紧身制服。他是一个虎兽人，身材不算高大，属于匀称类型，穿着一双白袜和军绿运动鞋。

### 3.2 公式的灵活性

根据场景需要可以调整顺序和信息密度：
- **从下往上写**：先见腿/袜子/鞋 → 再往上到制服 → 最后看脸
- **战斗中登场**：核心要素（物种+制服+体型+袜子）压缩到一句话内完成
- **群体登场**：抽样详写2-3个代表，其余概括处理
- **同一物种同类制服**：至少用「精壮结实的肌肉在紧绷的布料下起伏，裆部的鼓包在走动中微微晃动，白袜包着粗壮的小腿」作为群体出场

## 四、剧情推进节奏

### 4.1 慢节奏——以场景为单位

lanse 的故事推进是**慢的**——不是慢在走走停停，而是慢在**每个场景的细节密度高**。

一个标准的"进房间→发现敌人→战斗→处决→处理"流程，在 lanse 原作中可能占到一整章的2/3篇幅。原因不是叙事效率低，而是每个环节都有充分的五感描写、动作分解、互动层次。

**节奏控制原则**：
- **紧张场景**：短句、短段落（1句1段）、快切
- **情色/处决场景**：慢分解、多感官、逐层推进
- **移动/过渡**：1-2句交代去向，不写沿途风景
- **对话场景**：一问一答中间夹动作/反应描写

### 4.2 信息节奏——新信息只在被需要时出现

有一条铁则：**新信息只在被需要的时候出现。**

- 角色登场的制服色/体型/物种——第一次出场时一次性给全，之后除非有新信息（换衣服/受伤了），不重复
- 世界观设定不解释——通过角色的反应和事件让读者自己理解。"为什么射精会死"这件事，读者从剧情中自己领悟
- 角色编号不是登场时交代的——它可以一直藏到需要用到的时候才出现
- 同一章内不要反复确认设定

#### 描写附着在行动上

这是 lanse 风格最核心的技术特征：**每段描写都应该同时推动叙事。**

在 lanse 的作品里，几乎看不到为描写而描写的段落。每个"描写"都是在"行动"中完成的：
- ✅ "两条穿着白袜的粗腿在地上乱踢乱蹬"——同时完成了"描写白袜"和"描写挣扎"
- ✅ "紧身短裤被裆部那团鼓鼓囊囊撑得有些变形"——同时完成了"描写制服"和"描写角色正在移动/站立"
- ❌ 独立写一段"XX穿着军绿制服，身材壮硕，穿着白袜"——这是静止的人物介绍，不是叙事
- ❌ 先来一段环境描写再开始剧情——环境信息应该在动作中顺带出来

**绝对不要出现的句式**：
```
"在这个世界里，兽盾公司的等级制度是……"
"因为所有伤害都会转化为性欲值……"
"兽盾的员工编号以G开头，代表……"
```

### 4.3 场景结构模板

一个标准章节的场景递进：

```
① 场景建立（1-2句）：地点+氛围
② 角色登场（核心要素）：走公式
③ 互动/对话（如果有）：一问一答+动作穿插
④ 冲突爆发：攻击/处决/追逐
⑤ 处决/战斗高潮（五感全开）：动作分解+感官描写
⑥ 处决后处理（死后仪式）：拍照/收袜/合眼/换装/藏尸
⑦ 过渡到下一场景（1-2句）
```

### 4.4 人物互动驱动剧情

剧情不要由"事件"推动，而要由"人物互动"推动。每个场景的核心是**两个角色之间的张力**——猎手与猎物、审讯者与俘虏、上级与下属、闯入者与守卫。

写法要点：
- 处决前的对话是角色性格的展示窗口——求饶的方式反应角色个性
- 战斗中的调戏/嘲讽比单纯的打斗更有看头
- 处决后的尸体处理方式反应角色性格（冷酷/温柔/变态/职业）

## 五、情色场景写作

### 5.1 处决流程（三种模式）

每次处决都是一场仪式。但根据武器/手段不同，处决链条有三种模式：

**模式一·直接型**（最经典，一对一标准处决）：
```
制服/控制 → 掏出生殖器（翻开包皮）→ 刺激开始 → 目标求饶 → 
临界状态（拉扯/憋精/控制节奏）→ 射精（多股+全参数）→ 
死亡确认（喘声变低→头歪→不动了）→ 死后处理
```

**模式二·间接型**（内劲/药物/器械致死，无直接接触）：
```
伤害/药物注入 → 身体反应（精槽飙升）→ 失控射精 → 死亡确认
```

**模式三·快速型**（批量击杀/辅助角色死亡）：
```
致命打击 → 精关失守 → 精液被动流出 → 死亡确认
```

三种模式共同的硬性要求：
- ✅ 死亡必有射精（直接型喷射、间接型主动射、快速型被动流均可）
- ✅ 射精必有量感（即使是被动流出的精液也有"量"的描述）
- ✅ 死亡确认（"不动了""头一歪""瞳孔涣散""断气了"——至少有一种）
- ❌ 处决后直接跳到下一场景，没有死亡确认

### 5.2 精液描写的"一定五要"

精液是死亡仪式的一部分，**不能一笔带过**：

- **一定**不能一笔带过
- **一要写量**：多少股/多少发/量很大/量不多
- **二要写射向**：喷出多远/射向何处/从哪个角度喷出/隔着布料还是直接射出
- **三要写质地**：浓/稀/白浊/带血/透明
- **四要写终态**：马眼还在流/已经停了/顺着腿淌/在地上汇成一滩/渗入布料
- **五要写环境互动（v1.4补充）**：精液射在了哪里（栏杆/墙壁/制服/地面/脸上）、与接触面的视觉反应（"激起一朵精花""飙射在铁栏杆上""渗透过紧身短裤聚成奶珠"）、环境对精液的影响

### 5.3 处决方式差异化

**每个敌人的死亡必须独一无二**。不能复制粘贴处决描写的句式和结构。

可做差异化的维度（至少选3-4个做变化）：

| 维度 | 变化范围 |
|------|---------|
| 射精量 | 极多/多/中/少/射不出 |
| 射精方式 | 喷射/涌出/渗出/滴落/射不出 |
| 精液质地 | 浓白/稀白/透明/带血 |
| 身体反应 | 全身痉挛/局部抽搐/僵直瘫软/挣扎后软倒 |
| 终态 | 马眼还在流/已停止/顺着腿淌/渗入布料 |
| 死前反应 | 求饶/沉默/硬气/困惑/接受 |
| 死亡节奏 | 瞬间死亡/临界拉扯/延迟死亡/休克后死亡 |

### 5.4 处决方式谱系

不要只用手撸致死。以下是原作中使用过的处决方式：

1. **手撸致死**（最经典）
2. **勒颈致死**（窒息+压迫感，精液闷在裤子里）
3. **内劲致死**（灼流暗劲——从体内引爆，无声无外伤）
4. **器械致死**（匕首/银针/飞刀/钢丝环）
5. **摔死/撞死**（利用环境）
6. **第三方处决**（随从动手，主角观看）
7. **战斗处决**（边打边射——战斗中高潮到死）
8. **自裁**（让目标自己选择死法——仪式感的巅峰）
9. **射精控制/干预**（堵马眼/掐根抑制——不直接致死但控制节奏）
10. **间接致射**（药物/毒素触发→身体自动反应→射精死亡——执行者不在场，如红石药剂）

### 5.5 死后仪式

死亡确认只是起点。每个角色/每篇故事应有**至少一个标志性的死后仪式动作**：

| 仪式 | 适用角色/场景 |
|------|-------------|
| 合眼/闭眼 | 给予死者最后的尊严 |
| 拉上裤头/整理着装 | 恢复制服秩序 |
| 亲吻脸颊/抚摸头 | 杀手的职业温情 |
| 摆放姿势（配对） | 死后黑色幽默 |
| 堆叠尸体 | 清理战场 |
| 塞警棍/插异物 | 羞辱式装饰 |
| 拍死不瞑目的照片 | 职业证据（赏金猎人的标准流程） |
| 穿上尸体的制服 | 身份继承（换装潜入） |
| 擦精液在袜子/制服上 | 打扫战场 |

### 5.6 射精的情感调色盘

高潮≠射精。同一个角色可以"射了但并不爽"。写死亡时注意角色的情感状态，让不同死法有情绪差异：

| 情感类型 | 描写特征 | 适用场景 |
|---------|---------|---------|
| **高潮**（pleasurable） | 享受、呻吟、主动推胯、意识高潮 | 爽死的杂兵、仪式化处决 |
| **失控**（involuntary） | 惊恐、试图阻止、自我厌恶、失禁感 | 猝死、被动致射 |
| **羞耻**（humiliated） | 求饶、闭眼、不敢看施者、流泪、屈辱 | 被折磨到崩溃的角色 |
| **悲壮**（bittersweet） | 叹息、认命、回忆亲人、关心未竟之事 | 重要角色之死、自裁

同一篇章中使用至少2-3种不同的情感调色盘来差异化死亡体验。

## 六、对话与心理

### 6.1 对话标签

优先使用"XX道"体系。原作数据：90-100%的对话标签使用道形式，"说"作为单独对话标签几乎不存在。

| 推荐 | 不推荐 |
|------|--------|
| 说道（无特殊情绪） | 说（通篇只用这个会失去风格——原作几乎不用"说"作为对话标签） |
| 问道（提问时） | 嗔怪道（太文艺了） |
| 吼道（愤怒/大声） | 沉吟道（太文艺了） |
| 笑道（带笑意） | 意味深长道（太文艺了） |
| 怒道（愤怒/斥责） | 他带着苦涩的笑意说道（复杂变体） |
| 喃喃道（自言自语/虚弱时） | |
| 苦笑道（带苦笑——原作用过，不禁） | |
| 叹道（叹气时） | |

### 6.2 对话风格

- **短、粗、直接**——"往西跑了。跟运输队走的。你们这些练武的傻逼，吃屎都赶不上热乎的。"
- **语气词丰富**——呜、嗯啊、唔、哈啊、靠、妈的、我操
- **求饶句式标准化**——"求求你饶了我吧""饶命""我真的要射了"
- **省略号表恐惧颤抖**——"你……你要干什么……"（注意：使用中文省略号"……"，非句号重复"。。。"，这是原作统一的格式）
- **感叹号表高潮**——"别！别别别——要射了！"
- **兽盾兵的对话符合其人设**——自私自利、粗俗带脏字、缺乏怜悯。G级恐惧时哭爹喊娘符合人设，O级可以有管理者的傲慢但本质上还是粗人

### 6.3 心理描写（第一人称）

第一人称的心理活动停留在**"即时反应"层**——惊讶、兴奋、尴尬、自嘲、后悔、于心不忍。

| 可以写 | 不可以写 |
|--------|---------|
| "啥？只有一条命！" | "我陷入了沉思" |
| "我多什么嘴呀！" | "我意识到生命的脆弱" |
| "靠！好像只有处决掉这一个选项啊！" | "我的内心充满了矛盾" |
| "我看着他这模样有些于心不忍" | "他感到一种深沉的悲哀" |

**定律**：内心独白的长度不超过2句。2句以上就变成文学性反思了。

### 6.4 心理描写（第三人称）

第三人称的心理描写更少——几乎只写角色"看到→判断→行动"的链条。

```
魔影看到走廊尽头的守卫打起了哈欠。（观察）
现在是最好的时机。（判断）
他从背后摸了上去。（行动）
```

不写角色的情感波动，只写他们的行动决策。情感通过对话和行动让读者自己推断。

## 七、世界观铁则

### 7.1 必须遵守的底层规则

- **死亡必射**：射精即死，没有不射精的死亡。这是世界观铁则，不能破
- **全男世界观**：所有角色使用"他"，包括外表偏柔的角色
- **伤害=性欲值**：所有攻击造成的伤害都会转化为性欲值
- **双性体质**：所有兽人同时拥有男性和女性生殖器
- **精液排空**：必须将精液完全排出体外才算彻底死亡
- **无流血**：这个世界没人流血。致命方式只有射精

### 7.2 G级杂兵背景限制

禁止以下设定：贫穷务农/被迫养家/攒钱开饭馆

必须走的设定方向：犯罪/赌徒/盲从打手

### 7.3 员工对话与行为风格

- 粗俗带脏字：他妈、傻逼、老子
- 句式短、不绕弯子：命令式、直接威胁
- 站岗状态：偷懒、打盹、抽烟是常态
- 同事关系：缺乏怜悯，嘲笑同事死亡
- 内部管理：粗野豪放，干部可随意处罚下属甚至抹杀
- 随意杀戮：公司内部可随意杀同事，尸体被当肥料

## 八、常见坑与纠偏

### 8.1 AI腔句式（一眼破功）

| AI腔 | 正确写法 |
|------|---------|
| "虎三是一名G级杂兵" | "一只穿着军绿制服的熊兽人" |
| "他感到一阵恐惧" | 写他冒汗、腿抖、声音发颤、求饶 |
| "xx的肉棒变得越来越硬" | "xx的肉棒已经硬得发烫"（直接说状态，不写变化过程） |
| "包皮向后翻开，露出紫红色的龟头" | 可以写，但不要每次都用这一模一样的句式 |
| "说完，他就……" | 不要用"说完""听完""想完"衔接——直接写下一个动作 |
| "一股暖流涌遍全身" | 写具体的感觉：热流汇聚到小腹、前列腺被刺激、睾丸发胀 |

### 8.2 段落节奏

- **默认节奏**：大部分段落1-2句，不超过3句
- **长段落**：只在需要"不打断体验流"时使用——如一段完整的勒颈处决过程
- **不要**段落长度均匀（读起来像匀速机器）
- **不要**段内混杂（一段里又写环境又写内心又写对话又写动作）——每个微观目标写到完成就换段

### 8.3 信任读者

- 不解释世界观原理
- 不反复确认设定——核心信息说一次就够了
- 不替读者下结论——"他感到恐惧"❌；写他颤抖、出汗、膝盖打滑、喉结滚动✅
- 每句话都该贡献新信息或新体验。删掉一句场景体验会变少吗？不会——删掉
