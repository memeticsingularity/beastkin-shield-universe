# 1 兽盾公司：组织与员工

## 1.1 公司概况与文化

* 【组织/制度】兽盾公司的制服制度已改革。部长级人员因我行我素不穿制服，导致库存积压的黑制服下发给新晋战斗人员。【o-cs-1-ch-2】
* 【组织/文化】兽盾公司高层管理严酷，对重大失职者会责令其当众自裁谢罪，方式多为强制射精至死。【o-cs-1-ch-3】
* 【组织/设施】兽盾公司设施内（如总部）设有尺寸巨大的垃圾箱，疑似专为处理员工尸体而设计。【o-cs-1-ch-3】

## 1.2 通用员工设定

* 【组织/通用】兽盾公司聘用标准以直观的身体力量为主，因此员工普遍身材粗壮、肌肉发达。【o-cs-1-ch-1】
* 【生理/通用】兽盾员工的致死弱点高度统一：被特定手法强制引发剧烈射精后，会精尽人亡。【o-cs-1-ch-1/2/3】

## 1.3 员工等级与兵种

* 【组织/等级】最低级的新兵或杂兵穿着**军绿色制服（绿制服）**。【o-cs-1-ch-1】
* 【组织/制度】绿制服员工转正后，根据体能测试结果分流：【o-cs-1-ch-2】
    * **武斗兵 (E级)**：皮糙肉厚、适合近战，穿着**黑色紧身制服（黑制服）**，日常进行高强度体能训练，体味较重。
    * **枪械兵 (R级)**：枪法精准、适合远程，穿着**白色紧身制服（白制服）**，被近身后战斗力大减。
    * **监工/管理 (O级)**：战斗能力不突出，负责管理工作，穿着**蓝色制服（蓝制服）**。
* 【物品/特性】白色紧身制服被液体浸湿后会呈半透明状，遮蔽效果变差。【o-cs-1-ch-2】

# 2 游戏核心机制

## 2.1 战斗与交互

* 【技能/功法】**灼流暗劲**
  ：核心功法之一。通过手掌接触（尤其是握住雄性生殖器）传递特殊内力，使目标体温升高，无法抗拒地迅速勃起并达到射精临界点，最终射精身亡。功力高低直接影响生效速度。【o-cs-1-ch-1/2/3】
* 【技能/功法】**银针封穴术**：使用细小银针刺入穴道，能使目标身体无法动弹，但意识清醒、知觉保留，只能任人摆布。【o-cs-1-ch-3】
* 【技能/功法】**金刚护体**：可使身体硬化，弹开普通子弹。【o-cs-1-ch-1】
* 【交互/处决】处决者可以通过持续刺激目标的生殖器或其他敏感点（如乳头）加速其死亡过程。【o-cs-1-ch-1/3】

# 3 玩家角色与行为

## 3.1 身份与状态

* 【生态/身份】**赏金猎人**：潜入兽盾设施，以猎杀其员工并获取身份标识换取赏金的独立角色。【o-cs-1-ch-1/3】
* 【生态/行为】赏金猎人的核心工作流程是：猎杀目标 -> 记录目标袜子底部的唯一编号 ->
  凭编号兑换赏金。【o-cs-1-ch-1】
* 【规则/禁忌】猎人之间存在不成文的规矩：不得记录已被其他猎人杀死的目标编号，此行为被视为“虎口夺食”。【o-cs-1-ch-3】

# 4 世界环境与场景

## 4.1 兽盾公司设施

* 【地点/类型】兽盾公司拥有**新兵训练基地**、**总部大楼**、**地下关押室**等综合设施。【o-cs-1-ch-1/3】
* 【物品/设施】高级关押室配备有需要特定操作才能打开的精密仪器门锁。【o-cs-1-ch-3】

# 5 物品与装备图鉴

## 5.1 服装与标识

* 【物品/服装】兽盾全员标配**长筒运动袜**和**运动鞋**。袜子底部绣有**个人唯一编号**。【o-cs-1-ch-1】
* 【物品/服装】武斗兵的黑制服与枪械兵的白制服均为凸显身材的紧身设计，会突出胸肌与下体轮廓。【o-cs-1-ch-2/3】

## 5.2 武器与道具

* 【物品/武器】守卫标准装备包括**电击棒**和**手枪**。【o-cs-1-ch-2/3】
* 【物品/弹药】存在特制的**春药弹**，可以被功夫高手徒手接住并反掷。【o-cs-1-ch-3】

# 6 生物与生理图鉴

## 6.1 通用生理

* 【生理/通用】该世界的雄性兽人，射精行为与生命能量高度绑定，过量或强制射精会直接导致死亡。【o-cs-1-ch-1/2/3】
* 【生理/通用】死亡时，许多个体会呈现翻白眼、身体抽搐、最后瘫软的状态。【o-cs-1-ch-1】

## 6.2 兽人种族特性

* 【生理/种族】**牛兽人**：部分个体乳头极为敏感，刺激后可分泌少量乳汁。【o-cs-1-ch-1】
* 【生理/种族】**犀牛兽人**：以意志刚猛著称，部分强者可凭借意志力短暂抵抗即死效果。【o-cs-1-ch-3】

# 7 社会、经济与势力

## 7.1 其他势力与人物

* 【势力/身份】**神武传人**：一个实力极强的传承称号，其成员（如熊猫兽人）是兽盾公司的抓捕目标。他们通常拥有极高的武学修为。【o-cs-1-ch-3】
* 【生态/关联】存在为救出“神武传人”而独自潜入兽盾基地执行救援任务的高手（如银狼兽人）。【o-cs-1-ch-3】
