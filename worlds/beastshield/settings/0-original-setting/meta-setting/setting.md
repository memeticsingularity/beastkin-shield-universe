# 世界设定整合文档

## 1. 兽盾公司 (Beast Shield)

### 1.1 概述

- 【组织/制度】公司聘请标准为实力过关，力量是最直观的体现。制服制度已经改革，部长人数缩减且现任部长们普遍不穿制服，工厂积压的黑制服被重新利用。【o-cs-1-ch-1,
  o-cs-1-ch-2】
- 【组织/制度】绿制服守卫转正后，需接受体能测试，并根据结果分配至不同兵种。【o-cs-1-ch-2】
- 【组织/管理】新兵训练基地存在新兵名单与对讲机呼叫制度（按编号管理），组长可通过频道逐个传唤新兵。【o-cs-1-ch-1】
- 【组织/氛围】“部长级人物实力恐怖”的认知在基层（包括外部人员）中根深蒂固，形成一种心理威慑。公司内部对失职者的处理方式冷酷高效，如同处理报废品。【o-cs-1-ch-2,
  o-cs-1-ch-3】
- 【组织/事件】基地可能被潜入并屠戮。【o-cs-1-ch-3】
- 【组织/反应】基地警铃会因尸体被发现而拉响，警报响起会引来大量援兵。【o-cs-1-ch-3】

### 1.2 地点设施

- 【地点/设施】新兵训练基地设有办公室、垃圾箱、草丛等设施。更核心的区域包括中心地区入口、过道、死胡同、正门、杂物间（内设储物柜）等。【o-cs-1-ch-1,
  o-cs-1-ch-2】
- 【地点/设施】基地内设有会议室（门口有守卫）、负一层（有关押室）、电梯和狭窄的楼梯（一次最多容两只兽人并行）。【o-cs-1-ch-3】
- 【地点/环境】负一层最深处为关押室。楼梯在激烈战斗后可能铺满尸体，喷出的精液会顺楼梯滴落汇聚成池。【o-cs-1-ch-3】
- 【地点/设施】兽盾总部楼道上设有尺寸巨大的垃圾箱，疑似专为处理大量尸体而设计。【o-cs-1-ch-3】

### 1.3 绿制服 - 杂兵/新兵 (最低级员工)

- **制服、装备与标识**
    - 【物品/服装】穿着军绿色的紧身裤、长筒白袜和运动鞋。白袜袜底有唯一编号，是赏金猎人领取赏金的凭证。【o-cs-1-ch-1】
- **角色与状态**
    - 【角色/身份】最低级员工（新兵/杂兵），是赏金猎人的主要狩猎目标。【o-cs-1-ch-1】
    - 【状态/死亡】被特定手法（如灼流暗劲）迫使射精后，会进入濒死状态，最终精尽而亡。【o-cs-1-ch-1,
      o-cs-1-ch-3】
- **已知成员/案例**
    - 狼守卫（白熊组长的新人员工，二号），膀大腰圆。【o-cs-1-ch-1】
    - 熊兽人守卫（三号），肉壮无比，性格蠢笨，脚近60码。【o-cs-1-ch-1】
    - 蓝毛虎守卫，身材粗壮异常。【o-cs-1-ch-1】
    - 犀牛守卫。【o-cs-1-ch-1】
    - 牛兽人守卫，身材粗壮，敏感点为乳头，受刺激时可分泌少量奶汁。【o-cs-1-ch-1】
    - 野猪守卫（名单上最后一只）。【o-cs-1-ch-1】
    - 绿制服虎兽人（基地杂兵）。【o-cs-1-ch-3】

### 1.4 蓝制服 - 组长/管理人员

- **制服与身份**
    - 【物品/服装】组长级别员工穿着蓝色制服（蓝制服），包括蓝色紧身短袖上衣，蓝色紧身短裤、长筒白袜和蓝色运动鞋。【o-cs-1-ch-1】
    - 【组织/兵种】转正后，近战与远程能力均不突出的员工，会担任管理职务，负责管理新兵。【o-cs-1-ch-2】
- **已知成员/案例**
    - 白熊组长，新兵训练基地某办公室组长，有近三百斤的身体。【o-cs-1-ch-1】

### 1.5 E级/黑制服 - 武斗兵

- **选拔、特征与装备**
    - 【组织/兵种】转正后，皮糙肉厚、适合近身搏斗者分配至武斗组，穿上黑色制服。他们力量比绿制服守卫大很多，肌肉更硬，但因高强度训练，脚部可能有较重体味。【o-cs-1-ch-2】
    - 【物品/服装】穿着黑色紧身制服，通常包括黑色紧身短袖上衣和黑色紧身短裤（紧身设计兼具内裤功能，不配发独立内裤），以及长筒黑袜和运动鞋，袜底有编号，格式为E-自然数。【o-cs-1-ch-2】
    - 【物品/道具】标配近战武器如电击棒。【o-cs-1-ch-3】
- **已知成员/案例**
    - 黑制服熊守卫（中心地区入口武斗组成员）。【o-cs-1-ch-2】
    - 黑制服狗兽人（武斗组成员），身材粗壮，肉棒细长。【o-cs-1-ch-2】
    - 黑制服熊兽人、牛兽人（被熊猫解决的小队及楼梯守卫）。【o-cs-1-ch-3】
    - 总部高层牛兽人（穿黑制服，肩有高级军徽）。【o-cs-1-ch-3】

### 1.6 R级/白制服 - 枪械兵

- **选拔、特征与装备**
    - 【组织/兵种】转正后，枪法精准、适合远程作战者分配至枪械组，穿上白色制服。【o-cs-1-ch-2】
    -
  【物品/服装】穿着白色紧身制服，包括勾勒肌肉线条的白色紧身短袖和白色紧身短裤。白色紧身短裤被精液或淫水浸湿后会变成半透明。脚穿长筒白袜和运动鞋，袜底有编号，格式为R-自然数。【o-cs-1-ch-1,
  o-cs-1-ch-2】
    - 【物品/道具】配备手枪，弹药可能为特制的春药弹，这种弹药可被高手接住并反掷。【o-cs-1-ch-3】
    - 【物品/标识】具有一定官职的人员，其制服肩膀上可能配有特殊印章。【o-cs-1-ch-3】
- **已知成员/案例**
    - 白制服虎守卫（枪械组成员），身材粗壮。【o-cs-1-ch-2】
    - 白制服犀牛兽人（会议室），年近四十，战功累累，官职不低。【o-cs-1-ch-3】
    - 两名白制服狼兽人（熊猫解决的小队）。【o-cs-1-ch-3】
    - （推断）裸体黄毛狮子兽人生前应为白制服士兵（依据肌肉强度与食指枪茧判断）。【o-cs-1-ch-2】

## 2. 赏金猎人生态

### 2.1 主要角色

- **炎**
  -
  【角色/能力】掌握“灼流暗劲”（初级），需通过接触（如握住肉棒）缓慢传输内力以迫使目标射精。他通过计算目标坚持的时间来评估自己功力进步。同时拥有“金刚护体”，可弹开子弹。【o-cs-1-ch-1】
    - 【角色/行为】作为主力猎手，负责制服、控制并处决目标。行动果断，追求效率，但也会在特定情况下（如敬佩对手）给予相对“人道”的处决。【o-cs-1-ch-1,
      o-cs-1-ch-3】
    - 【生态/行为】以狩猎兽盾员工并记录其编号换取赏金为生。【o-cs-1-ch-1】
- **魉**
    - 【角色/身份】辅助者，负责善后处理与情报支持。【o-cs-1-ch-2】
    - 【角色/能力】拥有变色龙般的先天隐身天赋，可凭空出现和消失，但在真正的高手面前可能被感知。【o-cs-1-ch-1,
      o-cs-1-ch-3】
    - 【角色/动机】并非好杀之人，因缺钱而与炎合作。性格中带有怜悯，常对死者进行简单整理以示尊重。【o-cs-1-ch-1】

### 2.2 狩猎规则、行为与流程

- 【生态/行为】核心盈利模式为猎杀兽盾员工并拍摄其袜底编号作为凭证。【o-cs-1-ch-1】
-

【行为/流程】标准化操作流程包括：主力猎手制服并迫使目标射精；确认目标濒死后，常通过“握紧肉棒根部挤净残余精液”确保死亡；辅助者随后进行编号记录、尸体整理（穿衣、合眼等）与藏匿。【o-cs-1-ch-1】

- 【规则/禁忌】严禁记录或窃取其他赏金猎人已击杀目标的编号，此行为被视为“虎口夺食”，破坏行业规矩。【o-cs-1-ch-3】
- 【生态/策略】常利用换装进行伪装渗透。行动力求隐蔽，一旦警报响起引来大量援兵，通常会选择撤退以避免正面冲突。【o-cs-1-ch-2,
  o-cs-1-ch-3】
- 【生态/环境】存在多名独立或隶属不同势力的赏金猎人同时在兽盾基地内活动，彼此可能存在竞争或互不干涉。【o-cs-1-ch-2】

## 3. 功法与技能

- 【技能/通用】**灼流暗劲**：一种可通过接触传输内力，刺激目标性器官，迫使其迅速达到高潮并射精的功夫。不同修炼者境界差异巨大：
    - **初级/皮毛**：需持续接触肉体才能缓慢传输内力，生效需要一定时间（如炎）。【o-cs-1-ch-1】
    - **高级/精通**：可隔空发劲，瞬间透入穴道，几乎立即引爆目标精关，实现秒杀（如熊猫）。【o-cs-1-ch-3】
- 【技能/通用】**金刚护体**：一种可弹开普通子弹的护体功夫。【o-cs-1-ch-1】
- 【技能/功法】**银针封穴术**
  ：用细小银针刺入特定穴道，能使目标身体无法动弹但意识保持清醒。常与“灼流暗劲”或其他刺激手段结合使用，形成一种控制型虐杀。【o-cs-1-ch-3】

## 4. 其他角色与势力

- **熊猫兽人**：【角色/身份】“神武传人”，实力深不可测，精通高阶灼流暗劲。曾被兽盾设计捕获，关押于基地深处。【o-cs-1-ch-3】
- **银灰色狼兽人**：【角色/身份】身手敏捷的潜入者，负责营救熊猫。行事干净利落，处决目标时会拧断脖子以防万一。【o-cs-1-ch-3】
- **牙董**：【角色/身份】兽盾总部高层，作风冷酷，对失职者下达的命令实质是令其自裁。【o-cs-1-ch-3】
- **牙董的手下**：【角色/身份】负责处理尸体等杂务。【o-cs-1-ch-3】

## 5. 通用状态与现象

- 【状态/濒死】被“灼流暗劲”等手法迫使射精后，目标会进入濒死状态：丧失战斗力，意识模糊，可能伴有抽搐、呻吟或遗言，生命体征急速衰减。若不处理，也将很快死亡。【o-cs-1-ch-1,
  o-cs-1-ch-3】
- 【状态/死亡】精尽而亡是常见的死亡方式。死后尸体通常保持**肉棒勃起、精液渗漏**的典型状态。【o-cs-1-ch-1】
- 【行为/补刀】为确保目标死亡或终结其痛苦，执行者常进行“补刀”，方式包括：挤净残余精液、继续撸动以排空、或直接扭断脖颈。【o-cs-1-ch-1,
  o-cs-1-ch-3】
- 【状态/受制】被“银针封穴术”命中后，身体无法动弹，但视觉、听觉、触觉及思维均保持清醒，能清晰感知到施加于自身的刺激与羞辱。【o-cs-1-ch-3】
