**核心美学**：死亡毫无价值，杀得顺手，死后像垃圾处理。

**学习范本**：`bs-a-cs-4-yanliang/ch-1.md` **Scene-1**

- ✅ 雷爪有名字，有挣扎求饶
- ✅ 炎顺手杀戮，面无表情
- ✅ 杀完用尸体擦手，推开
- ✅ 塞垃圾桶，腿露外面

**Scene-1的正确之处**：

```
虎兽人雷爪（有名字）→ 挣扎求饶（有过程）→ 炎顺手弄死（面无表情）
→ 用胸肌擦手（顺手利用）→ 推开尸体（像垃圾）→ 塞垃圾桶（腿露外面）
```

## 核心原则（这三条不能变）

### 1. 不写太多背景故事 ❌

**禁止**：

- 家乡在哪里
- 家里有什么人
- 梦想是什么
- 为什么加入兽盾

**Scene-1的正确示范**：

```
虎兽人雷爪正在巡逻...（只有当前状态，没有背景）
```

**Scene-3的错误示范**：

```
厚朴来自南方丛林...他最大的梦想是...（背景太多）
```

---

### 2. 死后处理顺手像垃圾 ✅

**必须包含**（这是核心）：

- 用尸体/衣服擦手或凶器
- 随手推开/踹翻尸体
- 塞垃圾桶/草丛/更衣柜
- **腿露在外面**（不像Series 2那样体面）
- 只脱一只鞋拍照（快速，不讲究）

**Scene-1正确示范**：

```
炎抽回手，在雷爪背肌上擦了擦，推开尸体。
魉把尸体塞进垃圾桶，腿露在外面，只脱一只鞋拍编号。
```

---

### 3. 杀得顺手 ✅

**核心感觉**：杀人不是目的，是顺手的事。

**正确示范**：

- 可以玩弄（但像是顺手玩弄，不是刻意享受）
- 可以高效（像炎一样面无表情）
- 可以羞辱（但像是顺手羞辱，不是专门设计）

**Scene-1的炎**：

```
面无表情，运功，10秒射精，擦手，推开，"下一个"
→ 全程顺手，没有刻意享受，但也没有排斥
```

**凶手风格可以多样**：

- **炎型**：面无表情，高效，计时
- **玩弄型**：顺手玩弄几下，但最终还是像垃圾一样处理
- **羞辱型**：顺手羞辱，但不是为了羞辱而羞辱

**关键**：哪怕玩弄/羞辱，也是"顺手"的，不是专门设计的复杂play。

## 角色设定规范（v3.0）

### 目标命名

**格式**：`名字-种族`

- 例如：雷爪-虎兽人、阿黄-狗兽人、厚朴-白熊兽人
- 可以有名字，不是必须用编号

**编号使用**：

- 只在收尾时出现（拍照领赏）
- 例如：魉脱下鞋子，露出袜底编号G-147

### 种族接受度

**全种族可接受**：

- 熊虎牛（粗壮体型，首选）
- 狗狼狐豹等（slender 体型，可以）
- 野猪、犀牛等（其他体型，可以）

**不限制种族**，但要有体型描写（脂包肌或肌肉）。

### 挣扎求饶

**可以写**：

- 被制服时的挣扎
- 求饶（"饶了我"、"不要"）
- 生理反应（勃起、射精、抽搐）

**Scene-1的雷爪**：

```
"快...快放开我！...不要！"
雷爪崩溃地哭求，声音嘶哑绝望。
```

✅ 这是可以的，有挣扎求饶更有张力。

## 凶手风格多样化

### 风格A：炎型（面无表情高效）

- 不废话，只计时
- 杀完擦手，推开
- 像完成工作

**示范**：

```
炎抓住卵蛋，运功，12秒射精。
"12秒，废物。"
在胸肌上擦了擦手，推开尸体，离开。
```

### 风格B：顺手玩弄型

- 玩弄几下，但不专门设计复杂play
- 最终还是像垃圾处理

**示范**：

```
炎抓住卵蛋，没有立刻发功，而是捏了捏。
"挺大的。"
玩弄几秒，然后发功，15秒射精。
推开尸体，擦手，离开。
```

### 风格C：顺手羞辱型

- 羞辱几句，但不是为了羞辱而羞辱
- 尸体还是像垃圾一样处理

**示范**：

```
炎制服虎兽人，捏住卵蛋。
"兽盾的杂兵，就这么点能耐？"
发功，10秒射精。
"废物。"
推开尸体，用他衣服擦手，离开。
```

**禁止**：

- ❌ 专门设计复杂的羞辱play（如Series 2的详细解锁）
- ❌ 凶手明显享受/兴奋（要保持"顺手"感）
- ❌ 对尸体有仪式感（必须像垃圾处理）

---

## 尸体处理标准（v3.0 - 核心中的核心）

这一步**不能妥协**，是Series 3的灵魂。

### 必须包含

1. **用尸体/衣服擦手或凶器**
   ```
   炎抽回手，在虎兽人胸肌上擦了擦。
   ```

2. **随手推开/踹翻**
   ```
   推开尸体，像扔垃圾一样。
   或者：一脚踹翻，尸体滚到墙角。
   ```

3. **塞入容器/角落，腿露外面**
   ```
   塞进垃圾桶，上半身在里面，腰部卡住，腿露在外面。
   塞进更衣柜，太胖了塞不进去，腿露在外面。
   拖进草丛/灌木丛，像扔垃圾一样扔进去。
   ```

4. **只脱一只鞋拍照**
   ```
   脱下右脚鞋子，露出袜底编号，拍照。
   （不拍脸，只拍编号）
   ```

5. **魉的轻微抱怨**
   ```
   "太胖了塞不进去..."
   "垃圾桶太小了..."
   ```

### 与Series 2的区别

| 处理步骤 | Series 2（体面） | Series 3（垃圾） |
|------|--------------|--------------|
| 尸体摆放 | 整齐放置，整理姿势    | 随手推开/踹翻      |
| 隐藏   | 认真藏好，不留痕迹    | 塞垃圾桶，腿露外面    |
| 鞋子   | 两只都脱，整齐摆放    | 只脱一只，快速拍照    |
| 尊严   | 保持尸体"体面"     | 像垃圾一样处理      |

## 写作规范（v3.0）

### 典型段落结构

```
[目标出现，有名字]
一只虎兽人正在巡逻，他叫雷爪。
近三百斤的壮硕身躯，军绿色制服紧绷。

[炎偷袭]
炎从阴影中伸手，扣住后颈，拖入墙角。
左手勒颈，右手抓裆。

[挣扎求饶，可以写]
"快放开我！...不要！"
雷爪崩溃地哭求。

[死亡过程]
炎运功，10秒，雷爪达到射精边缘。
精液喷在紧身裤内，身体痉挛，翻白眼。

[炎离开 - 核心步骤]
炎抽回手，在雷爪背肌上擦了擦。（用尸体擦手）
"10秒，废物。"
推开尸体，像扔垃圾一样。（顺手推开）
转身离开。

[魉善后 - 核心步骤]
魉现身，叹气。
拖尸体到垃圾桶。（拖行像垃圾）
上半身塞进去，腰部卡住，腿露在外面。（腿露外面！）
脱一只鞋，拍编号G-147。（只脱一只）
用塑料袋盖上尸体下半身。（伪装成垃圾）
追上炎的脚步。
```

### 检查清单

**必须包含（核心）**：

- [ ] 炎用尸体/衣服擦手
- [ ] 炎顺手推开/踹翻尸体
- [ ] 尸体塞入容器，腿露在外面
- [ ] 魉只脱一只鞋拍照
- [ ] 整体感觉像垃圾处理

**可以写（放宽）**：

- [ ] 目标有名字（雷爪-虎兽人）
- [ ] 挣扎求饶过程
- [ ] 凶手顺手玩弄/羞辱几句
- [ ] 各种种族（包括 slender 体型）

**禁止写（底线）**：

- [ ] 背景故事（家乡、家人、梦想）
- [ ] 死亡有仪式感/价值感
- [ ] 尸体被体面处理
- [ ] 凶手专门设计复杂play
