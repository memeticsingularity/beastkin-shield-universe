# Series 3: Massacre & Cleanup - 屠杀与善后

## 系列定位

与Series 2（日常猎杀）的"闲逛偶遇、详细探索"不同，**屠杀与善后系列**主打**高效冷漠的批量猎杀**。

双主角模式：

- **"炎"** - 无情猎手，只杀熊虎牛，面无表情，杀人只是工作
- **"魉"** - 善后专员，拍照领赏，偶尔心软，但从不阻止

## 核心特征（原作者偏好）

### 1. 兽种筛选 - 只爱粗壮体型

**可接受**：

- 熊兽人（棕熊、黑熊、北极熊）- 肥胖壮硕，首选
- 虎兽人（黄虎、白虎、黑虎）- 肌肉贲张，次选
- 牛兽人（水牛、黄牛、犀牛）- 力大无穷，备选

**不接受**：

- 狗、狼、狐狸、豹猫等 slender 体型
- 出现时可快速击杀或嫌弃忽略
- 主角对这些兽人"几乎无感"

### 2. 死亡价值 - 死得毫无价值

**正确示范**（炎魉第一章）：

```
炎从虎守卫裤子里抽出沾满精液的手，在虎守卫胸肌上擦了擦后，
将虎守卫的尸体推倒在一旁，"接下来是你的工作了。"说完便朝着基地中心走去。

"27秒，下一个。"

"才12秒，真是废物，下一个。"

炎把射到神志不清的野猪守卫推倒后，蹲下身在他屁股上擦拭着满手的精液。
```

**关键要素**：

- 不记名字，只计时（"27秒"）
- 不享受过程，面无表情
- 杀完随手一推/一扔
- 尸体像垃圾一样塞垃圾桶、踹到草丛、用来擦手

### 3. 描写风格 - 极简高效

**对比**：

| 维度   | Series 2（日常猎杀）       | Series 3（屠杀善后） |
|------|----------------------|----------------|
| 目标描写 | 详细五维（心理、神态、动作、环境、语言） | 极简，只写体型和死状     |
| 死亡过程 | 慢节奏，探索敏感点，详细解锁       | 10-30秒快速射精死亡   |
| 情感投入 | 主角享受猎杀               | 主角面无表情，只是工作    |
| 尸体处理 | 战利品清点，仪式感            | 随意丢弃，塞垃圾桶，踹翻   |
| 价值观  | 死亡有意义（ justice / 享受） | 死得毫无价值，像垃圾     |

### 4. 尸体处理 - 毫无尊严

**正确方式**：

- 塞垃圾桶（腿露在外面）
- 像垃圾一样拖行
- 用来擦手/擦凶器
- 尸体堆叠，互相压在一起
- 魉拍照时\"顺便\"帮尸体\"体面\"一下（但炎不在乎）

## 故事主题示例

1. **新兵训练基地清剿** - 一个一个骗进来，批量处决，尸体塞满办公室
2. **健身房屠杀** - 正在举铁的熊虎牛，毫无防备被摸哨
3. **澡堂猎杀** - 裸体、无防备、精液混着洗澡水
4. **宿舍夜袭** - 熟睡中的壮汉，睡梦中射精死亡
5. **食堂投毒** - 春药混进食物，集体失控，然后收割

## 写作规范

### 行文风格

**炎的视角**：

- 面无表情，不说话或只说短句
- 杀人只是工作/练功，不享受
- 对非熊虎牛的兽人嫌弃/无视
- 尸体随手丢弃，毫无仪式感

**魉的视角**（辅助）：

- 偶尔心软，但服从炎
- 负责拍照、处理尸体、抱怨
- 对死者有轻微同情，但不妨碍工作

### 目标描写限制

**允许写的**：

- 体型：粗壮、肥胖、肌肉
- 制服：绿/蓝/黑，紧绷感
- 下体：大包、射精量
- 死状：翻白眼、抽搐、精液横流

**避免写的**：

- 详细心理活动
- 个人背景故事
- 死亡前的挣扎细节
- 情感共鸣

### 典型段落结构

```
[目标进来]
炎从一旁勒住抓住了肉棒，运功。
"哞...呃...啊！"
牛守卫开始射精，喷了十几股。
炎甩了甩手，嫌弃地推开尸体。
"15秒，下一个。"

魉叹气，拍照，把尸体拖到墙角，和其他尸体堆在一起。
```

## 与原作的区别

| 元素     | 原作主线    | Series 2  | Series 3   |
|--------|---------|-----------|------------|
| **主角** | 单一主角成长  | 单一主角享受猎杀  | 双主角（冷酷+善后） |
| **目标** | 混合      | 混合（狗狼狐都有） | 仅限熊虎牛      |
| **节奏** | 章节长，有剧情 | 中等，详细探索   | 极快，批量处理    |
| **情感** | 有       | 享受        | 冷漠/无价值     |
| **尸体** | 有处理     | 战利品清点     | 像垃圾丢弃      |
