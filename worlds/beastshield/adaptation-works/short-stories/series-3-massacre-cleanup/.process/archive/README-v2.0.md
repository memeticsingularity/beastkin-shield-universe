## 系列定位（v2.0）

**核心理念**：死亡毫无价值，尸体只是垃圾。

双主角模式：

- **"炎"** - 无情猎手，只杀熊虎牛，面无表情，杀人只是顺手的事
- **"魉"** - 善后专员，拍照领赏，把尸体像垃圾一样处理

**对标范本**：`bs-a-cs-4-yanliang/chapters/ch-01.md` 的 **Scene-1 墙角的窒息**

---

## 核心特征（v2.0标准）

### 1. 兽种筛选 - 仅限熊虎牛

**可接受**（必须满足）：

- 虎兽人（黄虎、白虎、黑虎）- 肌肉贲张，首选
- 熊兽人（棕熊、黑熊、北极熊）- 肥胖壮硕，次选
- 牛兽人（水牛、黄牛、犀牛）- 力大无穷，备选

**不接受**（禁止出现或可快速无视）：

- 狗、狼、狐狸、豹猫等 slender 体型
- 如果出现，炎直接无视或1秒内解决，不描写
- 魉抱怨"太瘦了没赏金"

**Scene-1正确示范**：

```
一只虎兽人守卫正沿着墙根巡逻...近三百斤的壮硕身躯，脂包肌...
炎从阴影中伸手，扣住后颈，拖入墙角。
```

---

### 2. 目标描写 - 极简主义

**允许写的**（仅限这些）：

- 体型：粗壮、肥胖、肌肉、体重（300斤+）
- 制服：绿/蓝/黑，紧绷感，白袜
- 下体：大包、勃起、射精量
- 死状：翻白眼、抽搐、精液横流
- 编号：袜底编号（如G-147）

**禁止写的**：

- ❌ 名字（只用编号，如"虎兽人G-147"）
- ❌ 个人背景（家乡、家人、梦想）
- ❌ 心理活动（害怕、回忆、期望）
- ❌ 性格特征（勇敢、胆小、善良）
- ❌ 五维描写中的心理/环境/语言（只留神态+动作）

**Scene-1正确示范**：

```
虎兽人浑身剧震，眼睛瞪大，被勒住的喉咙里发出"嗬...嗬..."的抽气声。
他的肉棒在紧身裤内急速充血、膨胀、硬挺。
不到十秒，达到了射精的边缘。
```

**（没有名字，没有背景，只有生理反应）**

---

### 3. 死亡价值 - 死得毫无价值

**核心原则**：死亡不是事件，是数据。

**正确方式**：

- **计时**："27秒"、"15秒"、"才8秒，废物"
- **不记名字**：只用编号G-147
- **不享受过程**：面无表情，只是练功/工作
- **随手丢弃**：杀完推开，像扔垃圾

**Scene-1正确示范**：

```
炎冷漠地看着地上还在轻微抽搐的尸体，抽回了右手。
手掌上沾满了精液，他随意地将手在虎兽人背肌上擦了擦。
"接下来是你的工作了。"说完便朝着基地中心走去。
```

**错误示范**（Scene-3的问题）：

```
厚朴来自南方丛林...他最大的梦想是...
才刚当上组长还没享受几天就死于非命，真是可怜。
```

**（太多背景，太多同情，死亡有了"价值"）**

---

### 4. 尸体处理 - 像垃圾一样

**正确方式**（按Scene-1标准）：

1. **塞垃圾桶/杂物堆** - 上半身进去，腿露在外面
2. **脱一只鞋拍照** - 只拍编号，不拍脸
3. **用塑料袋/破布遮盖** - 伪装成垃圾，不是尊重
4. **尸体用来擦手** - 炎用手在尸体胸肌/衣服上擦精液

**Scene-1正确示范**：

```
魉费力地将这具超过三百斤的沉重躯体拖向墙角的绿色大型塑料垃圾桶。
上半身塞进去，腰部卡在桶口，两条穿着白袜的粗壮虎腿高高翘起露在外面。
魉脱下右脚鞋子，露出袜底编号G-147，拍照。
然后翻出几个塑料袋，盖在裸露的下半身上，隐藏好。
```

**关键细节**：

- 腿露在外面（不像Series 2的"体面处理"）
- 只脱一只鞋（快速，不讲究）
- 用塑料袋盖（伪装，不是安葬）
- 垃圾桶/草丛/灌木丛（垃圾的归宿）

---

### 5. 炎的态度 - 面无表情的顺手

**核心原则**：杀人不是目的，是过程。

**Scene-1正确示范**：

- 不说废话，只计时
- 用尸体擦手（"在背肌上擦了擦"）
- 杀完就走（"说完便朝着基地中心走去"）
- 面无表情（"炎冷漠地看着"）

**炎的台词规范**（仅限这些）：

- 计时："27秒"、"15秒"、"才8秒，废物"
- 命令："下一个"、"处理一下"
- 对魉："不要多嘴"、"杀人步骤是我的事"

**禁止**：

- ❌ 心理描写（炎在想什么）
- ❌ 情感流露（享受、厌恶、同情）
- ❌ 解释动机（为什么要杀）

---

### 6. 魉的态度 - 轻微抱怨但服从

**核心原则**：只是工作，轻微不满，但不阻止。

**Scene-1正确示范**：

```
"炎，你也真是无情，杀人也不让他死得爽一点。"
（轻微责备，但不阻止，继续工作）

"是，是，知道了。"魉无奈地叹了口气。
费力的将尸体塞进垃圾桶...
```

**魉的行为规范**：

- 拍照（只拍编号）
- 拖尸（像拖垃圾）
- 偶尔吐槽（"真是的...垃圾桶太小了"）
- 但绝不阻止炎

## 故事主题示例（v2.0）

## 写作规范（v2.0）

### 典型段落结构

```
[目标出现]
一只虎兽人守卫正沿着墙根巡逻，编号G-147。
近三百斤的壮硕身躯，脂包肌，军绿色制服紧绷。

[炎偷袭]
炎从阴影中伸手，扣住后颈，拖入墙角。
左手勒颈，右手抓裆，运功。

[死亡过程]
不到十秒，虎兽人达到射精边缘。
精液喷在紧身裤内，顺着裤腿流下。
身体痉挛，翻白眼，口水流出。

[炎离开]
炎抽回手，在虎兽人背肌上擦了擦。
"27秒，下一个。"
推开尸体，转身离开。

[魉善后]
魉从阴影中现身，叹气。
拖尸体到垃圾桶，上半身塞进去，腿露在外面。
脱一只鞋，拍编号G-147。
用塑料袋盖上，追上炎的脚步。
```

### 检查清单

- [ ] 目标只有熊虎牛（ slender 体型无视或1秒解决）
- [ ] 目标没有名字，只有编号
- [ ] 没有心理描写，只有生理反应
- [ ] 没有背景故事（家乡、家人、梦想）
- [ ] 炎面无表情，只说计时
- [ ] 炎用尸体/衣服擦手
- [ ] 尸体塞垃圾桶/草丛，腿露在外面
- [ ] 魉只拍编号，不拍脸
- [ ] 整体氛围：死亡毫无价值，只是工作
