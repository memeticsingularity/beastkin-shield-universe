# 特工局毕业实习系列 / Agent Bureau Graduation Internship

> 特工局每一名正式特工，都曾有过一场毕业实习。不是笔试，不是演练，而是一场真正的处决——目标：兽盾的杂兵、干部、乃至精英。活下来，完成任务，你就是特工局的一员。活不下来……你本来就不属于这里。

---

## 系列说明

本系列以**lanse原作《毕业实习》**为风格范本，为特工局核心成员各自撰写一场毕业实习。每篇故事独立成章，可按任意顺序阅读。

**风格锚点**：短段落、快节奏、制服-白袜-精液的视觉三角、射精即死、对话标签统一为"XX道"。

## 核心差异

| 角色 | 实习气质 |
|------|---------|
| 红虎 | 年轻气盛的火焰——戏谑、张扬、留下焦痕 |
| 魔影 | 无声的玩笑——打赌、毒牙、亲吻尸体告别 |
| 老雷 | 痞气的碾压——"别浪费"，用尸体泄火 |
| 熊猫 | 慵懒的恐怖——"烦死了"，按一下就射 |
| 银 | 冰冷的实验——银针入穴，记录数据 |
| 司令 | 微笑的棋局——手套脱下的仪式感，让对方自己崩溃 |
| 白熊 | 固执的纯白——武道家的拒绝，拳头即正义 |
| 苟正 | 克制的棋盘——"别冲动"，用行政手段编织死网 |
| 教官 | 严厉的课堂——"对敌人的怜悯就是对自己的残忍" |
| 曲先生 | 文雅的余音——笛声杀人，不沾一滴血 |
| 小豪 | 饥渴的犬牙——对精液的贪欲是他的武器也是弱点 |
| 狼谣 | 灰色的微笑——用情报和身体在刀尖上跳舞 |
