# 毕业实习系列·lanse风格调优经验总结

> 2026-05-28 — 11篇全线调优完成

---

## 一、调优检查清单（最终版）

每章调优逐项自检，最终验收标准如下：

1. **角色登场公式完整**：物种→制服→体型→下体鼓包→白袜→鞋。六项缺一不可，鞋是常被遗漏的末项。
2. **对话标签统一**：全用「XX道」，禁用无标签裸引语。常用词库：笑道、说道、问道、喝道、沉声道、淡然道、淡淡道、低声道、颤声道、吼道、朗声道、苦笑道。
3. **至少一个传统触觉处决**：每章至少一场握→撸→刺激→求饶→射精的完整流程。**例外**：若角色核心设定为远程/非接触型（白熊·武道冲击、曲先生·音波、银·银针），保留其特色不破坏人设。
4. **精液参数完整**：每场射精必须写清——质地（浓精）、股数（一股接一股）、射向（喷出/渗出/溅/洇开/淌）、终态（浸透布料/积成小摊/顺着腿往下淌）。
5. **省略号格式统一**：恐惧/犹豫用三个点「。。。」汉字全角。
6. **制服等级编码准确**：军绿=G级杂兵（白袜+军绿色运动鞋）、蓝/蓝白=O级干部/组长（白袜+黑色工作靴）、**黑=O级武斗兵（黑袜+黑色军靴）**、白=枪械组（白袜）。

## 二、关键经验教训

### 2.1 制服色码是最容易踩的坑

**问题**：ch4 银中将棕熊武斗兵写成"深蓝色制服+白袜"，被原作者当场纠正——武斗兵是黑制服+黑袜。

**根因**：武斗兵（combat soldier）的黑色制服+黑袜是一个特殊规则，与普通O级干部的蓝白制服+白袜不同。这个规则在 `world-setting-reference.md` 中有明确记录但容易被忽略。

**防范**：在检查清单中增加第6项，每次调优前先核对色码表：
- 不知道配色时，优先查 world-setting-reference.md
- 不确定时问原作者，不要猜测

### 2.2 白袜母题不是可选项，是必现项

**问题**：早期调优中白袜的添加不够自觉，经常漏掉鞋袜组合。

**发现**：白袜是 lanse 风格最具标志性的母题（mother motif），每章必须出现至少一次"白袜"描写。如果场景中的守卫全是便衣（如 ch9 曲先生、ch11 狼谣），则需要通过主角自身或场景细节自然嵌入。

**技巧**：
- 正式出场守卫：白袜+对应鞋（军绿运动鞋/黑色工作靴/黑色军靴）
- 便衣暗探：便裤下可见白袜边沿，或通过动作露出白袜
- 擦拭精液时首选白袜（保留"在白袜上擦了擦手"的仪式感）
- 若守卫为武斗兵（黑袜），则通过其他守卫或场景实现白袜母题

### 2.3 对话标签的"道"系统

**问题**：早期章节大量裸台词没有对话标签。

**经验**：除以下情况外，所有直接引语都必须有「XX道」标签：
- 语气词/惨叫声（"唔——！"、"嗷——！"）
- 自言自语/内心独白（"操。"）
- 连续短句对话（可用一个标签统领多个引语）

常用搭配：
- 教学/解释：淡然道、淡淡道、沉声道
- 命令/警告：喝道、沉声道
- 恐惧/求饶：颤声道
- 愤怒/攻击：吼道、低吼道
- 自嘲/收尾：苦笑道、咧嘴笑道

### 2.4 "精液"→"浓精"的统一标准

**问题**：原始文本中大部分写"精液"而非"浓精"。

**经验**：处决场景的射精描写全部使用"浓精"，枪版/低级版可以用"稀薄的精液"作为对比。但"精液"一词保留在：
- 考官评语/正文叙述性总结（"满地的精液和尸体"）
- 非处决场景的体液描写

### 2.5 三点省略号的使用场景

**经验**：三点省略号「。。。」用于以下场景：
- 守卫在恐惧中结巴（"你。。。你别过来——"）
- 痛苦中的断续呻吟（"呃。。。呃。。"）
- 主角劫后余生的感叹（"操。。。差一点翻车了。"）

不使用三点省略号的场景：
- 正常叙述（用标准省略号……或破折号——）
- 对话正常停顿（用逗号或句号）

### 2.6 编号一致性

**问题**：所有文件都发生了文件编号与内部标题编号不一致的情况（+1偏移）。

**原因**：读写过程中文件名已编号，但内部 Markdown 标题的 #N 编号未同步更新。

**经验**：任何时候修改/添加文件，第一件事就是检查文件名的序号与内部标题的 #N 是否一致。这个应该在检查清单最前面。

## 三、角色差异化——"那股劲"的祛魅

本次调优最重要的发现：原作方法中大量使用模糊的"那股劲"来描述精槽激发机制，但每篇故事的主角应该有完全不同的能力体系。

### 分类整理

| 角色 | 技能体系 | 处决核心机制 | 关键词 |
|------|---------|-------------|--------|
| 红虎·雷炎寰 | 灼流 | 热-based 内息，有温度/剂量/累积性 | 灼流、烫、灌入 |
| 魔影·白影 | 毒素 | 生物毒/毒血/毒牙，不同起效时间 | 毒液、毒牙、渡毒 |
| 熊猫·熊墨渊 | 暗劲 | 内家功夫灌入，有"透"的属性 | 暗劲、掌劲、透入 |
| 银·狼锋 | 神经阻断 | 银针刺尾椎第三关节，切除泄压反射 | 银针、穴位、阻断 |
| 司令·德镇 | 棋局 | 陷阱+气体春药+心理操控，几乎不出手 | 棋盘、计算、效率 |
| 白熊·熊白武 | 武道冲击 | 纯粹物理冲击波引发精槽震荡 | 掌力、震荡、共振 |
| 苟正·犬正 | 药理学 | 五种给药方式，化学手段促射 | 粉末、雾化棒、钢针 |
| 教官·虎威严 | 教学击杀 | 可复制的技术示范，教给学员 | 穴位、精准、教学 |
| 曲先生·兔曲 | 音波 | 不同物种不同频率的声波共振 | 天籁、频率、共振 |
| 小豪·犬豪 | 口交 | 舌头的触觉灵敏度和精液贪食 | 含住、舔、咽下 |
| 狼谣·白狼 | 即兴求生 | 环境驱动，逮到什么用什么 | 临时、本能、急智 |

关键原则：不能用模糊的"那股劲"覆盖所有角色。每人的技能体系必须有明确的物理/生物/化学机制，且机制本身影响叙事节奏和场景设计。

## 四、触觉处决的插入决策框架

不是每章都需要一个完整的手撸处决。决策树：

```
角色是否有远程/非接触型核心设定？
├── 是：保留人设，不强行插入。备选方案：
│   ├── 通过场景设计让其他守卫触发触觉描写
│   └── 保持角色特色，用其他方式实现 lanse 风格
│   实例：白熊（非性化处决）、曲先生（远程音波）
└── 否：必须插入至少一个完整触觉流程
    ├── 查角色性格是否适合"享受"处决
    │   ├── 残忍型（魔影）：边撸边享受对方的求饶
    │   ├── 随意型（熊猫）：随手揉搓，不经意的高效
    │   ├── 教学型（教官）：边做边解说，示范性质
    │   └── 效率型（银）：快速解决，无多余动作
    └── 触觉流程模板：
        握（握住/捏住/按住）
        ↓ 撸（套弄/揉搓/画圈）
        ↓ 刺激（加速/加重/加力）
        ↓ 求饶（"别。。。别——"或"要。。。要射了"）
        ↓ 射精（多股浓精喷涌/洇开布料）
        ↓ 擦拭（在白袜上擦手）
```

## 五、常用修正模式清单

### 模式A：补全公式
```
场景：守卫出场信息不全（常见于快速叙事）
修正：物种→制服→体型→下体鼓包→白袜→鞋
注意：便衣伪装不加制服色，但保留下体鼓包+白袜+鞋
```

### 模式B：精液参数升级
```
场景："精液喷了出来"——缺质地/股数/射向/终态
修正：
  质地：精液 → 浓精
  股数：增加"一股接一股"
  射向："喷出"→"洇开布料"/"顺着腿往下淌"/"在地上积成一摊"
```

### 模式C：对话标签添加
```
场景：裸引语
修正：检查引语前一句，找到主语，添加「XX道」
注意：连续动作中的引语，标签附着在动作句中
```

### 模式D：省略号规范化
```
场景：恐惧或结巴场景使用普通逗号或破折号
修正：替换为「。。。」格式
```

### 模式E：制服色码修正
```
场景：武斗兵/普通守卫制服混淆
修正：
  G级（军绿）→ 白袜+军绿色运动鞋
  O级干部（蓝白）→ 白袜+黑色工作靴
  O级武斗兵（黑）→ 黑袜+黑色军靴
```

## 六、调优工作流效率

本次调优按以下流程执行，效率较高：
1. 读角色档案（理解能力和性格边界）
2. 读原文（标注缺失项）
3. 输出分析（按6项检查清单逐项报告）
4. 用户确认后执行调优（全文件重写）
5. 更新 plan.md 实施记录

**反思**：
- 如果能一开始就知道制服色码规则，可以省去 ch4 的返工
- 对话标签应该在第一次读稿时就全部标记，而不是逐轮补
- 白袜母题的添加应该每章都在第一轮完成，而不是靠后面补
- 在调优执行前先做全系列统一扫描，比逐章处理更能发现系统性遗漏
