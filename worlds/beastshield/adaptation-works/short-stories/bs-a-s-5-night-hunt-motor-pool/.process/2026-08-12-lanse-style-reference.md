## 一、段落节奏

### 1.1 硬规则
- 段落不超过 3 句，大部分 1-2 句一段
- 战斗/处决场景 1 句 1 段
- 段落长度是节拍工具：更短 = 紧张；更长 = 舒缓。通篇 1-2 句一段会变成一条直线
- 最长不超过 5 句

### 1.2 两种段落语法（lanse 原作验证）
- **(a) 断奏微段落**：用于射精峰值/击杀瞬间。如 `一秒……` / `两秒……` / `"噗啊！！！"` 各成一行
- **(b) 长后勤段落** (2-3句)：用于布置和善后。如拖行三百多斤身体的描写
- 几乎没有超过 3 句的纯动作段落——lanse 会在第 3 句后用声音、嘲讽或后勤思考打断

### 1.3 紧张→松弛交替
- 战斗高潮后必有信息处理或移动
- "狩猎循环"：进入 → 遇到 → 制服 → 审讯/玩弄 → 处决 → 处理
- 循环在重复中通过细微差异维持新鲜感

## 二、死法变化机制

### 2.1 伸缩策略（`positive-creation-supplement.md` §3）
所有处决共享 7 步骨架（接近→制服→侵入→运功→临界→爆发→善后）。
**失败模式 = 均匀分配（流程感/填表感）。**
**修正 = 每场选 1-2 步放大到双倍篇幅，其余 5-6 步压缩到一半。**

四种命名策略：
| 类型 | 放大步骤 | 压缩步骤 |
|------|----------|----------|
| 压抑型 | 接近+侵入 | 爆发（裤内射精） |
| 延宕型 | 临界 | 接近 |
| 反转型 | 接近（假信任） | 侵入+爆发（突袭） |
| 展示型 | 善后 | 侵入+爆发（即杀） |

### 2.2 登场公式不必每次走完（`variants.md` §1）
- 只写前两步（无需展示下体/袜时）
- 从下往上写（先展示腿/袜/鞋）
- 通过环境折射（阴影/声音/气味先行）
- 公式打散成两段（第一印象极简，接触后补充下体/白袜）

### 2.3 四个变化轴（每场必换）
- **射向**：不总是射在肚皮上——脸/墙/腿/布料吸收/车底横梁
- **视角**：正面/背后/下方/远处——不用同一个角度
- **数量标记**：不总是"十几股"——有时精确"七股"，有时聚焦总量"地上流了一大滩"
- **终态**：射完就停 / 还在滴 / 没射完就断气

### 2.4 情感弧线差异化
每名受害者的情感弧线应有至少一个"转折点"——恐惧→困惑、绝望→接受→最后一搏。
**"相邻状态之间有'落差'（恐惧→困惑是落差，恐惧→更恐惧不是）"**

### 3.1 灼流暗劲的两个变体
- 暗劲灌器（注入匕首，3秒触发，静音暗杀）
- 捏睾强射（握住睾丸→强制射精，快速制服/审讯）

### 3.2 原创扩展原则
16 种是参照系，不是封闭列表。任何能将伤害转化为性欲值的手段都可以成为新机制。
创新维度：新武器/道具、新功法/技能、新环境/场景、新怪物/生物、新体位/互动。

### 3.3 触发机制选择指南
- 标准战斗 → ①/②
- 快速处决 → ②/③
- 虐杀/折磨 → 憋精→手动/⑦
- 群杀 → ⑥/⑩
- 羞辱 → ⑦/裤内射精
- 荒诞/意外 → ⑧

## 四、主角差异化原则

### 4.1 魔影 vs 老雷 镜像模型

| 维度 | 魔影 | 老雷 |
|------|------|------|
| 处决手法 | 温柔挑逗、享受过程 | 暴力重击、追求效率 |
| 对待尸体 | 亲吻、整理、道歉 | 清洁、拖走、堆放 |
| 战斗风格 | 敏捷、偷袭、毒素 | 硬刚、内功、拳拳到肉 |
| 性格 | 轻浮戏谑 | 粗鲁不耐烦 |

黄金案例：老雷尝试模仿魔影的温柔杀法时失败——他的手太粗糙，力道控制不准。这既是角色区分也是喜剧张力。

### 4.2 处决方式 = 性格的延伸
- 老雷 = 挤残精 + 泡面强迫症式清洁（暴力的"家务化"）
- 黑石 = 数处决数量（"1、2、3……19"像数俯卧撑）
- 银 = 北斗泄阳针法
- 墨犬 = 寸止/锁精门（不杀）
- 蒙图 = 数拧脖子 + 恋尸

### 4.3 主角签名动作
每位有名杀手有独特的程序签名。泡面/擦桌是老雷专属的"家务化暴力"签名——**不可复用于其他主角**。
对灰狼猎人：签名动作为**检查脉搏确认死亡**（两指搭颈侧，三秒，松手）——冷静的"职业验收"，非洁癖，非挤残精。

## 五、过渡方式

### 5.1 Ch.1 风格：时间跳跃
- `两分钟后。`（独立成段的跳转）
- `几天后，老雷家几条街外停着一辆无主吉普车`（尾声跳转）
- 用途：当有"读者内的角色"（小雷）需要避开暴力时

### 5.2 Ch.2 风格：受害者的日常任务作为钩子
- 每段小故事以目标正在做某件普通事开头（巡逻/点烟/泡面）
- 过渡 = 空间移动 + 内心独白→下一个目标
- `这样偷偷摸摸摸索前进实在太慢了……就在这时，他看到……`
- 换装 = 场景切换（`一整套白制服完整扒下……老雷换上了一整套白制服` → 进入体训室）

### 5.3 适用规则
- 硬切：场景切换直接用，不写过渡段落
- 移动/过渡 = 1-2 句交代去向
- 环境描写不超过 3 句

## 六、对话系统

### 6.1 Ch.1 vs Ch.2 对话差异
- Ch.1 有"读者内的角色"（小雷）：对话取代描写在死亡节拍处，杀戮被柔化/审查（"喷烟花"）、喜剧化
- Ch.2 纯杀戮：对话稀疏、位置性、功能性——出现在杀戮开始时（作为伪装或触发）或作为单行嘲讽
- 受害者台词几乎全是含混不清的拟声词（`"呃……你……"` `"喔啊！啊……呃……"`），读作音效而非对话

### 6.2 不同杀手的台词频道
- 老雷：双频道——冷血杀戮 / 温柔哄娃
- 黑石：唯一与猎物聊天的杀手
- 年轻雷：校园礼貌应用于谋杀 = 黑色幽默
- 牙董：礼貌恐怖，永远句号结尾，不用感叹号
- 夜袭潜入者：波浪号"～"作为变态标记
- 灰狼：极少说话。沉默是性格。

## 七、收尸与比喻

### 7.1 收尸描写（lanse 原作 15 具尸体统计）
- 抽搐/颤抖的肢体作为"还没死透"的证明——黑袜/白袜粗腿抽搐/颤抖/打摆子出现 6 次，但每次变换执行者（膝盖/脚尖/靴尖轻敲/手指）
- 尸体伪装（死体伪装）——椅子上的打盹/泡面碗/马桶，每次是不同的**笑话**（打盹 vs. 泡面 vs. 马桶），读作连续笑料而非复制

### 7.2 "从X看"视角——lanse 基本避免
- 全两章只有两处："这样在外人看来只像在偷懒打盹一样"（伪装逻辑）、"由于棕熊全程背对着队友，其他两名武斗兵并不知道发生了什么"（战术解释）
- 这两处都是**世界内感知**，非全知叙述者视角跳跃

### 7.3 比喻规则
- 简短、频繁、几乎总是**贬低性或家务性**，从不是英雄主义：
  - `像被拎鸡仔一样`、`像烂泥一样`、`如同蛆虫一般`、`像一瓶摇晃充分的香槟`、`像蚊子咬了一下`
  - 唯一拔高的比喻：`如同啸月孤狼`（牛鞭在月光下，罕见的喜剧史诗）
- 隐喻替代明喻：`清空了弹匣`（军事=性）、`烟花秀配乐`、`花坛的废料`（死亡=肥料）
- lanse 的真正签名：**武器和家务意象应用于性和死亡**
- 每个尸体比喻独一无二，从不复用模板

## 八、"写射就停"节奏

来源：`lanse-writing-process-notes.md`

### 8.1 核心事实
- lanse 以"自嗨"模式写作：由性兴奋驱动，非叙事规划
- **"写射就停"：在即将射精时停止写作**
- **断章点 = 作者本人射精点**：章节停止的位置反映作者的生理状态，非叙事设计
- 具体实例：保姆雷 Ch.2 终止于掀尸出窗 = lanse 自己的射精点

### 8.2 文本可观察推论
- **每章是"兴奋单元"而非"情节单元"**：每章有独立的迷你高潮结构（狩猎→处决→收尾）
- **章节之间无连接义务**：保姆雷 Ch.2 以全新牛兽兵闲聊开头，与 Ch.1 结尾零叙事连接
- **断章点通常在"处理完/排出去/清扫干净"之后**，非色情描写最密集处
  - Ch.1 结束于虎尸倒插垃圾桶
  - Ch.2 结束于掀尸出窗
  - 最密集的色情描写是**中间章节**（厕所白熊场景）
- **驱动力是完成度/满足感**，非单点刺激——泡面/擦桌细节存在的原因：清理完成是 lanse"平复"的地方
- **每章需要新的"场景诱饵"**（新猎物/新地点/新弱点）——这是 lanse 场景多样化的**创作原因**（他需要新鲜刺激才能继续写）

### 8.3 对写作的启示
- 别用连载逻辑要求 lanse 的章
- **每场杀戮都应是独立的"兴奋单元"**，有新鲜的场景诱饵——新地点/新弱点/新机制
- 这就是"每场处决不重复模板"的创作原理：新鲜刺激 = 新鲜场景诱饵

## 九、常见 AI 错误清单

### 9.1 绝对禁止
| 错误 | 正确 |
|------|------|
| 通篇用"说" | 用"道"或无标签 |
| 大段环境描写（>3句） | 压缩到 3 句以内 |
| 深层心理活动 | 只写外在行为和即时身体反应 |
| 省略性描写（"一番云雨"） | 逐步骤描写 |
| 复杂对话标签（低声道/苦笑道） | 简化标签 |
| 伤口描写（兽盾世界无人流血） | 精液描写替代 |
| 角色对杀戮的长期心理负担 | 不写 |

### 9.2 体型禁用词
精瘦 / 瘦削 / 纤细 / 苗条 / 轻巧 — "兽盾世界观不存在这些词"
必须用：精壮 / 粗壮 / 壮硕

### 9.3 射精描写 AI 指纹
| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 逐股单独成行（"视觉上在'数'"） | 多股并段（视觉上像洪流） |
| 递减排号（"第五股→稀了→第六股→几乎透明"） | 增量结构（"还没落地第二股已经""一股接一股""每射一股就"） |
| 6场量级相同 | 梯度差异（7-8 → 8-9 → 10-11 → 12-13 → 9-10 → 15+） |
| 每场精液描写相同 | 四轴全换（射向/视角/数量标记/终态） |

### 9.4 公式化烙印
- 照搬特定杀手的招牌技（灼流暗劲 = 老雷专属；泡面/擦桌 = 老雷签名）
- "从X看像Y"模板重复（lanse 每个尸体比喻独一无二）
- 千篇一律的情感模板（恐惧→羞耻→快感→死亡的平线，没有转折点）
- 登场公式每次都走完 7 步（应该按需伸缩，打散分段）

## 十、"疼→爽"转换：灰狼处决机制的感官签名

灰狼的精准解剖打击与灼流暗劲的核心区别：

| 维度 | 灼流暗劲（老雷） | 精准打击（灰狼） |
|------|------------------|-------------------|
| 能级来源 | 修炼内功（师父传承） | 解剖知识+落点精度（后天训练） |
| 传导路径 | 热流→掌心→前列腺 | 冲击力→接触点→组织损伤→性欲值转化 |
| 受害者第一感受 | 灼热/温热包裹 | 钝痛/闷痛/刺痛 |
| 转换过程 | 直接从热到射精冲动 | 先疼 → 疼在腹股沟变质 → 酥麻热潮 → 射精 |
| 速度 | 快（直接刺激前列腺） | 稍慢（需要损伤→转化时间差） |
| 武器兼容 | 暗劲灌器（匕首） | 纯徒手（掌根/指节/拳峰） |
| 杀后动作 | 挤残精 + 清洁 | 检查脉搏（两指颈侧，三秒） |

### 感官词汇体系
- **打击面**：掌根 / 指节 / 拳峰
- **力道动词**：贯穿 / 炸开 / 渗透 / 灌入
- **初始感受**：钝痛 / 闷痛 / 刺痛 / 胀痛
- **转换动词**：变质 / 化成 / 溶成 / 翻了天
- **最终感受**：酥麻 / 热潮 / 痉挛性快感 / 排精冲动
