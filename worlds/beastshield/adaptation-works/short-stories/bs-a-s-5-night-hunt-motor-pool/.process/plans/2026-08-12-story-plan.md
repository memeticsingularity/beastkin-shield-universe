# 创作计划：《车场夜狩》/ Night Hunt at the Motor Pool

> 计划日期：2026-08-12
> 故事编码：bs-a-s-5-night-hunt-motor-pool
> 目标：创作一个能让 lanse "写射就停"的兽盾处决短篇

---

## 1. 故事概念

**一句话钩子**：灰狼赏金猎人夜袭兽盾车辆调配场，六名夜班兽盾兵，六种死法，一个文件夹。

**核心设计理念**：
- 每个受害者有独特的人类瞬间（食物、电话、计划、习惯），死亡前被捕捉
- 六种完全不同的处决方式（呼应老雷16杀16种死法的模式）
- 按照"写射就停"节奏：死法逐步升级，最后一名受害者（目标）最详细
- 短段落快节奏，物理细节优先，无心理内省
- 事后收尸/摆设美学

## 3. 场景流程与死法升级

```
门岗(快速无声) → 机修工(车底作业) → 清洁工(背后) → 巡逻兵(搏斗) → 休息室白虎(人类瞬间) → 调度员(审讯高潮)
   ↑ 入门暖场        ↑ 机械化          ↑ 一丝怜悯     ↑ 动作戏        ↑ 人类味最浓            ↑ 最终高潮=写射就停点
```

## 4. lanse 风格检查清单

参照 `.process/plans/2026-06-10-lanse-style-tuning-plan.md` 的12步调校流程：

- [ ] **世界观机制**：无流血伤口（灼流暗劲不流血），G级背景"包吃住就去"的个体选择
- [ ] **段落拆分**：每段≤3句，战斗1句1段
- [ ] **环境压缩**：场景描述≤3句
- [ ] **心理删除**：只保留即时身体反应，无深层心理
- [ ] **登场公式**：每角色首次出场→物种+制服色+毛色+体型+下体鼓包+白袜+鞋
- [ ] **白袜检查**：每场至少1次白袜/黑袜描写
- [ ] **处决流程完整**：制服→刺激→求饶→射精→死亡确认
- [ ] **精液四参数**：股数+方向+质地+终态
- [ ] **词汇替换**：说→道，……→。。。，规范用字
- [ ] **空行确认**
- [ ] **种族限制**：熊虎牛猪犬科（全符合）
- [ ] **体型铁律**：精壮/粗壮/壮硕，不用精瘦
- [ ] **无"她"**：全文只用"他"
- [ ] **生父称谓**：无"母亲"

## 6. 特殊注意事项

- **"写射就停"节奏**：调度员的死是整篇的性高潮——最详细的憋精过程、最长的折磨、最完整的精液描写。此后的收尾干净利落，不拖沓。
- **尸体摆设**：每个死者都有"事后造型"——门岗像睡着、机修工推回车底、清洁工靠着拖把、巡逻兵靠在车头、白虎头在泡面碗旁、调度员瘫在椅子里。
- **主角不废话**：灰狼猎人极少说话，动作推进一切。与老雷的"黑色幽默"形成对比——这是lanse认可的另一种主角类型（冷面专业户）。
- **没有结局反转**：lanse的故事不需要道德反思或叙事转折。任务完成，故事结束。
