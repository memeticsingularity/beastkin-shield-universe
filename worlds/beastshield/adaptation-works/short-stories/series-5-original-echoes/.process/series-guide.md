# 原作回响系列 · 创作指南

> 本文档记录系列的核心创作规范，供后续篇章参考。

---

## 一、系列定位

原作回响系列是**基于兽盾原作剧情拓展的支线短篇**。每一篇选取原作中一闪而过的配角，从其第一人称视角重新经历那段剧情——直到死亡来临。

### 与其他系列的区别

| 系列 | 视角 | 核心体验 |
|------|------|---------|
| 哨兵清除/日常猎杀 | 特工/猎人 | 杀人者的爽感 |
| 屠杀与善后 | 第三人称远距离 | 死亡的无价值美学 |
| **原作回响** | **受害者第一人称** | **猎物死前的内部体验** |

### 核心原则

1. **不改变原作剧情**——角色的死亡方式和结局已被原作注定，本系列不另辟IF线
2. **不洗白角色**——虎就是勒索新人的地痞，不需要让他"其实是个好人"
3. **补全而非篡改**——补充原作未写的内心活动，但不推翻已写的外部行为

---

## 二、选角标准

### 必备条件

- [ ] 在原作中有明确的场景（有台词或动作）
- [ ] 死亡已被原作记载（本系列不倒叙已死角色）
- [ ] 有足够的文本线索支撑人物塑造（至少能推断性格、物种、等级）

### 优先选择

- 无名的杂兵（只有"一只XX兽人"这种称呼）
- 在原作中只有1-2个段落的角色
- 其死亡涉及处决/性行为（符合本系列的风格定位）

### 候选池（待挖掘）

|------|---------|---------|

## 三、角色预研流程

> 本节的流程源自 `12d4aa6` 的实践经验：先对原作章节做完整分析，再提炼角色，最后动笔。
> **原则：完成预研文档前，不开正文文件。**

### 步骤 1：原作章节分析

选定角色后，先在 `ai-discussion/` 或 `plan/` 下创建一份分析文档，命名格式：
```
YYYY-MM-DD-chX-[章节名]-[角色名]-analysis.md
```

文档必须包含：
- [ ] **出场段落定位**：角色在原作中的每一句话、每一个动作对应的原文位置
- [ ] **台词摘录**：逐句抄录，标注说话对象与语气
- [ ] **动作细节**：制服状态、身体姿态、与其他角色的空间关系
- [ ] **死亡方式**：与原作严格一致的处决/死亡描写
- [ ] **尸体处理**：原文如何描述尸体的最终去向
- [ ] **环境线索**：时间、地点、在场其他角色

### 步骤 2：角色提炼

基于原作分析，整理出角色的核心档案：

| 维度 | 必须明确 |
|------|---------|
| 物种 | 具体到亚种（橙虎≠黄虎） |
| 等级 | G/E/R/O/W，对应制服色 |
| 体格 | 与参照角色的对比（如"与黑牛同样体型"） |
| 薪资 | 查 `world-setting.md` 确认，不写模糊数字 |
| 宿舍/工作地位 | 附庸？主导？独来独往？ |
| 语言习惯 | 粗口频率、对上级/平级的语气差、有无口头禅 |
| 核心恐惧 | 死亡本身？疼痛？被同伴嘲笑？被发现软弱？ |
| 与凶手的关系 | 完全不认识？听过传闻？有过交集？ |

### 步骤 3：日常循环建立

写出角色在死亡当天（或前一天）的 `daily loop`：
- 几点起床，穿什么，去哪，遇到谁
- 宿舍内的权力互动（谁说了算，谁是附庸）
- 工作/休息时的固定路线
- **这个日常将在故事第一节被还原**

### 步骤 4：预研完成检查清单

- [ ] 分析文档已创建，且不少于 100 行
- [ ] 角色六维档案已填写
- [ ] 日常循环已写出，包含至少 3 个具体场景
- [ ] 死亡场景与原作逐句核对，无矛盾
- [ ] 与系列现有角色无设定冲突

**以上全部完成后，才能进入第四节的故事结构模板开始正文写作。**

## 四、原作约束（不可违反）

### 死亡方式

角色的死亡方式必须与原作严格一致。例如橙虎的死亡是"被小豪口杀，精液全吞"，就不能改成"被拧断脖子"或"边射边被掐死"。

### 死亡顺序

如果原作明确记载了死亡顺序（如虎先死→牛后到→牛再死），则顺序不可颠倒。

### 尸体处理

身体处置方式须与原作一致（如虎和牛的尸体在垃圾桶里）。

### 角色关系

角色之间的权力关系、亲疏关系不可改变。虎是牛的附庸这一设定不可改为"两人平等"或"虎主导"。

---

## 五、视角规则

### 基本要求

- 全程第一人称（"我"）
- 感官描写必须包含视觉、触觉、听觉，尽量包含嗅觉
- 心理活动保持在**即时反应层面**（恐惧/惊讶/困惑/兴奋），不深入人生反思或哲学思考

### 允许的POV跳出

- 主角死亡后，可切换为另一个角色的第一人称尾声（如橙虎篇的清洁工视角）
- 尾声应简短，3-5段内结束
- 尾声应起到"确认死亡+展现尸体处理"的功能

### 禁止的POV行为

- 不要在主角死亡前切换到其他角色的视角
- 不要使用全知第三人称叙述主角不知道的信息

## 六、风格边界

### 必须严格遵循的 lanse 风格标记

- [ ] **白袜**每章至少出现1次（穿在角色腿上的）
- [ ] **新角色登场走完公式**：物种→制服色→体型→下体→白袜→鞋
- [ ] **对话标签统一用「道」**（说道/问道/吼道/笑道/喃喃道）
- [ ] **省略号表恐惧/犹豫**，格式为三个点「。。。 」
- [ ] **射精描写写清**：量（多少股）、射向（何处）、质地、终态
- [ ] **处决流程完整**：制服→刺激→求饶→射精→死亡确认
- [ ] **段落不超过3句**，大部分1-2句一段

### 可以有限度深化的方向

- **受害者心理**：在原作基础上增加濒死时的恐惧和挣扎（但保持即时反应层面）
- **环境描写**：比lanse稍丰富，但不超过3句
- **角色语体差异**：不同杂兵可以有略微不同的说话方式

### 绝对避免的风格破功

- ❌ 用「说」作对话标签
- ❌ 省略性描写（"一番云雨"类）
- ❌ 流血/伤口描写（兽盾世界没人流血）
- ❌ 深层心理活动或哲学思考
- ❌ 复杂对话标签变体（低声道/苦笑道/幽幽地说等）

## 七、故事结构设计原则

> 本节取代固定八节模板。每个角色的故事结构应**因地制宜**，根据角色类型、死亡场景、处决者特征灵活设计。
> 以下是常见结构要素，按需选取，不强求全用，也不限定顺序。

### 常见结构要素

| 要素 | 适用场景 | 功能 |
|------|---------|------|
| **日常建立** | 角色有固定生活轨迹（宿舍、巡逻、食堂） | 让读者先"认识"这个角色 |
| **异常触发** | 角色因偶然/好奇/无聊卷入事件 | 解释"为什么是他" |
| **与猎手交集** | 角色在死前与凶手有多次接触 | 建立心理张力 |
| **信息暴露** | 角色听到/看到不该知道的事 | 解释死亡的必然性 |
| **被捕/被困** | 角色失去行动能力（中箭、被堵、被制服） | 制造无处可逃的绝望 |
| **处决过程** | 核心场景，必须保留 | 制服→刺激→求饶→射精→死亡 |
| **尾声·收尸** | 有第三方处理尸体时 | 确认死亡+体现尸体美学 |

### 设计原则

1. **先问三个问题再动笔**
   - 这个角色死前经历了什么？（日常→异常→死亡，还是直接死亡？）
   - 处决者是什么类型？（施虐型/不情愿型/工具型/被操控型）
   - 尸体由谁处理？（凶手本人/清洁工/无人问津）

2. **因角色制宜**
   - 宿舍恶霸（如橙虎）→ 需要日常建立+权力展示+反转死亡
   - 偷听杂兵（如 ch-10 虎）→ 不需要日常，从"无聊闲逛"直接切入
   - 被操控者（如 ch-4 狼）→ 重点在"失控感"，而非恐惧

3. **因处决者制宜**
   - 小豪型（捕食者）→ 受害者恐惧+挣扎+被吃掉
   - 大奔型（不情愿灭口）→ 受害者的困惑（"他明明不想杀我"）+ 死亡本身的荒诞
   - 儡部长型（施虐权力）→ 受害者的羞辱+绝望

4. **因场景制宜**
   - 宿舍/教室（封闭空间）→ 压抑、无处可逃
   - 荒林/野外（开放空间）→ 孤立、被追捕的绝望
   - 课堂/测试（体制空间）→ 体制性暴力、无力反抗

## 八、修订流程

当收到修改意见时，按以下优先级处理：

1. **原作剧情不符**（最严重）——立即修正，因为违反核心原则
2. **世界观设定错误**（如薪资、制服等级、宿舍结构）——查证后修正
3. **风格不一致**（对话标签、白袜缺失、省略号格式）——逐条修正
4. **心理表现不足**（角色太冷静、缺乏挣扎）——补充即时反应
5. **感官缺失**（缺某种感官描写）——补充

### 修订记录规范

每次修订后，在对应的 `plan/[故事名].md` 中追加一条修订记录，格式：
```
### 2026-XX-XX · 修订摘要

- 修正了xxx问题
- 因为：xxx原因
- 改动：xxx（简要说明）
```
