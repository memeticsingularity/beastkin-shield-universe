# Series 2 日常猎杀 - 角色画像档案库

> **核心原则**：他们在故事里只活了十五分钟，但在这个文档里，他们值得拥有完整的人生。

---

## 一、档案库说明

### 1.1 这是什么

本文件夹存放《兽盾·日常猎杀》系列（Series 2）全部已登场角色的完整人物画像。

与故事中作为"狩猎目标"的功能性存在不同，这里的每一个角色都被视为**完整的人**——他们有童年、家庭、梦想、秘密、遗憾，有属于自己的十几二十年兽生。

### 1.2 创作理念

**不是一次性配角，而是完整的人**

- 他们在故事中可能是背景、是数字、是"绿制服杂兵"
- 但在这里，他们有名字、有编号、有过去、有未来
- 他们爱过、怕过、希望过、失望过
- 他们死亡那天，本来都有各自的计划

### 1.3 文档用途

1. **创作参考**：为新故事创作提供角色原型和关系网络
2. **情感锚点**：理解每个角色的XP设计背后的人生逻辑
3. **世界填充**：让兽盾宇宙更加真实、有血有肉
4. **纪念**：记录每一个来过这个世界的生命

## 四、世界观速查

### 4.1 兽盾公司等级制度

| 等级 | 英文代号 | 编号格式 | 月薪 | 赏金 |
|-----|---------|---------|------|------|
| G级（杂兵） | Grunt | G-[自然数] | 100撸币 | 100撸币 |
| O级（监工） | Overseer | O-[自然数] | 200撸币 | 200撸币 |
| E级（武斗兵） | Enforcer | E-[自然数] | 500撸币 | 500撸币 |
| R级（枪械兵） | Ranged | R-[自然数] | 500撸币 | 500撸币 |
| W级（摔跤兵） | Wrestler | W-[自然数] | 1000撸币 | 1000撸币 |

### 4.2 G级绿制服标准

- **上衣**：军绿色短袖，两侧金色竖线，左胸白色兽盾LOGO（盾牌状），背部黄色"SHIELD"字样
- **短裤**：军绿色，两侧金色竖线
- **白袜**：白色长筒袜，袜口军绿色条纹，袜底印编号（如NO.892）
- **鞋子**：军绿色运动鞋

### 4.3 核心机制

**精槽系统**
- 所有伤害转化为性欲值（精槽）
- 精槽达到100% → 射精死亡
- 性行为豁免：特定性行为场景中射精不会死亡
- 精槽传递：性行为中射精方可将精槽值传递给对方

**详细资料解锁**
- 条件：控射至边缘（90%左右）并刺激特有敏感部位
- 效果：解锁属性值、人物技能、习性
- XP类型因人而异，与人生经历相关

## 五、创作原则

### 5.1 角色画像必备要素

每个角色画像必须包含：

1. **肖像定格**：外貌、此刻状态、气质
2. **制服状态**：细节观察、制服背后的故事
3. **人生长卷**：出生成长、加入兽盾前、在兽盾的日子
4. **这个人**：性格、他在意什么、他不知道的事、只有他知道的秘密
5. **他的世界**：重要的人、日常、今天（死亡那天的计划）
6. **故事里的他**：故事中的样子、XP敏感机制、死亡时刻
7. **如果他活下来**：平行人生的可能性

### 5.2 XP设计原则

**不是随机分配，而是人生映射**

- 每个XP都必须与角色的人生经历有逻辑关联
- XP触发时的反应应该反映角色的心理状态
- 敏感点不仅是生理的，更是心理的

**示例**：
- 格雷（大灰熊）：腹部被压迫敏感 → 源于童年背弟弟的记忆（"被压住=我在保护谁"）
- 哈克（鬣狗）：后颈被控制敏感 → 源于鬣狗族幼崽服从本能与渴望被允许软弱的矛盾
- 阿凯（豹猫）：兽耳根部敏感 → 源于长期被妻子忽视后对"被关注"的渴望

### 5.3 死亡那天的计划

**重要**：每个角色都必须有"今天本来的计划"

- 这让他从"猎物"变成"有生活的人"
- 这让死亡有了重量
- 这让读者（或作者）感到惋惜

**示例**：
- 格雷：今天是弟弟三十岁生日，口袋里有一块小熊形状的石头
- 哈克：今天打算对里科说"谢谢你"
- 赤焰（狐狸）：今天是他值夜班的最后一天，明天就换白班了
