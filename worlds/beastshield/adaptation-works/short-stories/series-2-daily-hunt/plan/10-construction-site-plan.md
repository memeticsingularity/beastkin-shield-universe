# 日常猎杀：工地陷阱 —— 写作计划

## 版本记录

- **v1.0** (2025-03-18): 初始版本，单人目标（大灰熊兽人），简单击杀
- **v2.0** (2025-03-18): 扩展为小队规模（12人），利用工地结构逐个暗杀，多样化击杀方式

---

## 一、故事大纲

### 核心概念
主角探索施工中的建筑工地，发现一只**兽盾绿制服杂兵**正在偷懒午睡。利用建筑工地的复杂结构（脚手架、未完工的楼层、电梯井），布置陷阱或利用地形优势将其击杀。

### 章节结构（偶遇式）
```
开场（20%）：探索工地 → 发现偷懒午睡的目标
观察（25%）：分析工地结构 → 选择最佳伏击点
埋伏（20%）：利用地形设伏 或 直接接近
击杀（30%）：脚手架/电梯井/水泥堆 处决
战后（5%）：搜刮后离开
```

## 三、关键情节点

### 1. 探索工地（约500字）
- 主角闲逛到一片施工区域，好奇心驱使进入
- 工地看似无人，但听到打呼噜的声音
- 发现一只**大灰熊兽人**躺在水泥堆上睡觉，旁边散落着零食包装

### 2. 观察环境（约600字）
- 主角分析工地结构：
  - 脚手架纵横交错
  - 未完工的楼层边缘无护栏
  - 电梯井深不见底
  - 堆放着钢筋和水泥袋
- 内心OS："这地方简直是天然猎场"
- 选择最佳方案

### 3. 方案选择（写作时可二选一或结合）

**方案A：高空坠落**
- 主角爬上脚手架，悄悄接近
- 大灰熊睡得正香，口水直流
- 主角一脚将他踢下未完工的楼层
- 坠落过程精槽暴涨，落地射精死亡

**方案B：重物砸击**
- 主角在上方楼层，推动堆放的钢筋
- 钢筋滚落砸中大灰熊
- 被压住无法动弹，主角补刀
- 射精死亡

### 4. 击杀（约900字）
- 实施伏击，大灰熊惊醒但已来不及
- 精槽快速上涨，射精
- 尸体姿势（坠落摔成大字/被钢筋压住）
- 撸下白袜（编号NO.666）

### 5. 战后（约200字）
- 搜刮战利品
- 主角看了眼工地："好地方，下次再来。"
- 离开

# v2.0 详细规划（小队规模版本）

## 一、故事大纲（v2.0）

### 核心概念
主角探索施工中的建筑工地，意外发现一整支**兽盾绿制服小队（12人）**正在午休偷懒。他们分布在工地的不同位置——有的在午睡，有的在打牌，有的在放哨。主角利用脚手架、电梯井、钢筋堆等建筑结构，像战术游戏一样逐个暗杀，制造"意外事故"的假象。

### 章节结构（v2.0 - 偶遇式）
```
开场（10%）：探索工地 → 发现12人小队分布
观察（15%）：分析敌人位置、状态、相互关系
战术规划（10%）：制定击杀顺序和路线
第一击（10%）：大灰熊兽人 - scaffolding坠落/重物砸击
第二击（10%）：两只鬣狗兽人 - 暗处割喉（牌桌）
第三击（10%）：杜宾犬兽人（哨兵）- 偷袭刺杀
第四击（15%）：一楼三人组 - 电梯井推下+割喉
第五击（15%）：三只野猪兽人 - 睡梦中处决
第六击（10%）：两只狼兽人 - scaffolding绞杀
战后（5%）：搜刮12双白袜，获得称号
```

## 三、关键情节点（v2.0 详细版）

### 1. 探索发现（约800字）
- 主角闲逛进入工地，被脚手架结构的复杂性吸引
- 听到多重声音：打鼾声、打牌声、聊天声
- 悄悄侦查，发现**12人小队**分布在三个楼层
- 内心OS："这是送上门的大礼包"
- **系统提示**：发现可击杀目标×12

### 2. 观察分析（约1000字）
- 详细描写每个敌人的位置和状态
- 分析相互之间的视线联系和可能的警报传播路径
- 制定击杀优先级：先解决孤立的、无防备的
- 标记可利用的环境元素：
  - 松动的scaffolding踏板
  - 深不见底的电梯井
  - 成捆的钢筋
  - 噪音掩盖（搅拌机、打鼾声）

### 3. 第一击：队长之死（约1200字）
- **大灰熊兽人**体型庞大，躺在水泥堆上鼾声如雷
- 主角爬上三楼，发现上方的scaffolding有一块松动踏板
- 轻轻踩住一端，计算角度和力度
- 蹬踏！踏板和钢筋一起坠落
- 大灰熊惊醒但来不及躲避，被钢筋和木板钉在水泥堆上
- 木板压住胸口无法惨叫，精槽上涨，射精死亡
- 尸体被建筑材料掩埋，看起来像意外事故
- 撸下白袜（NO.601）

### 4. 第二击：牌桌双杀（约1200字）
- 两只**鬣狗兽人**在角落专心打牌，背对着外界
- 主角从阴影中摸过去，他们正在争吵输赢
- 第一只：左手捂嘴，右手割喉，精槽瞬间爆满，射精扑倒在牌桌上
- 第二只还没反应过来，同样从背后割喉
- 尸体摆成趴在牌桌上的姿势，精液把牌浸湿
- 撸下白袜（NO.602、NO.603）

### 5. 第三击：哨兵刺杀（约800字）
- **杜宾犬兽人**半睡半醒，眼皮打架
- 主角从scaffolding爬下，落在他身后
- 他转头瞬间，匕首刺入心脏
- 精槽上涨，射精，尸体靠墙滑坐，像在打盹
- 撸下白袜（NO.604）

### 6. 第四击：一楼三人组（约1500字）
- **豺狼兽人**察觉楼上太安静，起身查看
- 主角埋伏在楼梯转角，一脚踹入电梯井
- 惨叫声在深井中回荡，然后"砰"的一声
- 两只**斗牛犬兽人**惊动，冲过来查看
- 主角利用阴影，先击杀B（割喉），再用钢筋砸死A
- 三只白袜（NO.605-607）

### 7. 第五击：睡梦中处决（约1200字）
- 三楼三只**野猪兽人**还在睡，其中一只说梦话"红烧肉"
- 第一只：后颈刺入，睡梦中死亡，射精
- 第二只：同样方式，睡梦中死亡
- 第三只：惊醒睁眼，但喉咙已被割开，精槽瞬间爆满，精液喷涌
- 三只白袜（NO.608-610）

### 8. 第六击：绞杀双狼（约1500字）
- 两只**狼兽人**终于惊醒，闻到血腥味
- "有敌人！"但他们发现时已经太迟
- 主角从scaffolding跃下，踢中一只，脖子卡在钢管间，颈椎断裂，射精悬挂
- 另一只想逃，被钢丝套索吊起，双腿乱蹬，精槽上涨，精液滴落
- 松开钢丝，尸体落下
- 两只白袜（NO.611、NO.612）

### 9. 战后搜刮（约800字）
- 十二具尸体分布在工地各处
- 逐个搜刮白袜，精液和鲜血混合的淫靡场景
- **系统提示**：击杀×12，经验值×600，战利品白袜×12
- **系统提示**：等级提升至15级，获得称号【工地清道夫】
- 主角满意地环顾猎场，翻墙离开
