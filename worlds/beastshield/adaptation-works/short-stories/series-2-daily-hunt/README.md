# Series 2: Daily Hunt - 日常猎杀系列

## 系列定位

与 Series 1（哨兵清除系列）的潜行暗杀不同，**日常猎杀系列**聚焦于主角在大世界闲逛探索时偶遇目标，以更轻松、更直接的方式猎杀兽盾员工。没有任务驱动，纯粹是"看到猎物就下手"的自由猎杀。

## 与 Series 1 的区别

| 维度 | Series 1: Sentry Elimination | Series 2: Daily Hunt |
|------|------------------------------|---------------------|
| **任务性质** | 特工局秘密任务，潜入据点清除哨兵 | 大世界偶遇，自由猎杀 |
| **目标类型** | 固定据点（仓库/哨站/营地） | 巡逻队/落单目标/临时据点 |
| **战斗风格** | 潜行为主，一击必杀 | 可潜行也可正面迎战 |
| **故事节奏** | 紧张刺激，有剧情悬念 | 轻松爽快，纯享受战斗 |
| **敌人配置** | 有Boss战，敌人数量固定 | 多为杂兵，随机遭遇 |

## 故事主题示例

1. **巡逻队截杀** - 闲逛时目击巡逻队作恶，临时起意为民除害
2. **落单肥羊** - 偶然发现独自外出的兽盾员工，顺手猎杀
3. **醉酒猎场** - 路过酒吧时看到醉酒的兽盾员工，跟上去下手
4. **后巷偶遇** - 在偏僻小巷偶遇落单目标，即兴截杀
5. **仓库偷袭** - 探索仓库区时发现正在休息的兽盾小队

## 命名规范

- 计划：`XX-title-plan.md` (如: 01-patrol-intercept-plan.md)
- 故事：`XX-title-story.md` (如: 01-patrol-intercept-story.md)

## 文档版本管理规范

### Plan文件的更新规则

**重要：不要直接修改原plan内容！**

当需要调整故事规划时，应在plan文件末尾追加版本更新记录：

```markdown
## 版本记录

- **v1.0** (日期): 初始版本，原方案描述...
- **v2.0** (日期): 第一次更新，修改内容...
- **v3.0** (日期): 第二次更新，修改内容...
```

**示例：**
```markdown
- **v1.0** (2025-03-18): 初始版本，任务式结构（接受委托→限时击杀→回公会领赏）
- **v2.0** (2025-03-18): 重构为偶遇式，主角大世界闲逛主动发现目标，无任务驱动
```

### Story文件的更新规则

**后缀版本管理**：通过后缀 `_v1`, `_v2` 等标识版本，旧版本迁移到 `history/` 文件夹。

**文件命名规则：**
- `XX-title-story_v1.md` - 第一版（首次创作）
- `XX-title-story_v2.md` - 第二版（第一次修改）
- `XX-title-story_v3.md` - 第三版（第二次修改）
- ...以此类推

**目录结构示例：**
```
story/
├── 02-drunk-hunt-story_v2.md      # 当前最新版（偶遇式）
├── 03-patrol-intercept-story_v2.md
└── history/
    ├── 02-drunk-hunt-story_v1.md  # 旧版（任务式）
    └── 03-patrol-intercept-story_v1.md
```

**工作流程：**
1. 第一次写 → `02-drunk-hunt-story_v1.md`
2. 修改时 → 创建 `02-drunk-hunt-story_v2.md`
3. 归档旧版 → 将 `v1` 移动到 `history/` 文件夹

**好处：**
- 一眼就能看出当前是第几版
- 旧版本有迹可循，不会直接消失
- 没有软链接，跨平台兼容

## 写作规范

### 行文风格指南

本系列使用**原作者写作风格**，具体规范参见：

📄 [`worlds/beastshield/original-archives/ai-discussion/insights/writing-style-guide.md`](../../../../../original-archives/ai-discussion/insights/writing-style-guide.md)

**核心要点**：
- **第一人称口语化**：直播式叙述，弹幕吐槽
- **精槽系统**：所有伤害转化为性欲值，满槽射精死亡
- **XP元素**：白袜编号、精液分布、粗壮下肢、尸体美学
- **游戏元认知**：系统提示、存档/读档、属性点分配
- **死亡仪式感**：控制→挑逗→突破→射精死亡的完整流程

### 与原作的区别

虽然仿原作者风格，但本系列（Daily Hunt）与原作主线章节有以下区别：

| 元素 | 原作主线 | 本系列 |
|------|---------|--------|
| **目标来源** | 特工局/剧情推动 | 大世界闲逛偶遇 |
| **故事长度** | 完整章节（5000+字） | 以内容丰富为主，字数上不封顶 |
| **剧情深度** | 有世界观揭秘/角色成长 | 纯战斗/轻松向 |
| **敌人配置** | 混合杂兵+Boss | 多为杂兵，偶有精英 |
| **结尾** | 悬念/新机制解锁 | 搜刮战利品/升级/无缝继续探索 |
