# bs-a-s-4-babysitter-lei · 扩写计划

> 基于原作 bs-o-cs-3 第107–115行的楼下双牛兽人对决段落进行战斗场景扩写。
> 扩写目标：保持原作笔风，将"两分钟搞定"的摘要展开为有质感的具体场景。

---

## 一、扩写范围划定

### 1.1 选段理由

原文第107–115行是**全篇唯一的摘要式跳转**：

```
老雷出门继续狩猎。

两分钟后。
"呃！"
"啊！"
楼下传来两声闷哼，老雷扛着两具牛尸回到浴室。
（叙述总结：一拳一个打射，高级兵，一脸疑惑地射进裤裆）
```

其他所有战斗段落（熊·浴室、棕熊·小雷房间、虎·求饶反转）均有完整的场景描写——只有这里用了"两分钟后"的跳切。这并非笔力不足，而是叙事节奏的主动选择（快速收束中层敌人，赶在天亮前处理最后一个入侵者）。扩写的目标是**在不破坏叙事节奏的前提下，补足这个跳切的内容**，而非推翻原来的节奏判断。

### 1.2 边界定义

- **起点**：老雷确认熊死透 → 出门下楼（紧接原文第107行"安心地出门继续狩猎"）
- **终点**：老雷扛着两只牛兽人推开浴室门（接回原文第112–115行的扛尸描写 + 叙事总结）
- **不触及**：浴室内的剧情、小雷的反应、虎兽人段落

---

## 二、设计要点

### 2.1 叙事功能

扩写段落需要完成以下叙事任务：

1. **展示"高级兵"的实力**——原文说"以一敌十"，但读者没看到他们的表现。需要让他们在溃败之前展现出至少一点专业素养（站位、反应、战斗动作）
2. **双杀方式的区分**——两只牛兽人不能死法雷同。第一只强调"未察觉即被制伏"的碾压感；第二只强调"有反应、有应对、但仍然无用"的反差
3. **收束到原文"一脸疑惑"的评价**——这是 lanse 标志性笔触，扩写后的场景应该自然导向这个结论
4. **不破坏老雷的人物一致性**——他的实用主义（怕弄脏地板、不让孩子看到）、战斗风格（一击制敌、不留隐患）

### 2.2 写入方向

| 方向 | 选择 | 理由 |
|------|------|------|
| 第一只用什么招式 | **掌贴后腰**（与楼上熊的技巧联动） | 老雷的灼流暗劲有多种运用方式，掌贴是"从容版"，呼应楼上熊的处理但过程更短 |
| 第二只用什么招式 | **寸劲拳**（应原文"一拳一个"） | 原文明确写了"一拳一个"，第二只必须用拳。寸劲是武术概念，贴合"武林高手"设定 |
| 第二只是否有战斗反应 | **有——翻滚、拔刀、冷静应对** | 展示"高级兵"水平的最佳方式：让对方展现出反击能力，再让他连反击的机会都没有 |
| 是否加新对话 | **仅一句**（"不错，这把刀倒是好钢"） | 老雷不是话多的人，但偶尔一句轻描淡写的评价，比长篇嘲讽更有压迫感 |
| 是否描写精液气味 | **是——第二只通过气味察觉异样** | 这是 lanse 风格的感官层次，也顺便活用牛兽人的嗅觉/战斗经验 |
| 收尸检查 | **检查地毯湿痕** | 延续前文的"方便清理"强迫症，强化老雷的人物一致性 |

### 2.3 不被写入的方向

以下方向在构思时被排除：

| 方向 | 排除理由 |
|------|---------|
| 牛兽人之间的对话 | 他们在搜索任务中保持静默才符合专业素养，开口说话会削弱"高级兵"的印象 |
| 激烈的打斗（多回合攻防） | 和老雷的战斗风格冲突——他的优势是秒杀，不是缠斗。多回合反而削弱压迫感 |
| 小雷视角下楼偷看 | 原文已说明"不想让小雷看到更多"，而且小雷从小板凳上跑下来会破坏"陪叔叔玩"的设定 |
| 第三人称叙事转为牛兽人视角 | 全文始终跟随老雷/小雷视角，插入敌人POV会破坏叙事统一性 |

## 三、笔风对照清单

扩写中逐项对照以下 lanse 风格要素：

- [x] **战斗力反差**：先塑造高级兵的实力，再被秒杀
- [x] **"一脸疑惑"具象化**：牛兽人至死不理解发生了什么
- [x] **物种特征**：牛尾抽搐、牛兽人体味
- [x] **老雷的实用主义**：检查地毯、评估明天让特工局换
- [x] **灼流暗劲的感官描写**：温度感、路径感、失控感
- [x] **处决方式的多样性**：掌 vs 拳，长程 vs 短程
- [x] **精液描写的节制与精确**：不卖弄，不省略
- [x] **"白袜/黑袜"等制服细节**：黑袜描写一致
- [x] **叙事节奏**：不拖沓，两分钟内完成的紧张感

## 四、衔接方案

### 4.1 原文出入点

```
[入口] ← 第107行
老雷犹豫了一下，踢了踢地上被黑袜包裹的粗壮熊腿……
安心地出门继续狩猎。

[扩写段落]
他贴着墙沿轻手轻脚下到一楼……
……迈步上楼。

[出口] → 接回原文第112行
浴室的门被推开……
```

扩写段落以"迈步上楼"收尾，原文以"浴室的门被推开"起始——中间存在一个时间间隙。这是有意保留的：原文中两处叙事总结（"老雷不想让小雷看到"/"这两只体格壮硕训练有素的高级兽盾兵"）仍然保留在扩写版中，分别放在扛尸进门后的叙述位置，维持原文的节奏呼吸。

### 4.2 改编文件中的标记

扩写段落前后使用分隔线标记：

```
> —— 以下为扩写段落（原文第107–115行展开）——
[扩写内容]
> —— 扩写段落结束，恢复原文 ——
```
