## 三、系列说明 / Series Notes

- **哨兵清除系列 / Sentry Elimination**: 专注于兽盾哨兵角色的清除任务场景。
- **日常猎杀系列 / Daily Hunt**: 基于原作"市中心开放世界阶段"，强调多样化处决方式与详细资料解锁。
- **屠杀与善后 / Massacre & Cleanup**: 基于原作者"死亡毫无价值"美学，强调杀得顺手、死后像垃圾处理的风格。
