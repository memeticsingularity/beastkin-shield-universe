# 《兽盾农家乐》故事设定档案

---

## 1. 世界观背景

故事发生在兽盾公司（Beastshield Corporation）统治下的城市边缘。兽盾是一家臭名昭著的企业，员工多为欺软怕硬的地痞流氓，在基层横行霸道。主角小谷曾在打工期间多次被兽盾员工欺辱。

---

## 2. 核心设定

### 2.1 实验农场

小谷的爷爷是一位生化学家，留下了一片实验农场。农场种植的不是普通作物，而是需要兽人精液灌溉的特殊植物。

**已知作物**：

| 作物名 | 特性 | 精液需求量 | 效果 | 副作用 |
|--------|------|-----------|------|--------|
| 蛮力萝卜 | 白色普通种子 | 较少（单只兽人即可） | 食用后力量大增 | 无 |
| 欲望黑参 | 通体漆黑，带紫色光泽 | 蛮力萝卜的三倍以上，需连续高强度灌溉 | 精力极度旺盛，睡眠变浅，感官敏锐 | 无 |
| 活力紫茎 | 茎秆泛紫红色，散发甜香 | 需求量高，需大规模同时灌溉 | 强效恢复和增强体力，提升恢复力和某些方面能力 | 无 |
| 魅欲藤 | 粉紫色雾气，幼苗带甜香 | 极高，需多重高强度刺激 | 大幅提升作物产量 | 施肥者自身会进入极度敏感状态，可能导致集体发情 |

### 2.2 肥料获取机制

- **来源**：兽盾公司员工（或其他兽人）的新鲜精液
- **获取方式**：
  1. 用爷爷研发的"无色无味迷药"使目标全身发软、意识模糊、带有催情效果
  2. 通过手动刺激使目标射精
  3. 可控制射精量（捏住根部止精）以避免目标死亡
- **副作用**：过量射精会导致目标死亡；长期被榨取需注射营养液和维持管

### 2.3 经营体系

| 阶段 | 描述 |
|------|------|
| 初期 | 地下室单独处理，手动操作 |
| 发展期 | 后院搭建木棚，批量管理"肥料" |
| 扩张期 | 欲望黑参需要一次处理多只兽人，跟班协助同时榨取 |
| 转型期 | 活力紫茎大规模种植；农家乐开始正经经营；后棚扩建为宿舍 |
| 稳定期 | 与警方达成联盟；前成员成为正式员工；形成分工明确的小团队 |

## 3. 主要角色档案

### 3.1 小谷

- **种族**：牛兽人
- **身份**：实验农场主 / "兽盾农家乐"餐厅老板
- **特点**：原社畜，事业无成；继承农场后展现出极强的经营头脑和冷酷执行力
- **能力**：食用蛮力萝卜后力量大增，可单手提起黑熊兽人
- **心理转变**：从单纯复仇 → 经营野心 → 掌控一切的满足感 → 柔软守护（vol2）

### 3.2 阿铁

- **种族**：黑熊兽人
- **原身份**：兽盾分部巡逻队员 / 收保护费
- **现状**：小谷的第一个跟班
- **特点**：力气大，熟悉兽盾内部情况，干活得力
- **隐患**：对旧识虎威有深厚感情，忠诚建立在恐惧之上而非真心归附

### 3.3 老夯

- **种族**：野猪兽人
- **原身份**：兽盾基层员工（送货、看仓库）
- **现状**：小谷的第二个跟班
- **特点**：老实憨厚，重情重义，真心依赖和信任小谷
- **关系**：与小谷关系日渐升温，对小谷有依赖感和亲近感

### 3.4 虎威

- **种族**：老虎兽人
- **原身份**：兽盾小队长 / 阿铁的旧上司
- **现状**：小谷的私有财产（地位低于跟班）
- **特点**：身材高大肌肉虬结，性格粗犷
- **处境**：被戴项圈，限制在农场活动；与阿铁有肉体关系但内心不甘

### 3.5 老周

- **种族**：灰狼兽人
- **原身份**：兽盾另一个小队的队长
- **现状**：农家乐新成员，负责对外联络和供货方对接
- **特点**：色眯眯、直率、对小谷一见钟情，苏醒后展开热烈追求
- **关系**：与虎威以前私下认识，和农家乐众人关系融洽

### 3.6 雷克斯

- **种族**：德牧兽人
- **身份**：市警局特别行动组负责人
- **现状**：农家乐的正式成员，客房常住
- **特点**：身材健壮、胡茬性感、工作干练，但生活常识灾难性缺失（用打火机点煤气、鸡蛋放微波炉、用擦脸毛巾擦脚）
- **关系**：被小谷的真诚打动，与虎威、老周打成一片，对农家乐产生归属感
- **隐秘**：最初带有警局的监视任务，后选择站在农家乐这边（vol2-ch10）

### 3.7 古博士

- **种族**：年迈的雪纳瑞狗兽人
- **身份**：小谷爷爷的朋友兼同事 / 生化学家
- **作用**：提供种子、技术指导、收购作物
- **已知**：vol2-ch5 带来危险新种子"魅欲藤"，讲解副作用后离开

### 3.8 大木（已离开）

- **种族**：棕熊兽人
- **原身份**：兽盾调查小队队长
- **现状**：与狼峰、狼玛一同离开，远离兽盾纷争
- **特点**：落魄疲惫、重情义，临走前警告小谷"雷克斯是警局派来监视你们的"

### 3.9 狼峰、狼玛（已离开）

- **种族**：灰狼兽人
- **原身份**：大木小队队员
- **现状**：被雷克斯救回，与大木重逢后一同离开

### 3.10 小竹

- **种族**：雪豹兽人
- **原身份**：大木小队年轻队员
- **现状**：暂时留在农家乐，在厨房帮忙
- **特点**：青涩倔强、重情义，误以为队友被害前来报仇，得知真相后释怀

### 3.11 刘昴

- **种族**：野猪兽人
- **身份**：影牙特别行动小队压轴成员 / 老夯的亲弟弟
- **现状**：被警局逮捕（vol2-ch15）
- **特点**：矛盾扭曲、自我毁灭式人格，对老夯既有恨又有期待
- **正文台词**：被捕前对老夯说"别后悔……别留下遗憾"，对小谷说"嫂……哥夫……这条命先欠着"

## 4. 关键地点

| 地点 | 描述 |
|------|------|
| 实验农场 | 荒废的农场，有破旧木屋和杂草丛生的农田 |
| 木屋地下室 | 最初处理"肥料"的地点，暗板隐藏入口；后被遗忘的灰狼老周曾被关在这里 |
| 兽盾农家乐餐厅 | 木屋一楼改造的简易餐厅，用于诱捕兽盾员工；后期逐渐转为正经经营 |
| 处理间 | 后厨旁的地下室隔间，固定和榨取兽人的场所 |
| 后院木棚 | 批量关押恢复中"肥料"的简易棚屋；后期扩建为像样的宿舍 |
| 兽盾分部 | 隔壁的兽盾分公司，员工们昔日的据点，也是农家乐最初的"肥料"来源 |
| 小树林 | 农场后面偏僻的小树林，曾用来埋葬意外死亡的豹兽人 |

## 5. 势力关系

```
小谷（农场主/老板）
├── 古博士（合作者/供应商）
├── 阿铁（跟班） ──→ 虎威（恋人/旧识）
├── 刘夯（老夯/跟班） ──→ 对小谷有爱慕之情
│   └── 刘昴（弟弟/影牙成员）──→ 被捕
├── 虎威（前私有财产/现成员） ──→ 与阿铁恋人关系
├── 老周（成员/对外联络） ──→ 对小谷追求 → 对雷克斯转移寄托
├── 雷克斯（警官/正式成员） ──→ 监视任务 → 选择站在农家乐这边
├── 大木（前调查组/已离开）
│   ├── 狼峰（已离开）
│   └── 狼玛（已离开）
├── 小竹（雪豹/暂时留下）
├── 后棚伙计们（留下来的前"肥料"）
├── 兽盾分公司（敌对/肥料来源）
│   └── 影牙小队（残余势力，袭击农家乐）
│       ├── 电网刺客二人组（被捕）
│       ├── 小竹（已转化）
│       ├── 变色龙刺客（被擒）
│       └── 刘昴（压轴，被捕）
└── 市警局（复杂关系）
    └── 雷克斯的上级（施压要求调查农家乐）
```

## 6. 叙事时间线

| 时间 | 事件 |
|------|------|
| Day 1 | 小谷继承农场，用地下室黑熊种下第一批蛮力萝卜，获得1000撸币 |
| Day 2 | 开设餐厅，捕获灰狼兽人（老周），种下第二批种子 |
| Day 3 | 捕获老虎兽人（虎威），发现其恢复力强，作为长期种马；黑熊阿铁被收为跟班 |
| Day 4-5 | 批量捕获兽盾员工，后院木棚渐满；老夯被捕获后收为第二个跟班 |
| Day 6-7 | 欲望黑参种植；阿铁与虎威的旧情暴露 |
| Day 8 | 豹兽人死亡事件；阿铁偷偷喂虎威精液被发现 |
| Day 9 | 小谷与阿铁摊牌，虎威正式成为私有财产 |
| Day 10-14 | 活力紫茎种植；虎威在地下室发现被遗忘的老周；老周被救出 |
| Day 15-20 | 老周苏醒，对老板一见钟情；后院争风吃醋日常；紫茎丰收庆祝 |
| Day 21-30 | 调查组来袭；备战；雷克斯警官出现，局势逆转；农家乐迎来新盟友 |
| Day 31+ | 雷克斯正式加入；后棚宿舍扩建；农家乐转型为正经经营+奇特家庭 |
| Day 35-40 | 古博士带来"魅欲藤"种子；众人集体发情事件；大木落魄造访 |
| Day 41-45 | 大木误食魅欲藤催情粉；雷克斯出差救回狼峰狼玛；大木三人告别离开 |
| Day 46-50 | 大木警告小谷"雷克斯是警局派来监视你们的"；雷克斯坦白监视任务；农家乐备战 |
| Day 51-55 | 影牙小队袭击：电网电晕双人刺客；虎威智取雪豹刺客（小竹）；小竹得知真相后留下 |
| Day 56-60 | 老周向小谷袒露心底秘密；变色龙刺客潜入被阿铁反杀；阿铁昏迷、虎威守夜 |
| Day 61-62 | 刘昴（老夯弟弟）率兽盾兵正面挑战；与小谷交手；被老夯崩溃打倒 |
| Day 62 夜 | 雷克斯带队收网，逮捕刘昴和兽盾兵；老夯崩溃大哭；农家乐众人围拢安慰 |
