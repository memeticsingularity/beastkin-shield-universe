# 《兽盾农家乐》故事设定档案

---

## 1. 世界观背景

故事发生在兽盾公司（Beastshield Corporation）统治下的城市边缘。兽盾是一家臭名昭著的企业，员工多为欺软怕硬的地痞流氓，在基层横行霸道。主角小谷曾在打工期间多次被兽盾员工欺辱。

---

## 2. 核心设定

### 2.1 实验农场

小谷的爷爷是一位生化学家，留下了一片实验农场。农场种植的不是普通作物，而是需要兽人精液灌溉的特殊植物。

**已知作物**：

| 作物名 | 特性 | 精液需求量 | 效果 |
|--------|------|-----------|------|
| 蛮力萝卜 | 白色普通种子 | 较少（单只兽人即可） | 食用后力量大增 |
| 欲望黑参 | 通体漆黑，带紫色光泽 | 蛮力萝卜的三倍以上，需连续高强度灌溉 | 精力极度旺盛，睡眠变浅，感官敏锐 |

### 2.2 肥料获取机制

- **来源**：兽盾公司员工（或其他兽人）的新鲜精液
- **获取方式**：
  1. 用爷爷研发的"无色无味迷药"使目标全身发软、意识模糊、带有催情效果
  2. 通过手动刺激使目标射精
  3. 可控制射精量（捏住根部止精）以避免目标死亡
- **副作用**：过量射精会导致目标死亡；长期被榨取需注射营养液和维持管

### 2.3 经营体系

| 阶段 | 描述 |
|------|------|
| 初期 | 地下室单独处理，手动操作 |
| 发展期 | 后院搭建木棚，批量管理"肥料" |
| 扩张期 | 欲望黑参需要一次处理多只兽人，跟班协助同时榨取 |

---

## 3. 主要角色档案

### 3.1 小谷

- **种族**：牛兽人
- **身份**：实验农场主 / "兽盾农家乐"餐厅老板
- **特点**：原社畜，事业无成；继承农场后展现出极强的经营头脑和冷酷执行力
- **能力**：食用蛮力萝卜后力量大增，可单手提起黑熊兽人
- **心理转变**：从单纯复仇 → 经营野心 → 掌控一切的满足感

### 3.2 阿铁

- **种族**：黑熊兽人
- **原身份**：兽盾分部巡逻队员 / 收保护费
- **现状**：小谷的第一个跟班
- **特点**：力气大，熟悉兽盾内部情况，干活得力
- **隐患**：对旧识虎威有深厚感情，忠诚建立在恐惧之上而非真心归附

### 3.3 老夯

- **种族**：野猪兽人
- **原身份**：兽盾基层员工（送货、看仓库）
- **现状**：小谷的第二个跟班
- **特点**：老实憨厚，重情重义，真心依赖和信任小谷
- **关系**：与小谷关系日渐升温，对小谷有依赖感和亲近感

### 3.4 虎威

- **种族**：老虎兽人
- **原身份**：兽盾小队长 / 阿铁的旧上司
- **现状**：小谷的私有财产（地位低于跟班）
- **特点**：身材高大肌肉虬结，性格粗犷
- **处境**：被戴项圈，限制在农场活动；与阿铁有肉体关系但内心不甘

### 3.5 古博士

- **种族**：年迈的雪纳瑞狗兽人
- **身份**：小谷爷爷的朋友兼同事 / 生化学家
- **作用**：提供种子、技术指导、收购作物

---

## 4. 关键地点

| 地点 | 描述 |
|------|------|
| 实验农场 | 荒废的农场，有破旧木屋和杂草丛生的农田 |
| 木屋地下室 | 最初处理"肥料"的地点，暗板隐藏入口 |
| 兽盾农家乐餐厅 | 木屋一楼改造的简易餐厅，用于诱捕兽盾员工 |
| 处理间 | 后厨旁的地下室隔间，固定和榨取兽人的场所 |
| 后院木棚 | 批量关押恢复中"肥料"的简易棚屋 |

---

## 5. 势力关系

```
小谷（农场主/老板）
├── 古博士（合作者/供应商）
├── 阿铁（跟班） ──→ 虎威（旧识/私有财产）
├── 老夯（跟班）
└── 兽盾分公司（敌对/肥料来源）
```

---

## 6. 叙事时间线

| 时间 | 事件 |
|------|------|
| Day 1 | 小谷继承农场，用地下室黑熊种下第一批蛮力萝卜，获得1000撸币 |
| Day 2 | 开设餐厅，捕获灰狼兽人，种下第二批种子 |
| Day 3 | 捕获老虎兽人（虎威），发现其恢复力强，作为长期种马；黑熊阿铁被收为跟班 |
| Day 4-5 | 批量捕获兽盾员工，后院木棚渐满；老夯被捕获后收为第二个跟班 |
| Day 6-7 | 欲望黑参种植；阿铁与虎威的旧情暴露 |
| Day 8 | 豹兽人死亡事件；阿铁偷偷喂虎威精液被发现 |
| Day 9 | 小谷与阿铁摊牌，虎威正式成为私有财产 |
