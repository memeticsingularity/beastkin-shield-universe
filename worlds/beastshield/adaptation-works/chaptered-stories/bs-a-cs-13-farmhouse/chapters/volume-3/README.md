## 简介 / Introduction

农家乐散了。

后棚的伙计们被遣散，各奔东西。有人回到了原来的城市，有人选择了新的生活。但命运的线并没有真正断开——那些在农家乐里建立起的羁绊，那些被特殊作物改变的身体，那些在黑暗日子里互相取暖的记忆，都还在。

本卷以被遣散伙计的视角展开，讲述"散开"之后的故事。当农家乐的阴影和恩情同时笼罩着每一个离开的人，当老周带着他的腿刃踏上那条"更重要"的道路，当雷克斯的监视任务与个人情感纠缠不清，当那些曾经被迫相连的人们在各自的人生轨迹中依然彼此牵扯——

散开了，却还相连着。
