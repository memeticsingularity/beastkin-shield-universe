# Save Us Then Load World · 创作手记

> 记录写作决策、风格约束与跨章节需要一致的规则，供后续章节参考。

---

## 一、项目核心规则（由用户逐条确认）

### 1. 章节结构原则
- **一章只推进一个角色**。不是一关一个章节。
- Ch.1：熊石厚（G-078）。Ch.2：犬齐锋（G-217）。Ch.3：虎金烈（O-089）。后续同理。
- 群体角色（黑猪、灰蓝牛、黑熊）归入对应核心角色的章节或独立章节处理。

### 2. NPC 对读档无感知
- 存档记录所有人存档时刻的位置与状态。
- 读档后 NPC 无缝衔接，没有任何"时间跳跃"的感知。
- 熊石厚在尸堆里眨眼——前一秒裸着等，下一秒主角推门进来，中间没有任何异常感。

### 3. 换装 = 物理扒衣
- 不是技能/魔法变身。必须逐层脱下目标的衣物，再逐层穿到自己身上。
- 衣物会自适应身材（游戏机制）。
- 步骤顺序：鞋 → 白袜 → 短裤 → 短袖。（兽盾各级制服短裤均为紧身设计，兼具内裤功能，不配发独立内裤）
- 参考原作 Ch.5 的物理流程。

### 4. NPC 看不到任何 UI
- 系统面板、精槽条、随从招募菜单——全部由主角独享视角。
- NPC 只能看到主角的物理动作和表情变化。
- 随从招募在 NPC 眼中只是"主角松了口气/表情放松"之类的体感变化。

### 5. 禁止"计划宣告"式台词
- 主角不会在 NPC 面前说"我打算救谁""我的计划变了"之类的话。
- 行动即表达。主角做什么，NPC 只看到什么。

### 6. 开门见山
- 每章开头直接进入动作/场景，不铺垫、不总结前文。
- 短段落（1-2句为主），硬切场景切换。

### 7. 存档编号规则（新 AI 必须遵守）
- **格式**：`Na/b/c` —— 数字 = 角色序号；字母 = 该角色的第几次存档（a→b→c）
- **所有存档都必须带字母后缀**，不存在纯数字存档。熊石厚 1a；犬齐锋 2a, 2b；虎金烈 3a...
- **完整存档日志**：见 `.process/SAVE-LOAD-LOG.md`
- **存档模板**：见 `.process/templates/save-load-entry-template.md`

## 二、写作风格（lanse 风味 + Save Us 变体）

### 基础笔风来源
基于 `author/001-lanse/style-analysis/` 下的完整分析体系：
- `lanse-style-checklist.md` —— 硬性要求与检查清单
- `lanse-style-prompt.md` —— AI 标准化提示词
- `lanse-style-variants.md` —— 变体策略（避免同质化）

### Save Us 的变体调整
lanse 原风格核心是处决流程（制服 → 刺激 → 射精 → 死亡）。
Save Us 因"不杀"主题，将处决流程改写为**边缘控制招募流程**：

```
制服（捏蛋/控制）→ 掏出下体（翻开包皮）→ 刺激（敏感点探索）→ 求饶（"要射了"）→ 临界点停手（90%）→ 详细资料解锁 → 随从招募
```

**保留**：精液描写精细度、精槽机制、触觉主导、求饶句式、短段落节奏。
**替换**：射精死亡 → 边缘停手；摸尸 → 换装扒衣；死亡确认 → 招募确认。

### 每章必检清单（写作后自查）
- [ ] 每章至少 1 次「白袜」描写（穿在角色腿上）
- [ ] 新角色登场走完公式：物种→制服色→体型→下体鼓包→白袜→鞋
- [ ] 对话标签只用「道」（说道/问道/吼道/怒道/笑道/喃喃道），不用「说」
- [ ] 恐惧/犹豫用省略号「。。。 」（全角+空格）
- [ ] 段落不超过 3 句，大部分 1-2 句
- [ ] 场景切换硬切，无过渡
- [ ] 不出现深层心理活动/哲学思考
- [ ] 不省略性描写细节
- [ ] 不写流血/伤口（致命方式只有射精；Save Us 中连射精都不致死）
- [ ] NPC 看不到 UI
