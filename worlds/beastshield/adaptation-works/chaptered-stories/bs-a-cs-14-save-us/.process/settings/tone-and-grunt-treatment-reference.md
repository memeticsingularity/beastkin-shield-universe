# 原作调性与设定综合梳理

> 基于完整阅读中文原作后的提炼，用于指导 Save Us 改编项目
> 阅读范围：主线第一卷13章、第二卷关键章节、短篇《兽盾员工的一天》、支线《墨犬》

---

## 一、原作调性（最重要）

### 1.1 整体气质

原作是 **色情喜剧/游戏向** 作品，不是黑暗写实或社会批判。

**关键证据**：
- 主角知道自己在玩游戏（"反正游戏重置后他就会刷新复活的，我干嘛要有负罪感"）
- 死亡被轻描淡写地处理（尸体塞垃圾桶、"和现实世界中的繁华都市差别不大"）
- NPC的台词是游戏NPC式的（红牛司机试图骗玩家选他当随从、被揭穿后撞车同归于尽）
- 游戏机制始终在场（精槽、等级、技能、属性点、换装、读档）
- 色情描写是目标，不是噱头

**这不是**：《黑社会》式的犯罪现实主义、政治寓言、社会批判。

### 1.2 G级杂兵在原作中的真实待遇

**这是最核心的发现，直接影响 Save Us 的角色档案写法。**

| 维度 | 原作实际做法 |
|------|-------------|
| 名字 | **没有名字**。全部以"狗兽人"、"虎队长"、"牛兽人"代称 |
| 背景 | **没有背景**。没有童年、家庭、梦想、经济状况、入职原因 |
| 性格 | **极少性格描写**。最多一个习性标签（如"愚钝""懒惰"） |
| 个人历史 | **零**。G级角色死后不会有任何人记得他们 |
| 死法 | 纯物理描写 + 死法描写。没有一个字关于死者的心理 |
| 尸体处理 | 扔垃圾桶/留在原地/被垃圾车运走——"像处理垃圾一样" |

**唯一例外**：Ch.7 的熊贺晟（熊掌）和牛蒋顿（牛杂）——但他们：
- 是"正在招募的新兵"，不是普通G级
- 立刻被主角改名为"熊掌""牛杂"
- 仍没有家庭背景、童年、梦想
- 他们的存在是为了展示"G级兵源从哪里来"这一世界观设定

### 1.3 G级兵源的官方定义（直接引用）

来自原作 Ch.7 和 Ch.12：

1. **牛蒋顿的自述**："当然是为了能不受法律约束，想干谁就干谁啦！"
2. **熊贺晟的自述**："我是因为有前科，找不到其他工作只能进兽盾"——前科：抢劫便利店（太饿了没钱）
3. **特工局老师的定义**："兽盾组织就喜欢招募这种四肢发达头脑简单的兽人做为走狗"
4. **特工局老师的定义2**："他们只不过是一群外强中干的废物，在外面只敢欺软怕硬"

**结论**：G级兵源 = 地痞流氓 + 有前科者 + 走投无路的人。**不是经济受害的普通人。**

## 二、世界观关键设定

### 2.1 制服等级体系（确认）

| 等级 | 颜色 | 身份 | 装备 |
|------|------|------|------|
| G级（杂兵） | 军绿短袖短裤 | 低级守卫 | 白袜+运动鞋，无防具 |
| 队长/干部 | 蓝色 | 小队长 | 白袜+运动鞋/军靴 |
| W级/武斗兵 | 黑制服+军靴 | 精英近战 | 护裆（金属片）、黑袜 |
| 远程兵 | 白色+军靴 | 枪械兵 | 白紧身裤+背心 |
| 部长/董事 | 黑/白 | 高层 | 西装/定制制服 |

**关键区分**：
- G级杂兵 = 炮灰，没有忠诚度，一威胁就招供
- 黑制服武斗兵 = 有纪律，"死忠于兽盾"，拷问也不招供

**后期制服改革（第三卷/支线炎魉确认）**：
- 背景：部长人数大缩减，现任部长我行我素不穿制服 → 工厂屯了大量黑制服
- **新制度**：
  1. **绿制服**：最低级新兵/杂兵
  2. 转正后体能测试分三类：
     - 皮糙肉厚适合近身搏斗 → **武斗组** → **黑色制服** + 黑袜 + 军靴
     - 枪法精准适合远程作战 → **枪械组** → **白色制服** + 白紧身裤 + 白袜
     - 都不突出 → 管理新兵 → **蓝色制服**
- 黑制服武斗兵实力确实比G级强（耐力更久），但和部长级仍不是一个级别
- 白制服枪械兵：身材仍然粗壮，但被近身后不堪一击
- 蓝制服被黑制服嘲笑为"进不了战斗编制的垃圾"——等级间存在鄙视链

### 2.2 编号体系

- 每个兽盾员工袜底印有编号
- G级格式：G-XXX（如 G-123）
- 不同兵种前缀不同（摔跤兵 W-593）
- 赏金猎人凭袜子领赏
- "这些编号和他的主人们一样，已经失去了作用，将永远被人遗忘"

### 2.3 赏金体系

- G级杂兵（绿制服）：**100撸币/只**
- 蓝制服（管理岗）：**200撸币/只**
- 白制服（枪械）/ 黑制服（武斗）：**500撸币/只**
- 摔跤兵：**1000撸币/只**
- "再次感叹绿制服杂兵的命贱"

**赏金猎人工作流程**（SS-002/炎魉确认）：
- 步骤1：杀死兽盾成员 + 拍下死状（脸部照片）
- 步骤2：拿走印有编号的袜子——证明人是你杀的
- 特工局根据黑入兽盾人事网的成员名单核对编号，发放赏金
- 不可抢他人猎物（"坏规矩"）

## 二点五、武力体系（Save Us 战斗系统基础）

### 灼流暗劲（促射功法）
- **来源**：特工局标准功法
- **使用者**：炎（炎魉）、熊猫兽人、雷炎寰（SS-007）
- **原理**：击中或握住目标后，一股灼热内劲涌入对方体内，使肉棒快速勃起→射精
- **特性**：可以隔物传导（拳套、衣物），不需要直接接触肉棒
- **强度**：不同对手需要不同量（新兵12秒、武斗兵30秒+）
- **评价**：熊猫说炎的灼流暗劲"火候比我那徒弟可差远了"——说明功法有熟练度等级

### 寸止功法（止射功法——Save Us 核心）
- **来源**：墨犬失忆前已掌握，危急时刻自动浮现
- **使用者**：黑狗（墨犬）
- **原理**：双指并拢按在睾丸和肉棒连接处，向内输入一道内劲→射精立刻中止
- **定位**：**Save Us "不杀"路线的技术基础**
- **意义**：证明这个世界观中存在"在不杀前提下控制精关"的技术手段

### 银针封穴术
- **来源**：银狼兽人、熊猫兽人（炎魉）
- **原理**：细小的银针刺入脖子穴道→目标全身无法动弹但意识清醒
- **效果**：目标眼睁睁看着凶手把自己撸射，银针拔出后尸体才会瘫倒

### 其他功法/能力
- **金刚护体**：肉身挡子弹（炎、墨犬的金钟罩变体）
- **黑石纯力气**：无特殊功法，纯凭怪力勒颈致死（SS-002/003）
- **春药子弹**：打中后直接触发射精（SS-007）
- **天籁四曲**：精神类功法，通过笛声控制目标精关（Vol 3）
- **五行相生术**：水→木→火→土元素攻击体系（龙神使用）

## 三、阵营关系

### 3.1 兽盾公司
- 势力最大，权势匹敌政府
- 走私军火、贩卖违禁品
- 员工杀人放火无恶不作
- 内部恐惧管理：干部可随意处死下属
- HQ有专门尸体处理设施（大型垃圾桶）
- 底层员工命不值钱

### 3.2 警察
- 不敢管兽盾（迫于权势）
- 但伤害平民依然会被逮捕
- 击杀兽盾员工：睁一只眼闭一只眼，甚至暗里支持
- 部分警察（牛警长）有实力，但最终会被兽盾杀害

### 3.3 特工局
- 反兽盾地下组织
- 成员通常有"家破人亡"的仇恨驱动
- 也把G级俘虏当教学材料使用（"外强中干的废物"）
- 在兽盾内部有眼线

### 3.4 赏金猎人
- 独立职业
- 击杀兽盾员工 → 拍照 → 取编号袜 → 领赏
- 武器店 = 赏金猎人接头点

### 3.5 平民
- 对兽盾恐惧（"兽盾公司的人你们惹不起"）
- 部分平民会反抗（白熊武道家）
- "刚正不阿"习性是"万中无一"
- 部分平民通过赏金猎人系统间接对抗兽盾

## 四、对 Save Us 角色档案的指导原则

### 4.1 G级杂兵档案应该长什么样？

基于原作实际处理方式：

**核心原则**：G级角色 = **障碍物/环境的一部分**，不是独立角色。

**原作标准的G级处理**：
1. 物种 + 体格描写（"棕皮熊兽人，膀大腰圆，身材肥壮"）
2. 死法（被什么方式处决）
3. **没有名字**
4. **没有背景**
5. **没有心理描写**
6. **没有家庭关系**

**Save Us 改编可以适当增加的**（因为Save Us有"拯救"主题）：
1. ✅ 一个核心特征（让玩家记住他的理由）
2. ✅ 和主角的互动可能（为什么值得救/不救）
3. ✅ 死亡方式的独特之处
4. ⚠️ **适度**的背景提示（1-2句，不是170行）
5. ❌ 不要写"家境贫寒""父亲的职业""童年上学""攒钱开饭馆"

### 4.2 当前档案存在的问题

**核心问题**：写了太多"经济受害型"背景。

具体来说：
- 父亲职业（种地、运输、赶车）→ 几乎每个角色都有
- 童年/上学经历 → 原作从不写这些
- "攒钱开饭馆/回村种地" → 原作G级没有这种中长期人生规划
- 经济分析（每月省20/50）→ 太详细了，像人物传记不像游戏设定

**原作G级的真实画像**：
- 犯罪前科（抢劫便利店）
- 想不受法律约束（"想干谁就干谁"）
- 找不到别的工作
- 四肢发达头脑简单

**少量可以保留的"人性时刻"**（参考白熊员工日记）：
- 对某个上级有暗恋/崇拜/恐惧
- 日常混混日子抽抽烟
- 怕死，被折磨时会求饶

### 4.3 改写方向

**需要强化的**：
1. 犯罪前科/劣迹
2. 地痞流氓气质
3. "被生活推着走"而不是"有梦想要实现"
4. 短视——G级不会想三年后的事

**需要弱化的**：
1. 父亲职业、童年上学、家庭经济分析
2. "攒钱开饭馆""回村种地"式的中长期梦想
3. 社会批判式的叙述口吻（"兽盾从不让卑微的梦成真"）
4. 过于详细的日常描写

## 五、原作中的死亡美学

### 5.1 G级之死的风格

- **绝对不是悲剧性的**。死亡是喜剧/色情的一部分
- 死法荒诞（被队友压射、被杠铃压死、被自己的袜子撸射）
- 尸体处理不尊重（塞垃圾桶、叠在一起、精液擦在白袜上）
- **但**：有时有一丝人性残影（熊贺晟说"谢谢"、白熊员工说"就这样死去似乎也不是很糟糕"）

**各短篇中G级之死的多样性**：
- **SS-002 黑石**：赌债死亡（野猪被当众玩弄撸射至死，同事只关心输赢）、内部处决（蓝制服牛被黑制服虎当场捏爆卵蛋）
- **SS-004 俘虏快递**：虎兽人运输途中被抑制器磨射至死、牛摔跤兵在睡梦中被蹭射——"货物化"的死亡
- **SS-005 员工日记**：白熊被暗恋对象的袜子撸射——最讽刺的死法，"就这样死去似乎也不是很糟糕"
- **SS-006 夜袭**：被逼到临界点后功亏一篑，死后被塞警棍——羞辱性处决
- **SS-007 毕业实习**：雷炎寰用灼流暗劲速杀6人——"毕业作业"式的效率化屠杀

### 5.2 "注入了些真情流露"的度

参考用户分享的反馈："原本这段笑料里掺些真情流露是刚刚好的，但硬上内核有点。"

**正确的度**：
- 白熊员工暗恋虎队长 → ✅ 笑料里掺真情流露
- 白熊被虎队长的袜子撸射 → ✅ 荒诞讽刺
- "这个世界太残酷了" → ❌ 硬上内核
- "兽盾从不让卑微的梦成真" → ❌ 硬上内核

**黄金法则**：让读者自己感受到悲剧性，而不是让旁白告诉他"这是悲剧"。

## 六、待解决/需要注意的问题

1. ~~**G级月薪**：当前档案模板写的是100撸币，但世界观参考写的是1000撸币。需要统一。~~ ✅ **已解决**：全线确认G级为100撸币/月。SS-001（农场小谷一天赚1000）、SS-002（黑石杂兵袜子藏几十撸币）等所有阅读材料均一致支持100撸币/月。世界观参考中的1000撸币是赏金价格（杀一个G级领1000），不是月薪。
2. **"五兽种"的定位**：原作中牛/熊/虎/猪/狗是常见兽种，不应被理解为"只有这五种"
3. **编号格式**：G级确认格式为 G-XXX（如 G-123），非 G-XXX-XXX
4. **Save Us 的改编幅度**：原作中G级没有名字，但Save Us给了编号+代号。这是合理的改编——只要不进一步编造详细背景。新增参考：SS-007评述中AI追加的名字/背景（"牛大壮""狗来福"等）是**不应采用的**"经济受害型"背景典型。
5. **功法体系对Save Us的影响**：灼流暗劲（促射）和寸止（止射）是Save Us战斗系统的两极。建议主角以寸止为核心技能，灼流暗劲为可选/敌对技能。
