# 场景档案：蟒蛇岛基地广场

## 概述

蟒蛇岛基地的中心广场。第15章中所有兽盾成员聚集在此，嗜精兽头目带着几个蓝制服守卫站在广场边缘。广场中心地面上由儡先生使用精液绘制了神秘法阵，最终法阵启动引发冲天红光和巨大震动。
