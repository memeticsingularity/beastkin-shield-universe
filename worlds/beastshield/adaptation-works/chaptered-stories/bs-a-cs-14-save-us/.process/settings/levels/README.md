## 建档规范

- 关卡目录命名：`l-XX-关卡英文名/`
- 关卡索引：`l-XX-关卡英文名/index.md`
- 场景档案：`l-XX-关卡英文名/scenes/sc-NN-场景名.md`
- 场景编号规则：`sc-01`, `sc-02`... 按玩家在关卡中的遭遇顺序
