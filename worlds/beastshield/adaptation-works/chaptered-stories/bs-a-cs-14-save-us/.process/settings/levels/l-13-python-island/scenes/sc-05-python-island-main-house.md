# 场景档案：蟒蛇岛基地主营房

> 所属故事：故事2（魔影卷）

---

## 概述

蟒蛇岛基地内的主要营房，由于占领时间不长，只建了一间简单砖房暂供使用。房内有一个金属盒子，里面存放着关键物品——泛着血红光芒的红色水晶（血精矿）。房间内有桌、椅等基本家具。守卫在此处看守铁箱。

## 场景功能（叙事/关卡设计）

- **叙事功能**：魔影获得毒血/毒牙能力的转折点场景；白熊的叛变与复仇完成；红水晶（血精矿）的首次出现，为后续剧情埋下伏笔；春药香烟的首次使用
- **关卡设计参考**：室内战斗场景；可设计为"利用内应下毒"的智取关卡；红水晶可作为关卡关键交互物品（接触后触发剧情强制转变）；BOSS战（虎队长）设计参考
