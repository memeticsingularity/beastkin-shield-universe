## 1. 体重与体格 / Body Weights & Physiques

### 1.1 基线体重标准 / Baseline Weight Standard

所有兽盾守卫/战斗人员的体重基线为 **300+斤 (150kg+)**。这是贯穿所有原作的统一标准。

**关键数据点**:
- 主线1 ch-8: "牛杂那三百多斤的体重"（牛杂是摔跤手熊兽人，300+斤）
- 主线1 ch-9: 薛鼎接住牛兽人"不下于三百斤"（no less than 300 jin）
- 主线3 ch-6: 大奔"近四百斤"（nearly 400 jin）
- 主线2 ch-6: 虎兽人"300多斤" body
- 主线3 ch-13: "三百多斤的肉体"（熊兽人压住主角）
- 短篇《守夜人》: 熊大宝"身高近两米，体重超过三百斤"
- 主线1 ch-11: 灰熊"三百多斤的身体"被老雷一只手举起
- 短篇《员工日记》: "三百多斤的肉体"（水牛哥压在白熊身上）

**换算**: 1斤 = 0.5kg, 所以300斤 = 150kg, 400斤 = 200kg

### 1.2 体脂类型 / Body Composition Types

原作文本中识别出三种主要体格类型:

**A. 纯肌肉型 / Pure Muscle**
- 虎兽人、黑制服武斗兵最常见
- 肌肉紧实饱满，线条分明
- 例: 虎队长（员工日记）、黑制服虎守卫（炎魉ch-2）
- 特征: "肌肉练得像搓衣板似的"，"肌肉更紧实，捏起来更有弹性"

**B. 脂包肌型 / Fat-over-Muscle**
- 牛兽人、熊兽人最常见
- 厚重脂肪包裹下层肌肉
- 例: 牛杂（主线1 ch-7/8）、熊厚实（毕业实习）、豕牙（守夜人）
- 特征: "厚重的脂肪层下是常年干体力活练出的肌肉"，"圆滚的硬肚子"

**C. 肥壮型 / Bulky Fat**
- 部分野猪兽人、部分牛兽人
- 例: 野猪（黑石）、蓝制服牛（黑石）
- 特征: "偏肥壮"，"肚子上那圈长毛的肥肉"

### 1.3 特定种族体格特征 / Race-Specific Physique Traits

**牛兽种 / Bovine**:
- 储精量最多（主线1 ch-7, 主线2 ch-9）
- 通常体型最大/最重（主线1 ch-7）
- 乳头异常敏感（炎魉ch-1: 牛守卫乳头渗奶）
- 精压最高，射程远（主线3 ch-16: "不愧是多精的牛兽种，精压也与众不同"）

**熊兽种 / Ursine**:
- 皮糙肉厚，耐力型（主线1 ch-7, 主线3 ch-16）
- 熊鞭粗硬，蓄精量次于牛（主线1 ch-12）
- 有硬肚子特征（黑熊守卫在炎魉ch-1: "四肢粗壮，肚子也很圆滚，还是那种圆鼓鼓的硬肚子"）

**虎兽种 / Tiger**:
- 肌肉型，敏捷与力量平衡（主线2 ch-4）
- 虎鞭上有系带（主线3 ch-14: "用指甲在黑虎兽人的系带上轻轻刮蹭"）
- 虎兽人几乎绝种（主线1 ch-12）——解释为何虎角色在故事中如此罕见

**猪兽种 / Porcine**:
- 脂包肌典型，身材矮宽（守夜人）
- "身高只有一米七，在兽人里算矮的，但体宽超过一米"
- 猪鞭粗短但结实
- 獠牙是种族尊严象征（守夜人settings）

**狗兽种 / Canine**:
- 身材偏精瘦（墨犬）或中等（黑石中的狗杂役兵）
- 狗鞭较长但不粗（炎魉ch-2）

**其他种族**:
- 狼兽人: 敏捷型，精瘦肌肉（银/影爪）
- 犀牛兽人: 厚皮防御型（主线3 ch-22）
- 鳄鱼兽人: 角斗士体型（主线3 ch-11）
- 鲨鱼兽人（流墟）: 身形挺拔健美，可化为胶液
- 熊猫兽人: 中等体型，实力深不可测（炎魉ch-3）

## 2. 制服与装备 / Uniform & Equipment

### 2.1 兽盾制服体系 / Beastshield Uniform System

**颜色等级制度 (从低到高)**:

| 等级 | 颜色 | 兵种 | 装备特点 | 首次出现 |
|------|------|------|----------|----------|
| G级杂兵 | 军绿色 | 基础守卫 | 紧身短袖+短裤+白袜+运动鞋 | 主线1 ch-1 |
| 干部/组长 | 蓝色 | 管理者 | 蓝制服+白袜 | 主线1 ch-6 |
| O级/W级(武斗兵) | 黑色 | 近战兵种 | 黑紧身衣+黑袜 | 主线1 ch-8 |
| 枪械组 | 白色 | 远程兵种 | 白紧身衣+白袜 | 主线3 ch-11 |
| 高级守卫 | 蓝白 | 高层管理者 | 蓝白相间+徽章白袜 | 主线2 ch-3/5 |
| 部长级 | 黑色(旧款) | 部长 | 黑制服+黑袜(有时不穿) | 主线1 ch-9 |

**改革后新制度**（炎魉ch-2交代）:
- 绿制服 → 转正后体能测试
- 体能优秀近战型 → 黑制服（武斗组）
- 枪法精准远程型 → 白制服（枪械组）
- 两者都不突出 → 蓝制服（管理新兵）

**纹章/标志**:
- 盾型logo（墨犬ch-1: "军帽和长筒白袜上印有一个盾型logo"）
- 公司logo在紧身衣胸口（炎魉ch-2）
- 熊族徽章（主线2 ch-7）
- 肩膀上的印章表示官职（炎魉ch-3: "从他们肩膀上的印章可以看出他们不是普通的士兵"）
- 高级军徽（炎魉ch-3: "肩膀上印有高级军徽"）

### 2.2 袜子编号系统 / Sock Number System

这是兽盾世界最独特的设定之一:

**规则**:
- 每名兽盾员工的白袜袜底印有员工编号
- 赏金猎人通过索要一只编号袜作为击杀凭证（黑石短篇）
- 特工局通过黑入兽盾人事系统核对编号后发放赏金

**编号格式**: `字母-数字` (如 G-612, G-533)
- G = Grunt (杂兵)
- 数字 = 员工唯一编号

**来源例证**:
- 短篇《黑石》: "完成两个步骤：一是杀死兽盾成员拍下死状；二是拿走一只印有他编号的袜子"
- 短篇《守夜人》: "他的编号是G-612，印在他左脚白袜的袜底"
- 短篇《毕业实习》: "编号G-533到G-538"
- 短篇《员工日记》: "默默脱下虎守卫的鞋子，托起脚掌拍下了白袜底的编号"
- 炎魉ch-1: "露出白袜袜底上的编号，然后用手机拍了下来"
- 主线1 ch-4: 白袜编号首次出现，作为身份标识

**赏金流程**: 杀敌→拍死状照片→取编号袜→特工局核对→领赏

### 2.3 特定装备细节 / Specific Equipment Details

**鞋类**:
- 杂兵标配: 军绿色/黑色运动鞋（主线1 ch-1, 全篇）
- 军靴: 黑色硬底军靴（主线1 ch-6, 主线2 ch-13）
- 深蓝摔跤靴: 摔跤兵种（主线1 ch-8）
- 黑袜+军靴: 武斗兵（黑石2, 主线2 ch-13）
- 蓝白相间摔跤鞋: E级摔跤兵（主线1 ch-8）

**白袜细节**:
- 所有人统一穿长筒白袜（主线1 ch-1始贯穿全系列）
- 袜口如碗口一样粗（炎魉ch-1）
- 袜子用于擦灰（主线3 ch-14: "将手机屏盖在白熊的粗腿白袜摩擦"）
- 原味袜用于催情（员工日记: 黑袜套在肉棒上）
- 袜子作为堵嘴工具（很多章节都有）

**特殊护甲**:
- 光之铠（辉董）: 凭空出现的光之铠甲（主线3 ch-11）
- 角斗士式铠甲（鳄鱼兽人）: 只披少量铠甲片（主线3 ch-11）
- 藤甲（墩常）: 用于配合夔牛弓（主线3 ch-12）

**武器**:
- 标配: 警棍（主线1 ch-1, 守夜人）、电击棒（主线1 ch-9）
- 手枪: 绿制服及以上均可配枪（主线1 ch-6）
- 春药弹: 特制子弹，性刺激效果（主线2 ch-13, 主线3 ch-13）
- 砍刀: 部分高级守卫（主线3 ch-11）
- 巨斧: 大奔的武器（主线3 ch-13）
- 弓: 夔牛弓（神武）（主线3 ch-9）

## 3. 世界观规则 / World-Building Rules

### 3.1 五兽种规则 / 5-Species Rule

**核心设定**: 作品中常见的五大兽种为 **熊/牛/虎/猪/狗**。

**原文出处**: 主线1 ch-12 武斗兵营分为三个区域（熊/牛/虎），但猪和狗也有常见出现。

**种族分布特征**:
- 牛兽种: 白之都郊区有水牛村（主线3 ch-5），牛族有专属楼层（主线2 ch-9）
- 熊兽种: 11层为熊族专属领地（主线2 ch-7）
- 虎兽种: "虎兽人几乎绝种"（主线1 ch-12），但仍有虎卫组（主线2 ch-4）
- 狗兽种: 多为杂役/低层兵种
- 猪兽种: 多为底层杂兵

### 3.2 非五兽种待遇 / Non-5-Species Treatment

除五兽种外，作品中出现了多种其他兽种:

**出现过的非五兽种**:
- 狼兽人: 银（特工局首席特工）、影爪（赏金猎人）、红狼（黑石）
- 狮子兽人: 守卫、军官
- 豹兽人: 雪豹（特工局）、黑豹（毕业实习）
- 犀牛兽人: 高级守卫、军官（犀牛在主线3 ch-22作为部长级守卫）
- 鳄鱼兽人: 辉董的角斗士护卫
- 鲨鱼兽人: 流墟（可化为胶液的怪物）
- 龙兽人: 龙武神（青龙）、辉董（白龙）
- 熊猫兽人: 武道馆馆长（熊猫师父在五竹峰）
- 变色龙兽人: 魉（天生的隐身天赋）
- 鼠兽人: 儡部长/儡爵
- 兔兽人: 曲先生
- 白猿: 一线天神武的守护者
- 猫兽人: 光照会信徒
- 德牧: 勤川（警局局长）
- 鬣狗: 守卫

**处理方式**: 非五兽种作为特殊情况/稀有角色出现，不做常规化处理。每个非五兽种角色都有其独特能力和背景。

### 3.3 薪资体系 / Salary System

**货币名称**: 撸币

**薪资数据**:
- **G级杂兵月薪: 约100撸币/月**（主线中多个G级角色确认）
  - 牛战蛮（G-123）："每个月从100撸币的工资里省下20"
  - 猪黑鬃（G-706）："G级工资100撸币/月，每月寄50回家"
  - 牛墨角（G-8917）："G级工资100撸币/月"
- **赏金价格（按制服等级）**:
  - G级（绿制服）: **100撸币/只**
  - 蓝制服（管理岗）: **200撸币/只**
  - 白制服（枪械）/ 黑制服（武斗）: **500撸币/只**
  - 摔跤兵: **1000撸币/只**
  - 低级=价格低: "这些绿制服的杂兵能值几个钱"（炎魉ch-1）
- **赏金猎人收入**: SS-001小谷一天赚1000撸币（种蛮力萝卜卖钱，非工资）
- 仓库津贴: 比市区高200撸币（守夜人）
- 杂兵攒钱速度: "三年...还差五千就能在老家盖一间新房子"（守夜人）
- 赏金奖励: "抓住他（龙武神）人物奖赏一个亿"（主线3 ch-13）

**购买力参考**:
- 100撸币 = G级杂兵月薪
- 1000撸币 = 杀一个G级的赏金
- 几千撸币 = 回村盖房首付（守夜人）
- 几十撸币 = 熊兽人身上搜出的零钱（墨犬ch-1）
- 月省20撸币 = 牛战蛮的存款速度

### 3.4 职级体系 / Hierarchy

**兽盾公司内部等级**:

1. **G级杂兵** (G-level Grunt)
   - 绿制服，最低级
   - 负责站岗、搬运、巡逻
   - 编号格式: G-XXX
   - 来源: 全系列

2. **组长/干部** (Team Leader)
   - 蓝制服
   - 管理新兵，中层管理
   - 来源: 主线1 ch-6, 炎魉ch-1

3. **战斗兵种** (Combat Specialist)
   - 黑制服武斗兵 / 白制服枪械兵
   - 需通过转正体能测试
   - 来源: 炎魉ch-2, 主线1 ch-8

4. **部长** (Minister)
   - 黑制服(旧款)，高层管理
   - 每个部门/楼层有部长
   - 例: 阿宝部长、流墟部长、儡部长
   - 来源: 主线1 ch-9

5. **董事** (Director/Chairman)
   - 兽盾公司最高层
   - 牙董(白狼，董事长)、辉董(白龙)、岚董(蓝虎)
   - 来源: 主线1 ch-10, 主线3 ch-11

**特工局等级**:
- 总司令（司令/峰）- 最高指挥（主线1 ch-11）
- 首席特工（银）- 精英（主线1 ch-11）
- 普通特工（小豪、雷炎寰、魔影等）
- 实习生（毕业实习中的雷炎寰）

**赏金猎人等级**:
- 独立职业，非官方组织
- 通过特工局获取赏金任务
- 不同实力层次: 黑石（强）、影爪（中等）、炎（中等偏下，不如熊猫）

### 3.5 精槽系统 / Lust Value System

这是兽盾世界最核心的战斗机制。

**核心规则**:
- 兽人受到伤害时，痛感转化为性快感
- 精槽(精关)蓄满后自动射精
- 射精=死亡（精尽而亡）
- 憋精=续命（但需要强大意志力）

**精通类能力**:
- 憋精功（主线1 ch-7: 牛杂用诈死技能）
- 中断射精保命（主线3 ch-17: "特殊兽种，拥有中断射精的保命神技"）
- 寸止功法（墨犬ch-2: 黑狗自悟的阻止射精手法）

**特殊机制**:
- 捏爆卵蛋 = 强行挤精，瞬间致死（主线1 ch-9, 主线2 ch-9）
- 银针封穴 = 无法动弹+强制射精（主线1 ch-11, 主线3 ch-11）
- 毒雾致死 = 吸入不到五分钟喷精毙命（主线3 ch-14）
- 灼流暗劲 = 内力转化为灼热，加速精槽（主线2 ch-6）

## 4. 命名规范 / Character Naming Conventions

### 4.1 兽盾公司命名规则

**编号系统**:
- 格式: `[等级字母]-[数字]`（如 G-612, G-533-538）
- G = Grunt 杂兵
- 三位数编号具有随机性

**中文姓名风格**:
- 动物姓氏 + 特征名: 牛大壮、熊厚实、熊大力、狗来福、豹速、黄彪、豕牙
- 种族相关: 大壮（牛）、来福（狗）、厚实（熊）、速（豹）、彪（虎）
- 来源: 毕业实习、守夜人

**角色代号**:
- 突出特征型: 黑石（肤色+硬）、魔影（能力）、银（毛色）、炎（能力=灼流）、魉（能力=隐身）
- 种族+职务型: 白熊组长、虎队长、牛哥
- 绰号型: 大奔、小豪、老雷

### 4.2 命名来源规则

- 农村来源: "名字是村里识字先生随便起的"（毕业实习）
- 自取名: "名字是自己起的"（豹速）
- 教官取名: "名字是入伍时教官给的"（黄彪）
- 收养者取名: "名字是收养他的老乞丐起的"（狗来福）
- 父母取名: "名字是母亲起的"（熊厚实、熊大力）

### 4.3 特殊命名

- 复合名: 雷炎寰（雷+炎+寰=雷霆火焰寰宇）、薛鼎（鼎+薛）、岚起鹏（岚+鹏）
- 功能型名: 古博士（古+博士）、儡爵（傀儡+爵位）

## 5. 武器与战斗 / Weapons & Combat

### 5.1 内功/功法体系 / Internal Techniques

**灼流暗劲** (Scorching Flow Dark Force):
- 使用者: 老雷（雷炎寰）、炎
- 效果: 攻击转化为灼热内力，侵入敌人体内加速精槽蓄满
- 特征: 战斗时毛发变红如火焰，眼冒红光（毕业实习）
- 来源: 主线2 ch-6首次正式登场，主线1 ch-01已有雏形

**银针封穴术** (Silver Needle Acupoint Seal):
- 使用者: 银（灰狼特工）、熊猫
- 效果: 银针刺入穴位使敌人无法动弹，然后可随意撸射
- 精通版: 北斗泄阳针法（主线3 ch-11: 七针必死，无论神佛）
- 来源: 主线1 ch-11, 主线3 ch-11, 炎魉全篇

**金钟罩** (Iron Body / Golden Bell Shield):
- 使用者: 熊兽人较多（主线1 ch-9狗熊护卫组长）
- 效果: 身体硬如钢铁，子弹弹开
- 来源: 主线1 ch-9, 主线3 ch-13

**血毒** (Blood Poison):
- 使用者: 虎卫组（主线2 ch-4）
- 效果: 血液有毒
- 来源: 主线2 ch-4

**虎纹分身** (Tiger Stripe Clone):
- 使用者: 薛鼎
- 效果: 分裂出复制体
- 来源: 主线3 ch-6

**魂术** (Soul Technique):
- 使用者: 血君王
- 效果: 灵魂占据他人身体
- 来源: 主线3 ch-19

**寸止功法**:
- 使用者: 黑狗（墨犬）
- 效果: 阻止射精中的兽人继续射精，救活对方
- 来源: 墨犬ch-2

**金刚护体**:
- 使用者: 炎（炎魉）
- 效果: 子弹弹开
- 来源: 炎魉ch-1

**五行封禁** (Five Elements Seal):
- 使用者: 龙武神
- 效果: 天下最强防御技，吸收五行攻击转化为能量
- 相生相克: 纯物理攻击属金→火克金反击；冰系属水→被吸收
- 来源: 主线3 ch-13

### 5.2 武器系统 / Weapon System

**普通武器**:
- 警棍: 杂兵标配
- 电击棒: 蓝制服及以上
- 手枪: 腰佩配枪
- 春药弹: 特制子弹（用翠绿遗迹毒草制作）
- 砍刀: 部分高级守卫（主线3 ch-11）
- 巨斧: 大奔（主线3 ch-13）
- 飞刀: 影爪（守夜人）
- 弩箭: 部分守卫（主线3 ch-14）

**神武系统**（详见8.4十二神武）:
- 每件神武都有独特能力
- 需认主/传承
- 部分可共鸣增强

### 5.3 战斗风格 / Combat Styles

**兽盾风格**: 
- 绿制服: 群殴，力量压制
- 蓝制服: 有组织的小队战斗
- 黑制服: 近身肉搏，一对一
- 白制服: 远程射击支援

**特工局风格**:
- 暗杀/潜入为主
- 匕首和短刀熟练
- 割喉处决（主线3 ch-16）
- 一对一利落击杀

**赏金猎人风格**:
- 偷袭摸哨，利用弱点
- 手法各异:
  - 黑石: 纯力气勒杀+撸射
  - 炎: 灼流暗劲
  - 影爪: 飞刀+撸杀

## 8. 其他设定 / Other World-Building Elements

### 8.1 货币 / Currency

**撸币** (Lu Coin/Lu Bi):
- 唯一流通货币
- 纸币形式（墨犬ch-1: "几张钞票被脚汗沾在了袜底"）
- 面额: 有不同面值的纸币（黑石: "各种面额的纸币"）
- 工资: 绿制服杂兵约1000撸币/月
- 商店可用撸币购物（主线1 ch-4: 武器店/服装店）

### 8.2 组织 / Organizations

**兽盾公司** (Beastshield Corp):
- 官方网站全称
- 总部在白之都
- 三位董事: 牙董(白狼)、辉董(白龙)、岚董(蓝虎)
- 内部纪律松散，同事互相残杀常见
- 杂兵更替频繁，失踪死亡不追究
- 员工大多为罪犯地痞
- 招聘流程简单粗暴
- 来源: 全系列

**特工局** (Agent Bureau):
- 与兽盾对立的地下组织
- 总司令: 德牧兽人（代号/名字: 峰）
- 知名特工: 银（已死）、魔影、雷炎寰/老雷、小豪
- 擅长暗杀、潜入
- 司令曾与辉董交手并吃亏（主线3 ch-11）
- 来源: 主线1 ch-11起

**光照会** (Light Cult):
- 宗教组织
- 教主: 辉董（白龙，兽盾第三董事）
- 总部: 白之都西部
- 信徒额头出现太阳纹路
- 口号: "信光照，得永生" / 真实版: "你们信光照，唯我得永生"
- 来源: 主线3 ch-11

**武道馆/武馆**:
- 教授武术的场所
- 熊馆长（白熊，主线1 ch-11）
- 龙拳馆（主线3 ch-2）
- 五竹峰（熊猫师父）

**赏金猎人系统**:
- 独立职业
- 通过特工局发布任务+核对赏金
- 标准流程: 击杀→拍照→取编号袜→核对→领赏
- 地下赏金工会（守夜人settings）
- 来源: 黑石系列、炎魉系列、守夜人

**警察系统**:
- 白之都警局
- 局长: 傅局长（水牛，主线3 ch-7）
- 警探: 勤川（猎犬德牧，一线天神武持有者）
- 来源: 主线3 ch-7

### 8.3 血精石与嗜精兽 / Blood Essence Stone & Semen-Eater Beast

**血精石** (Blood Essence Stone):
- 本质: 嗜精兽战死后灵魂封印在血液中结晶形成
- 历史: 蛮山一战，血君王耗尽精气施展邪咒
- 效果: 触摸血精石→灵魂喧宾夺主→如果匹配→共生为嗜精兽；不匹配→喷精毙命
- 红水晶→血精石前身（主线2 ch-14）
- 用途: 强化兽人战斗力（主线3 ch-16）
- 来源: 主线3 ch-19（完整解释）

**嗜精兽** (Semen-Eater Beast):
- 由血精石与宿主共生形成
- 特征: 眼冒红光（主线3 ch-16: "这些被血精石强化过的兽人"）
- 能力: 可吞噬精液恢复体力（主线3 ch-20: 阿宝吸食精液）
- 力量远超普通兽人
- 来源: 主线1 ch-10起

**血君王** (Blood King):
- 嗜精兽的祖先/最高统领
- 蛮山一战被龙武神率神武传人剿灭
- 化为黑色血精石存活
- 最终占据龙武神身体复活
- 来源: 主线3 ch-19~22

### 8.5 社会规范 / Social Norms

**雄性社会**:
- 全雄性兽人世界
- 双性征: 所有兽人同时拥有胸肌(类似乳房)+阴茎(雄雄关系)
- 性既是力量也是弱点
- 死亡与射精绑定

**阶级差距**:
- 兽盾内部等级森严
- 高层可以随意杀害低层
- 同事间相互残杀不追究
- 低层生命廉价

**文化特点**:
- 农村来源兽人用"俺"自称
- 城市兽人用语更现代化
- 员工守则存在但低层不识字的也带着
- 赌博文化（黑石中的赌命局）
- 吸烟常见（多个角色的习惯）

**食物与特殊作物**:
- 蛮力萝卜（特殊作物，吃了涨力气，需要兽人精液作肥料）
- 特殊作物种植体系: 精液作为肥料，不同种子产出不同效果（SS-001）
- 生化科技: 爷爷（生化学家）+ 古博士的研究（SS-001）
- 炒菜、肉食（农家乐）
- 吸烟（多重角色: 黑石、守夜人、夜袭）
- 说"好的"杀必死文化

**俘虏买卖与处决权交易**:
- 有专门店铺出售兽盾俘虏——购买"处决享受权"（SS-004）
- 价格: 约一个月工资（普通兽人）
- 运输: 木箱包装，后穴塞抑制器防止自行射精
- 抑制器/泄力棒: 塞后穴的圆柱体，拔出时后穴缩紧闭合；不同兵种用不同尺寸（摔跤兵30cm）
- 售后: 运输途中死亡可免费换更高级的（SS-004）
- 店铺警告"尽快处决，不要试图放生"——但主角可能产生"假怜悯"（SS-004的教训）

**公司文化**:
- 有储物柜（员工日记/毕业实习）
- 包吃包住（毕业实习: 牛大壮家里"管饭管住还发钱"）
- 体罚/自裁（炎魉ch-3: 高级军官在牙董面前自撸射死，捏乳头促进射精）
- 升职靠体能测试（炎魉ch-2）
- 制服改革制度（炎魉ch-2: 绿→转正后分武斗黑/枪械白/管理蓝）
- 设施质量一般（年久失修的铁栏杆、大型垃圾箱）
