## 外貌特征

**面容**
吻部较宽，灰棕色短毛覆盖口鼻周围，鼻头黑色湿润。双眼为深棕色，目光沉稳安静，不凶狠也不机敏——像一座不会说话的石碑。面部肌肉放松时嘴角微微下垂，使他看起来总像在沉思，而非不悦。两颊的毛色比头顶略浅，剃得整齐的鬓角边缘露出一截深灰色的原生毛根。

**体型**
典型的成年灰熊体格——肩宽背厚，上半身呈倒三角，腰腹还算紧实但已隐约开始囤积一层脂肪（站岗生涯的副作用）。站立时习惯微微含胸，两只大掌交握在身前或垂在体侧，给人一种"这人不惹事"的直觉印象。手臂粗壮，但没有刻意训练出的肌肉线条，更像天生骨架大加上常年体力劳动的结果。

**皮肤与毛发**
全身覆盖灰棕色短密被毛，背部最深（近乎灰褐），至胸腹渐变为浅棕色。毛质偏硬但不扎手，像旧刷子。右手腕有一道浅色旧疤（约五厘米长），是被伐木工具割伤后留下的痕迹，如今已被毛丛半掩。

## 人生时间线（白历纪年）

### 白历289年（0岁）

- **3月22日**：出生于北山省灰石镇的普通人家。父亲在镇上做零活，生父种菜喂鸡。家里不算穷，就是普通。

### 白历295年-302年（6-13岁）

- 在灰石镇唯一的小学读书。坐不住，成绩垫底——不是笨，是凳子烫屁股。放学后满山跑，抓兔子掏鸟窝，一身力气就是这么野出来的。
- 父亲骂过他几回，后来也懒得骂了——"不是读书的料就算了，别惹事就行。"

### 白历303年-307年（14-18岁）

- 勉强读完小学就死活不肯再去了。父亲说那你去干点活吧，他就在镇上的木材场给人搬料。活儿不算重，但也没多轻松——无非是扛木头、装车、卸车。干了一年多觉得没啥意思，辞了。
- 之后在镇周边断断续续打零工。帮人盖房子、修路、搬货——什么活都干不长久。"太累的不想干，太闲的钱少。"他自己也说不清楚到底想干啥。

### 白历308年-312年（19-23岁）

- **白历307年冬**：在镇上一家小酒馆喝酒，邻桌几个喝大了的年轻人推搡到他身上。他第一次说了句"别挤了"，对方没听，又撞了一下。他站起来推了一把——灰熊的力气他没控制好，对方飞出去撞在桌角上，头破血流，当场不省人事。他以为把人打死了，酒醒了大半，拔腿就跑。
- 连夜搭了一辆拉木头的货车出了山，辗转到了省城。身上没几个钱，也不敢回家。在车站蹲了两天，看到兽盾的招聘告示——"招人，不问来路，包吃住"。他撕了告示找过去，对方看他这身板，二话不说就收了。
- **白历312年9月**：正式入职，编号G-178。

### 白历313年-316年（24-28岁）

- **白历313年初**：完成三个月基础训练，被分配到市区序列，编为G-178。
- **入职后第一次穿制服**：G级军绿色短袖套上身的一刻，灰熊魁梧的身板把衣服撑得满满当当。尺码偏大一号的制服穿在他身上刚好合身——胸肌和腹部的轮廓在绿色布料下若隐若现。短裤的裆部兜着熊鞭粗短厚实的形状，他低头看了看，伸手调整了一下角度让它别歪到一边去。旁边的同期同事说"老熊你穿这身挺精神的"，他憨厚地笑了笑，心里想的是"比伐木工的衣服轻多了"。
- **白历313年9月14日**：入职后第一次随队执行"场地清理"任务——一处废弃厂房内，三名拒绝配合兽盾"转租协议"的租户被强制驱逐。熊石坚被安排在厂房后门外站岗。他听到里面传出砸东西的声音和一个老者嘶哑的叫喊，然后是重物倒地的闷响。他没有进去看，只是在门外一动不动地站了两个小时，直到组长从后门探出头说"完事了"。
- **白历314年-316年**：陆续执行过仓库看守、厂房巡逻、护送押运等任务。表现中规中矩——不出彩也不出错。上司对他的评价是"可靠，但别指望他主动做事"。
- 食堂里杂兵们吃饭时的话题他从来不参与——不是不想，是不知道该说什么。那些"你猜那狗崽子射了多少"的讨论从他左耳进右耳出，他埋头把饭扒完，端着空碗站起来的时候，那桌人还在争论是七发还是八发。
- **白历314年7月22日**：某夜值勤，在仓库后门看到两名武斗兵将一只沉重的黑色裹尸袋装入货车后备箱。他下意识地多看了一眼——裹尸袋的拉链没拉严，露出一截灰白色的兽爪。一名武斗兵注意到他的目光，淡淡地说："你什么都没看见。"熊石坚点了点头，转过头去，面朝墙壁站完了剩下的夜班。
- **白历315年某日**：站岗时天气炎热，他解开领口第一颗扣子散热，胸口的灰棕色皮毛从领口露出来一丛。路过的一位兽人看了他一眼，他不好意思地把扣子又系上了——但过了十分钟又热得解开了。后来他发现只要保持面无表情，大多数路人不会注意到他。但他没注意到的是，楼上走廊里的灰狼杂兵透过窗户看了他站岗的背影好几眼。
- **白历315年12月3日**：接到紧急调令前往城外一处"事故现场"——一名外勤组G级杂兵在巡逻途中遭遇赏金猎人伏击，尸体倒在城郊排水沟中。熊石坚被命令搬运尸体。死者他认识——是上周还在食堂一张桌上吃过饭的同事，绰号"大刘"，一个爱在饭后剔牙说笑的熊族中年人。此刻那张脸灰白僵硬，胸口被利器贯穿，血已经在衣服上凝成了黑紫色的硬壳。熊石坚沉默地把尸体装上了车，当天晚饭一口都没吃。

### 白历317年5月（28岁）

- **5月某日**：被临时调派到利达酒店执行外围警戒任务，在正门口站岗。直属上级是橙虎队长（虎金烈）。
- （剧情事件）主角潜入利达酒店，熊石坚作为门口守卫可能是主角第一个接触的兽盾人员。

## 个人背景与经历

### 1. 本质与性格

熊石坚是一座沉默的山。他话不多，不是冷漠，是习惯——山里的孩子从小就不太会表达。别人聊天他听着，别人吵架他躲着，别人打架他拉架。他不笨，只是反应慢半拍，凡事需要多转一个弯才能理解，但他想通的事情就很少再动摇。

他有一种大山般的钝感力：被上司骂了不往心里去，被同事排挤了也不计较。"反正我就是个站岗的，站好自己的岗就行。"这种性格让他既不招人喜欢也不招人讨厌——完美地融入了兽盾庞大机器里的一颗螺丝钉。

道德观朴素而直接：老板给钱，我干活。组织让我站门口，我就站门口。至于这家公司到底在干什么——他没想过，也不太想。反正他也不是因为认同什么才来的，只是碰巧走到了这里。

### 2. 认知局限与幻梦

熊石坚对世界的理解是物理层面的：力气大就不吃亏，站好岗就不会被骂，不惹事就不会惹麻烦。他对兽盾的复杂性质没有任何认知——在他眼里这和以前干过的货运站、木材厂没有本质区别。

他不太想以后的事。离开村子的时候什么都没带，也不知道还能不能回去。站岗的时候就站着，站完一天算一天。有时候发呆的时候会想到老家——想到屋后的桦树林、秋天满山的红叶——但那个画面越来越模糊了。他不知道那个被他推倒的人后来怎么样了，也不敢打听。

### 3. 系统下的生存

在兽盾的等级体系中，G-178是最底层的存在。没有话语权，不了解任务全貌，被告知去哪里就站在那里。他的价值就是他的体型——灰熊站在门口，本身就是一种威慑。系统利用他的沉默和服从，让他成为一道"活着的路障"。

他的生存策略极其简单：不惹事、不打听、不缺席。食堂开饭就去吃，下班就回宿舍躺着。休息日偶尔去街上走走，买点卤肉和馒头，回来边吃边发呆。他不太想兽盾的事——反正也不是什么好人待的地方，但他也不是什么好人。

### 4. 重要关系网络

- **老家**（灰石镇）：跑出来之后没再联系过。不知道家里人知不知道他在哪，也不知道那个被他推倒的人后来有没有醒过来。偶尔路过邮筒会顿一下，但从来没寄过信。
- **虎金烈（O-089，橙虎队长）**：直属上级。虎金烈对他的态度是"还行，不惹事"。熊石坚对虎金烈的印象是"这个队长说话挺利索的，就是嗓门有点大"。

### 5. 重要遗产与象征物

- **那张招聘告示**：从车站告示栏撕下来的时候边角还带着干掉的糨糊，叠了四折塞在兜里，后来一直压在宿舍床垫底下。不是留着纪念——就是懒得扔。
- **灰石镇老屋**：在他记忆里永远是秋天——院子里晒着玉米，灶台上炖着野菜汤。这个画面越来越模糊了，但他站岗发呆的时候偶尔还是会想起来。

## 原作剧情

**出场关卡**：L-05 警局区域·潜入 — 利达酒店 SC-01

**在本关中的角色**：
利达酒店正门外站岗守卫。负责阻拦无关人员进入，监视街道动静，发现异常用对讲机通报。

**关键事件流程**：
1. 站在酒店正门口，保持基本警戒姿态
2. 主角接近酒店时，他是第一个需要注意的障碍
3. 如果主角选择从正门进入，需要绕过或处理熊石坚
4. 如果主角选择从侧面/后门潜入，熊石坚全程不会意识到有人进入
5. 酒店内发生骚动后，熊石坚可能被虎金烈呼叫支援（视主角行动而定）

**原作结局**：原作中熊石坚属于"可绕过"角色——如果主角从其他路线进入，他全程不会进入冲突场景；如果主角正面对上，大概率被击晕或击杀。在原作以杀戮为主的路线中，熊石坚通常被绕过不处理，而非被刻意针对。

## 本作改编设定（Save Us Then Load World）

**核心挑战**：
熊石坚不是战斗型敌人，他是一个"安静的门卫"。他的威胁不在于攻击性，而在于"他会如实报告看到的一切"。如果主角从正门进入被他看见，他会描述主角的外貌给虎金烈，导致后续关卡的警戒等级提升。

### 拯救路线

- **路线A（潜行绕过）**：主角不经过正门，从酒店侧面翻墙或走员工通道进入。熊石坚全程不会知道主角的存在。最简单、最安全的方案，但需要主角具备基础潜行能力或提前探索过酒店周边环境。

- **路线B（套近乎分散注意力）**：主角伪装成酒店工作人员或快递员，接近熊石坚后用话术转移他的注意力——"老哥，门口有辆货车挡路了，队长让你去帮忙挪一下。"利用熊石坚不怀疑上级指令的特点，将他从岗位上调离。需要成功伪造指令（至少看起来合理），或利用对讲机干扰。

- **路线C（食物诱惑）**：熊石坚站岗时间较长，如果主角在附近买一份热食（烤肉串/馅饼），以"队长让我给你们站岗的兄弟带份饭"的名义递给他。灰熊对食物的兴趣会让他在接过食物后放松警惕，主角趁机从他视线盲区进入。风险较低，但需要额外花费少量资金。

**与主角的关系基础**：
初次见面，完全陌生。熊石坚不认识主角，主角也不认识他——只是档案上知道有这么一个灰熊守卫在门口。

**读档条件**：
如果熊石坚被惊动并通报虎金烈，导致主角暴露——读档点回到接近酒店外围的时刻，切换接近路线或更换伪装方案。

| **兵种与等级** | G级（军绿）— 基础站岗守卫，无武器配发，核心职能为"警戒与通报" |
| **种族特性** | 灰熊体格的天然威慑力——不需要武器就能让人不敢轻举妄动；耐力好，能长时间站岗不疲惫；代谢低，一天吃两顿正餐就够了 |
| **入职背景** | 小镇出身，在木材场干过几年搬运。酒馆打架失手伤人后跑路，为避风头加入兽盾——属于"惹事跑路"型被动入职 |
| **经济状况** | 没什么存款——工资发了就花，买卤肉买烟买酒，月底剩不下几个子儿。反正也没什么需要攒钱买的东西 |
| **家庭关系** | 老家在灰石镇，跑出来后没再联系过。不知道家里人怎么想他，他也不太敢想 |
| **性格动机** | 务实者/麻木者混合——不是没有感情，而是习惯了不表露感情。做事的动力是"做完该做的事"而非"追求什么" |
| **技能特长** | 体力劳动全能（搬运/装卸/简单木工）；格斗水平零（除了仗着体型推搡，没有任何系统训练经验） |
| **人际关系** | 独行侠型——不主动社交也不排斥社交，同事对他"没印象"本身就是一种存在状态 |
| **未来计划** | 没想过。走一步看一步，走到哪天算哪天 |
| **加入兽盾契机** | 在车站蹲了两天没饭吃的时候看到招聘告示——"招人，不问来路，包吃住"——他就去了。和忠诚、理想、抱负都无关 |

## 备注

- 熊石坚是全作中**最"普通"的角色之一**。他的叙事意义在于展示：兽盾这家公司的底层员工并不都是穷凶极恶之徒，很多只是稀里糊涂就来到了这里。他在这个体系里既不快乐也不痛苦，只是"存在着"。
- 如果主角成功穿越本关且未惊动熊石坚，他不会对后续剧情产生任何影响；但如果主角在他面前暴露了身份和意图而不杀他，他会被兽盾内部调查审问——一个老实人被迫在"如实招供"和"保护入侵者"之间做选择时，会是怎样的局面？本作未必要深入这条线，但值得在角色设计中留下这个伏笔。
