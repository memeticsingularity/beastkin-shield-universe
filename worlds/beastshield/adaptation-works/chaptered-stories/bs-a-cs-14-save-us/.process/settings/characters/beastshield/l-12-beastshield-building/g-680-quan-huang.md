## 外貌特征

**面容**
瘦长的犬族面孔——吻部突出，鼻头黑色湿润，耳朵直立呈三角形，耳尖微垂。眼睛是深褐色的，眼神灵活而警惕——在恐惧时会左右快速扫视寻找逃生路线。嘴唇薄，紧张时会不自觉地露出上排犬齿。

**体型**
犬族的典型精干体型——肌肉线条分明但不夸张，肩宽适中，腰腹收紧，四肢修长有力。整体给人一种"灵活、敏捷、擅长奔跑"的印象——和其他守卫站在一起时，他是最瘦小的那个。

**皮肤与毛发**
全身覆盖黄褐色短毛，腹部毛色较浅呈米黄色。背部的毛在光线下有深浅不一的花纹。尾巴（如果有）是蓬松的帚尾，紧张时夹在两腿之间。

## 人生时间线（白历纪年）

### 白历291年（0岁）

- **白历291年4月**：出生于犬族聚居的城郊社区。父亲是街边小贩，生父在菜市场卖菜，家境贫寒。

### 白历309年（18岁）

- **白历309年**：成年后做过多份零工——快递员、送餐员、夜市帮工。犬族的灵活和速度让他在这些工作中如鱼得水，但都不长久。

### 白历313年（22岁）

- **白历313年6月**：经朋友介绍入职兽盾公司，以G级杂兵身份分配至总部守卫队。他本不想干这行——但兽盾"包食宿"的条件对一个在城市里漂着的人来说太有吸引力了。

### 白历317年——剧情事件（26岁）

- **事发当日**：随虎领队的增援小队赶到一层。看到虎卫啸、虎蒋雪、猪吴刚、犀陈甲、狮李烈、豹王影等同伴接连死亡后吓得腿软失去战意，转身就逃。被老雷追上，以和虎卫啸同样的方式处决——捏碎卵蛋挤精而死。

## 个人背景与经历

### 1. 本质与性格

犬郑风是天生胆小的人——不是懦夫，而是那种对危险有着敏锐直觉的人。他能比其他人更早地感知到"这里待不下去了"，然后第一反应就是跑。这种本能在街头送外卖时帮了他很多次（避开危险区域、躲开醉汉），但在守卫这个岗位上成了致命的弱点。

### 2. 认知局限与幻梦

他从来就不想当守卫——只是想找个包吃包住的地方攒点钱，然后回老家开一间小卖部。他以为当守卫就是站站岗，没想到会真的打起来，更没想到会死人。

### 3. 系统下的生存

在兽盾的守卫体系中，犬郑风是最"不划算"的那种员工——体格不如牛族和熊族，气势不如虎族和狮族，唯一的优势是速度快，站岗放哨也算合适。但他缺乏战意，这在需要充场面的时候就成了短板。

食堂里杂兵们讨论处决细节的时候，犬郑风总是挑最角落的位置坐下。他不是听不见——他只是不想听。那些数字和描述钻进耳朵里，跟他送外卖时见过的那些被追债的人重叠在一起，让他胃里发酸。

### 4. 重要关系网络

- **豹王影（同僚）**：同一个小队里和他"体型"最接近的守卫。两人偶尔在食堂一起吃饭，聊过老家的事。
- **父亲（健在）**：街边小贩，卖炒栗子，收入不稳定。
- **生父（健在）**：菜市场卖菜，和父亲一起维持着家用。
- **无伴侣**：没钱没房没稳定工作，他自己觉得"哪个会看上我"。

### 5. 重要遗产与象征物

无——来兽盾公司报道时只带了一个背包的换洗衣物。

## 本作改编设定（Save Us Then Load World）

**核心挑战**：
犬郑风是唯一一个试图逃跑的守卫——他的求生欲比其他人都强。在原作中他仍然被追上处决，因为老雷的原则是不留活口。在Save Us路线中，逃跑行为本身反而为他创造了生存空间——只要老雷选择"追不上"或"懒得追"。

### 拯救路线

- **路线A：利用速度优势顺利逃脱**——犬郑风比其他人跑得都快，如果老雷优先处理其他威胁（如增援的更多守卫或报警系统），他可能真的能跑出大楼。
- **路线B：老雷主动放过**——一个逃跑的守卫对老雷来说威胁最小，如果老雷判断"追他不值得"，他就能活。
- **路线C：躲藏而非逃跑**——如果犬郑风不是向大门外跑，而是就近躲进某个房间或角落，老雷在清理完其他目标后可能直接上楼，忽略躲起来的他。

**与主角的关系基础**：
陌生人。

**读档条件**：
如果犬郑风被追上处决，读档点设在一层大厅连杀开始前。关键变数在于老雷是否选择追击逃跑者。

### 时间线变动记录

| 读档 | 尝试方法 | 结果 | 角色命运 |
|------|---------|------|---------|
| #1 | 原作路线——逃跑后被追上处决 | 被老雷追上捏碎卵蛋 | 死亡 |
| #2 | 老雷优先处理报警系统，犬郑风趁机逃脱 | 跑出大楼，消失在街道尽头 | **存活** |

## 差异化设计维度

| 维度 | 设定 |
|------|------|
| **兵种与等级** | G — 低层守卫（绿色制服） |
| **种族特性** | 犬族——行动敏捷灵活，善于奔跑，但力量和耐力不如牛族和熊族。直觉敏锐，对危险的感知力远强于其他种族 |
| **入职背景** | 城市零工族——送过快递和外卖，在夜市帮过工，一直没找到稳定的饭碗 |
| **经济状况** | 月薪100撸币，几乎月光——偶尔寄一点回老家，但大部分花在了吃饭和廉价租房上（入职兽盾前） |
| **家庭关系** | 父亲街边小贩、生父菜市场卖菜、无伴侣 |
| **性格动机** | 求生本能驱动型——所有行为的最高优先级是"活下去"。胆小但不懦弱，只是比其他人更清醒地评估了风险 |
| **技能特长** | 速度快、灵活、擅长逃跑 |
| **人际关系** | 在队里存在感低——没人讨厌他但也没人和他特别亲近 |
| **未来计划** | 攒钱回老家开小卖部——"这破地方我一天都不想多待" |
| **加入兽盾契机** | 朋友介绍——被"包食宿"吸引，本想干几个月攒点钱就走，结果一干干了四年 |
