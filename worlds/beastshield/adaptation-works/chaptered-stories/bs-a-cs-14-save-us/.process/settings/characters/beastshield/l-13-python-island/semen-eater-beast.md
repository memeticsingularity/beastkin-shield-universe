# 角色档案：嗜精兽 - Semen Eater Beast

> 被血精石强化的兽盾蓝制服守卫——肉体超越兵器，理智被杀戮欲望吞没。

---

## 基础信息

| 项目 | 内容 |
|------|------|
| **常见种族** | 牛、虎、熊、狼、豹等（原为前组长级蓝制服守卫） |
| **毛色** | 因种族而异——共同特征是眼冒红光 |
| **制服等级** | O级 → 特殊强化（蓝制服） |
| **职位** | 原为组长级守卫，经血精石强化后成为嗜精兽突击部队 |
| **所属** | 兽盾公司/特殊强化部队 |
| **首次登场** | l-13-python-island 浮岛大战（故事3·第15章） |

---

## 外貌特征

**面容**
眼冒红光——与牙董的血精石状态相似。表情通常扭曲着嗜血的亢奋，嘴唇因兴奋而微微张开，犬齿外露。

**体型**
原为蓝制服前组长出身，身材普遍魁梧彪悍。经血精石强化后肌肉线条更加突出，体态比普通守卫更壮实。

**皮肤与毛发**
各色兽毛，共同特征是眼部的红光和皮肤下隐约透出的血精石纹路。

## 已知个体

### 灰熊嗜精兽
- **种族**：灰熊兽人
- **背景**：蓝制服灰熊
- **原作结局**：在老雷救白虎特工时被单手掐碎喉骨而死，死前在半空中射精

### 水牛嗜精兽
- **种族**：水牛兽人
- **背景**：蓝制服水牛
- **特殊**：被血精石强化后从未遇过敌手
- **原作结局**：被老雷一拳打入灼流暗劲，站着射精而死（"精液烟花"）

### 红牛嗜精兽
- **种族**：红牛兽人（特殊兽种）
- **背景**：蓝制服红牛
- **特殊能力**：拥有中断射精的保命神技——在曲先生的夏日灼魂歌中第一个倒下（假死），在曲先生力竭时偷袭
- **原作结局**：被赶到的魔影抓住牛鞭制服

### 其他嗜精兽
虎嗜精兽、狼嗜精兽、熊嗜精兽、豹嗜精兽等——均在夏日灼魂歌中射精毙命。

## 原作剧情

**出场关卡**：l-13-python-island（故事3·第15-17章）

**在本关中的角色**：
兽盾特殊强化突击部队

**关键事件流程**：
1. **第15章**：在浮岛大战中作为突袭部队从侧翼杀出。特工与之对阵不过十招就会被捏爆卵蛋惨死。老雷击杀其中数只。曲先生以笛声将其引走并用夏日灼魂歌全灭（除红牛假死）。
2. **第16章**：曲先生持续吹奏夏日灼魂歌追击嗜精兽，仅在曲声中就逐一射精而死。
3. **第17章**：红牛嗜精兽偷袭曲先生被魔影阻止。

## 本作改编设定（Save Us Then Load World）

**核心挑战**：
嗜精兽经血精石强化后实力远超普通守卫，且陷入嗜血狂暴状态后难以沟通。但他们有一个致命弱点——易受曲先生的夏日灼魂歌影响。

### 拯救路线
- **路线A**：非战斗回避——利用嗜精兽的狂暴特性，将他们引向无人区域而非直接对抗
- **路线B**：曲先生的声波控制——用夏日灼魂歌使其失去战斗力而非致命
- **路线C**：红牛嗜精兽的特殊能力意味着他可能可以被控制或收服

### 读档条件
嗜精兽个体死亡不影响主线，但如果曲先生力竭则可能被红牛偷袭得手。

## 性机制

| 项目 | 内容 |
|------|------|
| **特有敏感部位** | 因种族而异——血精石强化可能增强了性器官的敏感度和耐力 |
| **精槽特性** | 被血精石强化后精槽容量和精压似乎得到提升；在夏日灼魂歌影响下会失控射精，精液喷射量惊人（水牛嗜精兽的"精液烟花"） |
| **制服性特征** | 蓝制服经过强化后更加紧身，肌肉线条在布料下如同雕刻——胸肌、腹肌、大腿、裆部的轮廓都比普通守卫更加夸张醒目 |
| **性互动方式** | 战斗中的失控射精——血精石强化使他们在战斗中更容易进入性兴奋状态，但也会在夏日灼魂歌的影响下无法控制地射精而死 |
| **性偏好维度** | 未明确——血精石强化后嗜血欲望压倒了其他所有欲望 |

## 备注

- 嗜精兽是血精石强化的产物，眼睛冒红光是其标志性特征（与牙董的血精石状态相同）
- 不使用兵器，全靠肉体战斗——肉体破坏力远超常规武器
- 红牛嗜精兽是唯一的特殊个体，拥有打断射精的能力（假死技能）
- 嗜精兽的弱点明显——易受曲先生夏日灼魂歌影响，在笛声中失控射精而死
- 在Save Us中的定位参考：中后期精英敌人群体——正面战斗难度高，但可以通过声波攻击等特殊手段克制
