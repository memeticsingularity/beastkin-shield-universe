## 外貌特征

**面容**
极其醒目的纯白皮毛——在全作几乎所有兽人都是暖色系的世界中，他的一身白毛让人过目不忘。面部轮廓偏瘦削，尖吻，双耳直立，耳廓内侧是粉嫩的肉色。眼睛为浅灰色，目光中有一种街頭混久了才有的精明和警觉。嘴角常带着一丝似笑非笑的弧度——那是他在街头上练出来的保护色，让人拿不准他到底在想什么。

**体型**
修长但不单薄——属于"穿衣显瘦脱衣有肉"的类型。肩宽适中，腰线利落，白色的皮毛在颈部略长，像围了一圈天然的白围巾，衬得整个人既精神又有几分少年气。动作灵活，站立时总有一只脚轻轻点地，像是在随时准备转身离开。

**皮肤与毛发**
纯白色的柔软皮毛，毛质蓬松，在阳光下会泛出淡淡的银光——这是生父狼白原遗传给他的特征，全作中极罕见。脖子和胸口处的毛略长，形成了一个天然的白"围脖"。耳廓内侧是粉嫩的肉色，与白色皮毛形成鲜明对比。脚掌垫是深灰色的。

## 人生时间线（白历纪年）

### 白历296年（0岁）

- **4月15日**：出生于一个普通家庭。父亲狼北风是一名边境猎人，生父狼白原是南方商人。狼谣的纯白毛色遗传自生父——狼白原也是白化狼，这在狼族中非常罕见。双父对这个独子倾注了全部的爱，给他取名"谣"——父亲说，这孩子将来会有很多故事。

### 白历296-311年（0-15岁）

- 在白之都边境小镇度过童年。父亲每次狩猎回来都会给他带一些小玩意——好看的石头、异域的羽毛、兽骨雕刻的小挂件。生父则教他认字算数，给他讲南方城市的故事。他从小就有一个"出门看看"的念头。

### 白历311年（15岁）

- **9月14日**：父亲狼北风在边境狩猎时遭遇盗猎者袭击，重伤不治身亡。狼谣在死亡证明上签字的双手止不住发抖。"谣"字写歪了，墨迹洇开一小片——那是他这辈子第一次觉得自己的名字很讽刺。故事还没开始，父亲的故事就先结束了。

### 白历314年（17-18岁）

- **2月8日**：生父狼白原因丧偶抑郁成疾，在家中离世。狼白原的身体本就不好，狼北风死后他像一盏油灯一样慢慢燃尽了。狼谣在三天内独自处理完所有后事——卖房还债，在街頭租下一间单间开始讨生活。这三天他没有掉过一滴眼泪。不是不想哭——是眼泪流干了。

- **6月18日**：开始在酒吧和黑市之间跑腿贩卖小情报。第一次发现自己的白毛和长相是种优势——一个喝醉的牛兽人拍拍他屁股说"白毛小子挺俊啊"之后就管不住嘴了，把兽盾一个据点换防的时间全说了。他表面陪笑，心里记下了："原来你们这群人吃这套。"

### 白历315年（19岁）

- **9月22日**：为了换取一份重要情报，被对方要求"陪一晚"。他衡量了风险后答应了——用的是手和嘴，没让对方插进来。结束后对方呼呼大睡，他在洗手台前漱了很久的口，对着镜子里的自己说"就这一次"。但后来这种事又发生了三四次。每一次他都告诉自己"这是情报的成本"，每一次漱口的时间都在变短。

### 白历316年（20岁）

- **4月20日**：贩卖情报时被兽盾的人盯上，被堵在巷子里打断了三根肋骨。特工局的人救了他——这是他欠特工局那条命的开始。养伤期间他想了很多：如果不是特工局，他可能已经精槽被清空死在巷子里了，和那些他见过的"处理品"一样。

### 白历317年（21岁）

- **L-09**：以特工局外围线人身份出现在特工局，为特工局提供关于兽盾内部动向的情报。欠特工局的情——他给的信息总是打折扣的价格，但情报本身不打折扣。

## 个人背景与经历

### 1. 本质与性格

圆滑机灵——嘴甜会来事，见什么人说什么话。能在三句话内判断出对方是什么样的人，然后迅速调整自己的应对方式。信息即货币——他收集情报不是为了正义，而是为了交易。对他来说，知道得越多就越安全。但他有底线：不碰真正危险的情报交易，不留把柄。他知道自己的价值在于"活着且自由"。对特工局有感激之心——特工局的某个人（可能是银或熊馆长）曾经帮过他一个大忙（在他被兽盾追杀时救了他），因此他愿意为特工局提供情报——打折扣的价格，但情报本身不打折扣。

### 2. 认知局限与幻梦

他的世界观是在街頭摸爬滚打中形成的——人与人之间只有利益交换，信任是奢侈的奢侈品。他的梦想很具体：攒够钱，在白之都好一点的街区开一家小酒馆——在那里他只招待他看得顺眼的人，每个进门的人他都认识，没人能在他店里搞事。这个梦想是他每次用身体换情报时对自己说"再忍忍"的理由。他的认知局限在于：他把所有人都默认归类为"可利用/不可利用"——这让他难以建立真正深入的关系，也让他低估了某些人可能对他怀有的真诚。

### 3. 系统下的生存

他不属于任何一个系统——他是游走在系统边缘的人。在兽盾眼里他是"需要清除的苍蝇"，在特工局眼里他是"有用的外围线人"。他精确地维持着自己的位置：离特工局够近以获得保护，离兽盾够远以避免被清算。他知道自己的白毛太显眼，走在街上三步外就能被认出来——所以他学会了用帽子、斗篷和阴影来缩短自己的"可见半径"。他不对任何组织忠诚，但他对"救过我命的人"忠诚——这是他在街頭学到的最后一条准则：欠命还命。

### 4. 重要关系网络

| 关系 | 角色 | 关系说明 |
|------|------|---------|
| 父亲（已故） | 狼北风 | 边境猎人。狼谣性格中的机灵和察言观色有一部分来自小时候跟父亲在边境集市上跟人打交道练出来的本事。父亲死于盗猎者之手——这是狼谣开始"讨厌暴力"的起点。 |
| 生父（已故） | 狼白原 | 南方商人。教狼谣认字、算数、讲价，给了他唯一一点"正经谋生技能"。白化狼的毛色遗传自他。 |
| 救命恩人/雇主 | 银或熊馆长（特工局） | 具体是谁救了他，狼谣从不细说——他怕说得太多会连累对方。他只知道自己欠一条命，信息费打折就是他在还。 |
| 交易伙伴 | 多个无名情报买家 | 纯粹的买卖关系。狼谣和他们保持微笑和距离——微笑是为了让他们放松，距离是为了自己安全。 |
| 身体交易对象 | 无名（多人） | 为了情报用身体交换过四五次。他告诉自己那是"信息成本"，但每次完事后的恶心感和漱口时间总在提醒他这不完全是成本——这是磨损。 |

狼谣在双父去世后没有再建立过真正亲密的关系。不是不想——是不会了。他太早学会了把所有人分成"有用"和"没用"，以至于忘了怎么简单地和一个人待着什么都不做。

### 5. 重要遗产与象征物

- **左手腕的红绳**：来源不明，他自己从不说。但认识他久的人都知道——他从十五岁那年父亲死后就开始系着，从来没摘下来过。可能是某种纪念，可能是某个人的信物，也可能只是"提醒自己还有牵挂"的东西。
- **父亲的小挂件**：狼北风最后一次狩猎前给他带的骨雕小狼——很粗糙，但父亲的手艺就是这样。他贴身带着，被兽盾打断肋骨那次挂件被压裂了一道缝。他心疼了很久。
- **白毛**：生父遗传给他的纯白皮毛。小时候他讨厌自己太显眼——"为什么我不是灰的？"长大后才明白，显眼有时也是武器——你够显眼，别人就会先记住你的脸，然后才去想你是谁。他学会了用这份显眼来操纵别人的注意力。

## 原作剧情

**出场关卡**：L-09 特工局

**在本关中的角色**：
情报贩子/外围线人，为特工局提供关于兽盾内部动向的关键情报。属于"信息NPC"——提供信息后即退场，不参与后续战斗或剧情。

**关键事件流程**：
1. 在特工局与主角碰面——他认出主角是"特工局的人"后放松下来
2. 以情报交换的方式提供关于L-10武斗兵营和兽盾内部状况的信息
3. 交换完成后离开——"有事再找我，老地方。"

**原作结局**：存活——作为特工局外围线人，在原作中没有遭遇不测。但如果线人身份暴露，他随时可能被兽盾追杀。

## 本作改编设定（Save Us Then Load World）

**核心挑战**：
他本身不属于需要被"拯救"的对象——他不是俘虏也不是受害者。但他是Save Us世界中一个脆弱的平衡点：如果他因为帮特工局而暴露，兽盾会追杀他；如果特工局不再保护他，他会死得很惨。核心在于：如何在这个灰色地带中让他不是"用完就丢的棋子"。

### 拯救路线

- **路线A：情报保护**——不让他卷入太核心的任务，只让他接触"即便暴露也不会立刻致命"的信息
- **路线B：安全转移**——如果他的线人身份暴露，帮助他撤离白之都，甚至帮他实现开酒馆的梦想
- **路线C：身份升级**——推荐他从"外围线人"转为正式特工局后勤人员，让他获得组织庇护

**与主角的关系基础**：
陌生人，但同为特工局关联者。他会对主角产生兴趣——一个在兽盾内部搞"不杀路线"的人，他从来没听说过。他的第一反应是好奇，然后是半开玩笑的报价："你这故事……值不少钱呢。"

**读档条件**：
如果他因情报交易暴露被兽盾追杀致死，读档点回到L-09交易现场。需要限制交易内容或提前安排保护措施。

### 时间线变动记录

| 读档 | 尝试方法 | 结果 | 角色命运 |
|------|---------|------|---------|
| #1 | 正常交易后无保护措施 | 三日后被兽盾查出线人身份，在住处被堵住 | 死亡 |
| #2 | 交易后安排临时庇护所 | 躲过追杀，建议离开白之都避风头 | 存活（转移） |
| #3 | 交易前建议他向特工局申请正式身份 | 被纳入特工局后勤编制，不再单独行动 | 存活（编入） |

| **性偏好维度** | side（等价交换型）——故意避免插入式，在身体交易中以手和嘴为主，设有精槽上限。不主动不抗拒，性对他来说是一种可计算的货币，而非欲望的满足。他私下幻想过的亲密关系不是这样的——应该是温和的、互相的、不带金钱或情报交换的那种。但那只是幻想。现实里他在洗手台前漱口的时间一次比一次短——不是因为习惯了，是因为不想承认自己不习惯。 |

## 差异化设计维度

| 维度 | 设定 |
|------|------|
| **兵种与等级** | 无编制——非兽盾非特工局正式成员。他的"等级"由他掌握的信息量和人脉网络决定。 |
| **种族特性** | 白化狼——纯白毛色在全作中极为罕见，既是显眼的负担也是引人注目/降低戒心的武器。狼族听觉敏锐、耐力强。 |
| **入职背景** | 不适用——没有正式入职过任何组织。少年丧父后从街頭跑腿做起，逐渐成为情报贩子。 |
| **经济状况** | 不稳定收入——情报买卖的收入波动很大。好的时候月入200撸币，差的时候倒贴。没有存款——钱都花在租金和"维护关系"上了。偶尔靠身体换情报时能省下一笔信息费。 |
| **家庭关系** | 父亲狼北风（已故，边境猎人）、生父狼白原（已故，南方商人）。十五岁丧父，十八岁双父俱亡——此后无亲无故。 |
| **性格动机** | 生存驱动——他的所有行为都围绕一个核心：活着。情报是工具，关系是工具，身体也是工具。他想要的不多——一家自己的小酒馆就够了。 |
| **技能特长** | 情报收集与分析——他能从零散的信息中拼出完整的图景。察言观色能力极强，三句话内能判断对方类型。熟悉白之都的地下网络和黑市运作。 |
| **人际关系** | 广泛的弱连接——认识很多人，但没有真正亲近的人。唯一让他有点"欠着"感觉的是救过他的特工局某人。独来独往是习惯也是保护。 |
| **未来计划** | 攒钱开一家小酒馆——在白之都好一点的街区，有自己的地盘，不用再看人脸色过日子。这个计划看起来很远，但他一直在朝它走——虽然走了很久还在半路上。 |
| **加入兽盾契机** | 不适用——从未考虑过加入兽盾。对兽盾的认知是"穿制服的那群暴徒"。在街頭混久了，见过太多被兽盾"处理"的人，他宁愿饿死也不穿那身军绿。 |
