## 外貌特征

**面容**
野猪面相，吻部前突明显，扁平的鼻盘宽大——鼻端深黑色，常年湿润。一对獠牙从下颚向上弯曲伸出唇外，左侧獠牙长出一指余，右侧略短——是在山里打斗时折断过。眼睛小且深，嵌在眉弓的厚皮褶皱中，看人时有一种"你在瞅啥"的原始警觉。耳朵小，竖立，覆盖着粗糙的黑毛。

**体型**
野猪兽人中不算最大号，但非常"敦实"——肩宽背厚、脖子粗短、躯干呈圆筒状。脂肪不少但不是虚胖——厚厚的脂肪层下是扎实的肌肉，抗击打能力极强。整体给人的感觉是"矮壮稳重"，像一根被钉在地上的木桩。

**皮肤与毛发**
背部从头顶到尾巴覆盖一层粗糙的黑棕色硬鬃毛——摸上去扎手，像刷子。两肋和腹部的毛稍软偏棕。颈部和肩部的鬃毛最硬最长——战时可以竖起来威慑对手。皮肤（尤其面部）粗糙厚实，布满了深浅不一的褶皱和旧伤痕——是山里生活留下的天然印记。

## 人生时间线（白历纪年）

### 白历289年（0岁）

- **4月3日**：出生于白之都以西三百公里外的黑石山——一个偏远的山村聚落。父亲是村里的猎人，生父操持家务。他是家中的老三（上有两个哥哥）。

### 白历295年（6岁）

- **9月1日**：在村小读了三年书——所谓"村小"不过是一个识字的退伍老兵在家里搭的课桌。他学会了写自己的名字、算简单的加减法、认一些常用的字。之后就"毕业"了——"字够用了，回山上帮爹。"

### 白历298年~56年（9~19岁）

- **长期**：跟着父亲在山里打猎。黑石山一带的野猪兽人世代以狩猎和采药为生。他从9岁开始学设陷阱、10岁学追踪、12岁第一次亲手猎杀了一头鹿。十七八岁的时候，他已经是方圆十里最好的猎手之一——熟悉山里的每一条兽道、每一种草木的气味。

### 白历308年（19岁）

- **3月1日**：一场山火吞没了黑石山大半个南坡。烧了七天七夜，村子虽然没有被波及，但山里的猎物几乎绝迹了。那年冬天，村里的人开始往外走——"山里待不下去了"。
- **12月1日**：猪吴林跟着几个同村人一起来到白之都。"听说城里有工做，管饭。"

### 白历309年~59年（20~22岁）

- **长期**：在城市里辗转打零工——工地搬运、市场杀鱼、垃圾清运。他什么都能干，也不挑活儿。但因为不识字、不会说漂亮的城里话、长得又凶，他被人骗过好几次工资。"城里人花花肠子多，不如山里实在。"但他也逐渐意识到自己这身山里人的皮囊在城里人眼里是"凶"——走在街上有人绕着他走，食堂打饭时阿姨会多给他舀一勺（怕他）。他对自己的身体没有太多感觉——在山里身体就是工具，用来打猎、赶路、扛东西。到了城里，他第一次发现有人会盯着他的胸肌和腰看——他不理解为什么，但也不反感。他开始萌生了"想回去"的念头，但山里的猎物还没回来。

### 白历311年（22岁）

- **5月15日**：在同村兄弟的介绍下，得知兽盾公司在招"体格强壮的保安"。
- **7月15日**：面试时，面试官问他"你有什么特长"——他想了想说："我能打。"（他说的是打猎）。面试官理解成了"能打架"，加上他獠牙外露的凶悍外表，当场就录用了。
- **9月1日**：入职兽盾，被分配至总部1F大厅，编号G-267，职责是"大厅站岗守卫"——实际上就是"站在那里让人不敢闹事"的活招牌。
- **首次穿上G级制服**：在后勤仓库的角落换上军绿色制服——他粗壮的黑棕色身躯把这身衣服撑得圆鼓鼓的，胸围和腰围几乎一样宽。他扯了扯领口——有点紧，但不碍事。旁边发制服的文员多看了他几眼——那对獠牙和厚实身材确实扎眼。

### 白历312年~64年（23~27岁）

- **长期**：在总部大厅站了五年多的岗。从一个山里来的"野猪"慢慢变成了"总部最凶的守卫"——虽然他自己从来不觉得自己凶。"我就是站在那里，他们自己害怕，怪我咯？"
- **期间**：每个月工资四成寄回山里（给双父和哥哥），三成吃饭，一成买烟叶（他抽不惯城里的香烟，托人从老家带烟叶），两成存着。

### 白历315年（26岁）

- **白历315年3月20日**：猪吴林在总部大门外值勤时，一辆黑色篷车停在门口，两名赏金猎人从车斗里拖出一具裹着帆布的尸体——尸体的手臂从帆布下露出，手腕上挂着兽盾工牌的绳扣。帆布一角掀开时露出尸体的大腿——上面布满了掐痕和干涸的白色液体痕迹。他认出那是上周还在食堂跟他打过招呼的一个后勤员工。赏金猎人冲他咧嘴笑了笑，"麻烦让让"，然后拖着尸体进了后门。猪吴林攥紧拳头又松开——在山里他学会了一件事：有些事你管不了，就当没看见。但山里没有这种事。

### 白历317年·秋（28岁）

- **原作**：L-08总部攻略中，他在大厅入口处站岗。看到了一个陌生人从大门走进来——他还没来得及张嘴问"你找谁"，战斗已经结束了。野猪的厚皮和力量没有改变任何事。

## 个人背景与经历

### 1. 本质与性格

猪吴林是一个**从山里搬到城里的猎人，被困在了水泥森林里**。他的性格中有两种看似矛盾的特质：一方面，他粗犷、外形凶悍、说话直来直去不拐弯；另一方面，他在内心深处并不好斗——他只是一个"靠体力吃饭的乡下人"。

他不像其他守卫那样有"职业尊严"——他不在乎自己是不是一个好的兽盾员工。他在乎的只有几件事：**饭好不好吃、觉够不够睡、钱有没有被坑**。这些在山里就够了的生存法则，在城市里也还是够用。

他的粗犷不是故意的——他从小就是这样，没有人教过他"说话要委婉"、"看人要微笑"。他的獠牙是他的一部分，就像粗嗓门是他的天性一样。他不是要吓唬人，他只是不会别的表达方式。

本质上，他是一个**简单而诚实的人**——不骗人、不偷懒、不贪心。在山里，那些品质会害死你；在城市里，那些品质让你当不上干部。

### 2. 认知局限与幻梦

猪吴林对世界的理解是"山里逻辑"式的——强弱、饿饱、冷热。他对城市的社会结构、商业规则、人际关系网络完全摸不着头脑。他分不清O级和E级的区别（"不都是穿制服的吗？"），也搞不懂为什么"有些人坐着就能赚钱"。

他的"幻梦"非常具体：**攒够了钱，回黑石山重新过日子**。不是回村——村里已经没什么人了。他想在山脚下盖一间小木屋，屋前挖一口井、屋后种一片菜地，再养几条猎狗。春天上山采药，秋天打猎，冬天窝在屋里烤火。不需要很多钱，够用就行。

这个梦想支撑着他在城里"熬"了六年。每次觉得撑不下去了，他就想："再干一年，攒够了就回去。"但一年复一年，"够了"的标准在城里不断膨胀——他永远觉得"还差一点点"。

### 3. 系统下的生存

在兽盾体系中，猪吴林的角色是**"威慑性存在"**——公司不需要他说话、不需要他聪明、甚至不需要他动手。他只需要站在那里，让来访者看到那对獠牙就自觉收敛。

他是被当作"道具"使用的——公司从未指望他升职、调岗或做出任何贡献。他唯一的价值就是他的外表。而他自己隐隐约约知道这一点，但不太在意——"他们用他们的，我攒我的钱。"

### 4. 重要关系网络

- **父亲（猪老林）**：老猎人，今年六十多，腿脚还硬朗。山火之后不肯下山——"我在山上住了大半辈子，下山干什么？"猪吴林每月寄钱回去，父亲用那些钱买粮食和火药。父子之间很少通话（村里信号不好），但偶尔托人捎话——"爹说天冷加衣"、"爹说今年山里的狍子又多了"。

- **生父**：比父亲小几岁，身体不太好——有风湿，下雨天膝盖疼。猪吴林最挂念的就是他。"等我攒够了钱，回来给你盖一间暖和屋子。"

- **同村兄弟（猪石根）**：跟他一起从黑石山出来的同乡，现在在南城的建筑工地干活。两人偶尔在休息日碰头——在街边摊吃碗面，聊几句老家的事。猪石根是他在这座城市里为数不多的"自己人"。

- **同僚（G-156 牛朱炎）**：两个人在1F大厅一起站岗。牛朱炎脾气暴，猪吴林脾气直，两人竟然处得来——"他说话不拐弯，我喜欢。"

### 5. 重要遗产与象征物

- **猎刀**：从山里带出来的老猎刀，刀柄是鹿角磨的，刀鞘是父亲年轻时缝的牛皮。这把刀跟了他十几年——砍过柴、剥过皮、切过菜。他现在用不着了（城里不让带刀），但一直压在宿舍枕头底下。

- **烟叶袋**：一个粗糙的布袋子，里面装着从老家托人带来的烟叶。他每隔一段时间就把烟叶拿出来晒一晒——"城里的烟哪叫烟，是纸卷的香水。"

- **山里带来的石头**：一块掌心大小的黑色河卵石，是从黑石山脚下的溪流里捡的。没有任何特殊意义——"就是走的时候随手揣兜里的。"但六年来他搬过三次住处，这块石头一直在。

## 原作剧情

**出场关卡**：L-08 兽盾总部攻略·1F大厅

**在本关中的角色**：
大厅站岗守卫——主要负责大厅入口的"威慑"。他站在大门内侧，来访者进门第一眼看到的就是他的獠牙。

**关键事件流程**：
1. 主角从大门进入总部时，猪吴林就站在门内两步远的位置。
2. 原作中他是距离入口最近的守卫——主角进门后的第一个目标。
3. 正面击杀——他的体魄让战斗多持续了几秒钟，但依然无法改变结果。
4. 尸体倒在入口处，后续的守卫发现后会立即关闭大门封锁大楼。

**原作结局**：死亡——首当其冲的入口守卫。

## 本作改编设定（Save Us Then Load World）

**核心挑战**：
猪吴林是1F大厅中位置最"死"的守卫——他站在大门内侧，一动不动。主角进门的那一刻，两人之间的距离不超过三米。这是一个没有周旋余地的位置——要么瞬间处理掉他，要么立刻暴露。

但猪吴林有一个其他守卫没有的弱点：**他是一个"山里人"，对城市里的"社交规则"不敏感。而主角恰恰可以利用这一点。**

### 拯救路线

- **路线A：伪装成"自己人"**
  猪吴林对"山里人"有一种天然的亲近感。如果主角在进门时用一种"山里口音"或者"打猎术语"跟他打招呼（比如用黑石山一带的方言说"老乡，打听个路"），猪吴林会在零点儿几秒内产生"这就是我们那边的人"的判断。这一瞬间的"自己人"错觉，足以让他的警惕延迟两三秒——这两三秒就是主角制服他的窗口。但注意：口音必须地道——他也会怀疑那些"装山里人"的城里人。

- **路线B：食物收买**
  猪吴林是一个非常"实在"的人。如果主角手里拿着食物（最好是大份的、肉多的、热乎的），进门后自然地递过去——"兄弟，门口有人让我捎给你的。"他大概率会先接过去再说。在他低头看食物的瞬间，主角可以快速从侧面绕到他的身后实施控制。这条路线需要事前准备合适的"道具食物"——一份红烧肉盖饭效果最好。

- **路线C：假装迷路的送货员**
  猪吴林对"城里人的套路"不熟。如果主角装扮成一个推着推车、拿着送货单的送货员，进门时自然地说一句"2F物资区的货，麻烦让一下"，猪吴林大概率会侧身让路——他的思维定式是"站岗=有人来了挡住→确认身份→放行"，但"送货员有货要送"这个场景在他的经验中是"应该放行"的。主角可以通过这个认知盲区直接穿过入口区域。难点在于后续要把推车和制服处理掉，否则猪吴林反应过来后会起疑。

**与主角的关系基础**：
初次见面时完全陌生。猪吴林不认识主角。

**读档条件**：
他是入口处的第一道关卡——如果在他这里暴露，整栋大楼将立刻封锁。读档点设置在进入总部大楼之前。关键教训：不要用"城里人的方式"跟他打交道——越直接越好，越"土"越好。

| **精槽特性** | 容量90%（G级水平），增速偏慢（山里人钝感体质，神经传导慢），控精能力为零——山里没有"控精"这个概念，性跟饿了吃饭一样简单。他的精槽曲线平缓得像他老家山丘的坡度——慢慢上来，慢慢下去 |
| **制服性特征** | G级军绿色制服在他身上被撑得圆鼓鼓的——胸围和腰围一样宽，整个人看起来像塞满了的布袋。獠牙从嘴唇两侧露出顶在领口边缘，在绿色布料上磨出两道浅浅的牙痕。他懒得洗袜子，白色长筒袜早就穿成了灰棕色——"山里人不讲究这个。" |
| **性互动方式** | "野兽派"——他没有性互动的经验也没有这个概念。在山里的时候偶尔打猎后身体有反应了，坐在溪边用手解决，整个过程五分钟，完了继续干活。进城之后他注意到城里兽人之间的性更复杂——有调情、有暗示、有推拉。他看不懂也不打算学。他更想回山里——山里的东西简单直接，不会让他困惑 |

## 差异化设计维度

| 维度 | 设定 |
|------|------|
| **兵种与等级** | G级 — 大厅入口站岗守卫（威慑兵种，非战斗特化） |
| **种族特性** | 野猪——厚皮、獠牙、力量大、耐力强。生存能力极高但爆发力有限。野猪兽人通常性格直率、不拘小节、对"信任"极为看重（山里人的品质） |
| **入职背景** | 山村猎人出身——山火后村落凋敝，随同乡进城打工。工地/市场杂工→经同乡介绍入兽盾 |
| **经济状况** | 节俭的山里人作风——每月花销控制在最低线。存款约3000撸币（目标是攒到5000撸币就回老家盖房子）。但"5000"的数字是他六年前的目标——城里几年让他隐约知道5000可能不够了，但他不愿意重新算 |
| **家庭关系** | 与双父保持疏远但稳固的联系。独身——在山里时没遇到合适的，进城后更不可能。他的情感寄托是"老家的山"而不是某个人 |
| **性格动机** | 直率的生存主义者——不贪不懒不坏，但也不关心与自己无关的事。"我的世界就那么大，管不了太多" |
| **技能特长** | 野外生存（追踪、设陷阱、辨识植物）、负重劳动、高抗击打能力（野猪厚皮）。但城市技能为零——不识字（仅限常用字）、不会用电脑、不会用智能手机 |
| **人际关系** | 在总部是"被害怕但不被讨厌"的存在——同事们嫌他粗鲁土气，但也不觉得他是坏人。他在城里唯一的朋友是同乡猪石根 |
| **未来计划** | 攒够钱→回黑石山山脚盖木屋→种菜养狗打猎→终老山林 |
| **加入兽盾契机** | 同乡介绍——"兽盾在招保安，管饭，工钱日结。"他不知道兽盾是干什么的，也不在乎 |

## 备注

- 猪吴林是L-08中**最容易被"本地化手段"绕过但最难被"战术手段"处理**的守卫——他的身体条件让他非常适合"扛住第一波攻击"，但他的认知模式让他对"山里来的自己人"几乎没有防备。
- 在Save Us改编中，他是"不杀路线"中最适合展示**阶级/地域差异打败系统**的角色——城市兽盾的高科技安保系统，被一个山里口音和一个递食物的手势绕过了。这不是战术上的胜利，是人性层面的穿透。
- 如果猪吴林获救并最终回到黑石山盖了自己的木屋，那可能是整章中最圆满的结局之一——一个被城市异化的人终于回到了他真正属于的地方。
- 他在原作中的死因有一种残酷的象征意义——从山里来到城市寻找活路，最终死在了城市的水泥大楼里。Save Us给了他一个不同的可能：活着回到他的山里去。
