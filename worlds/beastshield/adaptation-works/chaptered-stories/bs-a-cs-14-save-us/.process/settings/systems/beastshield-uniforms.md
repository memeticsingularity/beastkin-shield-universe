# 兽盾制服标准外观速查

> 基于 `worlds/beastshield/settings/0-original-setting/world-setting.md` 提取，仅保留标准外观（不含野外巡逻变体）。
> **适用范围**：Save Us Then Load World 项目内所有兽盾员工角色。

---

## G级 — 杂兵（Grunt）

| 项目 | 标准规格 |
|------|---------|
| 颜色 | 军绿色 |
| 上装 | 军绿色短袖紧身衣 |
| 下装 | 军绿色短裤（两侧金色竖线） |
| 标志 | 左胸：白色兽盾LOGO（盾牌状）；背部：黄色"SHIELD"字样 |
| 袜子 | 白色长筒袜（袜口军绿色条纹；部分个体有红色条纹变体） |
| 鞋履 | 军绿色运动鞋 |
| 配饰 | 部分配军绿色帽子；部分狗兽人胸前有"GUARD"标识；部分犀牛兽人穿三角裤（非标准短裤） |
| 编号 | 袜底印编号，格式 `G-[自然数]`（如 G-533） |

**典型穿着者**：仓库守卫、门口站岗、底层巡逻。

---

## O级 — 监工/干部（Overseer）

| 项目 | 标准规格 |
|------|---------|
| 颜色 | 蓝色 |
| 上装 | 蓝色短袖紧身衣（两侧白色竖线） |
| 下装 | 蓝色短裤（两侧白色竖线） **或** 蓝色连体紧身服 |
| 标志 | 无额外大字标识 |
| 袜子 | 白色长筒袜（袜口蓝色条纹） |
| 鞋履 | 蓝色运动鞋 |
| 编号 | 袜底印编号，格式 `O-[自然数]` |

**典型穿着者**：转正后的绿制服、基层管理、行动小队长。

---

## E级 — 武斗兵（Enforcer）

| 项目 | 标准规格 |
|------|---------|
| 颜色 | 黑色 |
| 上装 | 黑色紧身短袖（左胸白色兽盾LOGO；肩部/袖子有白色/灰色/红色/蓝色条纹） |
| 下装 | 黑色短裤（胸前可能有白色几何图案/V字形纹路；背部印有白色或蓝色"SHIELD"字样） |
| 标志 | 部分虎兽人有"SWAT"标识；部分狮子兽人有"SD"标识；极罕见红色LOGO |
| 袜子 | 黑色长筒袜（袜口白色/灰色/红色/蓝色横条纹） |
| 鞋履 | 黑色厚底军靴 |
| 护具 | 金属护裆（标配）；高级成员加配护肩/护胸/战术腰带/护目镜/电击棒/透明盾牌 |
| 编号 | 袜底印编号，格式 `E-[自然数]` |

**典型穿着者**：高级近战兵种、精锐守卫、楼层巡逻。

---

## R级 — 枪械兵（Ranged）

| 项目 | 标准规格 |
|------|---------|
| 颜色 | 白色 |
| 上装 | 白色紧身短袖（正面兽盾标志） |
| 下装 | 白色短裤 |
| 手套 | 黑色手套 |
| 袜子 | 白色长筒袜（袜口蓝色圆环；部分牛头人有红色条纹变体） |
| 鞋履 | 卡其色军靴 **或** 蓝白运动鞋 |
| 配饰 | 部分配有战术背带系统 |
| 编号 | 袜底印编号，格式 `R-[自然数]` |

**典型穿着者**：狙击手、远程火力支援。

---

## W级 — 摔跤兵（Wrestler）

| 项目 | 标准规格 |
|------|---------|
| 颜色 | 深蓝色 |
| 服装 | 深蓝色连体摔跤服（带白色/红色/紫色条纹或图案） |
| 标志 | 部分印有"BEAR"字样；部分印有"SD"字样 |
| 袜子 | 白色长筒袜（袜口蓝色/紫色条纹） |
| 鞋履 | 深蓝色摔跤靴 |
| 护具 | 护肩、护膝、白色护腕 |
| 配色变体 | 黑红配色（虎兽人专属）；蓝色变体（"BEAR"字样）；紫色变体（"SD"字样） |
| 编号 | 袜底印编号，格式 `W-[自然数]`（如 W-593） |

**典型穿着者**：地下格斗场培养的精英、特殊高级兵种。

---

## 通用配饰

- **白袜**：所有等级标配，底部印有员工编号，是赏金兑换凭证。
- **编号格式**：[等级字母]-[自然数]，随机分配，非连续。
