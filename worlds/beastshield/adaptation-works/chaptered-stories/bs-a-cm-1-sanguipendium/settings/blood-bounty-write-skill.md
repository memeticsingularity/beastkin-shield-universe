## 三、世界观核心机制（必读）

### 伤害→性欲转化

兽盾世界观的第一条核心规则：

**每一次攻击造成的伤害都会转化为性欲值（俗称"精槽"）。**

这意味着：
- 战斗中性欲是持续积累的，不是突发的
- 挨打越多，越兴奋
- 双方在战斗中都会勃起（程度因伤害量而异）
- 处决时精槽满溢自然导致射精→死亡

**写作必须体现**：
- 每一次有效打击后：被击中的部位发热→暖流向下蔓延→阴茎反应
- 这不是"受伤后硬了"——是"伤害直接转化为性快感"
- 胜者在战斗过程中也可能全程勃起打完

### 精槽积累→射精死亡

```
连续受击 → 精槽上升 → 阴茎半硬 → 硬 → 龟头膨胀 → 马眼张开 → 
 濒临极限（腰部发酸/会阴跳动） → 触碰/撸动触发 → 
  射精（七八股浓精） → 身体放松 → 瞳孔涣散 → 死亡
```

**关键点**：
- 射精就是死亡。在本世界观中，不可能有"活着的射精"
- 所以纯情色场景（卖肉）可以勃起、抚摸、插入，但不能射精
- 只有死战到最后关头才能射精

## 四、处决签名序列

每一场死亡必须遵循以下序列（可以压缩其中某阶段，但不能跳步）：

| 阶段 | 内容 | 写作要点 |
|:----|:-----|:---------|
| ① 积累 | 战斗中的反复打击 → 精槽持续上升 | 每次打击写体感：热感、跳动、勃起程度变化 |
| ② 临界 | 阴茎完全勃起 → 龟头露出 → 马眼张开淌前液 | 角色意识到"要到了"，可能挣扎/求饶/沉默 |
| ③ 触发 | 胜者接触败者的阴茎（握/覆/抓） | 接触方式每场不同（握/握住/手掌覆住/脚踩等） |
| ④ 撸动 | 有节奏的撸动（2-12下） | 速度、力度、节奏每场不一样 |
| ⑤ 射精 | 7-8股以上浓精喷出 | 量必须大，喷溅轨迹/落点每场不同 |
| ⑥ 断气 | 身体松弛 → 瞳孔涣散 | 最后一股精液变为透明/带血丝 |

### 射精差异化要求

每一场的死亡射精必须与之前不同：

| 场次 | 死法 | 射精特点 |
|:---:|:----|:---------|
| ch-06 | 锁喉+握撸 | 浓精溅在手指上，虎赵军的右手沾满精液 |
| ch-07 | 握撸（对手主动握住） | 精喷在棕熊兽人胸口制服上 |
| ch-08 | 骑乘+轻撸 | 精顺着手掌往下淌，像道歉 |
| ch-09+ | 待差异化 | 需要不同的方式/部位/节奏/量 |

可能的差异化方向：
- 暴力击打导致死亡暴射（不靠撸动，靠最后一击触发）
- 勒死过程中的精液喷射
- 让对手自己动腰直到射精
- 多人围观下射精
- 压倒性碾压后缓慢滴干

## 五、情色内容基线

### 每章情色基线

**每章必须有情色内容**（卖肉或处决）。不能出现连续多章无性。

| 章节类型 | 最低要求 |
|:--------|:---------|
| 赛前/日常章（ch-01~05） | 至少1处卖肉场景（勃起/抚摸/自慰/共浴） |
| 比赛章（ch-06起） | 处决射精全程 + 战斗中的精槽反馈 |

### 纯卖肉场景（不致死）

可以出现以下情色内容而不导致死亡：
- 勃起、硬挺、龟头露出
- 抚摸、撸动（但在射精前停止）
- 自慰（不射精）
- 共浴、共眠、裸体接触
- 身体打量、性化视线

**关键**：只要不射精，就不会死。这为前期篇章提供了情色空间。

## 六、写作红线（禁止项）

### ❌ 禁止深度心理描写

- ❌ 哲学性、内向化的独白（"如果他死了谁会记得他""我怕的不是输而是明天过后"）
- ✅ 允许的内心活动仅停留在**即时反应**层面：
  - "好壮" "真他妈疼" "怕有什么用" "操" "爽"
  - 对身体的直接感受："硬了""热""想射"
  - 对对方身体/动作的即时评价

### ❌ 禁止假名

- 所有角色名以 `story-setting.md` 官方名单为准
- 旧版曾用"牛刚""虎啸""犬忠"——永不再用

### ❌ 禁止编号

- 行文中永不出现 E-XXX、W-XXX、B-XXX、D-XXX 编号
- 不需要用编号来区分角色

### ❌ 禁止内衣描写

- 兽盾兵不穿内裤
- 下身只有黑色紧身短裤，脱裤直接见下体
- 制服：黑色紧身短袖 + 黑色紧身短裤 + 黑色长筒袜 + 黑色厚底军靴

### ❌ 禁止过度环境描写

- 不写大段的环境铺陈
- 环境描写服务于感官强化（光线/气味/触感），每次1-2句足够

## 七、战斗描写规范

### 情色维度（最重要）

战斗不是纯物理的——战斗就是性。

每场战斗写作自查：
- [ ] 受伤后是否有"热感向下蔓延"的描写？
- [ ] 双方是否有勃起进程？
- [ ] 精槽积累是否有体感描写？
- [ ] 处决前的临界状态是否清晰？

### 感官强化优先级

1. **视觉**：皮毛色、制服黑、精液白、血液红
2. **触觉**：握感（粗/细/硬/软/热）、温度、湿润度
3. **嗅觉**：汗水味、精液味、血腥味、阵营体味（熊甜、熊麝香等）
4. **听觉**：喘息、呻吟、肉体撞击、射精的啪嗒声、尸体被抬走的轮子声

### 段落控制

- 常规段落：2-5行
- 战斗高潮段：可拉到6-10行（每个打击/每次精槽积累分一段）
- 每段聚焦一个感官或动作节拍，不要堆砌
