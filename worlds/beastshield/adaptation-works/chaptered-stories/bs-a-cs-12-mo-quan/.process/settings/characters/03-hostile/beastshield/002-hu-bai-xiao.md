## 人生时间线（白历纪年）

> 原文未覆盖具体年份和完整履历，以下为基于剧情信息的时间框架。

### 出生 - 不明
白虎出身不明。在兽盾体系中，能升到E级的虎种通常来自兽盾的精英培养线或从G/R级中厮杀晋级的实战派。【补完】

#### 入职G级
- **第一次穿G级军绿色制服**：军绿色G级短袖套上白虎的虎躯时——他的体格不似棕熊那般粗壮，但匀称结实的肌肉在绿色布料下撑出了流畅的线条。白色皮毛与军绿色形成鲜明的视觉反差——他看起来像一棵覆雪的树。胸前"GUARD"字样下方，胸肌的轮廓在布料上清晰可见。短裤裆部的虎鞭鼓包不大不小——还带着年轻兽人特有的羞怯感。他在更衣室镜子前站了很久，不是因为合不合身，而是第一次觉得自己"属于"某个群体。【补完+原作】

#### 晋升E级
- **晋升E级后第一次穿黑色制服**：E级黑色制服与G级的粗糙军绿完全不同——材质更厚实、剪裁更讲究。套上身的瞬间，黑色布料将他的白色虎毛包裹出一种沉稳的压迫感——不再是G级那种"随时可以牺牲"的廉价感，而是"处决他人者"的威严。腰间配备了金属护裆——金属的重量让他行走时的姿态都不同了，脚步更沉、更稳。他站在新兵训练营的镜子前，虎须颤了一下——他终于不再是那个可以被随意处决的G级了。他以为自己会高兴，但镜中那双琥珀色虎眼里映出的是一种他自己也说不清的复杂神色。【补完+原作】



#### G级服役期·城市巡逻与初级战斗（G级时期）
- **第一次目睹同事被处决（G级时期）**：一名同批入职的狼兽人因为私藏公司财物被查出，被当众按在地上用电击器折磨至射精死亡。白虎站在指定的"观摩"队列中——他想闭眼但不敢，因为教官就在旁边看着每个人的眼睛。他全程看着，没有转头，没有闭眼。那天晚上他吐了三次。第二天他在食堂吃饭时坐在同一个狼兽人平时坐的位置——他自己也不知道为什么要这么做。可能是记住。【补完】
- **第一次参与围剿武林据点**：一只穿着军绿色制服的白皮虎兽人（白虎）随队突袭城外一处武林秘密联络点。他第一次见到真正的武林战斗人员——一名狐兽人只用三招就放倒了带队的R级。白虎在混乱中负责封堵后路，没正面交手，但狐兽人那双冰冷的眼睛他记了很久。这次行动让他意识到G级的战斗力在武林面前根本不够看。【补完】
- **第一次受伤**：在一次镇压平民骚乱时被石块砸中额角，虎血顺着白色皮毛流下来染红了半边脸。医务室缝了七针，回来后同僚笑他"被石头开瓢的G级"——他没反驳，但心里清楚下次可能就不是石头了。【补完】

### 从G/R级晋升为E级 - Ch.3的数年前
从无数G级和R级中厮杀晋升为E级武斗兵。E级地位远高于G级和R级，是兽盾体系中的高等战力。晋升过程中必然经历过多次生死任务和精关控制训练。【补完】

#### 晋升E级的最终试炼·一对一淘汰赛（晋级期）
- **最后一关**：晋升E级的最终考核是一对一实战抽签——胜者晋级，败者退回原级或降级。白虎抽到一只穿着军绿色制服的棕皮虎兽人（G-1棕虎宗虎）——比他高半头、经验更丰富的老兵。战斗持续了二十多分钟，白虎靠着虎种爆发力和不认命的韧性在最后时刻将宗虎压倒在地，虎爪抵在对方咽喉前三寸停住。宗虎认输。教官在考核表上写了两个字："通过。"白虎在更衣室坐了很久，白毛被汗血黏成一缕缕——他赢了一头比他强的虎，但没觉得开心，只觉得累。【补完】

#### E级初阵·首次以E级身份执行处决（晋升E级后不久）
- **入阶仪式**：晋升后第一个任务不是战斗，是处决——一名R级因"私通武林"被判处绩效注销。白虎被指定为执行人，这是E级的"入阶仪式"——每个新晋E级都必须亲手处决一个曾经的上级或同级，以此斩断旧身份牵绊。刑场上，一只穿着军绿色制服的R级鹿兽人被绑在柱子上，哭着说"我是被冤枉的"。白虎没有问——他不需要知道真相，只需要执行。他走上前握住鹿兽人的裆部，在绝望的哭喊中完成了处决。射了十二发后鹿兽人断气。白虎松开手，看着白毛上沾着的精液和血迹——他想吐，但忍住了。从那以后他再也没有在执行处决时犹豫过。【补完】

#### 精关控制特训·E级必修课（E级早期）
- **第一堂课**：E级训练营核心课程——精关控制。一只穿着黑色制服的灰狼兽人（E级前辈）要求他们在完全勃起状态下被握住裆部保持不射，持续计时。白虎第一次只坚持了九秒——虎种的敏感体质在E级中也属中下水平。教官只说了一句："你这水平上了战场，被武林碰一下就得跪。"【补完】
- **三个月的突破**：经过反复训练，控制时间从九秒提升到四分多钟。方法包括在接近射精临界点时默念任务清单、主动收缩会阴肌群锁住精关、训练后立刻高强度体能训练强迫身体代谢过剩的性兴奋。训练造成了持续的酸胀感——但效果显著。精关控制成为他后期作为E级的核心战斗技能之一，直到被封精指一击破除。【补完】

#### 武林清剿·E级第一次见血（E级中期，Ch.3前约一至二年）
- **夜袭武林前哨站**：获得精关认证后第一次参与高等级战斗——夜袭武林设在城外的一处前哨站。白虎负责正面突破，虎爪撕裂了两名守卫的咽喉——这是他第一次杀"外人"。他在尸体旁蹲了一会儿，看着白毛上滴落的红色血液——不是他自己的血。他发现杀外人和处决同事完全不同：没有恶心，没有犹豫，只有"任务完成"的平静。【补完】
- **缴获功法残页**：在前哨站中缴获一本残破的功法手册，其中提到"封精指"概念——一种通过封闭兽人精关造成性神经崩溃的招式。白虎将手册上交，但"封精指"三个字留在了他脑子里。他没想到几年后自己会亲身挨上这一招。【补完】

#### 调防青石镇·新驻地的第一印象（Ch.3前约数月）
- **抵达青石镇**：因E级人员调动被派往青石镇据点。这座小镇比他从前驻地的规模小得多，但兽盾的控制密度反而更高——每条街都有G级巡逻，每个路口都有检查点。他在据点二楼分到一间单人房，比G级的通铺好得多。他站在窗前看了一眼镇口的河——那时他还没想到，这条河会成为他和武林第一次对峙的地点，也没想到自己会在这座小镇经历从E级骄傲到假死藏匿的全部过程。【补完】

## 个人背景与经历

### 本质与性格
- **冷酷高效**：处决下级时毫不犹豫，动作干净利落。他的冷酷不是残忍，是"效率"——处决黄豹时动作专业，没有多余的情绪波动【原作 Ch.9】
- **警觉敏锐**：虎耳不断转动捕捉周围动静，即使在虚弱假死、被黑狗压在身下时也保持肌肉紧绷【原作 Ch.10】
- **骄傲自尊**：作为E级，对G级和R级有天然的俯视感。但被黑狗"救"后这种自尊受到冲击——一个G级杂兵（当时黑狗在他眼中）竟然救了他的命【原作+补完】
- **默认→接受→袒护**：对黑狗的态度变化轨迹，没有内部身份背叛威胁。这是他性格中"务实"一面的体现——认清现实、适应变化【原作+补完】

### 认知局限与幻梦
白虎的认知局限在于：他以为E级在兽盾体系中已经站在了"安全区"。他执行任务、杀G级、与武林对抗，从未想过自己也会有沦为"尸体"被藏匿的一天。

他的幻梦是"在兽盾中靠实力爬到最高"——E级之上应该还有更高的层级（S级或将军级），那是他曾经瞄准的目标。但在被黑狗救下后，这个幻梦被打破了——他发现兽盾体系中的E级也不过是高级一点的消耗品，武林用一记封精指就能让他跪在地上精液混着血往下淌。【补完】

### 系统下的生存
在兽盾体系中，E级是"执行者中的精英"——不需要像G级那样做杂务，但承担的战斗风险也更大。武林的"封精指"是专门针对兽盾E级的杀招，说明双方有过多次交锋，兽盾的高等战力已经被武林研究透了。

白虎在系统中的生存策略是"实力主义"——靠过硬的本事杀出自己的位置。他不巴结上级，不拉帮结派，只是高效完成任务。这种态度让他能升到E级，但也让他在假死后没有"自己人"来找他——他被黑狗藏匿后，兽盾方面并没有大张旗鼓地寻找他。【补完】

### 重要关系网络
- **黑狗（墨犬）**：强奸者/保护者/复杂对象——从最初的黑狗视角中的"尸体"，到被包扎藏匿。白虎对黑狗的态度轨迹是全书核心CP线：默认被救的事实→接受藏匿状态→逐渐产生袒护之意。黑狗救他的行为打破了白虎对"G级都是废物"的认知【原作 Ch.10–Ch.17】
- **黄豹（G级）**：处决对象。被白虎亲手绑在木桩上处决的G级，反映了白虎对"废物"的零容忍态度【原作 Ch.9】
- **武林人员（狐、蛇）**：宿敌。双方在Ch.10中激战，白虎被封精指+匕首捅入侧腹。这段仇恨成为后续他与黑狗合作的契机【原作 Ch.10】

### 重要遗产与象征物
- **金属护裆**：象征着E级的身份和地位——当它被打歪时，意味着E级的骄傲被击碎了。护裆歪斜的状态贯穿了他的假死期【原作 Ch.10】
- **精液泡透的黑色长袜袜口**：他狼狈状态的象征——曾经冷酷处决别人的E级，现在自己的精液顺着腿往下淌，泡透了袜口【原作 Ch.10】
- **军绿制服（黑狗盖在他身上的）**：象征着他与黑狗关系的起点——一个G级的制服盖在E级身上，保护和被保护的关系发生了颠倒【原作 Ch.10–Ch.17】

## 本作剧情定位

### 核心定位
**全书核心CP角色**：白虎与黑狗的关系是墨犬改编中最重要的情感线之一。白虎的E级身份、"冷酷高效→默认接受→逐渐袒护"的态度变化、以及与武林的宿怨，构成了他丰富的角色弧光。

### 剧情走向/发展空间
- **可能走向A（苏醒线）**：从假死中苏醒后，与黑狗的第一次正式对话将决定两人关系的走向。白虎如何面对自己"被一个G级救了"的事实？
- **可能走向B（选择线）**：恢复后面对兽盾的召回命令，白虎必须在体系忠诚（回兽盾）和生存+恩情（留在黑狗身边）之间做出选择
- **可能走向C（复仇线）**：对武林的复仇可能成为他和黑狗合作的契机——两人联手反攻武林，在战斗中建立真正的信任
- **关键悬念**：白虎苏醒后对黑狗的第一句话会是什么？他会接受这种"被藏匿"的处境吗？如果兽盾发现他还活着，会怎么处理？

## 性机制

| 项目 | 内容 |
|------|------|
| **特有敏感部位** | 虎尾椎根部——虎科兽人的敏感区域，受到刺激时尾巴会不自觉地绷直或甩动。在性兴奋时尾根周围的肌肉会痉挛收缩 |
| **精槽特性** | E级训练赋予的强控精能力——能自主控制射精节奏（正常状态下）。被封精指后方才失效。储精量大、精液浓度极高。即使在失血过多假死状态下，精液仍在缓慢分泌 |
| **制服性特征** | 黑色紧身制服凸显胸肌轮廓和腰线。白色胸毛从领口露出形成强烈色差对比。金属护裆包裹裆部，歪斜时暴露内里。湿透的制服贴在身上，勾勒出每一块肌肉的线条，血和精液的湿痕在黑色布料上形成深色印记 |
| **性互动方式** | 正常情况下在性战斗中占支配地位（E级的自信和力量）。但在Ch.10中处于完全被动——被封精指后失禁式射精，被黑狗强奸（误认为尸体）时无力反抗。苏醒后位置转向复杂互动 |
| **性偏好维度** | 在正常状态下偏向top/支配，但在与黑狗的关系中位置被动，发展中的动态关系 |

## 差异化设计维度

| 维度 | 设定 |
|------|------|
| **兵种与等级** | E级武斗兵（无编号——E级以上不配编号，以制服颜色和装备标识身份） |
| **种族特性** | 白虎——虎种中最高贵的毛色变种之一。虎爪可撕裂骨骼，虎尾平衡感极佳。白色虎毛在夜战中具有隐蔽劣势但也有极高的视觉威慑力 |
| **入职背景** | 从底层（G/R级）厮杀晋级的实战派，非空降/关系户 |
| **经济状况** | E级收入远高于G级，但无明显挥霍迹象，属于"任务—战斗—休息"的循环生活方式 |
| **家庭关系** | 无任何信息【补完】 |
| **性格动机** | 冷酷高效来源于"实力至上"的生存信条。对废物零容忍。被救后自尊与感激的矛盾驱动后续选择 |
| **技能特长** | 虎爪撕裂（天生武器）、精关控制（E级训练）、高度警觉感知（虎耳听觉）、近战格斗顶级 |
| **人际关系** | 对G级和R级保持距离和俯视；对同级E级保持竞争关系；对武林有宿仇；对黑狗从俯视→平视→复杂情感 |
| **未来发展** | 苏醒→面对黑狗→在兽盾和黑狗之间做选择→可能联手复仇武林。角色弧光从冷酷E级到有情有义的"背叛者" |
| **加入兽盾契机** | 不明【补完】 |
