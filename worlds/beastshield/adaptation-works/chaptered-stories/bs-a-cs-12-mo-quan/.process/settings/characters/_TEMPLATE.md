> 标注【v2.0新增】的为本次模板升级新增字段，需按说明填写。

## 外貌特征

### 面容
面部特征：吻部/鼻梁/眼型/眉骨/嘴型等。种族特有面部特征。可标注【原作】或【补完】。

### 体型
整体体格描述：身高/体宽/肌肉量/体脂感。站姿习惯、行动时的体态特征。【原作+补完】

### 皮肤与毛发
毛色、毛质（短硬/柔软/浓密）、肤色（裸露皮肤）、尾巴特征、气味特征等。【原作+补完】

### 性征描写（如适用）
> **世界观规则**：所有兽人同时具备雄性下体性征（阴茎/睾丸）与雌性乳部性征（两枚乳头）。差异体现在尺寸、颜色、乳晕大小、是否被毛发/肥肉遮盖。
- 阴茎：尺寸/形状/包皮状态/龟头颜色
- 睾丸：大小/位置/阴囊状态
- 乳头：大小/颜色/乳晕/是否被毛发遮盖
- 精液：质地/气味/量
- 仅在角色有相关场景时填写

## 个人背景与经历

### 本质与性格
用 3-5 个关键词概括核心性格，展开说明。【原作+补完】

### 认知局限与幻梦
角色对世界的认知边界在哪里？他的渴望和恐惧是什么？他的"幻梦"——那个他以为自己想要、但可能并不是真正需要的东西。【原作+补完】

### 系统下的生存
在兽盾体系（或所处环境）中，他如何生存？是适应、反抗、还是随波逐流？体系对他的塑造体现在哪里？【原作+补完】

### 重要关系网络
与其他角色的核心关系（非全部，仅写影响其命运的关键关系）。每个关系给出关系性质和对角色产生的影响。【原作+补完】

### 重要遗产与象征物
角色留下的/拥有的/与之相关的标志性事物——可能是一段记忆、一件物品、一道伤疤。写那些如果失去会让人物"不再是这个人"的东西。【原作+补完】

## 性机制

> 【v2.0新增】系统化记录角色的性相关设定。

| 项目 | 内容 |
|------|------|
| **特有敏感部位** | 角色独有的敏感区域（位置、刺激方式、反应）。至少有1个与种族特征挂钩（如牛角根部、虎尾椎、熊掌肉垫） |
| **精槽特性** | 容量/恢复速度/控精能力。特殊情况（如愤怒时加速、特定刺激下失控） |
| **制服性特征** | 制服如何凸显或包裹性特征（裆部鼓包、胸肌轮廓、湿透后透视感等） |
| **性互动方式** | 角色在性战斗/性互动中的定位（主动/被动/支配/服从），具体手法和习惯 |
| **性偏好维度** | top/bottom/vers，角色偏好的性互动模式 |

## 差异化设计维度

> 【v2.0新增】从以下维度确保每个角色有独特定位。

| 维度 | 设定 |
|------|------|
| **兵种与等级** | 兽盾体系内的具体兵种和等级 |
| **种族特性** | 种族带来的身体/感官/战斗特质 |
| **入职背景** | 如何加入兽盾/进入当前环境 |
| **经济状况** | 月薪/经济来源/消费习惯 |
| **家庭关系** | 家庭背景（如有），与家人的关系状态 |
| **性格动机** | 驱动角色行动的核心动机 |
| **技能特长** | 独特的战斗或非战斗技能 |
| **人际关系** | 与周围角色的关系网络特征 |
| **未来发展** | 可能的成长/变化方向 |
| **加入兽盾契机** | 为什么会在兽盾体系中 |
