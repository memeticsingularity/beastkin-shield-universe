# 墨犬 - 第十四章：跟我走（暂定）

> 本章核心：**收编旧部** + **憋精功诈死复活** + **六人小队成形**。黑狗在绿制服宿舍安顿好灰牛兽人后，独自开车去处理尸体。路上从尸体堆里救出一个憋精功假死者；在小巷与褐鹿、黑獒重逢后，搬尸过程中又发现第二个假死者；全部扔进垃圾桶后，桶里传出动静——第三个假死者。最终六人（黑狗+五个下属）回到据点，灰牛在宿舍迎接——七兽同室，班底初成。
>
> **注**：本章内容量极大（搬尸感官描写×3 + 三次复活发现 + 重逢对话 + 六人互动），**建议拆分为 Ch.14 + Ch.15**。分割点建议设在「第三个垃圾桶复活」之后：Ch.14 止于六人集合完毕、卡车启动回据点；Ch.15 处理回途/宿舍安置/七人同室张力。

## 二、核心原则

1. **单视角（黑狗）**：严格从黑狗视角展开。复活者的状态通过黑狗的观察、触摸和对话展现。
2. **憋精功的表现必须统一**：身体冰冷僵硬但胸口有微弱起伏；精关被强行锁住，马眼紧闭，没有精液外流痕迹；意识模糊，眼皮颤动，发不出完整音节。与普通死亡的区别在于——**没有射精痕迹**。
3. **三次发现的差异化**：第一次是"声音引导"（老灰在尸体堆里求救），第二次是"触觉发现"（搬动杜宾时感到肌肉抽动），第三次是"惊吓反转"（垃圾桶自己动了）。三次节奏递进，不可雷同。
4. **褐鹿的失声是暂时性的**：点穴封喉，只能发出气音。当前无人会解穴。
5. **黑獒的同族困惑**：仍然保持，不揭穿黑狗身份。
6. **灰牛留守宿舍**：本章灰牛不去小巷，在宿舍等待，结尾七人碰面时再出场。
7. **笔风对齐Ch.13**：角色名加粗，内心OS活跃直接，快节奏，感官驱动。

### 场景3：路上——第一个复活（老灰）

- 卡车驶出青石镇，沿着土路颠簸。暮色四合，车厢后厢里二十几具尸体随着颠簸互相碰撞
- 黑狗单手把着方向盘，另一只手揉了揉裤裆——还在胀着
- 突然，后厢传来一声微弱的声响："……救……救……我……"
- 黑狗的手僵住。他猛地踩下刹车，卡车吱嘎一声停在路边
- 他跳下车，拉开后厢门。尸体堆在暮色中像一座小山，甜腥味扑面而来
- 黑狗爬进后厢，拨开最上面的一具野猪尸体——下面压着一张苍白的狼脸
- **老灰**。灰白色的毛发上沾满血污和泥土，眼睛半睁着，嘴唇干裂，喉咙里发出"嗬……嗬……"的气音
- 黑狗伸手探老灰的鼻息——有，极其微弱。再摸胸口——有微弱起伏
- 他翻开老灰的裤裆检查——**精关处干燥，马眼紧闭，没有精液痕迹**。和周围那些射死后湿成一滩的尸体完全不同
- 内心OS：……没射？……没死？……怎么回事……
- 黑狗不懂憋精功，但他看得出老灰和其他尸体不一样。他拖着老灰的腋下，把灰狼从尸体堆里拽出来，像拖一条湿麻袋一样拖到副驾驶座
- 老灰的身体冰冷僵硬，但还在微微颤抖。黑狗把他塞进副驾驶，扯过一条破毯子盖在他身上
- "……别死。"黑狗低声说，"给我撑着。"
- 老灰的眼皮颤了颤，嘴唇动了动，但只发出一声"……唔……"
- 黑狗关上车门，绕回驾驶座。发动引擎时，他看了眼副驾驶上的老灰——灰狼的耳朵耷拉着，呼吸浅得像没有，但确实还活着
- 卡车重新上路。老灰在副驾驶上随着颠簸微微晃动，灰白色的胸毛从破毯子边缘露出来，沾着干涸的血迹

**情色/感官重点**：
- 后厢里尸体互相碰撞的闷响，突然混进一声微弱的"救……我……"
- 黑狗拨开野猪尸体时，下面露出老灰苍白的狼脸——灰白色毛发、尖牙、黄色眼睛半睁
- 检查老灰裤裆时的对比：周围尸体湿裆、精液硬壳、马眼张着；老灰精关干燥、马眼紧闭、没有射精痕迹
- 拖拽老灰时的冰冷僵硬触感，像拖一条刚从河里捞出来的湿狗
- 副驾驶上老灰随着颠簸微微晃动，破毯子下露出灰白色胸毛

### 场景5：搬尸——第二个复活（杜宾）

- 黑狗、褐鹿、黑獒开始搬尸体。目标是那个巨大的木桶垃圾桶——和第八章同一个
- 黑狗一手拽着脚踝拖，褐鹿和黑獒跟着搬。后厢里的尸体一具一具被拖到垃圾桶边上
- 黑獒力气大，一手拎起一具尸体抛进去。褐鹿拽着手臂拖，鹿腿发抖
- 搬到第十五具左右时，黑狗拖的是杜宾的尸体——精瘦，黑色短毛+棕褐色斑纹，刀削耳
- 黑狗拽着杜宾的脚踝拖向垃圾桶。杜宾的身体在泥地上滑行，军绿制服被血浸透
- **突然**，黑狗感到手里的脚踝**抽搐了一下**
- 黑狗僵住。他低头看杜宾的脸——黑色短毛下的瘦长脸，眼睛闭着，但**眼皮在颤动**
- 黑狗蹲下来，手指探到杜宾鼻前——有极其微弱的气息。再摸胸口——有起伏，比老灰明显一些
- 翻开裤裆检查——**同样干燥，马眼紧闭，没有射精痕迹**
- 内心OS：……又一个……没射……没死……
- 杜宾的眼皮颤得更厉害了，嘴唇动了动，发出一声"……长……长官……？"
- 黑狗盯着他看了几秒。然后笑了一下："……命挺大。"
- 他把杜宾从地上抱起来——比老灰轻，精瘦的——放到卡车驾驶座后面的空隙里，让他靠着车厢壁坐着
- 杜宾的头歪在一边，刀削耳耷拉着，意识模糊但还在呼吸

**情色/感官重点**：
- 杜宾脚踝突然抽搐的那一下——黑狗手指感到肌肉一跳
- 杜宾精瘦的身体被拖拽时在泥地上滑行的触感
- 检查裤裆时的对比：周围尸体湿成一滩，杜宾干燥紧绷
- 杜宾嘴唇动时发出的"长官"——声音嘶哑，像砂纸摩擦
- 黑狗把杜宾抱起来时的轻（精瘦）vs 老灰的沉（壮实）

### 场景6：扔垃圾桶——第三个复活（鬣狗）

- 继续搬尸。垃圾桶里已经塞了十几具尸体，从缝隙里渗出精液和血的混合物

- **突然**，垃圾桶里传来一声"咚"

- 鬣狗从尸体堆里抬起头，瘦骨嶙峋的肩膀撑着上面的死尸，像从坟墓里爬出来的鬼

**情色/感官重点**：
- 垃圾桶"咚"的一声响——在寂静的小巷里像炸雷

### 场景7：六人集结与回据点

- 卡车后厢：二十几具尸体 + 鬣狗趴着

- 黑狗发动引擎。卡车颠簸着从小巷驶出，暮色已尽，夜空繁星点点
- 褐鹿坐在尸体旁边，鹿腿发抖，不敢看周围那些死脸

**内心OS**：

## 五、憋精功复活的视觉/触觉规范

### 5.1 与普通尸体的区别（发现时的检查流程）

| 检查部位 | 真尸体（射精死亡） | 憋精功假死者 |
|---------|------------------|-------------|
| 鼻息 | 无 | 极其微弱，几乎摸不到 |
| 胸口起伏 | 无 | 微弱但确实存在 |
| 体温 | 逐渐变凉 | 冰冷但还有一丝余温 |
| 精关/裤裆 | 湿成一滩，精液硬壳，马眼张着 | **干燥，马眼紧闭，无精液痕迹** |
| 肌肉 | 完全松弛 | 僵硬但偶有抽搐 |
| 意识 | 无 | 模糊，眼皮颤动，发不出完整音节 |

### 5.2 黑狗的认知

- 黑狗**不懂**什么是憋精功。他只知道这些人"没射死"，和他见过的其他尸体不同。
- 内心OS应该是困惑而非掌控："……怎么回事……没射也能不死？……"
- 不要写成黑狗"识破了憋精功"，他就是跟着本能走——发现没死，就救了。

### 5.3 复活后的状态

- 极度虚弱，精槽被强行压住后身体像被掏空，走不动路
- 需要被搀扶/拖拽/抱着移动
- 意识模糊，说话断断续续，发不出完整句子
- 对黑狗的忠诚度：老灰最高（旧情），杜宾中等（精明判断），鬣狗最低（恐惧为主）
