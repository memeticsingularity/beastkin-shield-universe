# 墨犬 - 第八章：Plan（初步构想）

> 本章核心：**潜入兽盾控制区** + **E级阴影的首次铺垫** + **伪装策略的新挑战**。E级黑制服**不直接登场**，但通过"痕迹、传闻、现场"让观众（和黑狗）感受到比R级更强的压迫感。E级没有玄学能力，就是更壮、更能打、权限更高的兽人士兵。本章几乎没有战斗，张力全部来自"身份暴露风险"。

---

## 一、章节定位

| 项目 | 内容 |
|------|------|
| **标题** | 第八章：青石镇（暂定） |
| **场景** | 青石镇（兽盾补给站），黄昏到深夜 |
| **敌人** | 无直接敌人（E级未登场），身份暴露风险来自整个镇子 |
| **核心事件** | 黑狗沿猎人小径潜入→混入兽盾据点→被误认G-20→发现E级审查黑屋→借尿遁脱身→躲入废弃仓库 |
| **本章功能** | ① 首次展示兽盾控制区的日常生态 ② E级恐怖通过"缺席"体现——越不出现越可怕 ③ 伪装策略从"野外唬人"升级为"体制内求生" ④ 为E级正式登场（Ch9/Ch10）做最后铺垫 |

---

## 二、核心原则

1. **E级绝不登场**：不见黑制服本人，但见审问室、见被打伤的士兵、见镇民/士兵对E级的恐惧——E级没有玄学能力，就是更强壮、更有权限的战斗员
2. **没有实质性战斗**：张力来自"身份暴露风险"和"E级逼近的压迫感"，不是武力对抗
3. **G级制服是双刃剑**：在野外能唬住G级，在镇内意味着"要被指挥、要交任务"——伪装策略面临新挑战
4. **性元素淡化但存在**：作为"干扰项"点缀（好色导致差点暴露），不是本章核心驱动力
5. **黑狗的底色不变**：仍然是"失忆好色小鬼"，不是"精密潜入专家"——他会搞砸、会分心、会凭本能蒙混

---

## 三、场景拆分

### 场景1：后山小径——总算到了

**开篇范式**：直接进入事件。

- 黑狗沿着鬣狗纸条上的猎人小径走了大半个下午，太阳西斜，身上那件鬣狗的军绿制服被汗水浸得发软
- 小径尽头是一道矮墙，墙后就是青石镇——炊烟、军靴声、兽人的吼叫声混在一起飘过来
- 黑狗翻了过去，落在一堆柴草上，抬头看见镇子里的景象：军绿/蓝/白制服混杂，兽人士兵来来往往，长筒白袜在泥地上踩出一片杂乱的脚印
- 内心OS：妈的，这么多兽人……都好壮……但好像不太好惹……
- 他摸了摸腰间的手枪（空弹匣），又摸了摸兜里的几十撸币——得先找个地方吃东西，饿坏了

**伏笔**：镇口公告板上贴着更新的通缉令，但黑狗低着头没注意。

---

### 场景2：混入——G-20？

- 黑狗低着头走进镇子，尽量模仿G级那种懒散的步伐。军绿制服虽然有点松，但在黄昏的光线下不太显眼
- 他注意到镇口的公告板——自己的脸，但描述已经更新为"蓝制服+白斗篷+携带枪械"。他现在穿的是绿制服，通缉令上的描述不匹配了——虚假的安全感
- 镇子里的气味：食堂飘来的肉汤味、皮革保养油味、大量兽人聚集的浓烈雄汗味，混着远处马厩的粪便味
- 一个G级小队长（全新角色，比如一只老狼或老狗，经验丰富但眼神不好）看到他，喊："喂！G-20！你小子跑哪去了？任务完成了吗？"
- 黑狗僵住——G-20是鬣狗的编号！他被误认了！
- 内心OS：完……完蛋了……G-20是谁……啊，是那条鬣狗……

**黑狗的应对**：顺势扮演，学着鬣狗那种卑微的口吻："完……完成了……队长……"

---

### 场景3：误认与蒙混——E级的阴影

**小队长设计**：
- **种族**：老狼兽人或老狗兽人
- **特征**：灰白色毛发泛银边，瘸了一条腿，军绿制服洗得发白，胸口挂着好几枚杂牌勋章。左眼有疤，但右眼老花，所以没看清黑狗的脸
- **性格**：暴躁、爱骂街、但护短（对自己的小队）。底层老兵，见过太多新人送死，对上级（尤其是E级）又怕又恨
- **状态**：以为黑狗是自己小队里那个瘦弱的G-20（鬣狗），只是换了搭档（他没注意到鬣狗不在）

**互动节拍**：

1. **呵斥**：小队长骂骂咧咧走过来，一巴掌拍在黑狗后脑勺上（像野猪拍鬣狗那样，但这是"长官拍下属"）："完成了还不去交报告？磨蹭什么！老子等你交班等了一个时辰！"
2. **跟随意愿**：黑狗不敢反抗，低着头跟在小队长身后走。路过食堂时，他闻到肉汤味，肚子咕噜叫了一声
3. **好色干扰**：路边一个R级白制服的水牛士兵正在擦枪，白色制服被背肌撑出一道道褶皱，长筒白袜在小腿肚上绷得变形，裆部鼓鼓囊囊。黑狗咽了口唾沫，分了神，差点撞上一个推车的杂兵
4. **小队长察觉**："你小子今天怎么回事？魂丢了？"
5. **黑狗糊弄**："饿……饿了……"
6. **小队长冷笑**："饿了？等交完班再吃。今晚E组在镇上，你敢乱跑，被逮进去我可不管你。"

**E级阴影的首次具体化**：
- 他们经过一栋没有窗户的低矮建筑——墙壁是灰色的，门口站着两名身穿**黑色制服**的壮硕兽人，背对着街道，看不清面目，但肩膀比R级还宽，黑色制服被背肌撑出一道道褶皱
- 小队长压低声音，瘸腿不自觉地加快步伐："E组今天在里面审人。别靠近，别多看。"
- 从建筑门缝里传出闷响——不是惨叫，是拳头砸在肉上的闷响，还有粗重的喘息声和皮带抽动的脆响
- 小队长露出恐惧的表情："上次G-11进去，挨了三个时辰的打，出来路都走不稳了。E组那帮人……手重得很。"他摸了摸自己瘸腿上的一道旧疤，"老子这条腿就是当年被他们'审查'时打断的。"打了个寒颤
- 黑狗内心OS：三个时辰……那得多疼……

---

### 场景4：脱身——借尿遁与废弃仓库

- 交报告的地方是一间灯火通明的木屋，里面坐着一个O级监工（全新角色或复用某个模板）
- 黑狗意识到一旦进去交报告就会露馅——他不知道鬣狗和野猪的任务内容是什么
- 他借口"肚子疼要拉屎"，小队长骂了两句放他走
- 黑狗钻进镇子边缘的巷子里，找到一个废弃的柴房/仓库躲了进去
- 仓库里堆满了破旧的军需品：发霉的帐篷、断裂的枪托、破洞的白袜……还有一股陈年精液和雄汗混合的腥膻味

**仓库发现**：
- 黑狗在角落里发现了几块带血的绷带和一根折断的指甲——不是战场上那种撕裂伤，是指关节被人一根根掰断的痕迹
- 还有一张被揉皱的纸条，上面潦草地写着："别撒谎。E组打人很疼，专打脸和裆。——G-11"
- 黑狗皱起眉。G-11……就是小队长说"挨了三个时辰打"的那个。

---

### 场景5：暂时的喘息——夜色中的恐惧

- 黑狗在仓库里度过一夜。他吃了半块干粮，把鬣狗的军绿制服脱下来检查——肩膀处有一个小洞，可能是之前被树枝勾破的，但不明显
- 他听到外面传来的声音：
  - 巡逻队的脚步声（军靴踩地，白袜摩擦声）
  - 远处审问室里传来的闷哼和皮带抽动的脆响
  - 两个G级士兵在墙根下小声议论："E组明天要查全队档案……听说有人冒名顶替……"
- 黑狗内心一紧——冒名顶替？不就是在说他吗？
- 他摸了摸自己的脸。通缉令上的素描虽然像，但兽盾的低层士兵主要靠制服认人。可如果E组查档案……
- 他需要一个新的身份、新的伪装，或者找到逃出镇子的路
- 夜色中，审问室的方向偶尔传来一两声压抑的呻吟，然后是拳头砸在肉上的闷响

**性元素的点缀**：
- 深夜，黑狗半梦半醒间，听到仓库外有两个G级士兵在偷懒抽烟，聊起了荤段子——关于某个R级水牛的尺寸、关于食堂里哪个O级监工喜欢后入……
- 黑狗在黑暗中舔了舔嘴唇，棍棍微微硬了起来，但他不敢动，怕被外面的人发现
- 这种"想摸但不能摸"的压抑感，和前几章的"直接上手"形成反差

## 四、差异化重点

| 维度 | Ch7（茶棚） | Ch8（青石镇，本章） |
|------|------------|-------------------|
| **互动模式** | 心理战+举枪威慑 | 伪装混入+身份暴露风险 |
| **敌人关系** | 明确的敌人（G级） | 整个环境都是潜在威胁 |
| **E级** | 只存在于传闻（"审人"） | 通过"殴打声、断指甲、纸条"具体化 |
| **性元素** | 核心驱动力（春药弹+射精） | 干扰项（好色差点暴露） |
| **黑狗心态** | "试试看"的实验心态 | "随时可能被识破"的紧张感 |
| **信息获取** | 从敌人身上搜纸条 | 从环境/遗留物/传闻中拼凑 |
| **结尾状态** | 换装成功，前往青石镇 | 成功潜入但发现自己陷入了更大的牢笼 |

## 五、笔风检查清单

### 必须保留

- [ ] 开篇直接进入事件（翻墙、混入）
- [ ] 第三人称紧贴黑狗感官与心理
- [ ] 内心OS不加引号，口语化、碎片化
- [ ] **黑狗的紧张感**：手抖、说话发紧、差点撞上人
- [ ] **好色干扰决策**：看到水牛R级士兵分神、仓库外听荤段子硬了
- [ ] **E级压迫感通过"缺席"体现**：不见其人，但见其威（审问室的殴打声、G-11的断指甲和纸条）
- [ ] **伪装的新挑战**：G级制服在镇内不是优势，是枷锁
- [ ] **嗅觉主导**：肉汤味、雄汗味、皮革味、血腥味、陈年精液味
- [ ] **白袜要素**：镇上到处都是白袜脚印、R级水牛的白袜、仓库里的破白袜

### 严禁出现

- [ ] E级黑制服直接登场（不能看到脸、不能对话）
- [ ] 实质性战斗（本章没有武力对抗）
- [ ] 黑狗"掌控一切"的潜入感（他是靠运气和误认混进来的）
- [ ] 游戏化术语
- [ ] 诗意环境描写
- [ ] 道德评判

## 七、后续钩子

1. **E级正式登场**：Ch9或Ch10，黑制服本人出现
2. **G-20的身份还能用多久**：小队长随时可能发现真正的G-20失踪了
3. **G-11的纸条**："别撒谎，E组打人很疼"——E级的审查方式就是纯粹的暴力殴打
4. **审问室的殴打声**：拳头砸在肉上的闷响，比任何玄学描述都更真实
5. **逃出镇子的路**：后山小径只能进不能出（有检查站），需要找新的出路
6. **仓库里的破白袜**：黑狗在仓库过夜时，发现一双被撕破的R级白袜——上面没有盾型logo，而是另一个标记？
