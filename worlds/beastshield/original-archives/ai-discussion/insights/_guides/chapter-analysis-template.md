---

## 使用说明

1. 复制本模板后，将 `[方括号内容]` 替换为实际内容
2. 根据章节特点，可适当增删子章节
3. 保持 Markdown 表格格式的一致性
4. 核心特点标签使用反引号包裹，便于检索

---

# Chapter X [章节标题] - 分析

## 注意事项

1. **文件命名**：`ch-XX-analysis.md`（主线）或 `bs-o-s-X-title-analysis.md`（短篇）
2. **对应文件链接**：使用相对路径 `../../../../../chaptered-stories/...`
3. **表格格式**：保持列对齐，使用标准 Markdown 表格语法
4. **日期格式**：统一使用 `YYYY-MM-DD`
5. **标签格式**：使用反引号 `` ` `` 包裹，多个标签用顿号 `、` 分隔
