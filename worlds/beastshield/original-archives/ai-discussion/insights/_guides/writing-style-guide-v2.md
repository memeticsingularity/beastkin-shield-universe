## 第一部分：通用基础

### 1.1 核心世界观设定（不可更改）

#### "精槽"系统（世界观基础）

**规则**：
1. 所有伤害转化为"性欲值"（精槽）
2. 精槽满则强制射精并死亡
3. 弱点攻击（卵蛋、乳头、敏感点）加速精槽累积
4. 部分角色可能有第二条精槽（诈死）

**描写要求**：
- 死亡必须与射精同时发生
- 尸体必须包含：精液横流、特定姿势、白袜特写

#### 等级与制服系统

| 等级 | 制服颜色 | 白袜/黑袜 | 功能 |
|------|----------|-----------|------|
| 杂兵 | 绿色 | 白袜 | 经验包 |
| 干部 | 蓝色 | 白袜 | 小BOSS |
| 武斗兵 | 黑色 | 黑袜 | 精英敌人 |
| 顶层 | 白色/特殊 | 视角色而定 | 最终BOSS |

**重要**：赏金以"白袜/黑袜底部编号"为凭证

---

### 1.2 XP元素详细规范（核心视觉标签）

#### 强制出现元素（每章必写）

**白袜/黑袜的仪式化描写**：
- 每个兽人死亡时必须描写袜子状态（颜色、位置、污渍）
- 袜底编号是赏金凭证，脱袜是标准动作
- 精液必须出现在袜子上（沿着大腿流下、渗透袜底）

**粗壮下肢的反复强调**：
- "白袜粗腿"、"黑袜粗腿"作为高频词汇
- 描写顺序：制服 → 袜子 → 腿部肌肉 → 下体
- 腿部姿势：趴开、弯曲、翘起、绷直脚尖

**肌肉与体型的对比**：
- 反复强调兽人"膀大腰圆"、"虎背熊腰"
- 与主角（瘦弱）形成对比
- 肌肉在死亡时的状态：紧绷 → 放松

#### 身体部位描写优先级

**必须详细描写**（按重要性排序）：
1. **下体**：形状（短粗/细长）、包皮状态（包/露）、勃起过程
2. **袜子**：颜色（白/黑）、位置（小腿/脚踝）、编号、污渍
3. **腿部**：粗细、肌肉、姿势（趴开/并拢/翘起）
4. **乳头**：大小（葡萄/樱桃）、颜色（酱紫/粉嫩）、硬度
5. **臀部**：圆润度、翘起角度、菊花（后门场景）
6. **胸肌**：饱满度、抖动、毛发

#### 尸体美学标准

**必须出现的尸体元素**：

1. **姿势**：
   - 趴开双腿（最常用）
   - 跪姿（屈辱感）
   - 侧躺（曲线展示）
   - 挂在某处（栏杆/门/围栏）

2. **精液分布**：
   - 地上（汇聚成河/池）
   - 自己身上（肚皮/大腿/胸肌）
   - 其他尸体上
   - 袜子上（渗透/流淌）

3. **细节**：
   - 死不瞑目的眼神
   - 舌头外露（可选）
   - 四肢偶尔的抽搐
   - 下体仍保持勃起一段时间

### 1.3 情色描写功能化原则

**情色描写必须服务于**：
1. 战斗机制（精槽累积）
2. 角色塑造（展示性格）
3. 权力关系（控制与服从）

**禁止**：
- 无意义的情色堆砌
- 与剧情脱节的H场景

#### 器官称谓词库

**常用词汇**（根据语境选择）：
- 鸡巴/肉棒/屌/鞭（通用）
- 卵蛋/蛋蛋/睾丸（弱点）
- 龟头/冠状沟/系带（敏感点）
- 乳头/乳尖/葡萄（胸部）
- 菊花/后穴/直肠（后门）
- 精液/浓精/白浆/淫液（产物）

#### 感官描写要点

**必须包含**：
- 视觉（颜色、形状、液体流动）
- 触觉（硬度、温度、湿润度）
- 听觉（呻吟、求饶、体液声）
- 嗅觉（汗味、精味、雄性气息）

## 第二部分：四大风格

### Style 1: 第一人称游戏化（主线第一卷《兽游世界》）

#### 风格定位
- **类型定义**：猎奇向游戏异世界小说 + 第一人称沉浸式叙事 + 黑色幽默 + 情色战斗系统
- **核心卖点**：游戏元认知与情感真实的交织、外表凶悍兽人的脆弱与羞耻反差
- **目标读者**：喜欢游戏代入感、成长弧线的读者

#### 语言风格规范

**必须使用**：
- **第一人称口语化**："话不多说"、"咱就不装了"、"卧槽"
- **网络直播感**：像是在给朋友讲述游戏经历
- **弹幕式吐槽**：对剧情/系统的实时吐槽

**禁止使用**：
- 书面化叙述（"彼时"、"尔后"、"但见"）
- 过度修辞的文学语言
- 第三人称全知视角

**句式节奏**：

*快节奏战斗*：
```
短句为主，省略主语。
银光闪过，血花飞溅。
他瞪着眼，倒地不起。
```

*慢节奏处决*：
```
详细描写，多感官渲染。
每一股精液射出都单独描写。
加入角色的实时反应。
```

#### 主角塑造

**性格基调**：
- 谨慎但腹黑（i人特质）
- 善于观察总结
- 偶尔残留同情心
- 逐渐从"游戏思维"转向"情感投入"

**写作要点**：
- 不给详细外貌描写（最大化代入感）
- 通过选择展现性格（选潜行系而非英雄系）
- 内心独白占比高（吐槽、观察、挣扎）

#### 游戏元元素

**必须包含**：
- 系统提示弹窗（恭喜升级、获得技能）
- 存档/读档机制（可作为叙事工具）
- 属性点分配（战斗系/射击系/潜行系/英雄系）
- 技能解锁（影袭、银针封穴等）

#### 章节结构模板

```
开场（10%）→ 探索/对话（20%）→ 冲突触发（10%）→
战斗/调教（40%）→ 战后/新信息（20%）
```

#### 仿写示例

**原文风格**：
```
我发动影袭，直接瞬移到熊守卫的身后，然后将一根银针扎入了他的脖颈。
被扎的熊守卫身子一颤，然后保持着站岗的姿势一动不动了。
另一名熊守卫看到我的出现，立刻警惕地吼道："你是什么人……唔！"
话还没说完，从他背后一只大手伸了出来，将他的嘴捂得严严实实！
```

#### 自检问题

1. 主角是否有"这只是游戏"的元认知？
2. 是否有系统提示和存档机制？
3. 情色描写是否服务于战斗机制？
4. 是否有至少一个让人记住的吐槽？
5. 结尾是否让读者想看下一章？

### Style 2: 第三人称专业杀手（主线第二卷《魔影》）

#### 风格定位
- **类型定义**：专业杀手视角 + 杀戮艺术化 + 冷峻精致 + 黑色幽默
- **核心卖点**：将杀戮转化为"艺术"、不同角色的处决风格差异
- **目标读者**：喜欢专业杀手、精致暴力美学的读者

#### 语言风格规范

**必须使用**：
- **仪式化叙述**：每个处决都有完整"前戏-高潮-余韵"结构
- **专业化术语**：毒牙、血毒、灼流暗劲、前列腺捅射
- **冷静语调**："不守规则的坏孩子就应该接受惩罚哦～"

**禁止使用**：
- 口语化网络梗（"卧槽"、"咱就不装了"）
- 内心独白过多（侧重动作和对话）
- 游戏元元素（无系统提示、无存档）

**句式节奏**：

*魔影风格（戏谑精细）*：
```
长短句结合，描述性更强
"魔影叹了口气，收起一贯的笑脸，瞪着组长一脸冷漠的说道..."
对话占比高，角色间互动多
细节控：制服褶皱、精液股数、袜子臭味的精确描写
```

*老雷风格（暴力温柔）*：
```
动作连贯，三拳连击的节奏感
"马步一扎，气运全身，第一拳...第二拳...第三拳..."
温柔反差："放心，不会有太大的痛苦"、"真是个乖孩子"
```

#### 角色塑造

**魔影（专业杀手）**：
- **表面**：戏谑残忍，"坏孩子要接受惩罚哦～"
- **深层**：强迫症（尸体必须摆整齐）、反思能力
- **内核**：淫欲与杀戮的融合，血毒体质带来的欲望

**老雷（暴力美学代表）**：
- **视觉标签**：黑铁臂铠、血红冒火星、洁癖强迫症
- **战斗风格**：灼流暗劲三拳连击、焚体缠身群体战斗
- **温柔反差**：对最后一只熊的温柔处决

**小豪（学徒成长）**：
- 从被野猪吓到坐地到熟练特工的成长弧线

#### 多线叙事结构

```
场景A（魔影）→ 场景B（老雷并行）→ 场景C（魔影继续）→
角色汇合 → BOSS战 → 战后/教育场景 → 时间跳跃/回忆 → 最终对决
```

#### 处决流程多样化

**不同于第一卷的标准五阶段，第二卷强调多样化**：
- 手淫、窒息、毒血、功法、药物、心理暗示
- 批量屠杀时可缩短单个敌人的描写
- BOSS战需要1000-2000字的详细描写

#### 自检问题

1. 处决是否有"艺术感"和仪式感？
2. 不同角色是否有不同的处决风格？
3. 是否有黑色幽默元素（如老雷的洁癖）？
4. 是否通过行动和对话而非独白展现性格？
5. 是否有尸体艺术化的描写？

### Style 3: 第三人称群像史诗（主线第三卷《浮岛大战》）

#### 风格定位
- **类型定义**：多阵营群像 + 史诗悲壮 + 悲剧英雄 + 世界变革
- **核心卖点**：大规模团战、悲壮牺牲、多方势力对抗、情感冲击
- **目标读者**：喜欢史诗叙事、悲剧英雄、复杂势力对抗的读者

#### 语言风格规范

**必须使用**：
- **史诗化语调**：借鉴武侠小说和玄幻小说的宏大场面
- **武侠+玄幻术语**：禁咒、神武、血精石、五行相生、灼流暗劲
- **长短句结合**：动作描写用短句，情感描写用长句

**禁止使用**：
- 口语化网络化（第一卷的风格）
- 过度戏谑（第二卷魔影的风格）
- 单一主角视角

**句式节奏**：

*群战场景*：
```
加速：短句、省略主语（"银光闪过，血花飞溅"）
多线并进：快速切换不同角色的战斗
```

*情感高潮*：
```
减速：详细描写，多感官渲染
悲壮感：牺牲的意义、角色的内心独白
```

#### 群像塑造方法

**视觉标签+战斗风格**：
| 角色 | 视觉标签 | 战斗风格 |
|------|---------|---------|
| 薛鼎 | 虎纹分身、记忆融合 | 悲情英雄的决绝 |
| 白熊 | 熊掌、憨厚 | 传统武术的坚守 |
| 勤川 | 龙神之力、五行相生 | 天下第一的霸气 |
| 曲先生 | 音波攻击、秋霞染世调 | 绝唱般的悲壮 |

**悲剧性角色深化**：
- 为爱赴死的悲情英雄
- 记忆分裂的身份困境
- 师徒悲剧（白熊与阿正）

#### 叙事结构

**多线并进模式**：
```
开篇·体制残酷(CH-01) → 发展·道馆恩怨(CH-02~06) →
转折·神武觉醒(CH-07~11) → 高潮·浮岛大战(CH-12~18) →
结局·血君王降临(CH-19~22)
```

**情感弧线构建**：
```
残酷开篇 → 温情师徒 → 群像混战 → 悲壮牺牲 → 世界变革
```

#### 战斗场面构建

**大规模团战要点**：
- 五行相生相克（金木水火土）
- 神武系统展示（十二神武）
- 禁咒对轰（视觉效果）
- 不同势力的配合与对抗

**悲剧英雄的死亡**：
- 有意义牺牲（保护他人、完成使命）
- 情感铺垫（回忆、遗言）
- 高光时刻（最强一击）

#### 自检问题

1. 是否有多个令人印象深刻的角色？
2. 战斗是否有史诗感和视觉效果？
3. 悲剧角色的死亡是否有情感冲击力？
4. 多线叙事是否清晰不混乱？
5. 结尾是否让读者感受到"世界变革"的重量？

### Style 4: 多视角试验场（短篇故事系列）

#### 风格定位
- **类型定义**：多视角拼图 + 新机制试验 + 黑色幽默 + 世界观补充
- **核心卖点**：每篇独特玩法、不同主角视角、快速进入主题
- **目标读者**：喜欢多样化玩法、碎片化阅读、单元剧形式的读者

#### 语言风格规范

**必须使用**：
- **冷峻情色**：武侠术语+情色描写，"灼流暗劲"、"牛鞭挺立"
- **短句为主，动作连贯**："马步一扎，气运全身"
- **黑色幽默**：预期违背、一本正经的荒谬

**视角切换**：
- 受害者视角：SS-005《兽盾员工的一天》（暗恋尸体play的悲剧）
- 施害者视角：SS-002/003《黑石》系列、SS-007《毕业实习》
- 旁观者视角：SS-001《兽盾农家乐》、SS-004《俘虏快递》

#### 短篇标准节奏

```
开场（10%）→ 冲突升级（30%）→ 高潮处决（40%）→ 收尾（20%）
```

**特点**：
- 快速进入主题，无冗余铺垫
- 高潮处决场景占比大
- 结尾常带黑色幽默或反转

#### 新机制试验场

| 故事 | 核心机制 | 叙事功能 |
|------|----------|----------|
| SS-001 | 精液肥料 | 揭示兽盾实验农场设定 |
| SS-003 | 窒息play | 进阶玩法，20发射精计数 |
| SS-004 | 抑制器 | 道具系处决，梦境杀 |
| SS-006 | 临界射精 | 舔袜play，警棍羞辱 |
| SS-007 | 灼流暗劲 | 特工局特殊功法展示 |

#### 角色塑造特点

**主角多样化**：
| 故事 | 主角类型 | 特点 |
|------|----------|------|
| SS-001 | 转型社畜 | 从受害者到施害者 |
| SS-002/003 | 赏金猎人 | 雌雄同体，专业冷酷 |
| SS-005 | 普通员工 | 暗恋尸体play的悲剧 |
| SS-007 | 特工实习生 | 年轻嚣张，洁癖强迫症 |

**配角"记忆点"策略**：
| 角色 | 记忆点 | 功能 |
|------|--------|------|
| 牛大壮 | 老实牛想寄钱回家 | 悲剧象征 |
| 狗来福 | 街头混混想开店 | 梦想破灭 |
| 熊厚实 | 憨厚想吃母亲做的鱼 | 温情对比 |

#### 黑色幽默来源

- **预期违背**：SS-001主角从社畜变成农场主
- **一本正经的荒谬**：SS-007用尸体清洁
- **角色反差**：SS-005暗恋尸体play

#### 自检问题

1. 是否有独特的玩法机制？
2. 是否快速进入主题？
3. 结尾是否有黑色幽默或反转？
4. 视角选择是否适合这个故事？
5. 是否在短篇内完成了角色弧光？

## 第三部分：风格选择指南

### 如何根据创作目标选择风格

| 你的目标 | 推荐风格 | 理由 |
|---------|---------|------|
| 展示主角成长弧线 | Style 1 | 第一人称最大化代入感 |
| 复杂组织内部生态 | Style 2 | 第三人称多线适合群像 |
| 史诗级大规模团战 | Style 3 | 群像塑造+悲壮感 |
| 试验新玩法机制 | Style 4 | 短篇灵活，快速验证 |
| 轻松日常XP满足 | Style 4 | 单元剧形式，碎片化 |
| 深度情感冲击 | Style 3 | 悲剧英雄，牺牲意义 |
| 精致暴力美学 | Style 2 | 杀戮艺术化 |
| 游戏机制教学 | Style 1 | 元认知，系统提示 |

### 风格混合使用

某些场景可以混合使用不同风格：

**主线故事中的回忆/短篇**：
- 主线第三卷中可以用Style 4（短篇节奏）来写回忆片段
- 主线第二卷中可以用Style 1（第一人称）来写某个角色的内心独白

**短篇与主线的关联**：
- Style 4的短篇可以为Style 3的史诗大战铺垫
- Style 2的专业杀手可以出现在Style 1的新手任务中

## 第四部分：通用自检清单

### 世界观一致性检查

- [ ] 所有伤害是否转化为精槽？
- [ ] 死亡是否伴随射精？
- [ ] 制服颜色与等级是否对应？
- [ ] 情色描写是否功能化（服务于战斗或角色）？
- [ ] 每个兽人死亡时是否描写了袜子状态？

### 风格一致性检查

**Style 1（第一人称游戏化）**：
- [ ] 是否使用第一人称口语化？
- [ ] 是否有系统提示和存档机制？
- [ ] 主角是否有"这只是游戏"的元认知？

**Style 2（第三人称专业杀手）**：
- [ ] 是否避免游戏元元素？
- [ ] 处决是否有仪式感和艺术感？
- [ ] 是否通过行动而非独白展现性格？

**Style 3（第三人称群像史诗）**：
- [ ] 是否有多个令人印象深刻的角色？
- [ ] 战斗是否有史诗感？
- [ ] 悲剧角色是否有情感冲击力？

**Style 4（多视角试验场）**：
- [ ] 是否快速进入主题？
- [ ] 是否有独特的玩法机制？
- [ ] 结尾是否有黑色幽默或反转？

### 质量检查

- [ ] 情色描写是否避免了无意义堆砌？
- [ ] 每个场景是否有新鲜感？
- [ ] 兽人的死亡是否有仪式感和美感？
- [ ] 是否有至少一个让人记住的细节？
- [ ] 结尾是否让读者想看下一章/篇？
