#### Template v2.0 更新详情

##### 单章分析模板 v2.0（chapter-analysis-template-v2.md）

**更新前结构（v1.0）**:
- 6-8个章节，结构不统一
- 缺少标准化表格
- 处决统计不系统

**更新后结构（v2.0）** - 11个标准化章节:
1. **基本信息** - 标准化表格（标题、角色、视角、事件、时间线、字数）
2. **核心特点** - 玩法亮点表格、处决方式统计、场景特色
3. **叙事结构分析** - 章节流程图、节奏特点表格、关键转折
4. **角色塑造分析** - 人物弧光图、叙事功能、角色关系
5. **行文风格分析** - 语言特色表格、感官描写层次表格
6. **情色/战斗场景分析** - 处决流程五阶段表格、差异化描写
7. **核心设定与世界观** - 设定揭示、组织架构图、战力/等级体系
8. **剧情推进** - 主要事件、伏笔与线索、前后作关联
9. **主题与隐喻** - 核心主题、象征元素、情感基调
10. **写作技巧评价** - 优点、特点、可借鉴要素、可改进空间
11. **总结** - 核心特点标签、一句话总结

**新增标准化元素**:
- 基本信息表格（6个标准字段）
- 玩法亮点表格（元素+具体表现）
- 处决方式统计（角色/方式/股数/特点）
- 叙事流程图（阶段式）
- 节奏特点表格（阶段/节奏/描写重点）
- 人物弧光图（初始→转变→最终）
- 语言特色表格（维度/特点/示例）
- 感官描写层次表格（视/听/嗅/触）
- 处决流程五阶段表格（控制/挑逗/临界/射精死亡/余韵）
- 组织架构图（树形结构）
- 战力/等级体系表格（层级/代表/特征）
- 核心特点标签（5-6个关键词）

## 使用指南

### 创建新章节分析

1. 复制 `chapter-analysis-template-v2.md`
2. 替换 `[方括号内容]` 为实际内容
3. 保持11个章节结构
4. 添加5-6个核心特点标签
5. 设置分析日期为当前日期

### 创建新Overview

1. 复制 `overview-template.md`
2. 根据内容类型选择章节：
   - 主线故事：使用全部14章
   - 短篇系列：可删减至6-8章
3. 必须包含附录（章节目录+分类标签）

### 参考写作风格

- 查阅 `writing-style-guide.md` 了解基本写作规范
- 查阅 `writing-style-comparison.md` 了解四大系列差异
