# 《兽游世界》写作风格指南

> 用于向新的AI传达该作品的创作风格与技巧

---

## 一、核心风格定位

### 1.1 类型定义

**猎奇向游戏异世界小说** + **第一人称沉浸式叙事** + **黑色幽默** + **情色战斗系统**

### 1.2 核心卖点

- 将"射精"与"死亡"绑定的独特战斗机制
- 游戏元认知（存档/读档/系统提示）与情感真实的交织
- 外表凶悍兽人的脆弱与羞耻反差
- 暴力与性癖的诗意结合

---

## 二、语言风格规范

### 2.1 语体特征

**必须使用**：

- **第一人称口语化**："话不多说"、"咱就不装了"、"卧槽"
- **网络直播感**：像是在给朋友讲述游戏经历
- **弹幕式吐槽**：对剧情/系统的实时吐槽

**禁止使用**：

- 书面化叙述（"彼时"、"尔后"、"但见"）
- 过度修辞的文学语言
- 第三人称全知视角

### 2.2 句式节奏

**快节奏战斗**：

```
短句为主，省略主语。
银光闪过，血花飞溅。
他瞪着眼，倒地不起。
```

**慢节奏处决**：

```
详细描写，多感官渲染。
每一股精液射出都单独描写。
加入角色的实时反应。
```

### 2.3 宅文化梗运用

**可自然融入的元素**：

- 游戏术语（背版、越级打怪、缝了这个）
- 动漫梗（飞雷神、英雄系/恋爱养成）
- 网络流行语（i人、贤者模式、中二）

---

## 三、核心机制设定（不可更改）

### 3.1 "精槽"系统（世界观基础）

**规则**：

1. 所有伤害转化为"性欲值"（精槽）
2. 精槽满则强制射精并死亡
3. 弱点攻击（卵蛋、乳头、敏感点）加速精槽累积
4. 部分角色可能有第二条精槽（诈死）

**描写要求**：

- 必须实时显示精槽百分比（如"精槽值飙升到90%"）
- 死亡必须与射精同时发生
- 尸体必须包含：精液横流、特定姿势、白袜特写

### 3.2 等级与制服系统

| 等级  | 制服颜色  | 白袜/黑袜 | 功能     |
|-----|-------|-------|--------|
| 杂兵  | 绿色    | 白袜    | 经验包    |
| 干部  | 蓝色    | 白袜    | 小BOSS  |
| 武斗兵 | 黑色    | 黑袜    | 精英敌人   |
| 顶层  | 白色/特殊 | 视角色而定 | 最终BOSS |

**重要**：赏金以"白袜/黑袜底部编号"为凭证

### 3.3 游戏元元素

**必须包含**：

- 系统提示弹窗（恭喜升级、获得技能）
- 存档/读档机制（可作为叙事工具）
- 属性点分配（战斗系/射击系/潜行系/英雄系）
- 技能解锁（影袭、银针封穴等）

## 四、角色塑造模板

### 4.1 主角（玩家视角）

**主线第一卷模式 - 第一人称新手成长**：

**性格基调**：

- 谨慎但腹黑（i人特质）
- 善于观察总结
- 偶尔残留同情心
- 逐渐从"游戏思维"转向"情感投入"

**写作要点**：

- 不给详细外貌描写（最大化代入感）
- 通过选择展现性格（选潜行系而非英雄系）
- 内心独白占比高（吐槽、观察、挣扎）

**外传《炎魉》模式 - 第三人称双主角职业猎人**：

**炎（执行者）性格基调**：

- 专业冷漠，以练功和赚钱为目的
- 有原则底线（不抢别人猎物编号）
- 追求效率（通过秒数记录功力进步）
- 会对强者产生敬畏

**魉（善后者）性格基调**：

- 善良怜悯，帮死者合眼安息
- 非好杀之人，因缺钱才从事此工作
- 有底线会发火（因炎的残忍而发怒）
- 在血腥中保持人性的努力

**双主角写作要点**：

- 炎负责推动情节（杀人、判断、成长认知）
- 魉负责情感缓冲（善后、编号记录、内心怜悯）
- 两人互动推动人物深度（分歧→妥协）
- 专业细节：编号记录、对讲机使用、赏金计算

### 4.2 兽人角色模板

**每个兽人必须包含**：

1. **视觉标签**（选一个）：
    - 膀大腰圆/肌肉贲起
    - 白袜粗腿/黑袜军靴
    - 包皮包裹/龟头外露
    - 胸肌饱满/乳头粉嫩

2. **性格记忆点**（只选一个）：
    - 憨厚老实（熊掌）
    - M属性（牛杂）
    - 高傲不屈（虎队长）
    - 愚钝懒惰（红牛司机）

3. **死亡仪式**（必写）：
    - 射精股数（通常5-20股）
    - 身体反应（踮脚尖、绷紧肌肉）
    - 尸体姿势（趴着、跪着、躺着）
    - 精液分布（地上、身上、袜子上）

### 4.3 反差萌公式

**外表 vs 内在**：

```
凶狠外表 + 脆弱反应 = 萌点
粗壮身体 + 娇喘呻吟 = 反差
傲慢态度 + 求饶颤抖 = 戏剧张力
```

## 五、战斗场面写作模板

### 5.1 标准处决流程（按顺序）

**第一阶段：控制（50-100字）**

- 潜行接近或正面制服
- 抓住弱点（卵蛋）使其失去反抗
- 角色反应：闷哼、颤抖、软倒

**第二阶段：挑逗（150-300字）**

- 言语羞辱或调戏
- 手动刺激（撸动、揉捏）
- 精槽值逐步上升（标注百分比）
- 角色反应：求饶、喘息、流泪

**第三阶段：突破（100-200字）**

- 精槽达到临界（95%+）
- 详细资料解锁（可选）
- 最后刺激（敏感点）

**第四阶段：射精死亡（150-250字）**

- 射精启动（第一股的冲击力）
- 股数统计（"一股接一股"）
- 身体反应（脚尖踮起、腰部挺起）
- 意识消散（眼神涣散、头歪向一边）

**第五阶段：余韵（50-100字）**

- 尸体状态（姿势、精液分布）
- 环境渲染（气味、视觉）
- 主角反应（成就感、怜悯、吐槽）

### 5.2 变异处决（可选）

**快速处决**：

- 扭断脖子 → 精槽瞬满 → 射精
- 割喉 → 射精
- 银针封穴 → 保持姿势射精死亡

**羞辱处决**：

- 强迫对方自己玩乳头
- 控制射精节奏（欲射还停）
- 公开处决（让他人观看）

## 六、情节节奏公式

### 6.1 章节结构模板

```
开场（10%）→ 探索/对话（20%）→ 冲突触发（10%）→
战斗/调教（40%）→ 战后/新信息（20%）
```

### 6.2 情感对冲技巧

**残酷场景后必须插入**：

- 温情元素（摸头、安慰、内心触动）
- 喜剧元素（吐槽、意外、角色反差）
- 新信息（系统提示、世界观揭露）

**目的**：防止读者情感麻木

### 6.3 悬念设置点

**每章结尾建议包含**：

- 新角色登场
- 新机制解锁
- 悬念未解（"那个是什么？"）
- 主角内心疑问

## 七、XP元素详细规范（核心视觉标签）

### 7.1 强制出现元素（每章必写）

**白袜/黑袜的仪式化描写**：

- 每个兽人死亡时必须描写袜子状态（颜色、位置、污渍）
- 袜底编号是赏金凭证，脱袜是标准动作
- 精液必须出现在袜子上（沿着大腿流下、渗透袜底）

**粗壮下肢的反复强调**：

- "白袜粗腿"、"黑袜粗腿"作为高频词汇
- 描写顺序：制服 → 袜子 → 腿部肌肉 → 下体
- 腿部姿势：趴开、弯曲、翘起、绷直脚尖

**肌肉与体型的对比**：

- 反复强调兽人"膀大腰圆"、"虎背熊腰"
- 与主角（瘦弱）形成对比
- 肌肉在死亡时的状态：紧绷 → 放松

### 7.2 身体部位描写优先级

**必须详细描写**（按重要性排序）：

1. **下体**：形状（短粗/细长）、包皮状态（包/露）、勃起过程
2. **袜子**：颜色（白/黑）、位置（小腿/脚踝）、编号、污渍
3. **腿部**：粗细、肌肉、姿势（趴开/并拢/翘起）
4. **乳头**：大小（葡萄/樱桃）、颜色（酱紫/粉嫩）、硬度
5. **臀部**：圆润度、翘起角度、菊花（后门场景）
6. **胸肌**：饱满度、抖动、毛发

**可选描写**：

- 面部（仅在求饶/死亡瞬间）
- 手臂（仅在角力场景）

### 7.3 特定癖好的标准化描述

**包皮敏感度**（熊兽人专用）：

```
长期被包皮包裹的龟头很少与内裤摩擦，十分敏感
稍微刺激就浑身颤抖
比其他兽人更容易早泄
```

**储精量差异**（牛兽人专用）：

```
牛鞭粗长，蛋蛋如灌满水的水袋
射精股数多（10-20股），液压强劲
精液浓稠，射得远（2米以上）
```

**肉刺敏感点**（虎兽人专用）：

```
虎鞭上有特殊肉刺，充血后变成饱满肉颗粒
系带旁的肉刺是绝对敏感点
刺激时浑身颤抖、流口水
```

**M属性表现**（特定角色）：

```
被羞辱时反而更兴奋
被抽打后精槽超标
求饶时带有快感
```

### 7.4 尸体美学标准

**必须出现的尸体元素**：

1. **姿势**：
    - 趴开双腿（最常用）
    - 跪姿（屈辱感）
    - 侧躺（曲线展示）
    - 挂在某处（栏杆/门/围栏）

2. **精液分布**：
    - 地上（汇聚成河/池）
    - 自己身上（肚皮/大腿/胸肌）
    - 其他尸体上
    - 袜子上（渗透/流淌）

3. **细节**：
    - 死不瞑目的眼神
    - 舌头外露（可选）
    - 四肢偶尔的抽搐
    - 下体仍保持勃起一段时间

## 八、情色描写规范

### 7.1 功能化原则

**情色描写必须服务于**：

1. 战斗机制（精槽累积）
2. 角色塑造（展示性格）
3. 权力关系（控制与服从）

**禁止**：

- 无意义的情色堆砌
- 与剧情脱节的H场景

### 7.2 器官称谓词库

**常用词汇**（根据语境选择）：

- 鸡巴/肉棒/屌/鞭（通用）
- 卵蛋/蛋蛋/睾丸（弱点）
- 龟头/冠状沟/系带（敏感点）
- 乳头/乳尖/葡萄（胸部）
- 菊花/后穴/直肠（后门）
- 精液/浓精/白浆/淫液（产物）

### 7.3 感官描写要点

**必须包含**：

- 视觉（颜色、形状、液体流动）
- 触觉（硬度、温度、湿润度）
- 听觉（呻吟、求饶、体液声）
- 嗅觉（汗味、精味、雄性气息）

## 八、世界观一致性检查清单

### 8.1 每章必须确认

- [ ] 所有伤害是否转化为精槽？
- [ ] 死亡是否伴随射精？
- [ ] 制服颜色与等级是否对应？
- [ ] 系统提示是否符合游戏逻辑？
- [ ] 主角是否保持第一人称视角？

### 8.2 常见错误避免

**不要**：

- 让角色在没有性刺激的情况下死亡
- 忽视精槽系统的存在
- 让杂兵有超出其等级的智商
- 过度描写主角外貌
- 忘记存档/读档机制的存在

## 九、仿写示例

### 示例1：杂兵遭遇战

**原文风格**：

```
我发动影袭，直接瞬移到熊守卫的身后，然后将一根银针扎入了他的脖颈。
被扎的熊守卫身子一颤，然后保持着站岗的姿势一动不动了。
另一名熊守卫看到我的出现，立刻警惕地吼道："你是什么人……唔！"
话还没说完，从他背后一只大手伸了出来，将他的嘴捂得严严实实！
```

### 示例2：处决场景

**原文风格**：

```
我握住了虎队长的肉棒，轻轻揉搓了两下，虎队长的肉棒就慢慢充血勃起。
还别说，这些肉刺看着奇怪，但一旦充血就会变成饱满的肉颗粒，撸起来变得更有层次感！
"嗯。。。哈。"在我握住虎队长的肉棒根部撸动时，他还能忍住不发出声音，
但在我撸到系带附近的肉刺时，虎队长没有忍住，发出了一声娇喘。
```

## 十、给新AI的核心指令

### 开场提示词模板

```
你需要以第一人称撰写一篇《兽游世界》风格的章节。

核心设定：
- 这是一个VR游戏世界，所有伤害转化为"精槽"（性欲值），满槽则射精死亡
- 主角是谨慎腹黑的刺客型玩家，选潜行系
- 兽人外表凶悍但弱点是卵蛋/乳头，被控制后会娇喘求饶
- 必须包含系统提示、存档机制、情色战斗描写

本章任务：[简要剧情]
敌人类型：[绿制服杂兵/蓝制服干部/黑制服武斗兵]
必须包含：[特定情节要求]

写作要求：
1. 第一人称口语化，像直播一样讲述
2. 战斗详细描写，包含精槽百分比变化
3. 处决必须包含射精死亡的完整过程
4. 适当插入吐槽和内心独白
5. 结尾留悬念
```

## 十一、自检问题

完成后问自己：

1. 主角是否有"这只是游戏"的元认知？
2. 情色描写是否服务于战斗机制？
3. 兽人的死亡是否有仪式感和美感？
4. 是否有至少一个让人记住的细节？
5. 结尾是否让读者想看下一章？
