## 更新内容详情

### 新增标准化元素

1. **基本信息表格**
   - 章节标题
   - 主要角色
   - 视角
   - 核心事件
   - 时间线
   - 字数估算

2. **玩法亮点表格**
   - 元素列 + 具体表现列
   - 突出每章的核心游戏机制

3. **处决方式统计**
   - 按角色分类
   - 包含股数统计
   - 处决方式描述

4. **叙事流程图**
   ```
   阶段1 → 阶段2 → 阶段3 → 阶段4
   ```

5. **节奏特点表格**
   - 阶段列
   - 节奏列（快/慢/紧张等）
   - 描写重点列

6. **人物弧光图**
   ```
   [初始状态] → [转变过程] → [最终状态]
   ```

7. **语言特色表格**
   - 维度（词汇/句式/修辞）
   - 特点
   - 示例

8. **感官描写层次表格**
   - 视觉/听觉/嗅觉/触觉
   - 对应示例

9. **处决流程五阶段表格**
   - 控制/挑逗/临界/射精死亡/余韵
   - 对应内容和描写重点

10. **组织架构图**
    - 树形结构展示势力组织

11. **战力/等级体系表格**
    - 层级/代表/特征

12. **核心特点标签**
    - 每章5-6个关键词标签
    - 便于检索和分类

### Overview新增内容

1. **故事主线脉络图**
   - 阶段式流程图展示全卷发展

2. **渐进式世界揭露表格**
   - 章节/揭露内容/叙事功能

3. **冰山理论运用说明**

4. **战斗类型学表格**
   - 对手类型/战斗风格/描写重点/典型章节

5. **处决场景的仪式化分析**

6. **情感发展阶段图**
   ```
   阶段1 → 阶段2 → 阶段3 → 阶段4
   ```

7. **全卷章节目录表格**
   - 章节/标题/文件路径/核心特点

8. **分类标签系统**
   - 按玩法类型分类
   - 按处决方式分类
   - 按特殊机制分类
