# SS-008: 守夜人 / The Night Watch

---

## 故事简介

偏僻的**兽盾仓库**里，一只**野猪兽人守卫**正在独自守夜。他以为这只是无数个无聊夜晚中的一个，却不知道死神已经披上了夜色的外衣，正悄悄向他走来。

这是一个关于平凡小人物悲剧命运的故事，展现了**兽盾**世界底层员工的生存困境，以及赏金猎人与猎物之间复杂的关系。
