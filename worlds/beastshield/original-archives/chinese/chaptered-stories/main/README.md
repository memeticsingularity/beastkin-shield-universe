## 世界观设定（主线核心）

### 主要组织

- **兽盾公司**：白之都势力最大的组织，从事走私军火、贩卖违禁品，研究血精石和嗜精兽
- **特工局**：对抗兽盾的秘密组织，成员多为十二神武传人
- **光照神教**：神秘宗教组织，与兽盾有千丝万缕的联系

### 职级体系

1. **普通员工/杂兵**：绿制服
2. **干部/组长**：蓝制服
3. **部长**：黑制服
4. **董事**：牙董、辉董、岚董等

### 核心设定

- **血精石**：红色水晶，植入体内后使人变异为"嗜精兽"
- **嗜精兽**：需要不停吞噬兽人精液才能存活的异类，高级嗜精兽可吸食血液
- **十二神武**：五百年前人兽大战中十二位勇士的武器，各有特殊妙用
- **五行封禁**：龙武神的绝技，号称天下最强防御
