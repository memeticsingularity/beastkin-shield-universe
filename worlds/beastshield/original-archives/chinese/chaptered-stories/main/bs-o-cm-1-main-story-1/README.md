## 2. 故事总览

一名兽圈爱好者获得了一款神秘的VR游戏《兽游世界》。在游戏中，所有攻击伤害都会转化为性欲值，当性欲值达到上限，角色便会"
喷射"死亡。玩家必须利用这一机制，在游戏中生存、成长，并逐步揭开兽盾公司的秘密。

本卷为整个故事的第一部分，共13章，从玩家进入游戏开始，经历了教程关卡、初探兽盾总部、遭遇特工局、最终解开体内血精石秘密的全过程。

## 4. 世界观设定（本卷提及部分）

### 4.1 主要组织

- **兽盾公司**：白之都势力最大的组织，几乎匹敌政府，从事走私军火、贩卖违禁品等活动
- **特工局**：对抗兽盾的秘密组织，有自己的秘密基地和成员
- **武道馆**：民间武术组织，熊馆长是其中一员

### 4.2 兽盾公司职级体系

1. **普通员工/杂兵**：绿制服
2. **干部**：蓝制服（主角升职后获得）
3. **武斗兵**：黑制服（虎队长所属）
4. **摔跤兵**：深蓝色连体摔跤服（地下格斗场培养）
5. **高级兵种**：包括摔跤兵、枪械兵（狙击手）等，制服颜色未统一提及

### 4.3 游戏机制

1. **精槽系统**：所有伤害转化为精槽值，精槽满则射精死亡
2. **属性系统**：战斗系、射击系、潜行系、英雄系四种成长方向
3. **技能系统**：包括涂毒、换装、影袭、银针封穴等
4. **随从系统**：可收服兽人作为随从，初始随从位只有一个
5. **赏金系统**：击杀兽盾员工可获得赏金，通过袜子编号兑换

### 4.4 特殊设定

1. **血精石**：红色水晶，植入体内后使人变异为"嗜精兽"
2. **嗜精兽**：需要不停吞噬兽人精液才能存活的异类
3. **流墟**：吸食精液的黑色粘液怪物，兽盾制造的生物武器
4. **青雉缚阳锁**：十二神武之一，可封印体内一切异常状态

## 5. 主要角色

### 5.1 玩家相关

- **玩家**：游戏主角，从普通兽圈爱好者逐步成长为特工局成员
- **牛杂**：玩家在兽盾的下属，牛兽人，M体质，有诈死技能
- **熊掌**：玩家在兽盾的下属，熊兽人，憨厚老实，会金钟罩

### 5.2 兽盾公司

- **牙董**：兽盾董事长，白发狼兽人，神秘而强大
- **虎队长**：武斗部队队长，黑制服虎兽人，实力强悍
- **各种员工**：包括绿制服杂兵、蓝制服干部、黑制服武斗兵等

### 5.3 特工局

- **总司令**：德牧兽人，特工局领导者
- **银**：灰毛狼兽人，刺客系，擅长银针封穴
- **熊猫**：中年熊猫兽人，实力深不可测
- **熊馆长**：武道馆馆长，正直的白熊兽人，后加入特工局
