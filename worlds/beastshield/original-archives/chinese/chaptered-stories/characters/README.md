## 三、角色文件命名规范

- 使用 **中文拼音（小写，连字符连接）** 命名，如 `niu-za.md`
- 英文代号或绰号使用原始英文小写，如 `shadow-demon.md`
- 群体文件使用群体描述，如 `green-uniform-soldiers.md`
- 每个角色文件包含：基础信息、外貌特征、能力设定、出场章节、结局
