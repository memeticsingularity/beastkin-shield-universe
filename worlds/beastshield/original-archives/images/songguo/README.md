## 附录：作者补充设定

### 兽盾保镖的背景设定

**作者原话（lanse : 03-31 09:16）：**
> 兽盾保镖是有生命危险的工作
> 几乎招待都是孤儿或弃婴
> 所以大部分没有学历

**设定提炼：**

- **工作性质**：兽盾保镖是高度危险的职业，从业者面临生命危险
- **人员来源**：兽盾公司的员工几乎都是孤儿或弃婴出身
- **教育背景**：由于出身背景，大部分兽盾保镖没有接受过正规教育，缺乏学历
- **关联角色**：这解释了为什么松果（幼年翻垃圾桶、没有父亲）和大鲁（不知道学历是什么）都没有学历，也暗示了他们作为孤儿/弃婴进入兽盾公司的经历
