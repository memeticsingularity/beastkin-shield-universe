## 重要说明

### 关于文件命名日期

**文件名中的日期（如20260122、20260202等）是作者创作图片的时间，不代表故事内的时间顺序。**

- 文件名日期 = 作者画图时间
- 章节标题（如"领养中心篇"、"新家日常篇"） = 故事内容提示
- 故事内实际时间顺序需根据场景内容判断

**示例**：`20260309-初遇篇（倒叙）`表示这张图虽然是3月9日创作的，但在故事中是回忆/倒叙场景。

## 附录：角色设定总结

### 松果（Songguo）

**基本信息：**
- **种族**：棕黄色犬类兽人（类似德国牧羊犬）
- **体型**：极其健壮，肌肉发达
- **毛发**：棕黄色主体，胸部和面部深色毛发

**外观特征：**
- **身材**：胸肌饱满，腹肌隐约，手臂粗壮，大腿肌肉发达
- **面部**：棕黑色鼻子，棕色眼睛，表情丰富（害羞、开心、惊恐等）
- **耳朵**：直立，反应情绪（耷拉表示害怕/失落）
- **尾巴**：毛茸茸，翘起表示开心，夹紧表示害怕

**服装标准：**
- **制服**：军绿色短袖紧身衣+短裤，金色/黄色线条装饰
- **配饰**：黑色无指手套，黑色腰带
- **袜子**：白色长筒袜，绿色条纹
- **鞋子**：绿色运动鞋/靴子

**特殊设定：**
- **义肢**：右腿缺失，装有金属拐杖/义肢
- **身份**：兽盾公司退役战损员工
- **性格**：忠诚、害羞、认真、偶尔嘴硬（怕鬼）
