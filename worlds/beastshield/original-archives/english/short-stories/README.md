## III. Reading Advice & Content Warnings / 阅读建议与分级说明

- **R18**: All stories contain adult content, including but not limited to:
    - Violence, strangulation, asphyxiation, torture
    - Sexual content, sexual violence, non-consensual acts
    - Death, corpse handling, moral dilemmas
- **Intended Audience / 建议读者**: Suitable only for readers aged 18 and above, who are prepared for dark themes and adult content.
- **Reading Order / 阅读顺序**: Each story is independent and can be read in any order. However, reading in numerical order provides gradual immersion into the universe.
