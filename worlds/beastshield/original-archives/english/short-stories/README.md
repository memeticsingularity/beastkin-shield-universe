# Short Stories Collection / 短篇故事集

## ⚠️ Reading Advice & Content Warnings

- **R18**: All stories contain adult content, including but not limited to:
    - Violence, strangulation, asphyxiation, torture
    - Sexual content, sexual violence, non-consensual acts
    - Death, corpse handling, moral dilemmas
- **Intended Audience**: Suitable only for readers aged 18 and above, who are prepared for dark
  themes and adult content.
- **Reading Order**: Each story is independent and can be read in any order. However, reading in
  numerical order provides gradual immersion into the universe.
