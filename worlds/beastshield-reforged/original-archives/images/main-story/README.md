## 📁 文件命名规范 / File Naming Rules

所有配图文件均遵循以下命名格式：
All illustration files follow this naming convention:
bsr_chXXX_序号_关键词.扩展名
bsr_chXXX_sequence_keyword.extension

- **`bsr`**: 项目标识 (Beast Shield: Reforged)
- **`chXXX`**: 三位数章节编号 (如 `ch001`, `ch015`)
- **`序号` / `sequence`**: 同一章节内的图片顺序号 (如 `1`, `2`)
- **`关键词` / `keyword`**: 描述图片核心内容的英文关键词
- **`.扩展名` / `.extension`**: 图片文件格式 (如 `.png`, `.png`, `.webp`)
