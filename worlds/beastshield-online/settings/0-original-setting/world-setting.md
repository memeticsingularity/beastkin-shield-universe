# 兽游世界OL 世界观设定集（基于前三章）

> 基于《兽游世界OL》第一卷前三章原文整理
> 涵盖游戏机制、世界规则、势力组织、角色档案

---

## 一、世界概述

### 1.1 基本设定

- **游戏名称**：《兽游世界OL》网络版
- **开发商**：兽盾游戏公司
- **世界类型**：VR 网络游戏世界
- **主题**：R18 黄游 + 魂类动作冒险 + 生存竞争
- **核心机制**：所有伤害转化为精槽（性欲值），达到 100% 即射精死亡

### 1.2 进入方式

- **硬件设备**：VR 眼镜头套 + 高精度触摸内壁飞机杯
- **联动要求**：两个装置必须同时佩戴才能进入游戏
- **尺寸定制**：根据玩家填写的牛子尺寸定制设备（S码 / M码 / L码 / XL码）

### 1.3 内测规则

| 项目 | 说明 |
|------|------|
| 内测人数 | 一千名玩家 |
| 资格获取 | 抽奖抽取（免费资格无法选择出生条件） |
| 付费资格 | 可选择出生条件（推测） |
| 死亡惩罚 | 角色死亡即游戏结束，取消内测资格 |
| 通关奖励 | 一千万人民币现金，通关玩家平分（未对外公示） |
| 挑战次数 | 每位玩家只有一次机会 |

## 二、核心机制

### 2.1 精槽系统

- **替代血条**：无传统血条，取而代之的是灰色空槽——精槽
- **伤害转化**：所有攻击/受伤不扣血，而是增长精槽值
- **死亡条件**：精槽达到 100% 后立刻射精并死亡
- **射精表现**：身体绷直，精液喷涌，精槽清空后停止呼吸
- **击杀方式**：传统搏斗击杀 或 通过各种手段让对方射精致死

### 2.2 战斗系统

- **战斗类型**：魂类动作游戏（非回合制）
- **体力设定**：存在但无数值展示，无意义动作会浪费体力
- **翻滚机制**：不是无敌的
- **敌人信息**：仅显示精槽，无等级/蓝条等额外信息
- **暴击系统（暴鸡）**：攻击敏感部位（如下体）可造成巨额精槽增长
- **处决机制**：敌人精槽越高反抗能力越低，达到一定值后完全失去反抗能力，玩家可自由处决

### 2.3 成长系统

- **无明确等级**：无传统等级数值展示
- **属性感受**：人物成长靠实际身体感受（如击杀后感觉胳膊变粗有力）
- **装备属性**：可观测（护甲值、攻击力等）
- **身材成长**：随游戏进程自然改变（战士变壮，法师变瘦）

### 2.4 技能系统

- **学习方式**：动手实践领悟，非升级加点
- **已知技能**：厨艺精通（生火烤制食物后领悟）

### 2.5 装备系统

- **物品栏**：只有负重上限，无格数限制
- **自动适配**：不合身的装备穿上瞬间变得贴身
- **属性加成**：护甲值、攻击力等可直接观测
- **掉落来源**：击杀敌人后搜刮

### 2.6 货币系统

- **货币名称**：撸币
- **外观**：银白色

## 三、角色创建

### 3.1 创建规则

- **物种外观**：可自行选择调整
- **身材比例**：只能使用默认值
- **身材成长**：随游戏内行为改变（力量型变壮，魔力型变瘦）
- **取名**：无需取名，创建后直接登录

### 3.2 背景分配

- **付费资格**：可选择出生条件与背景
- **免费资格**：系统随机分配出生点与背景故事

### 3.3 已知初始背景

| 背景 | 描述 |
|------|------|
| 流浪弃兽 | 自幼被父母抛弃，靠乞讨和偷盗度日，身无分文，衣不蔽体 |

## 四、势力与组织

### 4.1 兽盾游戏公司

- **身份**：游戏开发商
- **行为**：内测资格区别对待（免费 vs 付费）
- **未公示内容**：一千万现金奖励仅登录玩家可见

### 4.2 山贼组织

- **结构**：寨主（大王）→ 先锋（队长）→ 普通山贼
- **据点**：山寨（有大厅、宝座等）
- **行为**：伏击路人、俘虏活口、招降或处决
- **战斗风格**：混战、伏击、压倒性数量优势

### 4.3 村庄社会

- **规模**：小型村落（十几户）
- **设施**：农田、民居、临时征兵处
- **商业**：无正式商店，以物易物或简单交易
- **社会规则**：
  - 同兽种忌讳：不吃与自己同兽种的肉
  - 农民对偷窃极度敏感

## 五、角色档案

### 5.1 玩家角色（主角）

- **种族**：黄毛狗兽人（玩家自选）
- **背景**：流浪弃兽
- **初始状态**：骨瘦嶙峋，一条破短裤，身无分文
- **身份**：内测玩家（免费资格）
- **已知技能**：厨艺精通一级

### 5.2 野猪兽人

- **身份**：新手教程怪 / 拦路山贼
- **外观**：膀大腰圆，肚皮圆滚，身披破兽皮，脚着粗皮革长靴
- **武器**：木柄铁锈斧
- **战斗特点**：动作缓慢，前摇明显
- **性格**：粗俗嚣张，求饶时喊"好汉饶命"
- **掉落**：兽皮衣裤、靴子、铁斧、3枚撸币

### 5.3 白白（白狼兽人）

- **外观**：年轻，白袍破烂，雪白毛发污浊，骨瘦嶙峋
- **身份**：狼风谷逃难者 / NPC骗子
- **骗术**：以介绍入伍为名骗取中介费，实际将人卖为志愿兵

### 5.4 牛先锋

- **种族**：牛兽人
- **身份**：山贼领队 / 精英怪
- **外观**：胸肌饱满，臀部圆润，体型粗而不肥
- **战斗特点**：赤手空拳，机关拳（可打出十三连击）
- **性格**：受用马屁，忠诚（对寨主）
- **命运**：被虎大王亲手处决

### 5.5 虎大王

- **种族**：红虎兽人
- **身份**：山贼寨主 / **玩家**
- **外观**：身材魁梧，比牛先锋更壮
- **玩家类型**：休息养成系，只想经营寨子
- **玩家身份识别**：对暗号（歌词）确认
- **暗号**："苍茫的天涯是我的爱" / "绵绵的青山脚下花正开"
- **性格**：初见热情豪爽，意识到竞争关系后立刻翻脸灭口
- **性取向**：对男性有明显性反应
- **处决方式**：性刺激（手指插入后穴 + 胸沟摩擦 + 窒息）

- **解毒**：石楠花汁液

## 七、游戏规则

### 7.1 玩家间关系

- **竞争关系**：通关奖励有限，玩家之间可能互相袭击
- **合作关系**：通关条件困难时可能需要协力
- **身份隐藏**：不要暴露玩家身份是生存关键
- **身份识别**：仅凭观察无法分辨玩家与NPC，需对暗号确认

### 7.2 死亡与尸体

- **死亡表现**：射精后身体绷直，四肢摊开，停止呼吸
- **尸体处理**：可被扛走"处理"（暗示后续性行为）
- **处决状态**：被打出处决状态后身体无法动弹，任人处置

### 7.3 社会交互

- **偷窃**：NPC 对偷窃行为有强烈反应
- **语言忌讳**：向兽人讨要同兽种肉食是极度不礼貌的行为
- **任务触发**：无明确引导，需自由探索触发
