# 设定资料总览

> 《兽游世界OL》续写项目 —— 所有设定资料的入口。

---

## 子目录索引

| 目录 | 内容 | README |
|------|------|--------|
| **characters/** | 角色档案（玩家、NPC、平民、生物） | [characters/README.md](./characters/README.md) |
| **scenes/** | 场景/地点档案（山坡、村庄、山寨等） | [scenes/README.md](./scenes/README.md) |
| **systems/** | 游戏机制档案（精槽、战斗、技能、货币等） | [systems/README.md](./systems/README.md) |
| **author-chat/** | 作者创作对话（预留） | — |
| **levels/** | 关卡/副本设计（预留） | — |

---

## 快速定位

- **想找某个角色** → 先看 [characters/README.md](./characters/README.md) 的表格，按编号进子目录
- **想找某个地点** → 先看 [scenes/README.md](./scenes/README.md) 的表格
- **想了解游戏机制** → 先看 [systems/README.md](./systems/README.md) 的表格
- **想新建角色档案** → 复制 `characters/_TEMPLATE.md`，按命名规范重命名

---

## 命名规范

- **角色**：`XXX-名字拼音.md`（3位编号 + 名字拼音）
- **场景**：`场景英文名.md`（小写，连字符）
- **系统**：`系统英文名.md`（小写，连字符）

---

*说明：所有设定档案统一采用【原作】+【补完】双标签标注来源。*
