# 玩家状态/存档模板 v1.0

> 《兽游世界OL》独有的存档记录模板。> 用于记录角色在特定时间点的完整游戏状态，将游戏 UI 元素自然融入叙事。>
> 使用方式：复制本文件，重命名为 `save-XXX-角色名-时间点.md`。

---

## SAVE-XXXXXX

| 项目 | 内容 |
|------|------|
| **存档编号** | 【SAVE + 6位数字。例：SAVE-000001】 |
| **记录时间** | 【游戏内时间 / 现实时间】 |
| **角色** | 【角色名】 |
| **当前位置** | 【坐标 / 场景名】 |

### 1.2 身材成长记录

> 无等级制，成长靠身体感受记录。

| 部位 | 当前状态 | 变化感受 |
|------|---------|---------|
| **上肢** | 【例：比创建时粗了一圈】 | 【例：击杀野猪后感觉胳膊变粗有力】 |
| **下肢** | 【例：无明显变化】 | 【例：长途行军后腿脚更稳健了】 |
| **躯干** | 【例：精瘦，肋骨隐约可见】 | 【例：流浪弃兽背景，营养不良】 |
