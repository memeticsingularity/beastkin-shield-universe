## 二、系统概述

### 2.1 核心规则 【原作】

游戏无传统等级数值展示。人物成长靠实际身体感受（如[主角](../characters/01-players/001-protagonist.md)击杀野猪后"感觉胳膊变粗有力"）。技能通过动手实践领悟，非升级加点。身材随游戏进程自然改变（战士变壮，法师变瘦）。

### 2.2 玩家体验 【原作+补完】

玩家永远看不到"LV.5"或"力量+10"这样的数字。取而代之的是模糊但真实的身体感知——击杀敌人后，你能"感觉胳膊变粗有力"；反复烹饪后，系统提示"领悟了厨艺一级"。这种成长方式让进步变得难以量化，增加了不确定性和探索感。玩家必须通过实际表现（能否举起更重的武器、能否跑得更快）来判断自己的成长，而不是盯着数值面板。身材也会随着游戏风格自然演变，让每个角色的外形都成为其游戏历程的见证。

## 三、详细机制

### 3.1 规则拆解 【原作+补完】

| 规则项 | 说明 | 来源 |
|--------|------|------|
| 无等级制 | 没有LV.1、LV.2这样的数值展示 | 原作+补完 |
| 身体感知成长 | 力量增长体现为"感觉胳膊变粗"，而非数值增加 | 原作 ch-01 |
| 技能领悟 | 通过实践自然学会，如生火烤制食物后领悟"厨艺精通" | 原作 ch-03 |
| 身材演变 | 根据游戏行为自然改变体型（战斗型变壮硕，魔法型变瘦削） | 原作+补完 |
| 装备属性 | 可观测具体数值（护甲值、攻击力等） | 原作+补完 |
| 技能等级 | 存在等级区分（如"厨艺一级"） | 原作 ch-03 |

### 3.2 数值设计（推测）【补完】

> 《兽游世界OL》原作未展示具体数值，以下为合理推测，供续写时保持内部一致性。

| 参数 | 估算值 | 说明 |
|------|--------|------|
| 技能等级 | 1-10级（推测） | 如"厨艺一级"之上可能有二级、三级 |
| 领悟阈值 | 视技能复杂度 | 简单技能1-3次实践，复杂技能数十次 |
| 成长感知间隔 | 每击杀5-10个敌人 | 感受到一次明显的身体变化 |
| 身材演变周期 | 数天至数周（游戏时间） | 根据行为频率自然改变 |
| 技能上限 | 推测存在，但可能因角色而异 | 某些角色可能有天赋加成 |

### 3.3 UI 表现 【原作+补完】

- **显示位置**：推测无固定等级面板；技能可能在菜单中以文字形式列出
- **显示形式**：无数字等级；技能显示为"厨艺一级""机关拳"等描述性文字
- **特殊提示**：领悟新技能时可能有系统提示；身体成长通过VR设备的肌肉反馈模拟
- **VR设备联动**："感觉胳膊变粗"通过设备的触觉/压力反馈让玩家真实感受到
- **身材可视化**：角色模型随游戏进程逐渐改变体型，玩家可在镜子或水面倒影中观察

## 四、与原作的联系

### 4.1 原作中明确描写 【原作】

#### 第一章：击杀后的成长感 【原作】
> 主角击杀野猪后，"感觉胳膊变粗有力"（大意）
- 击杀敌人后，身体能直接感受到力量的增长

#### 第三章：厨艺技能 【原作】
> "目前只学会了厨艺一级"
- 技能名：厨艺精通（或"厨艺"）
- 等级：一级
- 习得方式：通过生火烤制食物等实践领悟

#### 第三章：[牛先锋](../characters/02-hostile/003-niu-xianfeng.md)的机关拳 【原作】
> "[牛先锋](../characters/02-hostile/003-niu-xianfeng.md)这套机关拳打得真是漂亮呀！"
- 机关拳：连续组合拳，可打出十三连击
- 属于高阶战斗技能，需要长期修炼

### 4.2 与 beastshield 原作的关联（如适用）

- beastshield 原作中的角色同样没有明确的"等级"概念，实力通过战斗表现和身份地位体现。
- 十二兽部队成员（如虚逸）的战斗力来源于长期训练和特殊能力，而非数值升级。
- 差异：beastshield-online 将这种"无等级成长"游戏化，通过VR设备让玩家"感受"到成长。

## 五、补完设定

### 5.1 推断规则

1. **技能类型**：
   - 生活技能：厨艺、crafting、采集等
   - 战斗技能：机关拳、射术、伏击等
   - 被动技能：可能包括精槽抗性、体力恢复等

2. **领悟条件**：
   - 需要反复实践（如多次烹饪才能提升厨艺）
   - 可能在特定情境下顿悟（如生死关头领悟新招式）
   - observing 他人使用技能可能加速领悟

3. **身材成长方向**：
   - 力量型（频繁近战）：肌肉变壮硕，体重增加
   - 敏捷型（频繁闪避/远程）：体型变精瘦，反应变快
   - 魔力型（如有魔法）：可能变瘦削，或有其他外在表现

4. **技能上限**：
   - 是否存在技能等级上限？
   - 一级厨艺之上还有二级、三级吗？

### 5.2 续写扩展建议

- **技能组合**：生活技能与战斗技能的联动（如"厨艺"提升后制作的料理有战斗增益）
- **隐藏技能**：某些技能需要特殊条件才能领悟（如"性技"可能通过特定互动学会）
- **技能传授**：玩家之间是否可以互相传授技能？
- **精槽管理技能树**：新增"精槽管理"技能树，让玩家可以主动控制精槽增长速度
- **身材专精**：极端化身材可能解锁特殊技能（如极壮体型解锁"碾压攻击"）
- **技能遗忘**：是否可以选择遗忘旧技能以学习新技能？
- **师徒系统**：高技能玩家可以收徒，加速徒弟的领悟过程

### 5.3 与其他系统的联动

| 联动系统 | 联动方式 | 示例 |
|---------|---------|------|
| [战斗系统](./combat-system.md) | 技能直接决定战斗能力 | 机关拳=高阶连击技能 |
| [VR设备系统](./vr-device.md) | 身体感知成长通过设备强化 | "感觉胳膊变粗"=设备肌肉反馈 |
| [精槽系统](./essence-gauge.md) | 被动技能可能影响精槽 | "精槽抗性"降低增长速度 |
| [存档系统](./save-system.md) | 技能成长是存档的核心价值 | 死亡删号=所有技能清零 |
| [货币系统](./currency.md) | 某些技能可能需要付费学习 | 向NPC购买技能书？ |

## 六、对剧情的影响

### 6.1 已产生的影响 【原作】

- [主角](../characters/01-players/001-protagonist.md)因"厨艺一级"被[虎大王](../characters/01-players/002-hu-lie.md)留下性命，说明生活技能在这个世界里同样有战略价值
- [牛先锋](../characters/02-hostile/003-niu-xianfeng.md)的"机关拳"展示了高阶战斗技能的威力

### 6.2 潜在影响 【补完】

- **成长焦虑**：无等级制让玩家难以量化自己的成长进度
- **技能经济学**：稀有技能可能成为交易或竞争的焦点
- **角色定位**：根据技能组合，玩家可能自然分化为战士、工匠、商人等角色
- **技能垄断**：某些玩家或势力可能垄断稀有技能的传授途径
- **技能与身份**：高阶技能持有者在游戏社会中可能拥有更高地位
