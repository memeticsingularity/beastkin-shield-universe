## 二、系统概述

### 2.1 核心规则 【原作】

战斗采用魂类动作游戏机制（非回合制）。存在体力设定但无数值展示，翻滚不是无敌的。敌人仅显示[精槽系统](./essence-gauge.md)，无等级和蓝条。攻击敏感部位（"暴鸡"）可造成巨额精槽增长。敌人精槽越高反抗能力越低，达到一定值后进入处决状态，玩家可自由处决。

### 2.2 玩家体验 【原作+补完】

玩家体验到的是紧张刺激的实时动作战斗，每一次挥砍、每一次翻滚都关乎生死。但与传统魂类游戏不同的是，"血条"变成了"[精槽系统](./essence-gauge.md)"——敌人的抵抗能力以性兴奋程度衡量。当玩家攻击敌人下体（暴鸡）时，不仅造成大量"伤害"，还能通过[VR设备系统](./vr-device.md)感受到一种诡异的反馈。敌人进入处决状态后，玩家可以选择直接击杀，也可以进行性处决——后者往往更残忍，也更具有羞辱性。战斗的终点不是尸体的冰冷，而是精液喷涌的温热。

## 三、详细机制

### 3.1 规则拆解 【原作+补完】

| 规则项 | 说明 | 来源 |
|--------|------|------|
| 战斗类型 | 实时动作，强调操作和时机，非回合制 | 原作+补完 |
| 体力管理 | 存在体力条但无数值显示，无意义动作会浪费体力 | 原作+补完 |
| 翻滚机制 | 有规避作用，但非无敌帧，时机不当仍会受伤 | 原作+补完 |
| 敌人信息 | 极简UI，仅显示精槽百分比，无等级和蓝条 | 原作+补完 |
| 敏感部位攻击（暴鸡） | 攻击下体等敏感部位可造成巨额精槽增长 | 原作 ch-03 |
| 处决机制 | 敌人精槽达到高值后失去反抗能力，玩家可自由处决 | 原作 ch-03 |
| 连击系统 | 连续命中可触发连击计数（如牛先锋的十三连击） | 原作 ch-03 |
| 偷袭机制 | 从背后接近可发动偷袭，但可能被反制 | 原作 ch-03 |
| 武器与空手 | 武器提供攻击力加成但可能被击落；空手战斗同样强力 | 原作 ch-03 |

### 3.2 数值设计（推测）【补完】

> 《兽游世界OL》原作未展示具体数值，以下为合理推测，供续写时保持内部一致性。

| 参数 | 估算值 | 说明 |
|------|--------|------|
| 普通攻击精槽增长 | 1%-5%/击 | 取决于武器和攻击力 |
| 暴鸡（敏感部位攻击） | 20%-50%/击 | 攻击下体等敏感部位 |
| 处决状态阈值 | 70%-90% | 进入后无法反抗，任人处置 |
| 连击加成 | 每连击+5%-10% | 连续命中触发 |
| 体力恢复速度 | 推测2%-5%/秒 | 停止动作后恢复 |
| 翻滚体力消耗 | 推测15%-20% | 乱滚会快速耗尽体力 |
| 致命伤（斩首/穿脑） | 瞬间100%精槽 | 直接死亡 |

### 3.3 UI 表现 【原作+补完】

- **显示位置**：敌人头顶或附近显示精槽；玩家自身精槽在屏幕左下角
- **显示形式**：敌人仅显示灰色精槽条，无等级、无蓝条、无具体数值
- **特殊提示**：连击时可能弹出系统提示（如"【十三连击！】"）；进入处决状态时敌人身体可能发光或出现交互提示
- **VR设备联动**：被击中时设备反馈打击感；暴鸡时飞机杯同步刺激；处决时根据处决类型给予不同反馈
- **精彩瞬间**：系统可能自动捕捉并提示连击/处决的精彩瞬间

### 4.2 与 beastshield 原作的关联（如适用）

- 战斗系统中的"处决"概念与 beastshield 原作中的暴力美学一脉相承。
- beastshield 原作中十二兽部队的战斗风格（如卯兽的精准杀戮）可视为本作高阶战斗技能的灵感来源。
- 差异：beastshield 侧是真实的生死搏杀，beastshield-online 侧是游戏化的"精槽战斗"，但VR设备让后者同样具有真实感。

## 五、补完设定

### 5.1 推断规则

1. **连击系统**：
   - 连续命中可触发连击计数（如牛先锋的十三连击）
   - 连击可能伴随精槽增长加成

2. **处决状态的阈值**：
   - 精槽达到约70%-90%时进入处决状态
   - 处决状态下角色无法动弹，但仍有意识
   - 处决方式多样：可直接击杀，也可进行性处决

3. **偷袭机制**：
   - 从背后接近可发动偷袭
   - 偷袭可能被反制（如主角偷袭牛先锋失败）

4. **武器与空手**：
   - 武器提供攻击力加成但可能被击落
   - 空手战斗（如牛先锋的机关拳）同样强力

5. **暴击（暴鸡）机制**：
   - 攻击下体等敏感部位 = 巨额精槽增长
   - 但风险也高（需要接近目标下盘）

### 5.2 续写扩展建议

- **更多处决动画**：不同武器、不同体位、不同环境下的处决方式
- **组合技**：多名玩家/NPC配合的连击或处决
- **防御与反击**：是否存在格挡、弹反等高级技巧？
- **战斗流派分化**：可能出现"暴鸡流""窒息流""机关拳流"等不同战斗流派
- **环境互动**：利用地形（悬崖、陷阱、火焰）进行处决
- **PVP竞技场**：玩家之间的正式对决场地
- **处决技能树**：专精处决方式的技能分支

### 5.3 与其他系统的联动

| 联动系统 | 联动方式 | 示例 |
|---------|---------|------|
| [精槽系统](./essence-gauge.md) | 精槽增长决定战斗胜负 | 攻击下体=暴鸡=巨额精槽增长 |
| [VR设备系统](./vr-device.md) | 战斗中的打击感和暴鸡反馈通过设备传递 | 被击中下体时飞机杯同步刺激 |
| [技能成长系统](./skill-growth.md) | 技能影响战斗方式和效率 | 机关拳=高阶连击技能 |
| [存档系统](./save-system.md) | 死亡即删号，战斗失误代价极高 | 被处决=游戏结束 |
| [货币系统](./currency.md) | 击杀后搜刮掉落 | 击杀野猪获得3枚撸币 |

## 六、对剧情的影响

### 6.1 已产生的影响 【原作】

- [主角](../characters/01-players/001-protagonist.md)的首胜（野猪）展示了基础战斗逻辑
- [主角](../characters/01-players/001-protagonist.md)被[牛先锋](../characters/02-hostile/003-niu-xianfeng.md)秒杀展示了"挑错对手"的代价
- [牛先锋](../characters/02-hostile/003-niu-xianfeng.md)被[虎大王](../characters/01-players/002-hu-lie.md)处决展示了性处决的残酷美学

### 6.2 潜在影响 【补完】

- **PVP战斗**：玩家之间的战斗会如何利用处决机制？
- **羞辱机制**：性处决是否具有"羞辱"属性，影响阵营关系？
- **战斗流派**：可能出现"暴鸡流""窒息流""机关拳流"等不同战斗流派
- **道德选择**：玩家是否会选择"仁慈击杀"（直接致命）而非性处决？
- **处决的社交后果**：被公开处决的玩家是否会在游戏社区中失去地位？
