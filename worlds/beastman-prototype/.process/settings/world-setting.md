# 兽人原型世界设定集 / Beastman-Prototype World Setting

> **世界编码**: `beastman-prototype` | **作者**: lanse（笑天神犬）
> **定位**: lanse 创作生涯中最早的兽人世界观原型，后演变为兽盾（Beastshield）世界观

---

## 一、世界概述

### 1.1 基本设定

- **世界名称**：兽人原型世界 / Beastman-Prototype World
- **类型**：原生兽人世界（非 VR 游戏）
- **核心机制**：兽人拥有极强再生能力，生殖器为唯一弱点，强制射精即死
- **主题**：复仇动作 + 兽人世界观

### 1.2 核心规则

1. **再生能力**：兽人身体具有极强的再生能力，伤口可快速愈合。再生速度与个体天赋成正比[^ch3]
2. **百毒不侵**：兽人对所有毒物免疫（但击晕和迷晕是可行的）[^ch1]
3. **生殖器弱点**：兽人生殖器极其敏感，一旦被握住便会浑身无力、失去反抗能力[^ch1]
4. **唯一击杀方式**：**强制**使其射精（划重点：强制），射精即死亡[^ch1]
5. **一对一传统**：兽人之间的战斗永远是一对一，若其他人插手，便是玷污了荣誉[^ch1]

### 1.3 射精死亡例外机制

1. **真爱豁免**：若做爱的双方是真心相爱的情侣，兽人在心甘情愿的情况下射精不会有生命危险。这是兽人交配繁衍的唯一方法[^ch3]
2. **憋精法**：通过特殊技巧可在射精边缘强行憋回，用于诈死或延缓高潮。需要天赋和训练[^ch6]

### 1.4 特殊物品

1. **精金**：世界中最坚硬的金属之一，无法被锻造、无法被熔解，只有专门的钥匙才能打开其制成的锁具[^ch6]
2. **精金手铐**：用于囚禁兽人角斗士，无法被蛮力破坏[^ch6]
3. **窃听器**：人类发明的监听装置，可用于追踪目标[^ch7]
4. **H 毒气**：一种代号为 H 的气体，兽人吸入后会浑身燥热、强制高潮而亡，即使自慰也难逃一死[^ch7]
5. **雏龙坐标**：记载幼龙位置的神秘坐标，白虎以此作为协助警长的条件[^ch7]

## 二、势力组织

### 2.1 黄坡山寨

**定位**：山贼聚落，以寨主为首的山匪团伙

| 角色 | 种族 | 身份 | 结局 |
|------|------|------|------|
| 红虎寨主 | 红毛虎兽人 | 寨主，杀白虎之父的凶手 | 被白虎击杀（第三章） |
| 牛护卫 | 牛兽人 | 护卫长，身材异常粗壮 | 被白虎击杀（第二章） |

- 山寨位于银斧城附近的黄坡山上
- 寨主受银斧竞技场场主奔雷委托，杀害白岩

### 2.2 银斧竞技场

**定位**：银斧城最大的角斗竞技场，由奔雷经营

- **场主**：奔雷（棕发狮子兽人），银斧城最具权势的人物之一
- **业务**：正统赛（十轮擂主制）、野性赛（不死不休，一轮定胜负）
- **地下角斗士牢房**：关押奔雷抓捕的兽人，强迫训练为角斗士
- **野性赛**：每周一次的不死不休比赛，观众众多，以残忍著称

#### 奔雷的实力背景

奔雷年轻时曾误入魔兽洞穴，被触手怪抓住三天三夜。触手怪每次将他玩弄到接近高潮便放开，欣赏他自慰。奔雷逃出后练就了诡异的闪躲身法，凭借此从竞技场底层一路连胜，最终成为竞技场主人[^ch7]。

### 2.3 银斧城市警署

**定位**：银斧城的执法机构，但受限于上层腐败无法正常执法

| 角色 | 种族 | 身份 |
|------|------|------|
| 德牧警长 | 德国牧羊犬兽人 | 警长，试图扳倒局长 |
| 局长 | 不明 | 与奔雷勾结，私设 H 毒气工坊 |

- 警局总局长与奔雷有密切勾当，导致德牧警长无法正常执法
- 德牧警长一直在暗中寻找机会除掉奔雷和扳倒局长

### 2.4 狐狸委托店

**定位**：银斧城的地下委托中介，处理见不得光的行当

- **店主**：矮小的狐狸兽人
- **服务**：暗杀委托、灰色业务
- **原则**：不要多问

- 位于银斧城附近的山脉
- 山上有兽人山寨（黄坡山寨）

## 四、种族与生理

### 4.1 已知物种族

| 种族 | 特点 |
|------|------|
| 虎兽人 | 战斗技巧丰富，白虎种罕见。天生资质与再生速度成正比 |
| 牛兽人 | 体型粗壮，储精量大，耐力惊人 |
| 狮子兽人 | 体型矫健，身法灵活，领导者气质 |
| 狼兽人 | 敏捷型 |
| 熊兽人 | 体型庞大，力量惊人 |
| 豹兽人 | 敏捷矫健，肌肉线条明显 |
| 野猪兽人 | 体型高大壮硕 |
| 狐狸兽人 | 体型矮小，精明狡诈 |
| 老鼠兽人 | 个头矮小 |

### 4.2 生理特征

1. **再生能力**：兽人受伤后可快速愈合，愈合速度与天赋成正比[^ch3]
2. **生殖器敏感**：生殖器为最大弱点，被握持即失去反抗力[^ch1]
3. **射精即死**：强制射精是唯一击杀兽人的方式[^ch1]
4. **天赋差异**：天生资质决定再生速度和实力上限，可通过修行提升
5. **体液疗伤**：兽人的唾液等体液可促进伤口愈合。先将唾液涂在伤口上，再配合按摩帮助吸收，可加速恢复。有天赋的兽人效果更好[^ch6]
6. **不死之身**：白虎拥有特殊体质，强制射精后不会死亡（原因不明，可能与其出身有关）[^ch3]

### 4.3 取名习俗

兽人孩子的名字规则：从生父和另一位父亲的名字中各取一字。
例如：鹏勇 + 雄风 = 鹏小雄（鹏鹏）[^ch6]

## 五、重要角色

### 5.1 白虎

- **种族**：白虎兽人（人类与兽人的混血）
- **身份**：复仇者 → 赏金猎人（最终章）
- **特点**：
  - 罕见的白虎种
  - 拥有不死之身（强制射精后不会死亡）
  - 身手不凡，精通暗杀技巧
  - 外表冷酷但内心重情义
- **师父**：白岩（养父，实际无血缘关系）
- **背景**：被白岩抚养长大，以为白岩是生父。实际上白岩无生育能力，白虎是白岩的爱人归玲与人类所生。白虎实为半人半兽的混血[^ch5]
- **特殊能力**：不死体质，原因不明

### 5.2 白岩

- **种族**：白虎兽人（推测）
- **身份**：白虎的师父/养父
- **背景**：曾在银斧城的兽人药店工作，药店主人为归玲
- **结局**：被黄坡山寨寨主杀害
- **真实关系**：无生育能力，非白虎生父。归玲的伴侣，因归玲怀了人类的孩子而承担起抚养责任[^ch5]

### 5.3 归玲

- **种族**：人类
- **身份**：银斧城药剂店药剂师，奔雷的前恋人
- **背景**：与奔雷相恋，后怀上人类的孩子（白虎），因不再"配得上"奔雷而离开
- **与白岩关系**：在白岩失踪的几年里，白岩曾在她店里工作

### 5.4 奔雷

- **种族**：棕发狮子兽人
- **身份**：银斧竞技场主人，银斧城最具权势的人物之一
- **特点**：
  - 实力强大，拥有诡异闪避身法
  - 城府极深，布局精密
  - 操控比赛、设局害人、无恶不作
- **结局**：被白虎和鹏鹏联手击杀（第七章）
- **与归玲的关系**：曾是一对恋人，即将成亲时因赛程出差，归来时归玲已怀白虎而离去。他因此仇恨白岩，委托山寨杀害白岩[^ch5]

### 5.5 鹏小雄（鹏鹏）

- **种族**：灰狼兽人（未成年）
- **身份**：银斧城普通居民 → 角斗士俘虏 → 复仇者
- **父亲**：鹏勇（生父）和雄风（第二位父亲）
- **特点**：
  - 性格善良单纯
  - 会憋精法（二爸所教）
  - 懂得兽人体液疗伤的知识
- **结局**：在击杀奔雷后因高潮过度而死亡（第七章）
- **背景**：父亲鹏勇因拒绝让鹏鹏成为奔雷的角斗士而被奔雷设计杀害，父母尸体被 H 毒气处理。奔雷以父债子偿为由抓住鹏鹏，强迫训练为角斗士[^ch6]

### 5.6 德牧警长

- **种族**：德国牧羊犬兽人
- **身份**：银斧城市警署警长
- **特点**：
  - 正直但受制于局长与奔雷的勾结
  - 善于布局和借力
  - 在白虎身上安装了窃听器以追踪其行动[^ch7]
- **目的**：扳倒局长，重整银斧城的法治

## 六、故事时间线（全七章）

1. **入侵**：白虎闯入黄坡山寨，逐个击杀守卫[^ch1]
2. **寻仇**：白虎在大厅击杀牛护卫，逼问寨主关于白岩之死[^ch2]
3. **真相**：白虎被寨主击杀后复活，反杀寨主，得知幕后黑手是银斧城竞技场主[^ch3]
4. **银斧城**：白虎来到银斧城，接下暗杀足球明星巴顿的委托，获得竞技场入场费[^ch4]
5. **野性赛**：白虎参加竞技场野性赛，以一敌二获胜，见到场主奔雷。奔雷揭露白岩无生育能力、白虎身世之谜。德牧警长以谋杀罪逮捕白虎[^ch5]
6. **囚牢**：白虎在地牢中结识鹏鹏，联手击败野猪守卫越狱，得知鹏鹏身世与奔雷的阴谋[^ch6]
7. **清算**：白虎与鹏鹏联手击杀奔雷，鹏鹏力竭而死。德牧警长揭露局长 H 毒气阴谋，白虎以雏龙坐标为条件接受任务[^ch7]

## 七、与兽盾世界观的关系

本世界观是兽盾（Beastshield）的前身原型。两者共享核心机制（生殖器弱点、强制射精致死），但本世界观设定更为简单：

- **无 VR 游戏架构**：兽盾是 VR 游戏世界，本世界是原生世界
- **无精槽系统**：兽盾有精槽数值化，本世界无量化系统
- **无兽盾公司**：本世界无企业帝国设定
- **无神器系统**：无十二神武等特殊装备
- **世界观尺度**：本世界聚焦单人复仇故事，兽盾有完整势力体系
- **起源关系**：本世界是 lanse 最早的世界观尝试，兽盾是继承和发展
