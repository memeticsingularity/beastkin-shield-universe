# 骸虎风味 · 变体策略

> **用途**：在保持骸虎核心风味的前提下，避免同质化
> **与 `hutu-style-checklist.md` 配套使用**——checklist 确保"像骸虎"，本文确保"不腻"

---

## 1. 角色登场公式：可以不"走完"

公式的信息必须全部给到读者，但**不一定在同一个句子里、同一个时间点给完**。

| 变体策略 | 示例 |
|---------|------|
| **袜色后置**——先动作/环境，后补袜色 | "一个黑色人影走了出来……他脚上的袜子竟然有分叉，类似忍者袜的样式。"（刺客兵登场，支线 ch-06） |
| **袜色省略**——当身份已由其他方式证明 | 皇帝直接传送黑虎指挥官，赤裸→穿军袜→穿军服，袜色不是身份证明（支线 ch-15） |
| **逆向登场**——从脱装备开始 | 白狼悬浮抽离时，装备从身上剥离——从全身甲收敛为裙甲+胸甲（主线 vol-7） |
| **非公式化登场**——以生活动作优先 | 觉醒黑袜兵探头→钻出→拽出兄弟→伸懒腰→面罩呼出白气，完全背离军事公式（支线 ch-20） |

**原则**：公式信息必须全部传达，但传达顺序可以变。

---

## 2. 军袜：每次出现的方式不能一样

| 写法 | 示例 |
|------|------|
| 静态等级标识 | "脚上的白袜一尘不染" |
| 动态 | "灰袜兵汗水已经打湿了袜子，在地上留下了痕迹双腿发抖" |
| 触觉 | "袜底纹路透过面罩压在脸上" |
| 脱下/扒袜 | "袜子脱离脚踝的瞬间触发芯片自毁" |
| 污损 | "白袜被血液污染，鲜血染红尊贵袜子" |
| 塞嘴 | "雪豹把那三双黑袜团成一个球，塞进了这个黑袜兵小队长的嘴里" |
| 舔袜 | "跪在地上伸出舌头舔着那双黑袜。酸臭！" |
| 功能说明 | "这军袜才是帝国的象征，它防御力高排汗透气细菌微生物也无法生长" |
| 超越 | "这时候的虎猛已经不需要穿帝国军袜了！" |

**原则**：同一章有两次军袜描写时，第二次和第一次视角不同。

---

## 3. 处决流程：不必每次都走完

| 场景 | 可以省略 |
|------|---------|
| 批量处决/混战 | 不逐个确认死亡，节奏优先（金属采集柱处决，extra-003 ch-17） |
| 已在前文建立的模式 | 提取器处决可简化描写（extra-001 ch-2） |
| 非重点杂兵 | 直接进入死亡瞬间 |
| 调教式/节奏化处决 | 刺激阶段可延长分解（透明丝线勒颈调教，extra-002 ch-2） |
| 重要角色/新型处决 | **不能省略任何一步**，甚至要扩展 |

**原则**：角色越重要、处决方式越新，仪式越完整。

---

## 4. 精液描写：避开"每场都一样"

- **射向变化**：不要总"射在面罩上"。射在墙上、顺着腿流、喷到地上、被布料吸进去、被台阶吸收——每次换个靶子。
- **量标记变化**：不要每次都"巨量精液"。有时精确数（"十来分钟"），有时聚焦总量（"地上流了一大滩"）。
- **视角变化**：第三人称观察、死者第一人称残余视觉（vol-7 ch-089）、从远处看批量处决（extra-003 ch-17）。
- **终态变化**：射完就停、还在滴、没射完就断气、被机器收集、被台阶吸收。
- **处决媒介变化**：手撸、提取器、电击、丝线、獠牙、虚抓引导、尾巴绞杀——每换一种媒介，精液描写角度就不同。

## 5. 对话标签"说道"的变化范围

80% 保持裸"说道/说着"，20% 可加修饰：

| 裸"说道" | 加修饰 |
|---------|--------|
| "长官饶命！小的再也不敢了！"他说道。 | "你们俩互相撸杀对方吧。"白狼**冰冷的声音**说道。 |
| "报告长官！"他说道。 | "你这个蠢熊！"虎猛**命令**道。 |

**注意**：骸虎不使用"颤声说道""苦笑道"等情感修饰标签——情感通过**动作插入**而非标签修饰来表达：

> ✅ "长官饶命！小的再也不敢了！"他说道，**汗水打湿了面罩**。
> ❌ "长官饶命！小的再也不敢了！"他**颤抖着**说道。

## 6. 用段落长度制造节拍

更短的段落 = 紧张；更长的段落 = 舒缓。通篇 2-3 句一段会变成一条直线。

| 情感 | 段落长度 | 效果 |
|------|---------|------|
| 紧张/处决 | 1 句一段 | 急促，与心跳同步 |
| 巡查/对话 | 2-4 句一段 | 平稳，信息传递 |
| 设定说明 | 3-5 句一段 | 节奏放慢，消化信息 |
| 重要时刻/转折 | 突然打破规律 | 引起注意 |

**原则**：骸虎的主线段落很少超过 5 句。

---

## 7. 叙事结构变异：主线 vs 番外

| 作品类型 | 标准结构 | 可以变异 |
|---------|---------|---------|
| 主线 | 任务驱动（引语→任务→执行→冲突→处理→复命） | 多线并行时每条线轮流推进 |
| 支线 | 开放结构，部分章节无明确任务 | 记忆回放/训练章可暂缓任务驱动 |
| 番外短篇集 | 独立场景切片，章内冲突解决 | 不设跨章悬念 |
| 番外连续叙事 | 单线或双线叙事弧 | 双线可在最后一章交汇 |
