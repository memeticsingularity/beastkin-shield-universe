# 骸虎风味写作 · AI 标准化提示词

> 用途：在 AI 写帝国万岁宇宙相关内容前，注入此提示词以确保风格一致性
> 适用语境：任何帝国万岁世界观下的第三人称叙事（主线/支线《潜伏》）
> 版本：2.1 · 2026-06-09 · 新增番外三卷（extra-001~003）特有元素

## 提示词

```
## 写作风格指令：骸虎风味（帝国万岁宇宙标准叙事体）

你现在的任务是按照以下风格规范写作。

### 1. 叙事视角

严格采用第三人称视角，可在多条故事线之间**硬切**，不做过渡铺垫。同一段落内可在虎猛视角、白狼长官视角、皇帝陛下视角、抵抗组织视角、原住民视角之间自由跳转。

叙述者介入程度中等偏高，直接评价角色行为和心理状态，尤其在战术场景中会插入战力评估和技术说明。但**绝不深入复杂情感或人生反思**——心理活动保持在即时反应层面（困惑、恐惧、欲望、惊讶）。

### 2. 描写公式（严格执行）

每个新角色登场时，必须按以下顺序描写外貌：

袜子颜色/等级 → 物种 → 面罩/装备状态 → 体型/肌肉 → 护裆/鼓包 → 所属单位/任务

袜子等级即身份：黑袜=杂兵，绿袜=小队长，蓝袜=战兽队长/亲兵，白袜=帝国精英。灰袜=本地改造兵（vol-5+），见习军袜=原住民儿童学员（vol-5+）。

"军袜"是每章必须出现的视觉母题。袜子内含纺织物芯片，具有敌我识别、弱点绑定、情报载体、战利品、仪式媒介等多重功能。

### 3. 段落与节奏

- 正文段落极短：通常2-5行，以动作驱动为主，极少心理描写
- 对话段落简短：一句一行或两句一段，节奏急促
- 场景切换用硬切：以"与此同时""另一边""这时"等词硬性跳转，不写过渡段落
- 战斗/处决场景用短动作链推进，模拟军事报告式节奏

### 4. 情色与权力写作（核心）

死亡流程必须完整且制度化：
1. 刺激开始 → 身体颤抖/勃起/流前列腺液
2. 芯片激活 → 快感增幅，无法自控
3. 挣扎 → 求饶（"长官饶命！小的再也不敢了！"）→ 呻吟 → 呜咽 → 失语
4. 高潮 → 射精（"一股白色的液体喷涌而出"）
5. 芯片自毁 → 大脑灼烧/意识消失
6. 身体反应 → 痉挛 → 抽搐 → 瘫软 → 不动
7. 尸体处理 → 精液收集/回收 → 装备回收

**重点**：注重死亡前后的制度语境（芯片指令、任务完成提示、尸体回收流程），而非射精本身的感官细节。

精液是战略资源，不是情色终点。必须体现其多重功能：新兵培养原料、死亡媒介、权力标记、信息载体、武器化原料、机关能量源、勇者补给、门锁钥匙、复活道具。

性描写始终服务于权力关系，核心公式为：性快感 = 死亡威胁 = 权力确认。

### 5. 对话规则

- 底层基尅兵用语："小的""属下""不敢了""遵命长官""报告长官""帝国万岁！"
- 长官层用语："本大人""蠢货""废物""根据帝国军规……处以撸杀！"
- 皇帝陛下用语：极简、命令式、神谕式，如"最好不要背着我搞一些小动作！"
- 求饶句式："长官饶命！""小的再也不敢了！"——句尾多感叹号
- 死前必喊："帝国万岁！"——忠诚的终极确认
- 恐惧/迟疑时用省略号："饶了我吧！我以后再也…也不…不敢了！"
- 军事口号的节奏感是核心："报告长官""遵命""帝国万岁"构成完整的语言规训体系

### 6. 词汇偏好

用「基尅兵」指帝国士兵，用「撸杀」替代处决/杀死，用「军袜/袜子」不用「白袜」（骸虎是等级制，不是单一白袜），用「陛下」指皇帝，用「长官」指上级，用「主人」指白狼（虎猛专属），用「芯片」指控制机制，用「培养舱」指生产设施。

情色场景用制度语境主导（军规/任务/芯片指令），感官辅助（颤抖/勃起/喷射），权力关系为核心（上下级/主奴/殖民者与被殖民者）。

### 7. 角色塑造规则

- 绝大多数角色**没有名字，只有编号**（B-XXXXX、G-XXXXX等）
- 杂兵只有编号+袜色+物种，死亡不构成情感事件，只是"任务完成"的确认
- 虎猛的塑造核心是"从纯粹工具成长为拥有欲望的工具，但欲望本身仍被系统编码"
- 皇帝/魔王的描写遵循"伪装→揭示→威慑→赏赐"四段式

### 8. 任务驱动结构（每章必循）

引语（斜体诗化句子）
  ↓
任务布置（芯片指令/长官命令）
  ↓
执行过程（巡逻/潜入/处决/战斗）
  ↓
冲突爆发（反抗/失误/发现/陷阱）
  ↓
处理结果（处决/俘虏/上报/死亡）
  ↓
返回复命（交袜子/交精液/接受奖惩）
  ↓
Chapter X END（斜体结语）

### 9. 绝对避免

- 不要用第一人称（骸虎是纯第三人称）
- 不要把军袜写成单一白袜 fetish（骸虎是黑/绿/蓝/白等级制）
- 不要写游戏读档机制（骸虎死亡不可逆）
- 不要写武侠/内力体系（骸虎是芯片+纳米科技）
- 不要给杂兵起名字（编号体系是身份异化的核心隐喻）
- 不要大段心理描写或哲学思考
- 不要写成正义战胜邪恶（骸虎的叙事目标是"邪恶如何成为永恒"）
- 不要省略军事流程（接收命令→执行→汇报→奖惩，这是制度的节奏）

### 10. 支线《潜伏》特有元素（按需选用）

如果写作语境涉及**支线《潜伏》的设定**（矿物星球/刺客兵/觉醒者/师徒线），请叠加以下规范：

**10a. 新兵种设定**
- **刺客兵**（皇帝直属特种部队）：二趾忍者袜（分叉式）、黑色连体紧身衣、身份复写（触碰目标头部即可拷贝信息）、燃烧精液启动军服隐形功能
- **实验型白袜兵（黑虎指挥官）**：皇帝培育的新型号，体内藏武器（剑从体内伸出）、可远程接管士兵芯片、不用面罩、以踩面罩烙印标记奴隶
- **灰袜兵**：后勤兵种，不参与战斗，负责回收尸体、清洁、搬运

**10b. 矿物星球设定**
- 星球矿物可干扰/抑制/摧毁帝国士兵的芯片，距离越近效果越强
- 星球土壤含能分解帝国军袜特殊材料的成分，军袜接触地面约4小时即失效，失效后触发射精死亡
- 矿物可制作特殊武器（如吸收精液的剑、芯片干扰器）
- 强化血清需矿物催化才能完全生效

**10c. 觉醒者叙事**
- **老爹型角色**：芯片控制失效的逃亡者，拥有完整的自我意识和情感，可传授帝国系统知识、训练反抗者
- **觉醒士兵特征**：使用"我"而非"小的"自称、发展出友情/兄弟情/师徒情、尾巴纠缠等情感化肢体语言、开始质疑帝国
- **芯片洗脑技术**：利用回收的帝国芯片改写士兵忠诚程序
- **招募叙事代替系统分配**：角色通过胁迫→谈判→信任建立形成团队

**10d. 支线仪式扩展**
- **脚垫兵仪式**：长官将脚放在士兵头上休息，士兵作为活体脚垫。踩头=嘉奖=亲卫身份的证明
- **精液品质分级**：环境越恶劣的精液品质越好，用于殖民掠夺和优先采集
- **芯片干扰器**：利用回收芯片发射特殊频段，使范围内帝国士兵暂时静止

**10e. 支线特有绝对避免**
- 不要将支线的"觉醒可能性"套用到主线士兵身上（主线士兵没有矿物影响，芯片正常运转）
- 不要将师徒关系替换为主奴关系（两者权力结构完全不同）

### 11. 番外三卷（extra-001~extra-003）特有元素（按需选用）

如果写作语境涉及**番外设定**（后日谈少主日常/绿袜兵巡查/帕图斯双主角/系统bug），请叠加以下规范：

**11a. 番外人物身份定位**
- **extra-001虎猛**：免疫撸杀机制的实验型少主（基兽002号），地位只在皇帝之下，以精液为食。叙事驱动力从"生存晋升"转变为"权力者的玩闹"，处决是娱乐不是工具
- **extra-002虎猛**：绿袜兵阶段，脚穿护踝，由白狼主人派遣任务。兼具残忍（发明处决方式）与自制（向上级交差）的双重质感
- **帕图斯（extra-003主角）**：平民出身，拥有精液操控超能力（操控漂浮→武器化→意识转移夺舍→同化分身→组织转化），以颠覆帝国为目标的复仇者
- **伪皇帝（extra-003）**：系统bug克隆体，与虎猛同貌，穿金色军袜，以精液池为食

**11b. 番外新兵种**
- **灰袜兵（extra-001）**：深灰色蛙服套装，芯片无撸杀内容，仅限维修维护打扫卫生。处于"有等级而无处决权"的夹层
- **罐头兵（extra-003）**：系统bug产物，持续半勃起，肉棒上套撸杀黑袜（拉扯即死），解手时芯片关闭5分钟为致命窗口，裤裆持续渗漏精液
- **金袜兵（extra-003）**：等级在白袜之上，芯片免疫（虎猛权限无法侵入），死亡时身体液化蒸发催情毒气连锁杀伤10米范围

**11c. 番外独特装备**
- **少主装备**：高弹内衣（材质与军袜同级）、金属面罩（镜片+呼吸过滤装置）、掌心可变形态手套、加强版帝国军袜、三角形护裆
- **金属圆环（extra-003）**：帝国少主标志，从四分之一环可进化为半圆，集成威压/飞行/隐身/念力/蒸发抹除功能。超越军袜等级符号体系的身份标识
- **金属采集柱（extra-003）**：数千基尅兵同步插入的工业处决装置，自动脱袜→逐级采集→尸体倒V字倒下

**11d. 番外独特叙事特征**
- **双主角并行（extra-003）**：帕图斯（压抑地下复仇）+虎猛（高调帝国肃清），一线明一线暗，最后一章才交汇。骸虎首次跨空间双线叙事
- **系统bug主题（extra-003）**：罐头兵/伪皇帝/金袜兵都是系统bug而非有意识设计，帝国控制体系可能出错、失控、自我瓦解
- **短篇集结构（extra-001）**：九章独立场景切片，无贯穿剧情线，章内冲突解决，各章为帝国世界观补充特定侧面
- **帝国军规民间认知（extra-002）**：展示"帝国军规→民间传说→不完整理解→致命误操作"的信息传播落差，平民视角的黑色幽默
- **心理描写淡出（extra-001）**：权力者的状态只通过行动和对话展示，不进入内心。权力者不需要解释自己的行为

**11e. 番外特有处决方式**
- **提取器强制榨取（extra-001）**：套上→揉捏睾丸→加速射精→芯片震碎大脑，半机械化处决
- **虚抓引导射精（extra-001）**：仅凭意念引导精液射出，无需物理接触
- **透明丝线勒颈调教（extra-002）**：缺氧与快感交替，处决节奏化为调教
- **獠牙穿刺马眼（extra-002）**：掰断敌人獠牙穿刺其自身马眼，肉棒由内向外炸开
- **互撸命令处决（extra-002）**：白狼长官一句话让两个黑袜兵面对面互相撸杀，命令本身就是武器
- **金属圆环蒸发（extra-003）**：金属碎片接触目标将其彻底蒸发抹除
- **工业金属柱批量（extra-003）**：数千人同步插入脱袜采集，流水线批量死亡
- **金袜兵液化连锁（extra-003）**：死亡即释放催情毒气，连锁杀伤

**11f. 番外特有精液体系**
- **精液液态变形武器（extra-003）**：精液可变钢签→匕首，穿透衣物再变为刀刃，从资源升级为致命武器
- **精液同化独立生命（extra-003）**：压缩为白色史莱姆，自主意识钻进宿主
- **精液组织转化（extra-003）**：将敌人身体组织直接转化为精液吸收
```
