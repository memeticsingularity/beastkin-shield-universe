# 骸虎写作风格 · 落地检查清单

> **用途**：写作前参照、写完后逐项自检
> **来源**：主线 7 卷（ch-001~ch-113）+ 支线《潜伏》（26 章）+ 番外三卷（extra-001~003）综合分析

---

## 一、硬性要求（少一条就不像骸虎）

- [ ] **每章至少出现 1 次「军袜」描写**（袜色即身份——黑/绿/蓝/白/金/灰）
- [ ] **每个新角色登场走完公式**：袜色/等级 → 物种 → 面罩/装备 → 体型/肌肉 → 护裆/鼓包 → 所属单位/任务
- [ ] **对话标签统一用「说道」「说着」「回答」「命令道」**，不要用「说」「问」
- [ ] **省略号表恐惧/犹豫/语流中断**，格式为三个点「...」
- [ ] **射精死亡写清：量（多少股/持续多久）、射向（何处）、质地（浓/稀/白）、终态（停了/还在流）**
- [ ] **处决流程完整**：刺激→勃起→求饶→射精→芯片自毁→尸体处理
- [ ] **死前必喊「帝国万岁」**——口头禅式的忠诚确认
- [ ] **段落极短**：正文 2-5 行，对话 1 句 1 段
- [ ] **精液不能一笔带过**——它是死亡仪式兼战略资源，必须精细描写

---

## 二、描写系统（照着写）

### 角色登场公式（严格执行）

```
[袜色/等级] + [物种] + [面罩/装备状态] + [体型/肌肉] + [护裆/鼓包] + [所属单位/任务]
```

**正确范例（从原版提取的句式库）：**

| 要素 | 可用句式 |
|------|---------|
| 袜色等级 | 脚上的白袜一尘不染、穿着深蓝色的帝国军袜、灰色军袜配深灰色蛙服 |
| 物种 | 一只XX兽人、全身纯白色毛发的狼兽人、棕黄色虎兽人夹杂黑色条纹 |
| 面罩 | 五孔黑色面罩、眼眶部分黑色镜片、金属面罩带呼吸过滤装置 |
| 体型 | 肌肉饱满充满力量、膀大腰圆、身材粗壮、胸肌饱满 |
| 护裆/鼓包 | 裆部鼓鼓囊囊、护裆带弧度的三角形、裤裆湿漉漉的 |
| 单位 | 后勤兵种、黑袜兵小队长、白袜高级长官、蓝袜战兽队长 |

### 军袜颜色编码（严格执行）

| 袜色 | 等级 | 对应角色 | 备注 |
|------|------|---------|------|
| 黑袜 | 杂兵/普通兵 | 底层士兵、巡逻、站岗 | 袜筒可加横杠标识（一道=小队长，两道=中队长，三道=最高） |
| 绿袜 | 晋升兵/小队长 | 小队长、执行者 | 加护裆/护踝 |
| 蓝袜 | 战兽队长/亲兵 | 战兽队长、虎猛主线全程 | 加头盔/面罩 |
| 白袜 | 帝国精英 | 高级长官、白狼 | 换黑色连体衣+全身甲，材料一尘不染 |
| 金袜 | 皇家卫队 | 伪皇帝近卫、extra-003 | 地位在白袜之上，芯片免疫 |
| 灰袜 | 后勤兵 | 维修/清洁/尸体处理 | 芯片无撸杀内容，无权限 |
| 赤脚 | 皇帝 | 皇帝陛下 | 全帝国唯一可赤脚行走的人 |

### 高频词库（优先选用）

| 部位/动作 | 首选词 | 备选 |
|-----------|--------|------|
| 生殖器 | 肉棒、虎鞭/熊鞭/狼鞭 | 阴茎（极少用） |
| 射精口 | 马眼 | 尿道口（极少用） |
| 精液 | 精液 | 白浆、浓精 |
| 处决 | 撸杀 | 处刑、处决 |
| 士兵 | 基尅兵 | 帝国兵 |
| 上级 | 长官 | 主人（虎猛对白狼专属） |
| 袜子 | 军袜 | 袜子 |
| 高潮/死亡 | 射精、芯片自毁 | 喷射（作为动词） |

### 身份标识系统

- **编号体系**：B-XXXXX、G-XXXXX 等，杂兵只有编号没有名字
- **横杠标识**：袜筒上的一道/两道/三道白杠，标识小队长/中队长等级
- **护踝/护裆**：绿袜兵及以上等级的附加装备
- **金属圆环**：基兽002号（虎猛少主）的专属标识，从三分之一进化到半圆

## 三、对话写作规则

- [ ] **说道/说着/回答/命令道**——对话标签几乎只用这四个结构
- [ ] 求饶句式标准化：「长官饶命！小的再也不敢了！」「呃啊！饶命！」
- [ ] 省略号表示恐惧颤抖：「已经…已经太晚了！帝…国万岁！」
- [ ] 感叹号表示高潮/爆发：「帝国万岁！」
- [ ] 死前必喊「帝国万岁」——射精与死亡瞬间强制喊出
- [ ] 底层用语：「小的」「属下」「不敢了」「遵命长官」
- [ ] 长官层用语：「本大人」「蠢货」「废物」「根据帝国军规」
- [ ] 皇帝用语：极简、命令式、神谕式
- [ ] 对话密度低——大部分章节以动作和叙述驱动

## 四、情色场景写作模板

### 标准处决流程

```
刺激开始（手撸/提取器/丝线/电击/獠牙）→ 目标挣扎勃起
↓
求饶出现（"长官饶命！呃啊！"）
↓
射精（精液喷涌而出 → 量/射向/质地/终态）
↓
芯片自毁（大脑灼烧 / 意识消失）
↓
尸体反应（痉挛 → 抽搐 → 瘫软 → 不动）
↓
处决后处理（精液收集/装备回收/袜子回收）
```

### 精液描写的必写参数

- **射向**：射在面罩上/喷到地上/溅到墙上/顺着腿往下淌
- **量**：明确写持续喷射/巨量精液/十来分钟
- **质地**：浓稠、白色、冒着热气
- **终态**：还在往外渗/已经停了/裤裆湿透

### 各卷新增处决方式速查

| 卷/番外 | 新增处决方式 |
|---------|-------------|
| vol-1 | 手撸、提取装置、芯片后门响指、电刑、无限撸杀、互撸礼花 |
| vol-2 | 无限撸杀2.0、气化、集体射精 |
| vol-3 | 标准死亡四段式、暴力触发短路、死后擦拭 |
| vol-4 | 芯片计时统一射精、木偶化自毁、气化2.0 |
| vol-5 | 公开处决标准序列、植物触手处决 |
| vol-6 | 精液楼梯处决、芯片强制射精、皮化 |
| vol-7 | 卵蛋捏爆、第一人称死亡、食人 |
| 支线 | 尾巴绞杀+裆部、矿物触发、军袜分解、矿物武器 |
| extra-001 | 提取器强制榨取、獠牙吮吸、尾巴绞杀+捏碎、虚抓引导 |
| extra-002 | 透明丝线勒颈调教、反向拧断、獠牙穿刺马眼、卵蛋捏碎 |

## 五、节奏控制规则

- [ ] 段落 2-5 行（战斗/处决场景更是 1-2 句 1 段）
- [ ] 场景切换用硬切（「与此同时」「另一边」「这时」）
- [ ] 每章遵循任务驱动结构：引语→任务→执行→冲突→处理→复命
- [ ] 心理描写保持在即时反应层面（困惑/恐惧/欲望/惊讶），不深入复杂情感
- [ ] 结尾用简洁动作或一句对话收束，不抒情

---

## 六、绝对不要出现（破功标记）

- [ ] 不要用「说」「问」「答」作对话标签（换成「说道」「问道」「回答道」）
- [ ] 不要抒情化环境描写（超过 3 句的环境描写就太多了）
- [ ] 不要角色深层心理活动（活着真没意思、我为什么要这样做——不行）
- [ ] 不要省略处决流程（"一番云雨之后"这类省略——绝对不行）
- [ ] 不要给杂兵起名字（编号体系是身份异化的核心隐喻）
- [ ] 不要写成正义战胜邪恶（骸虎的叙事目标是"邪恶如何成为永恒"）
- [ ] 不要写武侠/内力体系（骸虎是芯片+纳米科技）
- [ ] 不要用第一人称（骸虎是纯第三人称）
- [ ] 不要省略军事流程（接收命令→执行→汇报→奖惩，这是制度的节奏）
- [ ] 不要写精液以外的非致命伤（芯片制裁替代了流血伤害）

## 七、各场景类型速查

| 场景 | 必须包含 | 可省略 |
|------|---------|--------|
| 新角色登场 | 公式全套（袜色→物种→面罩→体型→护裆→单位） | 角色背景 |
| 处决 | 刺激→求饶→射精→芯片自毁→尸体处理 + 精液描写 | 环境描写 |
| 对话/汇报 | 军事口令 + 帝国万岁 + 说道/回答标签 | 心理活动 |
| 巡逻/移动 | 硬切 + 1-2 句交代去向 | 景色描写 |
| 章节结尾 | 简洁动作/对话/命令收束 | 抒情总结 |
