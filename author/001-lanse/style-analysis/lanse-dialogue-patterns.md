## 1. 核心结论

**在兽盾宇宙中，台词 = 身份 × 场景 × 兽种。** 作者 lanse 为每个角色设计的台词受到三个维度共同决定：

| 维度 | 影响范围 | 权重 |
|:----|:--------|:---:|
| **兽种** | 第一人称代词偏好、脏话风格、语句长度、文化水平 | ★★★ 中 |
| **制服等级** | 自信程度、命令权、词汇文雅度、求饶门槛 | ★★★★★ 核心 |
| **场景** | 句式（完整句 vs 碎片词）、情绪强度、语速暗示 | ★★★★ 关键 |

**三条铁律：**

1. **兽盾兵不说长句。** 绝大多数台词在 15 字以内，即使虎兽人的羞辱也是短句堆叠，不是复杂从句。
2. **"道"是默认标签。** 约 70% 的对话用"道"标记，"说"约占 20%，其他标签（吼/骂/笑/哼等）只在特定情绪时使用。
3. **省略号是标配。** "。。。"（三个中文句号）在恐惧、濒死、被控制时大量使用。一个人说话不带省略号 ≈ 他还有反抗能力。

## 2. 兽种台词特征

### 2.1 熊兽人

| 特征 | 说明 |
|:----|:----|
| **第一人称** | 俺（乡下口音为主）/ 我（通用）|
| **口吻基调** | 憨厚、直接、句子短、情绪转换快 |
| **句式长度** | 极短，通常 5-10 字 |
| **文化水平** | 低——词汇量有限，不会用复杂句式 |
| **代表性场景** | 站岗抽烟、被偷袭时懵逼、临终时最原始的恐惧 |

**典型台词：**
- 日常："你他妈谁啊！俺为什么要听你。。。喔喔！"（ch-3，被偷袭时）
- 被控："快。。快住手。。。求你饶了我"（ch-1，被撸时）
- 濒死："你在说什么。。。我听不懂。。。求你。。。饶了我吧"（ch-1，流泪求饶）

**关键规律：** 熊的台词和熊的体型成正比——越壮的熊台词越短。恐惧时不会讨价还价，只会重复"求你了"。

---

### 2.2 牛兽人

| 特征 | 说明 |
|:----|:----|
| **第一人称** | 俺（乡下）/ 我（通用）/ 老子（愤怒时）|
| **口吻基调** | 固执、倔强、"牛脾气"——急了会爆粗，但平时老实 |
| **句式长度** | 短~中；愤怒时可说完整句子 |
| **文化水平** | 中低——比熊强一些，但也是基层 |
| **代表性场景** | 被欺压时暴怒、被处决时最久的憋精、遗言挂念家人 |

**典型台词：**
- 愤怒："凭什么？老子和你是同级！" / "你他妈的再说一遍！"（黑石，被虎羞辱时）
- 被虐时求饶："别……别杀我……求你……"（黑石2）
- 崩溃时："求…求你住手，我受不了了，在了一次…我就要射了…"（captive-delivery，带哭腔）
- 临终："你。。。你。。。"（黑石牛，被捏爆卵蛋，遗言未说完）
- 憨厚："不会！不会！俺一个字也不会说出去的！"（ch-3，紧张）

**关键规律：** 牛兽人的台词有一个"蓄力→爆发"的弧线——平时老实，被逼到极限会爆粗甚至动手。临终遗言往往挂念家人/责任，比熊更"有牵挂"。

---

### 2.3 虎兽人

| 特征 | 说明 |
|:----|:----|
| **第一人称** | 老子（最常用）/ 我（较少）|
| **口吻基调** | 嚣张、自信、鄙视链顶端、会用长句羞辱 |
| **句式长度** | 中~长；是所有兽种中最能说完整句子的 |
| **文化水平** | 中高——词汇量最大，会使用讽刺 |
| **代表性场景** | 羞辱下级、战斗中叫嚣、被处决时从嚣张到崩溃的反差最大 |

**典型台词：**
- 羞辱："哼！同级？谁不知道你们这种蓝制服的都是进不了战斗编制的垃圾，给你们个高级守卫职业，吊着面子罢了，还蹬鼻子上脸了？别笑死人了。"（黑石，最长单句台词之一）
- 命令："起来让开，没看到我们还站着吗！"（黑石）
- 战斗："别碰老子，有本事别用这种下三滥手段，和堂堂正正我再战一次！"（ch-10）
- 被处决时："为。。为什么，我为兽盾。。。忠心耿耿工作了十余年。。。为什么。。。呃！"（ch-10）
- 崩溃："不。。不要。。哈啊。。。我不想死得这么没有价值。。。"（ch-10，求牙董）

**关键规律：** 虎兽人是唯一会用讽刺和完整逻辑链羞辱人的兽种。他们的江湖地位越高，语言就越嚣张。但一旦被制服，从嚣张到崩溃的转折是所有兽种中最戏剧性的——"老子"变成"求求你"只需几秒。

---

### 2.4 狗兽人

| 特征 | 说明 |
|:----|:----|
| **第一人称** | 我 / 老子（吹牛时）|
| **口吻基调** | 实用主义、短句、不废话、看人下菜 |
| **句式长度** | 短——最简短直接的兽种之一 |
| **文化水平** | 中低——滑头、小聪明 |
| **代表性场景** | 日常搭话、处理尸体、临终时最像"打工人" |

**典型台词：**
- 日常："兄弟，帮个手呗。"（黑石）
- 抱怨："可惜个屁啊，要死也不死远点，累死我了。"（黑石）
- 临终："我知道的都已经说了，可以饶了我吗。"（ch-2，摇尾乞怜）
- 吹牛/日常："这。。呕。。这是怎么回事。。？"（毕业实习牛，被灼流暗劲击中）

**关键规律：** 狗兽人的台词最"轻量化"——不给对话加多余的修饰词。认知到自己处于劣势后不挣扎，直接投降。遗言往往涉及未完成的事业。

---

### 2.5 野猪兽人

| 特征 | 说明 |
|:----|:----|
| **第一人称** | 我 |
| **口吻基调** | 外强中干——外表凶悍但内心极易恐惧 |
| **句式长度** | 中；恐惧时变成碎片化哀嚎 |
| **文化水平** | 低 |
| **代表性场景** | 赌博输光后被当众处决、被玩到崩溃 |

**典型台词：**
- 求饶："不！不要！我一定还！谁借我点本金，我一定赢回来还你！"（黑石，惊慌失措）
- 崩溃："啊！。。不要！。。。快停下！。。。求。。求你们。。。快停下。。。"（黑石）
- 临终："呃啊！。。。啊啊啊啊啊！。。。"（黑石，只剩惨叫）

**关键规律：** 野猪的台词是所有兽种中最先崩溃的。他们看起来最凶，但一旦处境逆转，求饶最快、哭得最响、死得最没有尊严。

---

### 2.6 狼/狮/豹等其他兽种

| 兽种 | 口吻特征 |
|:----|:--------|
| **狼兽人** | 发现劣势后迅速投降，试图用情报换命。"我说我说" |
| **狮子警察** | 面对死亡时出卖同事最快。"在。。。301号房" |
| **黑豹兽人** | 好胜心强，看不起同事，但实力悬殊时死得最憋屈 |
| **红狼** | 残忍、享受施虐、把处决变成游戏。"来来来快来下注咯" |

## 3. 制服等级台词特征

### 3.1 G级（绿制服杂兵）

**台词核心特征：粗、短、怕。**

- **词汇水平：** 底层地痞流氓，日常用语粗糙
- **话题范围：** 烟、酒、饭、钱、女人（兽人语境下的性）
- **求饶模式：** 直接跪——"放过我" "求求你" "别杀我" 简单重复
- **尊严底线：** 最低。死前往往完全崩溃，不在乎形象
- **代表性：**
  - "你要不是……杀我……兽盾公司不会……放过你的……！"（农家乐熊——唯一死前还威胁的G级）
  - "谁！。。。谁打俺！"（ch-3，被莫名叫醒）
  - "快。。快住手。。。求你饶了我"（ch-1，被撸到临界点）

**句式规律：** 几乎全是简单主谓结构，无从句、无修饰、无修辞。一句话不超过15字。

---

### 3.2 O级（蓝制服监工）

**台词核心特征：比G级多想一步，但本质一样粗。**

- **词汇水平：** 中层管理，试图显得有地位但水平有限
- **敏感点：** 最不能忍受被说"和杂兵一样"
- **求饶模式：** 会先试图讲道理/谈条件，不行才跪
- **代表性：**
  - "凭什么？老子和你是同级！"（黑石——被虎羞辱后立刻炸毛）

**核心规律：** O级是"中间阶层焦虑"的典型——他们拼命想和G级划清界限，但实力和G级差距不大。对话中会强调自己的职位/身份。

---

### 3.3 E级（黑制服武斗兵）

**台词核心特征：自信、简练、有职业尊严。**

- **词汇水平：** 比G/O级高一档，少用"俺"，多用"老子"
- **语气：** 命令式、不屑式——"起来让开" "别碰老子"
- **求饶模式：** 最难开口。前期硬撑到底，一旦开口就最卑微（从"老子"到"求求你"的反差最大）
- **代表性：**
  - "属。。属下无能，辜负了牙董的。。。"（ch-10虎队长）
  - "为。。为什么，我为兽盾。。。忠心耿耿工作了十余年。。。为什么。。。呃！"（ch-10虎队长）
  - "别碰老子，有本事别用这种下三滥手段，和堂堂正正我再战一次！"（ch-10虎队长）

**核心规律：** E级是兽盾兵的"精英阶层"，对话中有一种"老子打架不靠阴招"的职业自尊。这种自尊在濒死时被粉碎的过程，是原作最戏剧性的部分。

---

### 3.4 R级（白制服枪械兵）/ W级（深蓝摔跤服）

台词样本较少，但可总结特征：
- **R级：** 有专业自信（"老子这枪法，五十米内指哪打哪"），但实战中被近身就怂
- **W级：** captive-delivery 的牛摔跤兵几乎不说话（嘴被塞住），但有限的对话表明高级兵种更会谈判/威胁

---

### 3.5 高层（牙董/总司令级别）

**台词核心特征：文雅、从容、完整句式。**

- **词汇水平：** 明显高于所有兵种——"鄙人" "请便" "忠心根本一文不值"
- **语气：** 永远平静、微笑、不提高音量。暴怒也用优雅的句子表达
- **主题：** 权术、人性、价值观输出——不是讨论吃饭睡觉
- **代表性：**
  - "鄙人姓牙，是兽盾的董事长。"（ch-10，优雅鞠躬）
  - "你击败了他，他就是你的战利品，你想怎样处置他都是你的自由。"（ch-10）
  - "既然你这么忠心，那麻烦你靠墙死远一点，不要弄脏我的衣服。"（ch-10——最冷酷的台词之一）
  - "可惜我要的不是忠心，我要的是实力！"（ch-10）

**核心规律：** 高层台词和杂兵台词的区别，本质上是"同一个世界里的两种语言"。高层可以彬彬有礼地杀死你，杂兵只会骂骂咧咧地杀死你。

## 4. 场景台词模式

### 4.1 站岗/日常闲聊

**特征：** 最放松的台词状态。句式完整，话题轻松，有来有回。

**常见话题：**
- 抽烟、吃饭、喝酒、下班后干什么
- 吹牛（"老子这枪法"级的吹嘘）
- 抱怨同事/上级、聊同事的肉体
- 性（调侃同事身材）

**示例：**
> "嘿，可以带我去一下杂物间吗，我想去找点工具。"——黑石
> "没问题，跟我来，不过一会得让我揉揉你那对巨乳当做回报。"——虎兽人（调情式回答）

**规律：** 日常对话中兽盾兵彼此之间会用前轻后重的语气——开头低声下气，结尾暴露本性。

---

### 4.2 战斗叫嚣/命令

**特征：** 短、硬、祈使句为主。不给对方留回话空间。

**句式模板：**
- "识相的快快滚出去！"
- "起来让开，没看到我们还站着吗！"
- "今天，你们就不要想着活着离开了。"
- "说，证人在哪个房间？"
- "快撸他的屌！"

**规律：** 战斗叫嚣中几乎全部使用**感叹号**结尾，没有问号。命令句不用"请"、"麻烦"等礼貌词。

---

### 4.3 被偷袭瞬间

**特征：** 没有完整句子。全是拟声词和碎片化词。

**序列：**
1. 第一反应： "唔！" "咳。。" "呃！"（咽喉被锁的闷哼）
2. 挣扎期： "咳。。咳。。。你是谁。。。咳"（艰难发声）
3. 认命期： "放。。。放开。。。"（放弃抵抗）

**规律：** 被偷袭的角色台词量=0。原作中几乎所有被勒喉的角色都说不出完整句子，这正是"摸哨"的恐怖之处。

---

### 4.4 求饶（标准弧线）

原作中求饶台词遵循一个可预见的四阶段弧线：

| 阶段 | 内容 | 语气 | 时长 |
|:----|:----|:----|:----|
| **① 还有希望** | "放过我…我愿意说出我知道的一切…" | 急促、慌乱 | 开场 |
| **② 希望破灭** | "别……别杀我……求你……" | 颤抖、断断续续 | 中期 |
| **③ 濒临崩溃** | "我受不了了，在了一次…我就要射了…" | 带哭腔 | 后期 |
| **④ 临终遗言** | 未说完的关键信息 | 气若游丝 | 最后 |

**常见求饶句式：**
- "不……不要杀我……我可以……呃啊！"（被打断）
- "放过我……我发誓再也不来打扰你，我发誓……呃！"（被打断）
- "好汉……可以放过我了吗？"（可怜巴巴）
- "不要……求求你……饶了我吧！"（声泪俱下）
- "别……别杀我……求你……"（简单重复型乞求）

### 4.6 逼问情报

**特征：** 简洁、高效、不容反驳。

**经典模板：**
> "说，证人在哪个房间？"——灰熊（业务娴熟）
> "说吧，为什么一个人大晚上出来锻炼？"——黑石（饶有兴趣）

**规律：** 逼问时杀手掌握完全的话语权。目标只有回答的份，没有反问的份。如果目标试图拖延或撒谎，立刻施加更多刺激。

## 5. 临终遗言分类

原作中临终遗言（包括死前最后一句话/意识中的最后一念）可归纳为 **7 种类型**：

### 5.1 挂念型（牛/熊类乡下兵最常见）

> 原作正文暂无明确挂念型遗言（该类多出现在故事评述的角色背景补充中）

**特征：** 惦记家人/责任，到死还想着"我该做的事还没做完"。在原作正文中多以未说完的半句话呈现。

---

### 5.2 事业未竟型（有梦想的兵）

> "我想升为……正式武斗兵……"——黑石2的牛（被处决前的愿望）

**特征：** 死前最后想的不是怕，而是"我的计划还没完成"。

---

### 5.3 辱骂型（死前最后硬一下）

> "操……我操你们……呃！"——babysitter-lei 棕熊（被老雷捂回去）

> "你他妈的再说一遍！"——黑石的牛（死前的最后一句完整话）

**特征：** 到死都在骂，是兽盾兵"即使死也要嘴硬"的典型。但通常说不完。

---

### 5.4 不甘型（有尊严的兵，主要是虎/E级）

> "我不想死得这么没有价值……"——虎队长（ch-10，看着牙董）

> "为。。为什么，我为兽盾。。。忠心耿耿工作了十余年。。。为什么。。。"——虎队长

**特征：** 质问命运/被背叛。不是怕死，是觉得"我不该这样死"。

---

### 5.5 接受型（最罕见的类型）

> "原来这就是射精的感觉……每射一发我便舒服地呻吟一声，直到射了十六发后……就这样死去……感觉……似乎也不是很糟糕……"——员工日记白熊

**特征：** 从恐惧到接受，最后坦然面对死亡。原作中仅此一例。需要特殊的叙事视角（第一人称）。

---

### 5.6 威胁型（最不理智的类型）

> "你要是……杀我……兽盾公司不会……放过你的……！"——农家乐熊

**特征：** 死前还在试图用组织吓唬对方。这种遗言往往加速自己的死亡（因为证明了"留活口有后患"）。

---

### 5.7 悔恨型

> "早知道就不来兽盾应聘了"——野猪守卫（炎魉篇，角色档案记载）

**特征：** 对人生选择的最大遗憾。死于兽盾，悔于加入兽盾。

---

## 6. 杀手/处决者台词风格

### 6.1 老雷（红虎·灼流暗劲）

**特征：** 最简练、最冷、最有人情味的杀手。

**台词风格：**
- 对猎物：毫无感情——"真是老套的遗言，上路吧。"
- 对儿子（小雷）：温柔编谎话——"爸爸……在和叔叔玩捉迷藏呢"
- 对浪费时间的猎物：不耐烦——"敢来偷袭我家？胆子挺肥嘛。"
- 名言："不可以在小朋友面前说脏话哟。"

**规律：** 老雷的台词有两个清晰的频道——杀人的频道（冷、短、不容置疑）和带娃的频道（温柔、编造、哄）。频道切换极快。

---

### 6.2 黑石（牛·赏金猎人）

**特征：** 有人情味的屠夫。会夸猎物、会惋惜、会调情。

**台词风格：**
- 处决时："真是可爱。" / "身材这么好，真是可惜了呢。"
- 调戏猎物："干嘛？不就是抽你根烟，不要这么小气嘛。"
- 羞辱计数："1、2、3……18、19。真不错，就算你20次吧。"
- 下杀手前："在成为兽盾公司兵的那一天，就该预料到可能会有这一天的。"

**规律：** 黑石是唯一一个会在杀人前和猎物聊天的杀手。他的台词让猎物"死得明白"——甚至会夸猎物努力、安慰猎物不要难过。

---

### 6.3 年轻雷（雷炎寰·毕业实习）

**特征：** 戏谑、战术性嘴炮、自信到狂妄。

**台词风格：**
- 开场："各位叔叔好，我叫雷炎寰，今天来这是为了完成毕业实习作业的，那么，就劳烦各位叔叔今天都在这里喷一发哈。"
- 战斗中："看来我功力还不够啊。"

**规律：** 年轻雷的台词比老雷时更"油"。他是把校园式的客气用语用在杀人场景中，制造黑色幽默。

---

### 6.4 牙董

**特征：** 优雅、从容、令人毛骨悚然的礼貌。

**台词风格：**
- 自我介绍："鄙人姓牙，是兽盾的董事长。"（优雅鞠躬）
- 处置属下："请便，希望你能快一点解决，我时间宝贵。"
- 冷酷哲学："忠心根本一文不值！"
- 对垂死的老虎："既然你这么忠心，那麻烦你靠墙死远一点，不要弄脏我的衣服。"

**规律：** 牙董的台词和所有兽盾兵形成最强烈的对比——越礼貌越恐怖，越从容越冷血。他说话从不用感叹号，永远用句号。

---

### 6.5 夜袭潜入者

**特征：** 变态的温柔。把处决变成艺术鉴赏。

**台词风格：**
- 纠正误解："你弄错了，我杀你并不是为了情报或者赏金，这只是我的小～兴～趣～"
- 对尸体："练这么壮真是辛苦你了。" / "这样一个人挂着太寂寞了，就奖励你一根磨牙棒。"

**规律：** 说话带波浪号"～"，是原作中最明显的"变态标识"。对活人温柔，对尸体更温柔。

---

### 6.6 其他处决者

| 角色 | 特征 | 代表性台词 |
|:----|:----|:---------|
| **银（银针封穴）** | 技术宅式解说 | "这就是北斗泄阳针法的奥义！" |
| **炎（灼流暗劲）** | 几乎不说话，沉默处决 | "知道了，谁要他骂人。" |
| **魉（隐身助手）** | 戏谑、吐槽同伴 | "你也真是无情，杀人也不让他死得爽一点。" |
| **熊猫（特工局）** | 懒散、怕麻烦 | "我都一把年纪了，这种跑腿的活以后就别叫我干了吧。" |
| **总司令（德牧）** | 正式、官腔 | "今天我召集大家，就是为了决定要不要处决掉这位兽盾的员工。" |

## 7. 高频词汇与语言特征

### 7.1 第一人称代词系统

| 代词 | 使用者 | 语气色彩 | 例句 |
|:----|:------|:--------|:----|
| **俺** | 熊/牛（乡下来） | 憨厚、土气、底层 | "谁打俺！" |
| **老子** | 虎（最常见）→ 所有兽种愤怒时 | 嚣张、挑衅 | "老子和你是同级！" |
| **我** | 通用 | 中性 | 无 |
| **鄙人** | 仅牙董 | 文雅、正式 | "鄙人姓牙" |
| **咱** | 极少使用 | 北方口音 | 极罕见 |

**规律：** 第一人称代词是兽盾兵"人设的锚点"。一个说"俺"的兵不可能突然改成"老子"（除非在特定情绪爆发时）。保持代词一致性是兽盾台词的第一要求。

---

### 7.2 高频脏话库

| 脏话 | 频率 | 使用者 | 力度 |
|:----|:---:|:------|:---:|
| 他妈的 | ★★★★★ | 通用 | 中——日常骂人 |
| 操/艹 | ★★★★ | 濒死/暴怒时 | 强——最原始的发泄 |
| 傻逼 | ★★★ | 通用 | 中 |
| 废物 | ★★★★ | E级→下级（最常见侮辱） | 强——兽盾的"官方蔑称" |
| 垃圾 | ★★★★ | E级及以上 | 强——牙董也用 |
| 杂种 | ★★★ | E级 | 强 |
| 他妈/草你妈 | ★★ | 濒死时 | 极强 |

**"废物"的特殊地位：** 在兽盾世界中，"废物"是最常用的蔑称。从牙董到虎队长到杂兵，所有人都会用这个词。它比"垃圾"更带个人攻击意味（"垃圾"更偏向对能力的否定）。

---

### 7.3 省略号语法

原作中的省略号使用有严格的语义规则：

| 省略号形式 | 含义 | 示例 |
|:---------|:----|:----|
| **。。。**（三句号） | 默认形式。恐惧/迟疑/中断 | "求。。。求你住手" |
| **。。**（两句号） | 轻度迟疑，比。。。弱 | "对..对不起" |
| **。。。。。。**（六句号） | 极端的恐惧/虚弱 | 极少使用 |
| **……**（中文省略号） | 不使用 | 原作完全不用 |

**规律：** 省略号的数量和角色的恐惧程度成正比。一个濒死的角色每两个字之间就有一个。。。，一个还有抵抗能力的角色几乎不用省略号。

---

### 7.4 语气词与拟声词

| 词 | 场景 | 例句 |
|:---|:----|:----|
| 唔！ | 被偷袭/被捂住嘴 | "唔……咳……！" |
| 喔/嗷 | 突然疼痛 | "喔！""嗷！" |
| 哈啊 | 濒死前的叹息 | "哈啊……" |
| 噗 | 喷血/喷精 | "噗嗤" |
| 哞啊 | 牛兽人临终特有的吼叫 | "哞啊！"（仅牛） |
| 嘿 | 搭话/套近乎 | "嘿，可以带我去一下……吗" |

## 8. 对话标签使用规律

### 8.1 标签频率

| 标签 | 频率 | 典型语境 |
|:----|:---:|:--------|
| **道** | ★★★★★ 约70% | 默认标签，所有场景通用 |
| **说** | ★★★★ 约15% | 陈述/回答时，比"道"稍弱 |
| **笑道** | ★★★ | 嘲讽、自信、调戏猎物时 |
| **吼道** | ★★★ | 愤怒、命令、远距离喊话 |
| **问道** | ★★ | 提问时 |
| **答道** | ★★ | 回答时 |
| **怒道** | ★★ | 暴怒时 |
| **哭道/求道** | ★★ | 求饶时 |
| **喊道** | ★ | 远距离、兴奋时 |
| **骂道** | ★ | 恶意辱骂时 |
| **叫道** | ★ | 突然受袭时 |
| **哼道** | ★ | 不屑时 |
| **叹道** | ★ | 感叹、惋惜时 |
| **闷哼道** | ★ | 被控制时艰难发声 |

### 8.2 标签选择原则

1. **默认用「道」**——不是"说"。lanse 的习惯是「道」主导。
2. **情绪上扬时用「笑道/吼道」**——不加程度副词，直接在标签前加一个副词："不屑的笑道" / "嚣张的道"
3. **处决者能用「道」的，杂兵也用「道」**——标签选择不区分角色地位
4. **「说」在对话交替中用于换人说话时**——尤其是短促的答话
5. **避免单一标签重复**——同一段对话中连续用同一个标签会显得单调

### 8.3 标签前副词规律

原作中对话标签前的副词使用模式：

| 模式 | 示例 |
|:----|:----|
| 形容词+的+标签 | "嚣张的道""不屑的笑道""兴奋的喊道""粗哑的声音吼道" |
| 无修饰+标签 | "道""问道""笑道"（最常用） |
| 动词性短语+标签 | "指着房门道""挣扎着挤出几个字道" |

## 9. 速查清单

### 写前规划
- [ ] **角色是什么兽种？**（熊→俺·憨厚·短句 / 牛→倔强·会爆粗 / 虎→老子·嚣张·讽刺 / 狗→实用·短句 / 猪→外强中干）
- [ ] **角色是什么等级？**（G级→粗短怕 / O级→比G多想一步 / E级→自信到卑微的反差 / 高层→优雅从容）
- [ ] **当前场景是什么？**（日常→放松完整句 / 战斗→祈使句感叹号 / 被偷袭→拟声词碎片 / 求饶→四阶段弧线）

### 写中执行
- [ ] **第一人称代词用对了吗？**（俺⇔老子⇔我，保持一致性）
- [ ] **句式长度匹配角色了吗？**（G级不超过15字，E级可稍长，牙董可说完整个逻辑链）
- [ ] **省略号用对了吗？**（恐惧/濒死时用。。。，还有反抗能力时不用）
- [ ] **对话标签用「道」为主了吗？**（避免通篇只用「说」）
- [ ] **脏话匹配等级了吗？**（G级用"他妈的"/E级用"废物垃圾"/牙董不爆粗）
- [ ] **这句话可以是这个兽种说的吗？**（虎说"起来让开"合理→牛说同样台词就怪）
- [ ] **临终遗言的类型选对了吗？**（挂念型适合乡下兵/不甘型适合E级虎/辱骂型濒死爆发）

### 写后检查
- [ ] **读一遍——这个角色像兽盾兵吗？**（不像精心设计的反派？像地痞流氓？）
- [ ] **这句台词如果换成另一只兽/另一个等级，还成立吗？**（成立说明写得太通用）
- [ ] **同一场景多个角色的台词听起来一样吗？**（每个角色应有可分辨的说话方式）
