# lanse 风味 · 变体策略

> 用途：在保持 lanse 核心风味的前提下，避免同质化  
> 与 `lanse-style-checklist.md` 配套使用——checklist 确保"像 lanse"，本文确保"不腻"

---

## 1. 角色登场公式：可以不"走完"

公式的信息必须全部给到读者，但**不一定在同一个句子里、同一个时间点给完**。

| 变体策略 | 示例 |
|---------|------|
| **只写前两步**——不需要看下体和袜子时 | "一只黑制服的虎兽人站在走廊尽头，身材粗壮得把走廊光线挡去一半。" |
| **从下往上写**——先看见腿/袜子/鞋 | "转角先露出一双白袜裹着的粗壮小腿，然后是军绿色短裤下摆——一只熊兽人扛着箱子走出来。" |
| **通过环境折射**——先看影子/声音/气味 | "走廊那头传来沉重的脚步声，伴随着钥匙碰撞的叮当响。" |
| **公式打散成两段**——交手后再补下体和白袜 | 第一眼："一只棕熊兽人蹲在货架前对账。" → 靠近后："紧身裤勒出一个鼓鼓囊囊的弧度。" |

---

## 2. 白袜：每次出现的方式不能一样

| 写法 | 示例 |
|------|------|
| 静态描写 | "白袜裹着粗壮的小腿" |
| 动态 | "他蹲下来的时候，白袜上缘勒进小腿肉里，勒出一道浅浅的红印" |
| 触感 | "指尖碰到他白袜包裹的脚踝，布料已经被汗浸透了，湿漉漉的" |
| 脱下 | "白袜脱下来的时候带着体温，袜筒里还冒着热气" |
| 污损 | "白袜脚底沾了灰，袜口有一圈汗渍干涸后的黄印" |
| 间接 | "他换了条干净的白袜，把脏的那团塞进靴子里" |

**原则**：同一章有两次白袜描写时，第二次和第一次视角不同。

---

## 3. 处决流程：不必每次都走完

| 场景 | 可以省略 |
|------|---------|
| 读档后重复处决 | 制服过程可跳过，用"同样的流程"交代 |
| 群战/混战 | 不逐个确认死亡，节奏优先 |
| 对方已半残 | 不需要再制服 |
| 快节奏追杀 | 直接进入临界点 |
| 重要角色 | **不能省略任何一步**，甚至要扩展 |

**原则**：角色越重要，仪式越完整。

---

## 4. 精液描写：避开"每场都一样"

- **射向变化**：不要总"射在肚皮上"。射到脸上、墙上、顺着大腿流下来、被布料吸进去——每次换个靶子。
- **视角变化**：正面看、从背后看、从下方看、从远处看。
- **数量标记变化**：不要每次都"十几股"。有时精准数（"七股"），有时聚焦总量（"地上流了一大滩"）。
- **终态变化**：射完就停、还在滴、没射完就断气。

---

## 5. 对话标签"道"的变化范围

80% 保持裸"道"，20% 可加修饰：

| 裸"道" | 加修饰 |
|--------|-------|
| "求你了。。。饶了我吧。。。"他道。 | "不行了。。。要射了。。。"他**颤声**道。 |
| "你是谁？"他道。 | "你是什么人！"他**厉声**道。 |

---

## 6. 用段落长度制造节拍

更短的段落 = 紧张；更长的段落 = 舒缓。通篇 1-2 句一段会变成一条直线。

| 情感 | 段落长度 | 效果 |
|------|---------|------|
| 紧张/战斗 | 1 句一段 | 急促 |
| 探索/对话 | 2-3 句一段 | 平稳 |
| 重要时刻/转折 | 突然打破规律 | 引起注意 |

**原则**：最长不超过 5 句。
