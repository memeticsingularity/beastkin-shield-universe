# lanse 写作风格 · 落地检查清单

> 用途：写作前参照、写完后逐项自检  
> 来源：主线三部 + 支线 + 短篇 + Online + Reforged 综合分析

---

## 一、硬性要求（少一条就不像 lanse）

- [ ] **每章至少出现 1 次「白袜」描写**（穿在角色腿上的，不是袜子堆）
- [ ] **每个新角色登场走完公式**：物种→制服色→体型（胸肌/腰/背）→下体鼓包→白袜→鞋
- [ ] **对话标签统一用「道」**（说道/问道/吼道/怒道/笑道/喃喃道），不要用「说」
- [ ] **省略号表恐惧/犹豫**，格式为三个点「。。。 」（汉字全角+一个空格）
- [ ] **射精描写写清：量（多少股）、射向（何处）、质地（浓/稀）、终态（停了/还在流）**
- [ ] **精液不能一笔带过**——它是死亡仪式，必须精细描写
- [ ] **处决流程完整**：制服→握→刺激→求饶→射精→确认死亡
- [ ] **如需死前拉扯**：可写临界状态/射后抽搐/濒死未死，给HE或残忍路线留空间；不需要时则瞬间死亡
- [ ] **段落不超过 3 句**，大部分 1-2 句一段

---

## 二、描写系统（照着写）

### 角色登场公式（严格执行）

```
[物种] + [制服颜色/款式] + [体型/肌肉] + [下体鼓包] + [白袜] + [鞋]
```

**正确范例（从原版提取的句式库）：**

| 要素 | 可用句式 |
|------|---------|
| 物种 | 一只XX兽人、一只XX皮的XX兽人 |
| 制服 | 身穿军绿色紧身短袖短裤、一身黑色制服、蓝白制服 |
| 体型 | 膀大腰圆、身材粗壮、胸肌饱满、粗壮的手臂如柱子 |
| 下体 | 大包在紧身裤下鼓起、裆部鼓鼓囊囊、能看到圆滚滚的轮廓 |
| 白袜 | 白袜裹着粗壮的小腿、长筒白袜紧绷地裹在小腿上、印着logo的白袜 |
| 鞋 | 军绿色运动鞋、黑色运动鞋、蓝色工作靴 |

### 高频词库（优先选用）

| 部位 | 首选词 | 备选 |
|------|--------|------|
| 小腿 | 粗腿、粗壮的双腿 | 大腿、肉腿 |
| 生殖器 | 肉棒、熊鞭/虎鞭/牛鞭 | 阴茎（少用） |
| 射精口 | 马眼 | 尿道口（极少用） |
| 精液 | 浓精、精液 | 白浆、白浊 |
| 胸部 | 胸肌 | 乳头、乳首 |
| 高潮/死亡临界 | 精槽（数值制）、射精 | 喷射（作为动词） |

### 制服颜色编码（不可乱用）

| 颜色 | 等级 | 对应角色 |
|------|------|---------|
| 军绿 | G级（杂兵） | 底层守卫、司机、搬运工 |
| 蓝/蓝白 | O级（监工/干部） | 小队长、中层管理 |
| 黑 | E级（精英武斗） | 组长、战斗部队精英 |
| 白 | 特殊/高层 | 精英部队、特殊部门 |

## 三、对话写作规则

- [ ] **XX道**——对话标签几乎只用这个结构
- [ ] 求饶句式标准化：「求求你饶了我吧」「饶命」「我真的要射了」
- [ ] 省略号表示恐惧颤抖：「你。。。你要干什么。。。」
- [ ] 感叹号表示高潮：「别！别别别——要射了！」
- [ ] 语气词丰富：呜、嗯啊、唔、哈啊
- [ ] 对话密度低——大部分章节对话占比不超过 20%

---

## 四、情色场景写作模板

### 标准处决流程

```
制服（捏蛋/锁喉/麻药/。。。）→ 目标失去反抗 / ...
掏出下体（拉开裤头、翻开包皮） / ...
刺激开始（揉乳头/撸杆/搓龟头/。。。） / ...
求饶出现（"要射了"等警告） / ...
临界点（精槽80-100%，身体绷紧，腰往上挺） / ...
射精（第一股射向何处 → 后续多股 → 力度减弱） / ...
死亡确认（喘声变低 → 头歪 → 不动了） / ...
处决后处理（擦拭/藏尸/搜刮/评价/。。。）
```

> 斜杠表示"可以在此处插入停顿或其他环节"。

### 精液描写的必写参数

- **射向**：射在制服上/溅到LOGO上/喷到脸上/洒在肚皮上
- **股数**：明确写十几股或具体数字
- **力度变化**：初射有力（抛物线/直线）→ 后几股变弱（流淌）
- **颜色和质地**：浓白、稀薄、透明黏液
- **终态**：还在往外渗 / 已经停了 / 顺着往下淌

## 五、节奏控制规则

- [ ] 段落不超过 3 句（战斗场景更是 1 句 1 段）
- [ ] 场景切换用硬切（直接用「xxx之后，我来到xxx」）
- [ ] 紧张→松弛交替：战斗高潮后必有信息处理或移动
- [ ] 心理描写保持在即时反应层面（惊讶/兴奋/害怕），不深入复杂情感
- [ ] 结尾用简洁的行动或一句评价收束，不抒情

---

## 六、绝对不要出现（破功标记）

- [ ] 不要用「说」「问」「答」作对话标签（换成「道」「问道」「答道」）
- [ ] 不要大段环境描写（超过 3 句的环境描写就太多了）
- [ ] 不要角色深层心理活动（活着真没意思、我为什么要这样做——不行）
- [ ] 不要省略性描写细节（"一番云雨之后"这类省略——绝对不行）
- [ ] 不要复杂对话标签变体（低声道/苦笑道/幽幽地说——偶尔可用，但不能泛滥）
- [ ] 不要写精液以外的伤口描写（兽盾世界没人流血）

---

## 七、各场景类型速查

| 场景 | 必须包含 | 可省略 |
|------|---------|--------|
| 新角色登场 | 公式全套（物种→制服→体型→下体→白袜→鞋） | 角色背景 |
| 战斗/处决 | 制服过程 + 精液描写 + 死亡确认 | 环境描写 |
| 对话/审讯 | 一问一答 + 求饶 + XX道标签 | 心理活动 |
| 移动/过渡 | 1-2句交代和去向 | 景色描写 |
| 章节结尾 | 简洁动作/对话收束 | 抒情总结 |
