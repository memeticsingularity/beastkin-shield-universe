## 一、出场公式的执行纪律

Checklist 已经写了公式，但**执行到什么粒度**只有在批量写过才知道：

### 1.1 敌人再多也要逐个走公式

一个场景同时出现 6 个敌人时，最容易犯的错是只详细描述第一个，后面的"同上"或者一笔带过。

**错误做法：**
```
哨站门口，两只灰狼兽人正在闲聊。
```

**正确做法（每个敌人都要走公式）：**
```
哨站门口，两只穿着军绿紧身短袖短裤的壮实灰狼兽人正在闲聊——军绿色的布料绷在结实的身上，裆部鼓着明显的包，白袜包着粗壮的小腿。
```

### 1.2 战斗中的敌人也要走公式

敌人从暗处冲出来、从掩体后跳出来、在半路被截杀——无论登场方式多紧急，公式都要在第一时间完成。

**错误做法（战斗中直接出现物种）：**
```
一只狗兽人冲在最前面，红虎侧身闪过他的拳头……
```
*——没有制服、没有体型、没有白袜，读者无法在脑中成像。*

**正确做法：**
```
一只军绿紧身衣绷在身上的壮实狗兽人冲在最前面——白袜包着粗壮的小腿，裆部鼓包在奔跑中晃动。
```

### 1.3 同一物种+相同制服也要分别描写

两只狼兽人穿着同样的军绿制服并肩走来——也不能写成"同上"。至少要有「精壮结实的肌肉在紧绷的布料下起伏，裆部的鼓包在走动中微微晃动，白袜包着粗壮的小腿」作为群体出场。

## 二、关于体型的纪律：肥壮/肉壮/脂包肌

### 2.1 核心概念：三百斤级的壮

兽盾兵的体型不是普通的"壮"—是**三百斤（150kg+）级别的肥壮**。lanse 原文中的核心描写词汇：

| 术语 | 出处 | 含义 | 适用兽种 |
|------|------|------|---------|
| **肥壮** | 主线 ch-1："膀大腰圆，身材肥壮" | 又肥又壮，体积庞大 | 熊、猪 |
| **肉壮** | 主线 ch-7："身材练得肉壮异常，明明肚子上有着一层厚厚的脂肪，却因为更加粗壮的手臂和饱满的胸肌让他仍然拥有倒三角体型" | 脂肪层下肌肉饱满，厚重感 | 熊、虎、牛 |
| **脂包肌** | 短篇守夜人（豕牙） | 肌肉外裹着一层脂肪，手感厚实 | 猪、牛 |
| **粗壮** | 主线 ch-6："身材十分粗壮，特别是那一对柱子般粗的手臂" | 整体粗大，四肢如柱 | 虎、牛 |
| **膀大腰圆** | 主线 ch-1 | 肩膀宽、腰身圆，横向体积感 | 熊、虎 |

**体重暗示**（lanse 原文）：
> "支撑着这上半身体重的双腿自然也粗壮无比"（主线 ch-7）

### 2.2 各兽种具体描写标准

- **熊兽人** → 肥壮、膀大腰圆、肉壮。肚子有厚脂肪但胸肌/手臂更粗 → 倒三角体型
- **猪兽人** → 肥壮、脂包肌、易出汗。圆滚厚实，三百斤起
- **虎兽人** → 粗壮、虎背熊腰、肉壮。手臂柱子般粗，胸肌饱满
- **牛兽人** → 粗壮、脂包肌。厚实的脂包肌身躯，四肢如柱
- **狼兽人** → 精壮结实（**❌ 禁：精瘦/瘦削** —— 即使在 lanse 原文中狼也是壮实的）
- **狗兽人** → 必须壮硕（mo-quan feedback 原文：狗少量且必须壮硕）
- **豹兽人** → 精壮结实，不能瘦

### 2.3 体重感的关键写法

光写"壮实"不够，需要让读者感受到**三百斤的体重**：

- ✅ 粗壮的白袜腿支撑着肥壮的身躯
- ✅ 每一步都踏得结实
- ✅ 柱子般粗的手臂 / 粗壮如柱的双腿
- ✅ 肚子上一层厚脂肪，但胸肌和手臂更粗 → 倒三角
- ✅ 紧身制服被肥壮的身躯撑得没有一丝缝隙
- ✅ 庞大的身躯/吨位

**关键词禁区：** 精瘦、瘦削、纤细、苗条、轻巧 —— 兽盾世界观不存在这些词。

## 三、袜色规则

白袜是兽盾兵的核心视觉元素，但**不是所有制服都配白袜**。设定集中明确规定了各等级的袜子颜色：

### 3.1 制服→袜色对照表

| 制服色 | 等级 | 袜色 | 说明 |
|--------|------|------|------|
| 军绿 | G级（杂兵） | **白袜** | 袜口军绿色条纹，袜身可能印有绿色"SHIELD"字样 |
| 蓝/蓝白 | O级（监工） | **白袜** | 袜口蓝色条纹 |
| 黑 | E级（武斗兵） | **黑袜** | 袜口白色/灰色/红色/蓝色横条纹，黑色厚底军靴 |
| 白 | R级（枪械兵） | **白袜** | 袜口蓝色圆环，配卡其色军靴或蓝白运动鞋 |
| 深蓝 | W级（摔跤兵） | **白袜** | 袜口蓝色/紫色条纹，配深蓝色摔跤靴 |

### 3.2 关键规则

- **军绿/蓝/白/深蓝制服 → 白袜** ✅
- **黑制服 → 黑袜** ✅（武斗兵专用，不要写成白袜）
- **便衣 → 无袜色描写**（便衣没有制服，可以不写袜色）
- **袜色出现在：** 「白袜包着粗壮的小腿」「白袜裹着粗壮的小腿」「白袜腿分立两侧」「黑袜腿分立两侧」

## 四、制服色编码执行

| 制服色 | 等级 | 出现在敌人时 | 身份 |
|--------|------|-------------|------|
| 军绿 | 杂兵 | 大部分守卫 | 底层、巡逻、站岗 |
| 蓝/蓝白 | 中层 | 小队长/组长 | 文职管理、据点负责人 |
| 黑 | 精英 | 武斗兵/精英 | 组长级、特殊部队 |

创作时可以根据敌人的位置/戏份分配制服色：门口站岗的→军绿，据点第三层坐办公室的→蓝/蓝白，特殊护卫→黑。

## 五、世界观铁则：射精即死

### 5.1 所有死亡必须伴随射精

这是兽盾世界的物理规则，不是情色选项。哪怕是：

- **武道家**（07-白熊）：不用性化方式杀人，但每一击都让对手死前射空
- **春药子弹**（01-红虎）：子弹击中后精液喷出
- **神经毒牙**（02-魔影）：毒液注入后下体失控射精
- **笛声杀人**（10-曲先生）：声波诱导射精至死

### 5.2 精液描写的"一定四要"

- **一定**：写清楚精液从哪射出来的（裤裆/马眼/隔布料）
- **要**：写多少股（一股接一股 / 十几股 / 射了整整十二股）
- **要**：写射向哪（裤裆湿透 / 喷到墙上 / 溅到文件上 / 顺着腿往下淌）
- **要**：写终态（裤裆还在渗精 / 停了 / 地上积了一滩）
- **要**：写伴随动作（腰弓起 / 浑身一颤 / 腿一软跪倒 / 抽搐了两下）

### 5.3 不要写"精槽"

在原作的 chaptered stories 里可以有精槽（数值化系统），但在短篇故事里 lanse 不用精槽。改用：
- 那股劲 / 那股热流 / 那股灼热
- 精液喷出 / 射出 / 涌出

## 六、毕业实习题材的特殊规则

### 6.1 毕业 = 杀人

实习生毕业实习就是杀人的。**不要写**「不允许任何人死亡」「尽量不伤害」这类对话——会被用户纠正。

✅ 正确台词：
- 「全歼目标，一个都不许放跑」
- 「今天的考核科目变更——从模拟考核变为实战歼灭」

### 6.2 敌人数量 ≥ 6

每个实习生至少杀 6 个。这不是建议，是用户的明确要求。

### 6.3 考官的评价

每篇结尾的考官评价要简短有力：
- 一个字：「过。」
- 附注：一句即可，点评风格和特点
- 禁止长篇大论的评语

## 七、批量创作流程

从这次 12 篇的批量开发中总结的最佳实践：

### 7.1 命名规范
文件名为 `N-角色名.md`（N 为数字序号），目录内 README.md 同步更新。

### 7.2 一篇的基准结构
```
# NN · 角色名——副标题

> 引语（一句话交代场景+冲突）

开篇：场景建立（1-2段）
→ 敌人逐个出场（每个走公式）
→ 逐个击杀（精液描写+死亡确认）
→ 考官评价
→ **特工XXX，满分毕业。**
→ [返回目录](README.md)
```

### 7.3 复查清单（出稿前必查）

1. □ 每个敌人都有完整出场公式（制服→物种→壮实体型→裆部鼓包→白袜）
2. □ 没有「精槽」二字
3. □ 所有死亡都伴随射精
4. □ 敌人数量 ≥ 6
5. □ 对话标签用的「道」不是「说」
6. □ 没有"精瘦"等违禁体型描述词
7. □ 白袜出现在每个制服装敌人身上
8. □ 省略号格式统一（三个点「。。。」）
9. □ 结尾有考官评价 + 角色名确认
