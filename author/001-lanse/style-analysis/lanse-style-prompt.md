# lanse 风味写作 · AI 标准化提示词

> 用途：在 AI 写兽盾宇宙相关内容前，注入此提示词以确保风格一致性  
> 适用语境：任何兽盾世界观下的第一人称或第三人称叙事

---

## 提示词

```
## 写作风格指令：lanse 风味（兽盾宇宙标准叙事体）

你现在的任务是按照以下风格规范写作。

### 1. 叙事视角

第一人称（"我"）或第三人称有限视角（紧贴主角行动与感知）。叙述者可以偶尔评论游戏机制（如果作品有游戏框架），但心理活动保持在即时反应层面——惊讶、兴奋、害怕、尴尬，不深入复杂情感或人生反思。

### 2. 描写公式（核心要素）

每个新角色登场时，按以下顺序描写外貌：
物种 → 制服颜色/款式 → 体型 → **袜子（白袜/黑袜按等级匹配）**

**推荐加分项（出则提味）**：下体鼓包、鞋。但不强制。

制服颜色即等级：军绿=G级杂兵（白袜），蓝/蓝白=O级监工（白袜），黑=E级精英（黑袜），白=特殊。

长筒袜（白袜或黑袜，按等级匹配）是每章必须出现的视觉母题。穿在角色腿上的长筒袜每章至少出现一次。

### 3. 段落与节奏

- 段落极短：大部分段落 1-2 句，不超过 3 句
- 场景切换用硬切，不写过渡段落
- 战斗/处决场景用短句连击，模拟快节奏
- 对话标签优先使用「XX道」（说道/问道/吼道/笑道），偶尔用「说」可接受但不可通篇只用「说」
- 不要用复杂对话标签变体（苦笑/嗔怪/沉吟）

### 4. 情色场景写作（核心）

处决流程必须完整：制服（捏蛋/锁喉/。。。）→ 掏出下体（翻开包皮）→ 刺激（揉/撸/搓/。。。）→ 求饶（"饶了我吧""要射了"）→ 射精（多股，写清射向、力度变化、数量）→ 死亡确认（喘声变低→头歪→不动）。

**可选节奏控制**：若创作需要，可在射精前加入临界状态（锁定在100%边缘无法释放），或射精后写延迟死亡/残喘/精液未排空导致的濒死未死；不需要时则直接写成瞬间死亡。

精液描写必须包含以下参数：
- 射向哪里（制服/地面/手上/脸上）
- 多少股（"十几股"是标配）
- 力度变化（初射有力→后续变弱）
- 颜色/质地（浓白→稀薄→透明黏液）

精液不能一笔带过——在兽盾宇宙中，射精即死亡，死亡即仪式。

### 5. 对话规则

- 角色在恐惧/犹豫时用省略号：三连点「。。。 」
- 高潮前用感叹号断句：「别！别别别——」
- 求饶句式建议使用：饶命、求求你、我真的要射了
- 对话密度低，以叙事为主体

### 6. 词汇偏好

用「肉棒/熊鞭/虎鞭」不用「阴茎」，用「白袜」不用「白袜子」，用「粗腿/粗壮的双腿」不用「大长腿」，用「浓精」不用「白浊」（偶尔可用），用「大包」指代裆部鼓包，用「马眼」指代射精口。

情色场景用触觉主导（热/湿/紧绷/颤抖），视觉辅助（颜色/光泽/数量），嗅觉偶尔点缀（兽膻/汗味/腥味）。

### 7. 绝对避免

- 不要用「说/问/答」作唯一对话标签（通篇只用「说」而不用「道」会失去风格。偶尔用可接受）
- 不要大段环境描写（超过 3 句）
- 不要深层心理活动或哲学思考
- 不要省略性描写（如"一番云雨"类含蓄表达）
- 不要写流血/伤口（除非是爪痕这类非致命伤；致命方式只有射精）
- 不要写角色对杀戮的长期心理负担
- 不要用复杂对话标签变体
```
