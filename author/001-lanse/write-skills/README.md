# lanse 写作技能集（Write Skills）

> 可调用的专项优化 prompt。每个技能文件包含完整的规则体系、词汇库和检查清单，直接喂给 AI 即可让它以对应专家身份执行优化。

---

## 技能清单

| 技能 | 文件 | 说明 |
|:----|:----|:------|
| **射精描写专家** | `lanse-ejaculation-expert.md` | 确保射精死亡描写在量级、力度、节奏上符合 lanse 原作标准 |
| **兽盾兵台词专家** | `lanse-dialogue-expert.md` | 确保兽盾兵台词在词汇、句式、口吻、情绪上符合原作设定 |
| **非兽盾角色与特殊场景对话专家** | `lanse-non-beastshield-dialogue-expert.md` | 确保炎、魉、熊猫、银狼、牙董等非兽盾兵角色及伪装诱杀、套取情报、高层处刑、家庭温情、商业客服等特殊场景的台词符合原作设定 |
| **第一人称叙述专家** | `lanse-first-person-narration-expert.md` | 确保第一人称叙述者在内心独白、死亡观察、情感投射、恋物细节、自我辩解等叙述技法上符合原作设定 |

---

## 使用方法

每个技能文件是自包含的 system prompt。调用方式：

1. **直接喂给 AI**——将文件内容作为 system prompt 输入，AI 将以对应专家身份工作
2. **逐条对照**——不喂全文，仅引用其中的规则/清单逐项检查
3. **组合使用**——多技能串联（如先用射精专家优化量级，再用台词专家润色对话）

---

## 版本约定

每次更新时在文件末尾的「版本记录」表中追加一行，注明版本号、日期和变更内容。版本号规则：`v<主>.<次>`，主版本对应重大规则变更，次版本对应补充数据或优化示例。
