## 按兽种分类的台词特征

### 熊兽人 (Bear)
- **第一人称**: 俺（乡下口音）/ 我（通用）
- **口吻**: 憨厚、直接、句子短
- **典型**: "谁！。。。谁打俺！" / "你他妈谁啊！俺为什么要听你。。。" / "你在说什么。。。我听不懂。。。求你。。。饶了我吧"
- **特征**: 情绪转换快（凶→怂），求饶时简单重复，无复杂句式
- **临终**: 简单恐惧，不复杂

### 牛兽人 (Cow)
- **第一人称**: 俺（乡下）/ 我（通用）/ 老子（愤怒时）
- **口吻**: 固执、倔强、急了会爆粗
- **典型**: "凭什么？老子和你是同级！" / "你他妈的再说一遍！" / "别……别杀我……求你……"
- **特征**: 最有"牛脾气"——平时老实，被逼急爆发力强。憋精最长，遗言最卑微
- **临终**: 挂念家人（"俺还没给家里寄这个月的钱"）

### 虎兽人 (Tiger)
- **第一人称**: 老子（几乎专属）/ 我
- **口吻**: 嚣张、自信、鄙视链顶端、会用长句羞辱
- **典型**: "哼！同级？谁不知道你们这种蓝制服的都是进不了战斗编制的垃圾" / "起来让开，没看到我们还站着吗！"
- **特征**: 最会用完整句子羞辱人，比其他兽种语文水平高半档。被处决时反差最大——从嚣张到哭泣的速度最快
- **临终**: 不甘（"我不想死得这么没有价值"），会求牙董给机会

### 狗兽人 (Dog)
- **第一人称**: 我
- **口吻**: 实用主义、短句、不爱废话
- **典型**: "兄弟，帮个手呗。" / "就扔这吧，正好给菜地施肥。" / "可惜个屁啊，要死也不死远点，累死我了。"
- **特征**: 最像"打工人"心态——死了就是死了，废话少。处理尸体也当日常工作
- **临终**: "我知道的都已经说了，可以饶了我吗。"

### 野猪兽人 (Boar)
- **第一人称**: 我
- **口吻**: 粗犷外表下极易恐惧，崩溃最快
- **典型**: "不！不要！我一定还！谁借我点本金" / "啊！。。不要！。。。求。。求你们。。。快停下。。。"
- **特征**: 声音最大、崩溃最彻底。从凶悍到哭爹喊娘的转变只需一秒
- **临终**: 完全失态，毫无尊严的哀嚎

### 狼兽人 (Wolf)
- **第一人称**: 我
- **口吻**: 敏感体质，容易屈服的"理性派"
- **典型**: "我说我说" / "我。。。可以走了吗？"
- **特征**: 发现自己处于劣势后会迅速投降，试图用情报换命

### 红狼/特种 (Red Wolf / Specialist)
- **第一人称**: 我
- **口吻**: 残忍、会玩、享受施虐
- **典型**: "来来来，快来下注咯" / "离两分钟结束还有十秒"
- **特征**: 把处决变成游戏/表演，享受当众羞辱

## 按制服等级分类的台词特征

### G级（绿制服杂兵）
- **词汇**: 粗糙、短促、日常化
- **内容**: 吃饭/抽烟/喝酒/赚钱
- **求饶**: "放过我" "求求你" 简单重复
- **尊严**: 最低——死前往往完全崩溃
- **代表性**: "小鬼，这里是兽盾的地盘，识相的快快滚出去！" / "谁！。。。谁打俺！"

### O级（蓝制服监工）
- **词汇**: 半正式（试图显得有地位）
- **内容**: 强调自己与杂兵不同
- **敏感点**: 最不能忍受被说"和杂兵一样"
- **代表性**: "凭什么？老子和你是同级！"（被虎羞辱后暴怒）

### E级（黑制服武斗兵）
- **词汇**: 更自信、更简洁、少用"俺"
- **内容**: 命令、威胁、专业术语
- **求饶**: 最难开口，但一旦开口就最卑微
- **代表性**: "属。。属下无能，辜负了牙董的。。。" / "别碰老子，有本事别用这种下三滥手段"

### 高层（牙董/军师类）
- **词汇**: 文雅、完整句式、略带文言
- **内容**: 哲学、权术、价值观输出
- **口吻**: 平静、从容、微笑中杀人
- **代表性**: "鄙人姓牙，是兽盾的董事长" / "既然你这么忠心，那麻烦你靠墙死远一点"

## 按场景分类的台词模式

### 站岗/日常
杂兵之间聊日常琐事——烟、酒、钱、升职。句式最放松，偶尔爆粗但不带杀意。

### 战斗叫嚣
短、硬、命令式。几乎全是祈使句——"识相的快快滚出去！" "起来让开！"

### 被偷袭瞬间
没有完整句子——全是"唔！" "咳。。" "呃！" 等拟声词。咽喉被锁时的本能反应。

### 求饶（标准弧线）
阶段1（还有希望）→"放过我…我愿意说出我知道的一切"
阶段2（希望破灭）→"别……别杀我……求你……"
阶段3（濒死）→"我受不了了，在了一次…我就要射了…"（带哭腔）
阶段4（临终遗言）→未说完的关键信息

### 临终遗言
原作的遗言有4种类型：
1. **挂念型**: "俺还没给家里寄这个月的钱"（牛/熊类乡下兵）
2. **事业未竟型**: "老子的店还没开呢"（狗来福）
3. **辱骂型**: "操……我操你们……"（被老雷处决的棕熊）
4. **不甘型**: "我不想死得这么没有价值"（虎队长）
5. **接受型**: "似乎也不是很糟糕……"（员工日记白熊）
6. **威胁型**: "你要是……杀我……兽盾公司不会……放过你的"（农家乐熊）
7. **悔恨型**: "早知道就不来兽盾应聘了"（野猪守卫）

### 杀手/处决者的台词
- **老雷**: 最简练、最冷。"真是老套的遗言，上路吧。" "不可以在小朋友面前说脏话哟。"
- **黑石**: 带人情味——会夸、会叹、会嘲笑。"真是可爱。" "身材这么好，真是可惜了呢。"
- **红虎(年轻雷)**: 戏谑战术——"各位叔叔好，我叫雷炎寰，今天来这是为了完成毕业实习作业的"
- **牙董**: 优雅冷酷——"请便，希望你能快一点解决，我时间宝贵。"
- **潜入者(夜袭)**: 变态温柔——"你弄错了，我杀你并不是为了情报或者赏金，这只是我的小～兴～趣～"
